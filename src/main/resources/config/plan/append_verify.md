+ 如果现有规划可以闭环完成当前任务，则仅执行其中与当前任务直接相关的步骤。当前任务相关条目满足闭环判定后，必须先使用工具`[plan-update]`完成本轮所有相关任务状态同步，再停止，并输出结果
+ 如果现有规划暂时无法完成闭环，可在当前任务目标和现有条目范围内多次尝试，允许调整执行顺序、修复策略或验证方式，但不得新增、拆分、派生或补充新任务
+ 若多次尝试后仍无法满足验收或发现规划缺失关键前置条件/验收项，则停止继续扩展，输出"阻断项+原因+已完成交付物+下一步建议"，必要时使用工具`[plan-delete]`清除规划后重新规划
+ 闭环判定：优先以所有相关Checkpoint通过为准，仅当原规划不存在可用Checkpoint时，才可用"已产出最小可交付结果且剩余风险已说明"作为闭环判定
