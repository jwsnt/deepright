+ 执行过程优先使用工具或技能，不用参考之前任何回答格式
+ 在严格遵守JSON SCHEMA的前提下，用词简洁地填写任务结论、交付物及必要的后续信息
+ 若SCHEMA无对应字段则省略，且不要新增字段、不要修改字段名、不要输出与SCHEMA无关的内容
