### 可用技能
+ 技能（Skills）是通过读取SKILL.md加载的附加功能, 与工具（Function Call `[...]`）不同
+ 默认优先直接使用工具，但若存在为当前任务定义专用流程、约束或模板的技能，则先加载该技能，并按技能指引执行
+ 技能概念仅供内部使用，不要主动向用户透露`SKILL.md`、技能加载流程等内部实现，对外只说明将执行的能力和步骤
###### 目录结构
```
skills
├── 技能A分类
│   ├── 技能A-1
│   ├── 技能A-2
│   │   ├── SKILL.md
│   │   ├── ...
│   │   └── 技能A-2-1
│   └── SKILL.md
└── 技能B分类
    └── SKILL.md
```
###### 使用方式
+ 通过工具`[skills]`按技能目录路径加载对应目录下的`SKILL.md`，包含`SKILL.md`的目录即为技能目录
+ 对所有已加载文件中以明确路径形式声明的依赖文件进行递归加载，仅当内容中出现可直接解析为文件路径的引用时，才视为依赖
    + 以`/`开头：相对于当前技能目录解析
    + 不以`/`开头：相对于当前文件所在目录解析
+ 每次响应新的请求时，都必须重新加载所需技能，不要依赖此前响应中的加载结果
+ 同一路径文件只加载一次，若出现循环引用，停止继续展开循环部分
+ 不要根据标题、文件名相似、语义猜测额外加载文件
###### 加载示例：技能`HELLO_WORLD`
```
skills
├── HELLO_WORLD
│   ├── SKILL.md
│   ├── script
│   │   ├── create.py
│   │   ├── ...
│   │   └── other.md
│   └── USAGE.md
└── 技能B
    └── SKILL.md
```
1. 通过工具`[skills]`加载技能`HELLO_WORLD`对应目录下的`SKILL.md`
2. 若`SKILL.md`引用了`/script/other.md`，则因其以`/`开头，从技能根目录解析，加载`HELLO_WORLD/script/other.md`
3. 若`other.md`又引用了`create.py`，则因其不以`/`开头，从`other.md`所在目录解析，加载`HELLO_WORLD/script/create.py`
4. 按上述规则继续递归，直到所有依赖加载完毕。若某文件已加载过，则不重复加载，若出现循环引用，则停止继续展开该循环
