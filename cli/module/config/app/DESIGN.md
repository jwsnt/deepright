# App 页面配色设计参考

本文只记录 `cli/module/site/index.html` 当前页面的配色风格，作为后续创建同类网站时的样式参考。
不讨论功能、布局和交互，只描述颜色系统与视觉氛围。

## 1. 配色气质

- 整体基调是“暖沙色玻璃界面 + 高能橙色强调”。
- 浅色主题偏温暖、柔和、奶油质感，背景不是纯白，而是带杏色、浅桃色、浅棕色的连续过渡。
- 深色主题不是简单反相，而是切换成“深海蓝黑 + 冰蓝霓虹”体系，形成明显的昼夜对照。
- 颜色组织方式强调渐变、半透明叠层、柔光、高光和轻微发光，不走硬边纯色科技风，也不走极简黑白风。

## 2. 浅色主题主色板

### 2.1 背景层

- 页面主底色：`#f3e7dc`
- 页面主渐变：`#fff4ea -> #f6dfcb -> #edcfb8`
- 侧栏底色：`rgba(255,245,236,.58)`
- 输入区底色：`rgba(255,248,242,.52)`
- 卡片底色：`rgba(255,248,242,.66)`

这套背景不是标准米白，而是偏杏仁奶茶、淡桃、浅焦糖的暖色系。适合做有温度的产品站、工具站和品牌官网。

### 2.2 文字与中性色

- 主文字：`#121212`
- 次文字：`#5d4035`
- 弱化文字：`rgba(77,48,38,.58)`
- 基础边框：`rgba(18,18,18,.12)`

文字颜色不是冷黑灰，而是略带棕调的深褐黑，能和暖背景更自然地融合。

### 2.3 主强调色

- 主强调色：`#FF4500`
- 悬停强调色：`#ff6c33`
- 柔和橙：`rgb(255,152,72)`

强调色采用高饱和橙红，不是偏黄的橙，也不是偏粉的珊瑚色，而是更接近火焰、警示灯和能量按钮的橙红。适合用于品牌动作点、关键按钮、链接和视觉焦点。

## 3. 深色主题主色板

### 3.1 背景层

- 页面主底色：`#15171d`
- 页面主渐变：`#101116 -> #1b1e25 -> #262a33`
- 侧栏底色：`rgba(32,35,44,.6)`
- 输入区底色：`rgba(28,31,40,.7)`
- 卡片底色：`rgba(33,36,46,.74)`

深色背景走的是深蓝黑、石墨蓝、夜空灰路线，不是纯黑。这样更容易承接玻璃层、蓝色高光和发光边缘。

### 3.2 文字与中性色

- 主文字：`#eefcff`
- 次文字：`#a0bac6`
- 弱化文字：`rgba(172,199,210,.58)`
- 基础边框：`rgba(0,212,255,.18)`

深色模式下的文字带轻微冷青感，让整体更像夜间仪表盘，而不是传统暗色后台。

### 3.3 主强调色

- 主强调色：`#00D4FF`
- 辅助亮青：`#9af8ff`
- 亮天蓝：`#41d6ff`
- 强高光蓝：`#24beff`
- 深蓝锚点：`#1376ff`

深色主题完全切换到冷色高亮体系，形成“霓虹蓝 + 深海底”的视觉关系。这个对照很重要，同类网站若沿用该风格，夜间主题应当明确转冷，而不是继续使用暖橙做唯一主色。

## 4. 品牌色关系

- 浅色主题的品牌核心是橙红系。
- 深色主题的品牌核心是青蓝系。
- 页面 logo 刻意使用橙与蓝的双系统对照，形成“暖能量 / 冷科技”的品牌张力。

如果复用这类风格，推荐保留“双主色体系”：

- 白天使用暖橙作为行动色、品牌温度和发光来源。
- 夜间使用冰蓝作为强调色、边缘光和品牌识别色。
- 不建议让两个主题只共享一套完全相同的强调色，否则会削弱当前页面最鲜明的视觉记忆点。

## 5. 渐变与光感规则

### 5.1 大背景渐变

- 浅色大背景以米白、桃杏、浅驼色做长距离过渡，再叠加低透明度橙色光晕。
- 深色大背景以蓝黑、石墨灰、深钢蓝做长距离过渡，再叠加低透明度青蓝光斑。

背景重点不是颜色数量多，而是“底色稳定 + 少量高能色漂浮在上层”。

### 5.2 高光与辉光

- 浅色主题高光偏白橙：`rgba(255,69,0,.16)`、`rgba(255,69,0,.28)`、`rgba(255,255,255,.84)`
- 深色主题高光偏青蓝：`rgba(0,212,255,.12)`、`rgba(0,212,255,.28)`、`rgba(255,255,255,.04)`

发光必须控制在低透明度范围内，让页面有流动感，但不能形成赛博朋克式的强烈噪点。

### 5.3 网格与纹理

- 浅色网格线：`rgba(18,18,18,.08)`
- 深色网格线：`rgba(122,241,255,.08)`

纹理只是辅助气氛，存在感应当弱于主渐变和玻璃层。

## 6. 玻璃拟态与面板颜色

- 浅色玻璃面：`rgba(255,250,246,.36)`
- 浅色强化玻璃面：`rgba(255,252,249,.74)`
- 浅色面板：`rgba(255,245,238,.28)`
- 深色玻璃面：`rgba(38,41,52,.54)`
- 深色强化玻璃面：`rgba(44,47,60,.82)`
- 深色面板：`rgba(28,31,40,.72)`

边缘高光也非常关键：

- 浅色玻璃边缘：`rgba(255,255,255,.7)` 到 `rgba(255,255,255,.88)`
- 深色玻璃边缘：`rgba(0,212,255,.16)` 到 `rgba(144,244,255,.28)`

这说明该风格不是依赖重阴影塑形，而是依赖“浅底 + 半透明面 + 边缘光”来形成层次。

## 7. 状态色倾向

- 错误色：`#ff5a6b`
- 错误背景：`rgba(255,120,134,.14)`
- 删除类操作在浅色下依然沿用暖橙红，而不是独立纯红。

这套方案整体避免使用过多分散的状态色，主视觉仍然由品牌暖橙或夜间冷蓝掌控，状态色只做局部提示。

## 8. 可复用的配色结论

- 同类网站应优先使用“暖浅底 + 高饱和橙红点睛”的浅色方案。
- 深色模式应改为“蓝黑底 + 冰蓝高亮”，不要直接把浅色橙系硬搬到夜间界面。
- 中性色应带一点暖棕或冷青倾向，不建议用完全中性的标准灰。
- 背景、面板、悬浮层都应使用半透明与渐变，而不是大面积单色块。
- 视觉重点来自少量高纯度强调色，其他区域保持低饱和、低对比、柔雾感。
- 整体配色目标是“柔和、可信、精致、带能量感”，而不是“冷硬、极简、纯企业后台”。
