# 20260611-3 用户手册

本次迭代为居中对话框里的 `__RETRY__` SSE 报文补充了一条独立的新手引导，并在所有新手引导进行期间临时屏蔽了输入框回车发送，避免误操作。

- 当居中对话框在当前一轮 SSE 响应里首次收到 `choices[0].metadata.__RETRY__` 非空的报文时，会自动触发这条独立引导
- 页面会在当前正在等待的响应气泡上方插入一条红色 retry 错误块，并把最新这条错误块作为引导第一步的高亮目标
- 第一步文案为 `这类错误通常是模型配置引起的。`，按钮为 `知道了`
- 点击第一步后，会自动打开设置、定位到当前 Agent 正在使用的模型配置，展开客户化配置区域并展示密钥
- 第二步文案为 `确认模型配置。`，按钮为 `知道了`
- 点击第二步后，会把高亮切到居中输入区的 `终止` 按钮；如果当前按钮还不是终止态，页面会临时切换成终止按钮样式
- 第三步文案为 `如果模型配置错误，点击终止后重新执行。`，按钮为 `完成`
- 引导期间只会播放新手引导，不会中断当前 SSE 响应；同一轮 SSE 响应里如果后续继续收到其它 `__RETRY__` 报文，也不会重复启动这一轮的引导
- 这条引导与首次使用、输入框引导、蜂群引导、插件引导、备忘录引导、沙盒引导、全屏引导等其它新手引导相互独立；如果触发时正有其它新手引导进行中，会等待当前引导结束后再补播
- 任意新手引导任务进行中时，即使键盘焦点停留在居中对话输入框，按 Enter 也不会触发发送；只有引导结束后才会恢复正常的 Enter 发送行为
