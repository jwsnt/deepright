# Site 迭代手册（20260725-4）

## 图片预览切图坐标工具

在图片预览浮层标题栏点击“切图工具”图标，打开当前图片的坐标网格工具。该工具只复制坐标文本，不会实际切图或修改图片文件。

1. 在“水平”和“垂直”中填写列数与行数，例如 `3` 和 `2`。
2. 如需排除图片边缘，填写上、下、左、右缩进；单位均为原图像素。
3. 网格会自动均分有效区域。拖动黄色竖线或蓝色横线，可微调每条内部切分线；每个单元会显示当前宽高。
4. 点击“导出”将结果复制到系统剪贴板。

导出结果的固定格式如下：

```text
取值时画布尺寸: 宽度 1920 px, 高度 1080 px, 共6组矩形坐标集合(左上/右上/右下/左下): [(0,540),(640,540),(640,0),(0,0)],[(640,540),...], 使用时需要按实际画布尺寸缩放坐标
```

- 坐标原点是原图左下角 `(0,0)`。
- 矩形按照从下到上、从左到右的顺序输出。
- 导出文本中的 `n` 为矩形总数。每个矩形独立使用一组方括号，组内依次输出左上、右上、右下、左下四个顶点。
- 相邻矩形的公共顶点会按各自矩形保留，因而会重复出现。
- 导出成功时，浮层左下角会显示“坐标位置已复制到系统剪贴板”，色系与取色成功提示一致；浏览器拒绝剪贴板权限时会显示异常提示。
