# 迭代 20260620-1：多模态输出参数面板

## 功能说明

1. 设置面板里，每个支持 `多模态输出` 的模型项左上角都会显示一个闪烁的荧光蓝色小球参数入口
2. 点击蓝色小球后，当前模型的客户化配置区会先收起，再以过渡动画展开独立的 `多模态输出参数` 面板
3. 面板默认提供两组参数：`aspectRatio:16:9` 与 `imageSize:2K`
4. 用户可以继续追加更多参数行，但 `Key` 和 `Value` 都只能填写英文
5. 点击 `取消` 或按 `Esc` 会关闭面板；点击 `保存` 或按 `Enter` 会立即保存当前模型对应的多模态输出参数，保存时会自动去掉参数值头尾空格
6. 当参数名为 `aspectRatio` 时，参数值仅支持 `1:1`、`3:4`、`4:3`、`9:16`、`16:9`；当参数名为 `imageSize` 时，参数值仅支持 `1K`、`2K`、`4K`
7. 参数按 `Agent -> 模型服务商名 -> 属性集合` 的结构写入当前 Agent 的 `config.json.media`
8. 切换设置中的 Agent 后，面板会重新加载该 Agent 最新保存的 `media` 配置，不复用上一个 Agent 的草稿

## 配置示例

保存后的 Agent `config.json` 结构示例：

```json
{
  "media": {
    "gemini": {
      "aspectRatio": "16:9",
      "imageSize": "2K"
    },
    "qwen": {
      "aspectRatio": "1:1",
      "imageSize": "1K"
    }
  }
}
```
