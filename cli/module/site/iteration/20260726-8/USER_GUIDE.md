# Site 迭代手册（20260726-8）

## 新建与编辑图片

在左侧虚拟文件系统点击“新增”，选择“图片”并填写名称后点击“创建”，会直接打开图片编辑浮层；此时不会在工作区创建空文件。

- 未填写后缀时自动补 `.png`；已有 `.png`（不区分大小写）会保留。填写其它后缀时页面会提示“图片只支持 .png 后缀”，不会打开编辑器。
- 新图片是 `1024×1024` 的透明 Canvas。编辑器会根据当前浮层空间缩放显示 Canvas，但绘制、取色和坐标始终基于原始像素尺寸。
- 图片预览/编辑区右上角提供完整可见的悬浮视图控制：缩小、放大和上、下、左、右移动。缩放每次会按原始宽高比同步调整宽度和高度，最小可缩至 `25%`、最大可放大至 `400%`；方向按钮会移动当前查看区域，到达边缘会自动禁用。放大后可滚动查看画布，所有视图操作都不改变保存图片的原始像素尺寸。
- 已有图片与新图片使用同一编辑器，可继续使用画笔、橡皮擦、文字、形状、取色、坐标与切图工具。“重置”会恢复新图片的透明空白画布，或恢复既有图片的原始内容。
- 点击“保存”后，所有图片都会导出为 PNG，并作为新文件保存到当前 Agent 工作区的 `images/` 目录。源图片与历史导出不会被覆盖。
- 保存文件使用图片基础名加服务端高精度时间戳，例如 `images/海报_20260726_120000_123456789.png`。保存成功后会刷新虚拟文件系统，并将返回的系统绝对路径复制到系统剪贴板；复制失败不会影响文件保存。
