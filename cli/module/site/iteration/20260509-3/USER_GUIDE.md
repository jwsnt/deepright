# 20260509-3 User Guide

## 目标

本次迭代修正了右侧 CLI 子面板触发的 CMD 执行异常展示顺序。

- 当点击 CLI 子气泡上的复制入口自动带入命令，或手动打开 `CMD` 浮层执行命令后，如果执行失败、超时或接口返回异常，页面会先关闭 `CMD` 执行窗口
- `CMD` 窗口关闭后，才会展示居中的错误提示层，避免两个浮层在中间会话区发生重叠

## 页面行为

- 成功执行命令时，仍保持原有行为：关闭 `CMD` 浮层并提示执行成功
- 执行失败时，包括以下情况：
  - `/api/cmd` 返回非 `200`
  - 返回体缺少成功状态
  - 网络异常、超时或请求被中断
- 上述异常都会统一先收起 `CMD` 浮层，再展示错误提示

## 交互说明

1. 打开右侧 `CMD` 浮层并输入命令，或从 CLI 子气泡复制内容进入 `CMD` 浮层。
2. 点击执行并确认。
3. 如果命令执行失败，当前 `CMD` 浮层会立即关闭。
4. 随后页面在中间区域展示错误提示，不再与执行窗口叠加。

## 说明

- 本次修改只调整异常时的展示顺序，不改变命令输入、二次确认、成功提示和终止逻辑
- 相关总体说明请继续参考上级手册 `../../USER_GUIDE.md`
