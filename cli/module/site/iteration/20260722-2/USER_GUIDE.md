# 迭代 20260722-2：设置中的模型配置测试

在“设置 → 模型与密钥”中，每个模型行的密钥右侧都会显示一个紧凑的烧瓶 Test 图标。它只在设置浮层中出现，位于客户化配置和删除图标之前。

## 使用方式

1. 选择服务商并填写密钥。
2. 展开客户化配置，确认“基础模型（`__model`）”有值。
3. 点击 Test 图标，等待结果提示。

测试使用当前输入框里的值，不需要先点击保存，也不会保存本次测试的密钥、URL 或模型名称。

## 结果与限制

- Test 图标的提示为“测试配置”。服务商、密钥或 `__model` 缺失时图标置灰，并说明原因。
- 测试进行时同一行会锁定为 loading 状态；再次点击只会取消本次测试，不会自动重试。
- 服务端确认 SSE 收到有效数据并正常结束后，页面提示“配置成功”。
- HTTP、SSE、超时和流中断错误会提示“配置错误：…”；主动取消显示“测试已取消”。
- 测试不创建聊天、不改变当前会话、模型选择或 Agent，也不会写入浏览器本地会话数据。只有 Test 操作的服务端转发会携带 `metadata.test = true` 并传到最终服务；普通聊天不会携带该标记。
