# Site 迭代 20260711-5 使用手册

## 本次更新

- 设置面板底部左侧新增了一个 `新手引导` 总开关，默认显示 `✓`。
- onboarding 卡片右上角新增了整条跳过用的 `×`，用于直接结束当前这条引导。
- 这次开关更新采用“修改后需保存才生效”的语义，不再是点一下立即生效。

## 设置里的新手引导开关

- 打开设置后，底部左侧会看到 `新手引导` 开关。
- 默认是 `✓`，表示允许后续 onboarding 正常触发。
- 点击后会切换成 `×`，再次点击会切回 `✓`。
- 这里的切换只会修改当前设置草稿；只有点击右下角 `保存` 后，新状态才真正生效。
- 如果点击 `取消`、点遮罩关闭设置，或其它未保存退出路径，这次切换会被丢弃。

## 保存后的生效规则

- 如果把开关保存成 `×`，页面会立即阻止后续所有 onboarding 再触发。
- 如果保存时页面上已经有 onboarding 正在播放，会立即结束当前引导。
- 已经排队等待播放的 onboarding 也会一起清掉，不会在关闭后继续补播。
- 如果之后再保存回 `✓`，页面只会恢复“允许后续 onboarding 触发”的能力，不会自动补播刚刚错过的旧引导。

## 引导卡片右上角 `×`

- 大多数 onboarding 卡片右上角现在都会显示一个 `×`。
- 点击这个 `×` 时，不是只跳过当前一步，而是直接跳过当前整条 onboarding。
- 最后一步如果主按钮文案是 `完成`，右上角不会显示这个 `×`。
- 首次使用主引导链路被 `×` 跳过后，会整体记为已完成，避免下次刷新又从头开始。
