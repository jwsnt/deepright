# 迭代 20260428-14：无本地连接时自动恢复等待态并轮询加载

## 功能说明

1. 首次进入页面或切换会话后，会先检查当前会话是否仍有本地 SSE 连接
2. 如果本地连接仍在，界面保持原有响应中逻辑不变
3. 如果本地连接已不存在，但当前会话最后一轮请求既不是 `完成` 也不是 `已取消`，界面会立即恢复为等待响应状态
4. 等待期间会每 `5s` 自动调用一次会话重新加载接口，并始终基于当前最新的最后一次实际请求时间增量拉取数据
5. 轮询过程中一旦拉到 `完成` 或 `已取消` 结果，界面会自动退出等待状态并恢复为待发送
6. 如果轮询期间点击终止，会按终止会话流程处理，但不会尝试关闭本地不存在的 SSE 连接
7. 页面刷新或重新进入时，如果只是浏览器中断了本地连接，不会展示 `网络错误`，而是继续按未完成请求进入自动轮询恢复

## 实现说明

- 会话会持久化记录“最后一次实际请求时间”和“是否仍有未完成请求”状态，用于页面刷新或切换会话后的自动恢复
- 自动恢复只针对最后一轮未完成请求，已完成、已取消或异常消息不会触发轮询
- 自动重新加载沿用现有 `/api/restore` 增量恢复逻辑，并会将同一轮回答的多条 `A` 增量记录顺序合并为一条 assistant 消息；收到 `data: [DONE]` 或取消标记后结束等待，继续避免重复渲染已展示内容
- 轮询期间保持 `努力工作中` 和发送按钮终止态，直到确认收到终态消息后再统一收口
- 轮询过程为静默刷新，不会在每次轮询点反复闪动页面或弹出成功提示，整体感受与一次连续等待 SSE 返回一致
