# 迭代 20260428-1：设置切换Agent重置备忘录

## 功能说明

在设置面板中切换 Agent 并保存时，如果右侧备忘录有未保存的输入，将自动重置所有备忘录状态。

## 备忘录输入检测范围

以下任一项有变动即视为"有输入"：
- 备忘录输入框有文字内容
- 已选择备忘录模型
- 已选择日历日期
- Thinking 模式已开启
- 重复周期非默认值（非"仅一次"）

## 交互行为

1. 打开设置，切换 Agent 下拉框时：
   - 如果备忘录有未保存输入，Agent 选择框下方显示红字提示："切换Agent会丢弃尚未保存的备忘录"
   - 如果备忘录无输入，不显示提示
2. 点击保存：
   - 如果 Agent 发生变更且备忘录有输入，保存后自动重置备忘录所有状态（输入框、模型、日历、时间、思考模式、重复周期）
   - 如果 Agent 未变更，备忘录保持不变
3. 点击取消：备忘录不受影响
