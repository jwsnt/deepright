# Site 迭代 20260627-3 使用手册

## 本次更新

- 居中对话框中识别到的 `http/https` URL，在点击 `预览` 后，会改为使用右侧 Sidebar 的独立 iframe 预览区展示，不再复用原文件编辑器浮层。
- 右侧 iframe 预览区会整体替换原右侧内容区，切换按钮悬浮在中间会话框与右侧栏的交界位置，并与 `复制会话` 按钮保持同一水平线。
- iframe 打开失败、站点明确禁止 iframe 预览、网站不存在或加载超时时，会自动关闭预览并切回原右侧布局，同时在 VFS Tips 位置提示原因。

## 页面行为

- 双击居中会话区中的 `http/https` URL 后，仍然会出现 `预览` 与 `打开` 两个小气泡操作。
- 点击 `预览`：
  - 右侧 Sidebar 会切换为独立 iframe 预览区。
  - 原右侧内容区会被整体替换，iframe 会尽量吃满右侧可用高度。
  - 预览打开时会带毛玻璃淡入效果，但不会抬高整体布局。
- 点击悬浮在边界处的切换按钮：
  - 右侧栏会切回原来的备忘录 / CLI / WIKI 布局。
  - 切回时同样保留毛玻璃淡出效果。

## 会话绑定

- 右侧 iframe 预览状态与当前 `Agent + Chat` 会话绑定。
- 同一个会话中，如果已经打开过某个 URL 预览，切换走再切回来时，会按该会话自己的状态决定是否继续展示。
- 切换到其他会话时，不会沿用上一个会话的 iframe 展示状态。

## 失败回退

- 如果目标站点不可访问、返回 `404/5xx`，页面会自动关闭 iframe 并切回原右侧布局。
- 如果目标站点通过 `X-Frame-Options` 或 `Content-Security-Policy frame-ancestors` 禁止 iframe 嵌入，也会自动关闭 iframe 并回退。
- 如果前端实际加载阶段超时或触发加载错误，同样会自动关闭 iframe 并切回原布局。
- 所有失败场景都会在左侧虚拟文件系统 Tips 位置给出原因提示，而不是只保留浏览器原生报错页。
