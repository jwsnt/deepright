# 20260526-3 用户手册

本次迭代为右侧边栏第一栏中的备忘录相关入口补充了一条独立的新手引导流程。

- 当浏览器本地还没有“点击过右侧备忘录区域”的记录时，第一次点击右侧第一栏中的备忘录日历、任务明细或备忘录元数据区域，都会触发这条备忘录引导
- 引导开始后会自动展开右侧 Sidebar，并临时锁定右侧相关交互；流程进行期间，其它区域会被暗化且不可点击
- 引导会依次高亮 `备忘录区域`、中间输入区的 `当前 Agent 展示区域`、`复用当前会话`、中间对话区的 `响应区域`、`模型选择`、`SWARM + Thinking`、`时间选择区域`、周期模式中的 `仅一次`、周期模式中的 `其他选项`、`创建按钮`、`备忘录列表按钮`、模拟 `测试任务`、模拟任务的 `重置按钮`、任务明细列表，以及待执行任务明细的 `删除按钮`
- 如果中间输入区当前 Agent 名称被截断，引导会额外显示一个带高亮动画的完整 Agent 名称提示
- 周期模式步骤会先展开下拉框并讲解 `仅一次`，随后继续讲解其它周期选项，帮助区分延迟任务与周期任务
- 进入任务列表示例步骤时，页面会临时展示一条假的 `测试任务`
- 进入任务明细步骤时，页面会临时展示一条假的 `已完成测试任务明细` 和一条假的 `待执行测试任务明细`
- 这些 `测试任务` 和 `测试任务明细` 仅用于新手引导演示，不会写入真实数据；点击最后一步 `完成` 后会立即清理
- 除最后一步外，每一步都通过 `知道了` 按钮推进；最后一步点击 `完成` 后结束引导并恢复正常交互
- 这条备忘录引导与首次使用引导、首次点击输入框引导、蜂群引导、插件引导、`SOUL.md / USER.md` 引导相互独立，可以兼容共存
