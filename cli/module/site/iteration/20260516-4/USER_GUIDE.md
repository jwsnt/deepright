# 20260516-4 使用说明

- 点击左侧 `新会话` 创建会话时，当前会话区底部的思考模式会固定从 `Auto` 开始，不再继承上一个会话刚刚使用的 `Thinking` 状态。
- 这个默认值只作用于新建出来的会话本身，不会改写当前 Agent 在 `config.json` 中保存的默认思考配置。
- 新会话如果手动切换到 `Thinking`，该选择会跟随这个会话一起保存；之后切换回这个会话时仍会保持你在该会话里最后一次选择的模式。
- 页面向 `/v1/chat/completions` 发送普通聊天请求时，会把当前会话自己的思考模式作为顶层 `thinking` 字段一并提交，因此界面显示与实际请求行为保持一致。
