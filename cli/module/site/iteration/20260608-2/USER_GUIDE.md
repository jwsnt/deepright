# 20260608-2 User Guide

本次迭代为左侧边栏补充了一个关闭应用按钮，并接入 `integration` 的 `/api/shutdown` 关闭能力。

## 新增能力

- 在左侧边栏底部 `设置` 按钮右侧新增了关闭应用按钮
- 点击后会先显示整窗居中的关闭应用确认浮层，并模糊背景
- 确认浮层提供 `关闭应用` / `取消` 两个动作按钮
- 点击 `关闭应用` 后才会播放关闭应用动画，并显示 `5` 秒倒计时
- 动画开始后会立刻调用 `/api/shutdown`
- 倒计时结束后会主动关闭当前窗口

## 交互说明

- 在确认浮层中，按回车等同于点击 `关闭应用`
- 在确认浮层中，按 `Esc` 等同于点击 `取消`
- 关闭应用流程开始后不会再弹出“是否离开当前页面”的浏览器提示
- 进入关闭应用动画后不支持取消
- 同一轮关闭应用流程内重复点击按钮不会重复发起第二次请求

## 同步说明

- 依赖 `integration` 在 `20260608-2` 迭代中新增的 `/api/shutdown`
