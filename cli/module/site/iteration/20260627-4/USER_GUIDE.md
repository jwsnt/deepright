# Site 迭代 20260627-4 使用手册

## 本次更新

- 当右侧 Sidebar 的 URL iframe 预览第一次真正加载成功后，页面会自动触发一条独立的新手引导。
- 引导会高亮右侧预览边界处用于切回原布局的按钮，并提示 `点击关闭网站浏览。`
- 这条引导只负责说明如何关闭网站浏览，不会强制关闭当前已经打开的 iframe 预览。

## 触发时机

- 只有在当前浏览器里第一次成功打开右侧 iframe 预览时，才会触发这条引导。
- 如果 iframe 打开失败、加载超时、目标站点返回 `404/5xx`，或目标站点通过 `X-Frame-Options`、`Content-Security-Policy frame-ancestors` 禁止嵌入，则不会触发这条引导。

## 页面行为

- 引导出现后，会高亮右侧预览边界处的切回原布局按钮。
- 除高亮区域外，其它区域会被暗化且不可点击。
- 引导卡片提供一个 `完成` 按钮。
- 点击 `完成` 后，只会关闭新手引导遮罩并恢复正常交互，不会强制关闭当前 iframe 预览。

## 兼容性

- 这条引导与首次使用引导、首次点击输入框引导、蜂群引导、插件引导、备忘录引导、沙盒引导、全屏引导等现有新手引导相互独立，可以兼容共存。

## 说明

- 本次迭代只补充右侧 iframe 预览的首次关闭指引，不改变右侧 iframe 预览本身的打开、失败回退、会话绑定和原布局切回逻辑。
- 当前目录交付文件为：`REQUIREMENT.md`、`USER_GUIDE.md`
