# Site 迭代 20260807-1：多模态服务商选择

在任一模型的客户化配置中，点击“多模态输入”或“多模态输出”输入框左侧的小箭头，才会展开并选择已配置的服务商。

- 候选项只包含已配置且具有相应多模态模型的服务商；已配置的 `deepright` 也会出现。
- 选择后模型字段显示为 `@服务商名称`，例如 `@deepright`。
- 当前服务商支持该能力时，仍可直接输入模型名；不支持时输入框不可编辑，但下拉选择仍可使用。
- 不支持该能力的字段默认为空，不会因复制配置自动填入代理；仅在通过箭头选择后才会保存代理。
- 打开菜单时会显示临时的“正在指定代理多模态模型”提示：暖色界面使用暖色光带，冷色界面使用冷色光带；选择或移出菜单后自动消失。
- 未展开客户化配置时，测试成功会在密钥输入区显示“✓ 配置成功”约 2 秒；展开后保持原有成功提示位置。
- 删除被引用的服务商会自动清空其他配置中对应的 `@服务商名称`。
