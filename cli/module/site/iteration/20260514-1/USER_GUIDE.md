# Site 迭代手册（20260514-1）

## 本次更新

- 由左侧 `Skill` 小图标触发的自动提炼请求，会额外请求：

```json
{
  "metadata": {
    "extract": "true"
  }
}
```

- 后端会把这份请求体 metadata 与共享 Agent 元数据一起转发

## 触发路径

当前会话中：

1. 最近一轮对话完成后，`Skill` 小图标点亮
2. 点击 `Skill` 小图标
3. 先选择日志范围并导出日志
4. 再填写提炼目标
5. 点击发送后，页面会自动向当前会话发起 SSE 请求

这条请求除了原有的提示词外，还会额外带上：

```json
"metadata": {
  "extract": "true"
}
```

## 目的

这个参数用于表达：

- 本次提炼 Skill 的自动请求，需要显式标记为提炼链路
- 前端通过请求体 metadata 显式传递一个临时开关
- 该开关会和共享 Agent 元数据一起进入最终转发请求

## 后端收口结果

`site` 发起：

```json
{
  "metadata": {
    "extract": "true"
  }
}
```

后端实际转发到上游模型服务时会保留这项 metadata：

```json
{
  "metadata": {
    "extract": "true"
  }
}
```

## 用户可见行为

- 页面交互流程不变
- 仍然是自动发起 SSE 请求
- 仍然在当前会话里展示响应
- 不需要手动输入该参数

## 说明

- 这个行为只作用于由 `Skill` 小图标触发的自动提炼请求
- 普通聊天发送流程仍然走原有 `/v1/chat/completions`
- 前端直接使用请求体 metadata 形式，与后端转发结构保持一致
