# 日志求助输入引导

第一次在以下任一任务浮层中点击“日志”时，会显示一次新手引导：

- 文字转语音
- 提取音频文字
- 提取图片主体
- 人物视频对口型
- 视频提取主体

引导直接显示在当前任务浮层内，只高亮“让 AI 解析日志”图标，并提示“点击让AI解析日志，定位问题。”。其余任务列表、日志和操作按钮都会被遮罩阻止交互。

点击“完成”后，引导直接结束，当前任务浮层与日志保持打开，所有控件恢复正常交互。该流程按浏览器全局记录一次，五类任务共享同一记录；之后打开任意任务日志都不会重复显示。

如果在引导中关闭任务浮层、按 `Esc`、改变窗口尺寸或切换任务，遮罩会立即失活，不会拦截后续点击或键盘焦点。
