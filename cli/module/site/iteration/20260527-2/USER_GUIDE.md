# 20260527-2 User Guide

本次迭代调整了“首次点击左侧新会话或居中输入框”触发的输入新手引导顺序。

- 原先在“等待响应结果”后会直接切到右侧 `CLI` 子面板
- 现在会先切到左侧边栏左上角的 `logoSvg`
- 这一步会提示“查看所消耗的Token明细”，点击 `知道了` 后才继续切到右侧 `CLI` 子面板
- 为了保证左侧引导卡片和高亮区域可见，如果左侧 Sidebar 当前处于收起状态，流程切到 `logoSvg` 时会自动展开左侧栏
- 进入这一步前，页面会先关闭可能残留的 Token 用量浮层，避免旧浮层影响引导遮罩和点击锁定
- 右侧 `CLI` 子面板步骤保持不变，仍会高亮右侧边栏第二栏整个 `CLI` 区域，并提示执行的系统命令会在这里显示
