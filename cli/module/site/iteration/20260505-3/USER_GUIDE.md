# 20260505-3 使用手册

## 目标

本次迭代补充了“会话数量已达上限”提示的中间域浮层表现，并继续统一固定定位弹层的分域交互规则：

- 当会话数达到 `10` 个时，提示浮层改为相对中间会话区水平垂直居中
- 提示浮层复用扇形菜单插件浮层同款背景模糊效果
- 未激活的固定定位遮罩层、弹窗、确认框继续保持彻底失活，避免跨区域拦截点击

## 页面行为

- 点击左侧 `新会话` 按钮时，如果当前会话数小于 `10`，仍会正常创建新会话
- 当当前会话数已达到 `10`：
  - 不会再继续创建新会话
  - 会在中间会话区弹出居中提示：`会话数量已达上限（10个）`
  - 提示浮层只覆盖中间会话区，不会遮挡左侧 Sidebar 与右侧 Sidebar
- 提示浮层视觉会与扇形菜单、设置面板、插件浮层保持同一套中间域玻璃态和背景模糊风格

## 分域规则

- 数量上限提示属于中间会话区的 overlay 域
- 中间域浮层位置会跟随左右 Sidebar 的实际宽度收口，不会退化成整屏遮罩
- 未显示时保持非激活态，不会拦截左右 Sidebar 的点击、悬停或滚动
- 固定定位的遮罩层、确认框、日志面板、透明点击层仍统一遵守“交互域隔离 + 隐藏视图彻底失活”原则
