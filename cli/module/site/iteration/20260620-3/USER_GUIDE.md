# 20260620-3 用户手册

本次迭代把 `__TASK_START__` / `__TASK_CLOSE__` 这类 SSE 控制包收敛为 assistant 气泡右上角的临时任务气泡，不再进入居中对话框正文。

## 任务气泡规则

- 当 SSE 报文里的 `choices[0].metadata.__TASK_START__` 非空，且 `choices[0].delta.content` 按现有前端规则归一化后仍能取到首字符时，页面会在当前等待响应的 assistant 气泡右上角新增或更新一个闪烁任务气泡
- 任务气泡的唯一 key 直接取 `__TASK_START__` 的值；气泡正文只显示归一化后的首字符，并统一转成大写
- 如果同一个 key 后续再次收到新的可展示首字符，页面会直接更新当前气泡内容，不会重复新增
- 如果收到的是尚未展示过的新 key，新气泡会追加到最右侧，并推动已有气泡整体左移
- 当 SSE 报文里的 `choices[0].metadata.__TASK_CLOSE__` 非空时，页面会按这个 key 删除对应任务气泡；剩余气泡会自动右移补位
- 任务气泡的出现和消失都会带过渡动画

## 作用域与收尾

- 任务气泡只按当前 `ChatId` 隔离；`agentId` 和 `__TARGET__` 都不参与作用域匹配，不同会话之间不会串扰
- 如果当前整轮 SSE 响应结束前始终没有收到非空 `choices[0].metadata.__TARGET__`，收尾时会把当前会话还没关闭的任务气泡统一清掉
- 这类 `__TASK_START__` / `__TASK_CLOSE__` 控制包在实时 SSE 和 restore 历史恢复时都不会进入居中对话框正文，也不会在页面刷新后的恢复流程里重复回放
