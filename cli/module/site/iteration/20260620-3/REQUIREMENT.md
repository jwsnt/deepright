### 需求介绍
+ 当SSE响应报文里的`choices[0].metadata.__TASK_START__`为非空标记时展示逻辑做特殊处理:
    + 在当前等待响应的assistant气泡右上角展示不断闪烁的任务气泡
    + 气泡以`__TASK_START__`的值为唯一KEY；只有该响应内容（content）按现有前端规则归一化后仍能取到首字符时，才新增或更新该气泡
    + 气泡正文只显示归一化后的首字符，并统一转为大写
    + 气泡可能有多个；当出现尚未展示过的新KEY时追加到最右侧，同时将已经有的气泡整体左移
    + 如果同一个KEY再次收到可展示的首字符，则更新现有气泡内容，不重复新增
+ 当SSE响应报文里的`choices[0].metadata.__TASK_CLOSE__`为非空标记时展示逻辑做特殊处理:
    + 气泡以`__TASK_CLOSE__`的值为唯一KEY，消除右上角对应的任务气泡
    + 气泡可能有多个；当有多个气泡时，剩余的气泡自动右移补位
+ 任务气泡作用域与`__TARGET__`需求相同：无论是否携带`__TARGET__`，匹配和清理都只按当前`ChatId`处理
    + __TARGET__需求：/20260620-2/REQUIREMENT.md
    + __PROCESS__需求：../20260618-2/REQUIREMENT.md
    + __RETRY__需求：../20260619-1/REQUIREMENT.md
    + 不同会话间不要影响，尤其在切换时
+ 这类`__TASK_START__`/`__TASK_CLOSE__`控制包不进入居中对话框正文；历史恢复和页面刷新后的restore也不重复回放这类临时任务气泡
+ 兜底收尾：如果当前整轮SSE响应结束前始终没有收到非空`__TARGET__`，则剩余的任务气泡都要清除
+ 气泡产生和消失都需要有动画
