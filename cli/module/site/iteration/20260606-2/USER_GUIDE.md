# Site 迭代 20260606-2 使用手册

## 响应中提交下一条查询

- 当当前会话仍在执行请求时，居中输入框里仍然可以先写好下一条查询并直接提交。
- 如果上一个请求还处于“等待真正发送”的阶段，页面会立刻取消这次未发出的请求，并自动改为发送你刚提交的新查询。
- 如果上一个请求已经进入 SSE 等待响应阶段，页面会先把这条新查询挂起，居中输入框会锁定为灰色不可编辑，同时在居中输入框右侧、发送按钮左边显示一个圆形等待小图标。
- 新查询进入这段“等待自动发送”状态时，会在 `Tips` 位置提示 `已开始等待发送`。
- 等上一个 SSE 响应完整结束后，挂起的新查询会自动发送；发送动作触发后，输入框会自动解锁，方便继续输入下一条内容。
- 等待小图标位于居中输入框右侧、发送按钮左边；点击它会立即取消这条“待自动发送”的新查询，等待图标消失，输入框恢复可编辑，但不会中断当前已经在跑的旧请求，同时会在 `Tips` 位置提示 `已取消等待发送`。
- 如果这条“待自动发送”的新查询已经挂起，这时再点击右侧红色终止按钮，页面会先终止当前正在执行的旧请求；终止成功后，挂起的新查询仍会自动发送。
- 这套“锁定输入框”和“等待小图标”的状态是按 `Agent + 会话` 维度分别维护的，所以切换到别的会话再切回来时，页面会按该会话自己的执行状态重新渲染。
- 如果左下角的 `节能` 已开启，这次新增的等待动画会自动关闭，只保留静态状态提示。
