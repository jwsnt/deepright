# 20260530-2 用户手册

本次迭代为右侧边栏 `知识库WIKI` 标题栏中的 `自动整理` 开关补充了一条独立的新手引导流程。

- 当浏览器本地还没有“点击过自动整理开关”的记录时，第一次点击右侧 `知识库WIKI` 标题栏中的 `自动` 开关，不会立刻切换自动整理状态，而是先显示引导遮罩
- 引导开始后会自动展开右侧 Sidebar，并只高亮 `自动整理` 开关；右侧知识库其他区域以及页面其余部分都会被暗化且不可点击
- 引导文案会提示：`知识库会自动整理，点击关闭后切换为手动模式。`
- 点击 `完成` 后会关闭这条引导，恢复知识库区域正常交互；再次点击 `自动` 开关才会真正切换自动整理状态
- 这条自动整理引导与首次使用引导、首次点击输入框引导、蜂群引导、插件引导、`SOUL.md / USER.md` 引导、右侧备忘录引导、知识库WIKI 区域引导、CLI 引导和 Skill 提炼引导相互独立，可以兼容共存
