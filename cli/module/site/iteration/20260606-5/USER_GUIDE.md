# Site 迭代 20260606-5 使用手册

## CLI 鲸鱼屏保

- 当页面连续 `5` 分钟没有执行中的任务，同时鼠标已经离开页面、没有悬停任何页面元素时，站点会自动进入全屏屏保。
- 屏保内容复用了右侧 `CLI` 子面板的鲸鱼动画，但会先尝试让页面进入浏览器全屏，再以放大版铺满屏幕循环播放，并暂时锁定整个页面。
- 屏保显示期间，任意鼠标事件或键盘事件都会触发退出；退出不是直接消失，而是会缓慢收缩并回到右侧 `CLI` 面板位置。
- 如果右侧边栏当前处于收起状态，屏保退出时会先展开右侧栏，再把动画收回 `CLI` 面板，方便继续查看系统指令区域。
- 左下角 `节能` 开关开启后，本次新增的屏保逻辑会整体停用，不会进入屏保；如果屏保已经显示，也会立即关闭。
