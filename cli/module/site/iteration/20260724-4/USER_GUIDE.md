# `@` 菜单响应

- 输入 `@` 时，文件和技能主入口会立即出现，不等待 Skill 或 Agent 接口。
- 开启 SWARM 后，`Agent` 入口会在 `/api/swarm_agent` 返回可用 Agent 后出现；没有可用结果或接口失败时会隐藏。
- Skill 与 Agent 数据由 Integration 的 `config/config.json.at` 缓存统一管理，页面不保存跨菜单打开周期的列表缓存。
- 同一次菜单打开期间，如果用户立刻选择“技能”或“Agent”，页面会复用已经发起的请求，不会重复调用接口。
- 禁用或恢复 Skill 目录成功后，当前会话后续打开的 `@ Skill` 菜单会直接使用服务端即时筛选并重新计时的结果。
- 保存任意 Agent 的蜂群开关后，后续打开的 `@ Agent` 菜单会直接使用服务端完整刷新并重新计时的结果。
- 创建、删除或导入 Agent 成功后，后续打开的 `@` 菜单会直接使用服务端完整刷新并重新计时的 Agent 数据。
- 复制 Agent 成功，或修改、删除会影响 Skill 定义或蜂群可见性的文件后，后续 `@` 菜单同样直接使用服务端完整刷新并重新计时的结果；文件目录展示本身仍实时读取。
