# 迭代 20260627-2：assistant 气泡内收起思考内容

本次迭代为居中对话框中的单条 assistant SSE 响应补充了“收起思考内容”交互，用来在不拆分消息气泡的前提下，单独折叠或展开这一条响应里的思考区。

## 功能说明

1. 只有当某条 assistant SSE 响应里存在可识别的思考内容时，这条气泡左上角才会显示 `收起思考内容` 入口
2. 点击后会在当前气泡内切换为 `展开思考内容 / 收起思考内容`，只影响这一条 assistant 响应
3. 普通响应、用户请求气泡和右侧 CLI 子任务气泡都不会显示这个入口
4. 思考内容与正式回复仍然放在同一条 assistant 气泡中，不会因为折叠而拆出新的独立消息
5. 首次渲染时默认进入收起态，优先展示正式回复内容；思考内容收起后不再占用正文高度

## 流式与恢复

- SSE 仍在流式返回时，如果当前气泡处于收起态，新增思考内容会继续缓存到当前气泡自己的思考区，但不会把气泡重新撑开
- 如果当前气泡已经展开，新增思考内容和正式回复会继续按原有节奏实时渲染
- 正式回复区原有的 Markdown 渲染、自动滚动、复制、时间和状态标记都保持不变
- 展开/收起状态绑定到当前 `Agent + Chat + assistant 响应气泡`
- 切换会话后不会串到其他会话；重新渲染当前会话、轮询恢复未结束响应或历史恢复消息时，会按该气泡自身记录恢复
- 如果历史消息没有保存过这个状态，则默认按收起处理

## 交互约束

- 左上角入口需要与现有 assistant 气泡中的复制、重试、统一临时提示、任务气泡等交互共存
- 悬浮、点击和失焦判断都只限定在当前 SSE 响应气泡内，不影响相邻消息
- 深色和浅色主题下都应保持可见性与反差，不破坏原有气泡视觉风格
