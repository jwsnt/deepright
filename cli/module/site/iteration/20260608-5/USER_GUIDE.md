# 20260608-5 User Guide

本次迭代为“首次保存模型密钥”补充了一条独立的新手引导。

- 当用户第一次在设置里配置模型密钥并成功保存后，如果本地还没有这条引导的完成记录，会弹出一个全屏遮罩浮层，询问：`模型密钥已保存，是否需要验证模型？`
- 浮层提供 `是` 和 `否` 两个按钮；弹出期间左侧、居中和右侧区域都会被暗淡，并且不可点击
- 点击 `否` 会直接关闭这条引导，并记录为已完成；后续不会再次弹出
- 点击 `是` 会先关闭浮层，再自动模拟一次对话输入验证流程：
- 在居中输入框逐字输入 `Hello World`
- 自动点击发送按钮
- 自动进入等待模型响应的状态
- 无论用户选择 `是` 还是 `否`，这条引导都会单独记录完成状态，不会重复触发
- 这条引导与首次使用引导、首次点击输入框引导、蜂群引导、插件引导、文档整理引导、备忘录引导、知识库引导、浏览器插件引导、客户化配置引导、客户化配置闪烁引导等其它引导相互独立，并且可以兼容共存
