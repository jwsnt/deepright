# 20260513-3 使用说明

## 迭代内容

- 居中对话框中的用户请求气泡，右下角新增发送时间标记
- 发送时间与 assistant SSE 响应气泡右下角的时间标记保持同一套样式和格式

## 显示规则

- 在输入框发送消息后，当前用户请求气泡会在气泡内右下角显示发送时间
- 时间格式为 `yyyy-MM-dd hh:mm:ss`
- 若同一条请求通过“重试”重新发送，新生成的请求气泡也会使用发送当下的时间重新标记

## 交互说明

- 该时间标记只显示在居中会话区的用户请求气泡内，不影响左侧 Sidebar 和右侧 Sidebar 的交互
- 时间标记与气泡内容同属一个消息卡片，复制、重试等右下角操作按钮仍保持原有位置和行为
- assistant 气泡原有的接收时间与流状态标记保持不变

## 说明

- 这次迭代只补充用户请求气泡的发送时间展示，不修改请求协议
- 历史消息如果本地已保存 `createdAt`，重新渲染时也会显示对应发送时间
