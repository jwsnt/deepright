# 20260610-8 使用手册

## 简介

本次迭代为左侧虚拟文件系统中的 `SKILL.md` 错误提醒补充了独立的新手引导，帮助用户在首次遇到 Skills 文件解析错误时快速定位并理解修复入口。

## 页面行为

- 当左侧虚拟文件系统第一次出现 Skills 文件错误提醒红色闪动时，页面会自动启动独立引导
- 第一步会高亮被提醒的路径，并提示 `SKILL.md存在错误，需要进行修复。`
- 点击 `知道了` 后，页面会逐层播放目录展开动画，自动切换到引发错误提醒的目标 `SKILL.md`
- 第二步会高亮目标 `SKILL.md`，并提示 `参考[https://agentskills.io/specification]修正错误，避免正确加载。`
- 点击 `完成` 后，引导结束，页面恢复正常交互

## 兼容规则

- 这条引导与首次使用引导、首次点击输入框引导、蜂群引导、插件引导、文档整理引导、备忘录引导、Skills 提炼引导等现有新手引导相互独立，可以兼容共存
- 只有在当前浏览器还没有 Skills 文件错误提醒引导记录时，首次出现错误提醒才会自动触发
- 引导期间除当前高亮区域外，其它部分会被暗化且不可点击
