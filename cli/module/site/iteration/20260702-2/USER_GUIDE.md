# 20260702-2 用户手册

本次迭代为虚拟文件系统中的 `Knowledge.md / knowledge.md` 文件入口补充了一条独立的新手引导流程。

- 当浏览器本地还没有“点击过 `Knowledge.md / knowledge.md`”的记录时，第一次点击这两个文件的任意入口都会触发引导
- 任意入口包括文件行本身、下载按钮、删除按钮等该文件的可点击位置；如果是单击文件行，原本的查看动作会先让位给新手引导
- 引导只有一步，会高亮当前触发的 `Knowledge.md` 或 `knowledge.md` 文件行，并展示文案：`编辑Knowledge.md调整知识库提取规则。`
- 点击 `完成` 后，遮罩会关闭，后续再次点击 `Knowledge.md / knowledge.md` 不会重复弹出这条引导
- 引导期间左侧 Sidebar 会保持展开，并自动回到虚拟文件系统根目录，确保知识库规则文件入口始终可以被稳定定位
- 这条引导与首次使用引导、首次点击输入框引导、蜂群引导、插件引导、`SOUL.md / USER.md` 引导、右侧知识库引导等其它新手引导相互独立，可以兼容共存
