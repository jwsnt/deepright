# 20260706-3 用户手册

本次迭代修正了居中对话区 Markdown 代码块的折叠判定。此前页面只按“代码块字符数是否超过 1000”决定是否显示折叠按钮，因此一些已经明显过高、但字符数不足 1000 的多行代码块不会出现折叠按钮。现在改为三重判定，视觉上过高的代码块也会被正确折叠。

## 折叠判定规则

- 代码块满足以下任一条件时，会显示折叠按钮
- 代码块内部纯文本字符数大于 `1000`
- 代码块内部总行数大于 `18`
- 代码块实际渲染高度超过折叠高度阈值

## 折叠高度

- 折叠后的可见高度继续沿用现有样式，高度为 `360px`
- 高度判定内部允许极小容差，用于避免浏览器排版边界抖动造成按钮时有时无

## 适用范围

- 首次进入会话后，全量渲染出来的 assistant 代码块会按新规则判断
- assistant SSE 流式输出过程中，代码块会随着内容增长实时重新判断是否需要折叠
- 上滑加载历史消息、restore 恢复历史消息、懒加载补渲染出的代码块同样使用新规则

## 交互保持不变

- 代码块工具栏仍沿用现有设计，不新增新的设置入口或额外操作模式
- 已显示的 `运行到 CMD` 和 `复制代码` 按钮行为不变
- 长代码块在首次命中折叠条件时仍默认收起，用户可以继续通过现有按钮展开或再次收起
- 短代码块如果既不长到超过 `1000` 字符、也不超过 `18` 行、也没有超过高度阈值，则不会显示折叠按钮

## 典型修复场景

- 一段 Python 代码虽然只有约 `900` 字符，但因为缩进和多行分支结构已经达到几十行，旧逻辑不会显示折叠按钮，新逻辑会因为“行数超阈值”而显示折叠按钮
- 一段字符数和行数都接近边界的代码块，如果实际浏览器渲染高度已经明显超过折叠高度，也会因为“实际高度超阈值”而显示折叠按钮
