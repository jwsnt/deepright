# 20260504-2 使用手册

## 目标

本次迭代为左上角扇形菜单补充插件详情浮层交互：

- 点击扇形菜单按钮后，在中间会话区弹出居中浮层
- 浮层根据插件声明的可选 `meta` 参数动态生成输入框，并自动回填已配置默认值
- 浮层底部固定展示 `重启`、`关闭`、`日志`、`取消`
- 点击浮层外空白区域、在浮层外点击/拖动/滚动，或按 `Esc` 会直接取消
- 浮层打开后会额外请求 `/api/plugins/status?name=插件key` 判断当前插件是否已启动

## 页面行为

- 扇形菜单按钮仍然来自 `/api/plugins/meta`
- 点击任意插件按钮后，会先收起扇形菜单，再弹出中间浮层
- 浮层顶部展示当前插件名称
- 浮层内容分为三段：
  - 第一段展示 `复用当前会话`、`选择 Agent`、`模型选择`、`Thinking`
  - 第二段展示插件声明的 `meta` 参数及其默认值
  - 第三段固定展示 `重启`、`关闭`、`日志`、`取消`
- `选择 Agent` 会通过 `/api/agentId` 动态加载，默认优先回填当前会话绑定的 Agent，没有时回填设置里的 Agent
- 若接口返回 `["a","b"]`，会生成两行表单：
  - 第一行标题为 `a`，右侧是对应输入框
  - 第二行标题为 `b`，右侧是对应输入框
- 如果接口同时返回已配置 `meta`，对应输入框会直接展示该默认值
- 第一段配置区位于插件参数声明区上方，并与下方内容保持 3px 视觉间距
- 第一段配置区整体会紧贴在插件标题说明下方约 3px 处显示
- 模型下拉会复用当前页面已有模型配置，默认显示当前会话正在使用的模型
- 勾选 `复用当前会话` 后，会在右侧虚拟文件夹区域弹出红色 Tip：`该任务会复用当前会话`
- 如果勾选 `复用当前会话` 后又切换成与当前会话不一致的 Agent，页面会自动取消复用并提示，避免跨 Agent 复用同一个 `chatId`
- Thinking 开关默认跟随当前会话区输入栏状态显示
- 模型下拉点击某个模型后，会先显示勾选态，再自动收起下拉框
- 每一行中，参数名与参数输入框保持同一行展示
- 参数较多时，浮层保持整体尺寸不变，由中间内容区滚动
- 最后一个参数与底部按钮分隔线之间保留约 15px 的间距
- 浮层关闭时不会影响左侧 Sidebar 和右侧 Sidebar 的点击
- 只要在浮层外发生交互，浮层会先执行关闭动画，再把操作让回对应区域
- `重启` 按钮始终可用，点击后会先调用 `/api/plugins/config` 保存当前配置，再调用 `/api/plugins/start` 启动插件
- `关闭` 按钮会先通过 `/api/plugins/status` 判断插件是否已启动，未启动时保持禁用变灰
- 状态检测期间，`关闭` 与 `日志` 会短暂进入不可点击状态，避免用户在状态未确定时误操作

## 按钮说明

- `取消`：直接关闭浮层
- `重启`：立即保存当前配置并重新启动插件
- `关闭`：仅在插件已启动时可点，成功后会保留当前浮层并同步刷新状态
- `日志`：切换到插件日志流视图，再次点击可返回参数输入区
- 四个按钮统一复用设置面板的按钮风格，并保持右下对齐

## 浮层规则

- 浮层属于中间会话区的 overlay 域
- 未激活时不会拦截其他区域点击
- 点击遮罩层空白区域会关闭浮层
- 点击、拖动、滚动左侧 Sidebar / 中间会话区 / 右侧 Sidebar 等任意浮层外区域时，都会立即收起浮层
- 按 `Esc` 会关闭浮层
- 浮层内模型下拉仅在当前浮层区域内响应，不会跨区域遮挡左侧或右侧 Sidebar
