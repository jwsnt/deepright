# 20260509-1 User Guide

## 目标

本次迭代补齐了左上角扇形菜单中文插件名过短截断的问题。

- 中文插件名最多显示 `4` 个字，不再固定只显示前 `2` 个字
- 扇形菜单圆按钮会按 `2/3/4` 个字自动调整尺寸，同时保持圆形
- 中文按钮文案不再使用英文式大写和拉开字距，避免 `3` 个字、`4` 个字显示缺字

## 交互样式

- 扇形菜单原有展开轨迹、圆形视觉和浅色/深色主题适配保持不变
- 中文名称较长时，单个圆按钮会按文案长度自适应放大
- 英文和数字类插件名仍沿用原有两字符缩写展示方式

## 使用说明

1. 打开页面左上角即时通讯扇形菜单
2. 配置并展示名称为 `2` 到 `4` 个汉字的插件
3. 展开菜单后，可直接在圆按钮内看到完整中文名称
4. 名称变长时，按钮会同步放大，但仍保持圆形和原有扇形排布

## 说明

- 本次修改只影响左上角扇形菜单按钮的名称展示与尺寸自适应
- 菜单展开逻辑、插件启动状态高亮、点击行为和其他浮层交互不受影响
- 更完整说明请查看上级手册 `../../USER_GUIDE.md`
