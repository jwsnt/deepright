# 20260611-1 用户手册

本次迭代为“任意插件首次成功启动”补充了一条独立的新手引导，用来提示用户识别左侧扇形插件开关的运行态颜色。

- 当浏览器本地还没有“插件启动成功引导”的记录时，只要任意插件第一次真正启动成功，就会自动触发这条引导
- 引导触发后会自动关闭插件配置浮层，展开左侧 Sidebar，并自动展开扇形插件菜单
- 高亮区域会同时覆盖左侧已经变成绿色的插件开关和展开后的扇形插件区域，提示 `插件启动成功后图标会变为绿色。`
- 这条引导只有一个 `完成` 按钮；点击后关闭遮罩并恢复页面正常交互
- 引导展示期间，除该引导卡片外的其它区域都会被暗化且不可点击
- 如果首次成功启动插件时页面正处于其它新手引导中，这条引导会等待当前引导结束后再补充展示，避免相互覆盖
- 这条引导与首次使用引导、首次点击输入框引导、蜂群引导、首次点击插件按钮引导、文档整理引导、备忘录引导、沙盒引导、全屏引导等其它新手引导相互独立，可以兼容共存
