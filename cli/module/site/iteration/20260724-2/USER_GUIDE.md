# Site 迭代手册（20260724-2）

## 本次更新

居中对话区新增“页面备注”。用户可以对当前 chat 最近一次正常完成的 SSE 助手响应进行框选标注，并在下一次提问时自动把引用和备注一起发送。

## 添加页面备注

1. 在最近一次正常完成的助手响应气泡中框选文字。
2. 点击选区附近的 `标注`。
3. 在浮层中输入“我的备注”，点击 `保存`。

浮层支持与居中输入框一致的 `@` 文件、技能、Agent 唤起，以及图片、视频、文件的粘贴和拖入上传。链接、文件名、技能名等特殊气泡中的可见文字同样可以框选；原有的预览、打开、下载等操作不受影响。

浮层顶部的“引用内容”固定单行展示，过长内容会以 `...` 省略；将鼠标悬停在该区域可查看完整引用。

已保存的引用会显示统一的纯色下滑波浪线，不会因标注顺序交替颜色。响应气泡下方会列出当前页面备注；暖色主题下气泡统一使用暖色，冷色主题下统一使用冷色。气泡正文显示引用内容前 5 个字符，超出部分以 `...` 省略；点击铅笔图标可修改备注，点击 `×` 可以删除。重新框选同一段已标注文字时，选区按钮也会变成“删除标注”。

标注列表最左侧的垃圾桶图标可完全清除当前 SSE 响应的所有标注。点击后会询问“是否清除所有标注？”，选择 `删除`（或按 `Enter`）后立即移除该响应的标注、波浪线和标注气泡；选择 `取消` 或按 `Esc` 则不做修改。

## 发送行为

同一响应可保存多条备注。发送时会按引用在原响应中的位置排序，汇总为 Markdown 表格并置于本次输入之前：

```markdown
### 标注内容

| 引用内容 | 我的备注 |
| --- | --- |
| xxx | yyy |
| xxx | yyy |

用户本次输入
```

备注中的附件、媒体和 `@` 内容会沿用输入框原有的实际提交格式。

- 新 SSE 正常结束后，已发送的页面备注及波浪线会自动清除；新生成的正常助手响应随即成为唯一可标注的响应。
- 新 SSE 失败、异常或手动中止时，原页面备注和波浪线会保留，可继续发送。
- 只有最后一条正常结束的 SSE 助手响应可标注；流式中、异常、终止和更早的响应均不提供标注入口。

## 本地保存与清理

页面备注按 chat 保存在当前浏览器的本地存储中，刷新页面后仍会恢复，不会写入服务端或数据库。

当本地存储超过自动治理预算，或浏览器空间不足触发保存降级时，系统会立即清除所有 chat 的页面备注、待发送内容和波浪线展示，再继续清理其它可回收缓存或压缩会话历史。

打开左侧的“本地存储统计”后，汇总卡片最后一项为“页面备注”，可查看占用空间、标注数量和涉及 chat 数量。点击该项的 `立即清空` 会马上删除所有 chat 的页面备注、待发送内容和波浪线展示。
