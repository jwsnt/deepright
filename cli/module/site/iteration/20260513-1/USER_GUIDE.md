# 20260513-1 使用说明

## 迭代内容

- 左侧 Sidebar 虚拟文件系统的 `返回上级` 按钮右侧新增 `Skill` 状态图标
- 图标与 `Agent + Chat` 绑定，只反映当前会话最近一轮请求是否进入过命令执行流程

## 触发规则

- 当前会话每次发起新一轮请求时，`Skill` 图标会先执行一次消隐动画
- 当前轮 SSE 响应结束后，页面会调用 `/log_skill_status?agentId=...&chatId=...&round=1`
- 若日志数据库最近一轮范围内存在 `工具请求（cli/get）` 或 `工具响应（cli/pub）`，则显示金色渐变发光闪动的 `Skill` 图标
- 若本轮没有执行命令，或当前没有可用日志，图标保持隐藏

## 重新判断场景

- 切换左侧会话
- 新建会话后进入空白会话
- 手动点击会话重载按钮恢复消息
- 从右侧备忘录时间线点击“查看”恢复历史会话

## 说明

- 该状态只读取 `site` 当前绑定的 `Agent + Chat`，不会跨会话复用
- 当最新一轮请求结束后既没有 `cli/get` 也没有 `cli/pub` 记录时，不会显示 `Skill` 图标
