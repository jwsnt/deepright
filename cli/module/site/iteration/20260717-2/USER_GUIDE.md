# 迭代 20260717-2：最新 SSE 响应思考过程

本次迭代为居中对话框的最新一条正常结束 assistant SSE 响应，增加独立的思考过程查看入口。

## 使用方式

1. 等待居中对话框中的 assistant SSE 响应正常结束。
2. 如果该响应包含可展示的思考片段，会在气泡右下角的复制图标右侧显示思考小图标。
3. 点击图标后，页面会在居中对话框正中打开“思考过程”浮层。
4. 浮层按思考片段的捕获顺序展示内容，支持 Markdown 渲染；内容较长时可直接拖动右侧滚动条阅读。
5. 可点击右上角关闭按钮、按 `Esc`，或点击浮层外遮罩关闭。
6. 图标、浮层、片段卡片与滚动条会跟随页面当前的浅色暖色系或深色冷色系显示。

## 显示规则

- 仅当前居中对话框中最近一条正常结束的 assistant SSE 响应会显示该图标。
- 发起下一条请求后，上一条响应的思考图标会继续显示；新 SSE 正在返回时仍可点击查看。
- 新一条 SSE 正常结束后，旧响应上的思考图标才会自动隐藏。
- 用户取消、网络异常、服务端终态错误或错误气泡不会产生新图标，也不会移除原有图标。
- 没有思考片段的正常响应也不会显示图标。
- 该功能不作用于用户消息、右侧 CLI 子任务、备忘录或插件消息。

## 本地历史清理

- 思考片段随浏览器本地会话历史保存。
- 当本地存储空间不足而页面压缩历史时，思考片段可能被优先清理，以保留中心对话正文。
- 此时思考图标仍会保留；点击后会在虚拟文件系统 Tips 区提示：`思考过程已经被清理`。
- 清理只影响浏览器本地的思考片段副本，不影响正式 assistant 回复正文。
