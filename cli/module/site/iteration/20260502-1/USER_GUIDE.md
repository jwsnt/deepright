# Site 迭代 20260502-1 使用手册

## 变更说明

图片预览从只读查看升级为可编辑模式，并新增橡皮擦工具。

## 图片编辑

- 图片文件打开后，仍然使用文件编辑器浮层展示
- 预览区域改为可编辑 `canvas`
- 默认工具为橡皮擦
- 鼠标按下并拖动时，会把经过区域直接擦成透明像素（`Alpha=0`）
- 支持调节橡皮擦笔刷大小
- 点击“重置”可重新加载原始图片内容，放弃当前涂抹结果
- 点击“保存”后，会把当前 canvas 导出为 base64，并通过原有 `/api/edit` 接口在原图目录下新建“原文件名 + 时间戳”的新图片
- 保存成功后，会自动把新图片的绝对路径复制到系统剪贴板，并在虚拟文件系统 Tips 位置提示路径已保存至黏贴板

## 适用范围

- PNG、JPG、JPEG、GIF、BMP、WEBP、ICO、TIFF、TIF、SVG 等图片文件
- 文本、HTML、PDF 和不支持预览的文件类型行为保持不变
