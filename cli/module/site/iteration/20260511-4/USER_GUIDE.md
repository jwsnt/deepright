# 20260511-4 User Guide

## 目标

本次迭代调整知识库默认入口，页面初始化时不再先打开知识库根目录树，而是优先加载知识库目录下的 `index.md`。

## 行为

1. 页面首次进入时，会默认请求 `/knowledge/index.md`。
2. 如果 `index.md` 存在，则直接以 Markdown 方式展示。
3. 后续知识库的路径导航、目录跳转、更新时间读取和右侧知识库全屏展开能力保持不变。

## 说明

- 本次仅调整默认初始加载路径
- 若知识库下不存在 `index.md`，页面会按现有失败兜底逻辑处理
- 更完整说明请继续参考上级手册 `../../USER_GUIDE.md`
