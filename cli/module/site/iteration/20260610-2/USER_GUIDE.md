# 20260610-2 用户手册

本次迭代为虚拟文件系统补充了一条独立的新手引导，用来说明文本文件编辑、新建文件、拖拽文件到输入框，以及通过 `@` 引入文件或技能的基本用法。

- 当浏览器本地还没有“点击过虚拟文件系统新建按钮 / 悬浮过可编辑文件”的记录时，第一次点击左侧虚拟文件系统的 `新建` 按钮，会先触发这条引导，而不会立刻进入真实的新建流程
- 当浏览器本地还没有这条记录时，第一次把鼠标悬停到左侧虚拟文件系统里任意可编辑文件上，也会触发这条引导
- `SOUL.md` 和 `USER.md` 不会触发这条引导，避免影响已有的文档整理引导
- 第一步会在左侧虚拟文件系统中高亮当前悬停的可编辑文件，或在首次点击 `新建` 时模拟出一个可编辑文件，并提示 `双击文本文件进入编辑模式。`
- 第二步会在引导专用的文本预览 / 编辑演示浮层中，先在预览页停留约 `3` 秒，再切到编辑页，模拟输入 `HELLO WORLD`，并提示 `文本文件可以直接进行编辑。`
- 第三步会单独高亮左侧虚拟文件系统 `新建` 按钮，并提示 `通过新建空文件编辑内容。`
- 第四步会切到引导专用的 `新建文件或目录` 演示浮层，高亮除底部 `取消 / 创建` 按钮外的主体区域，先展示默认状态，再动画切换到 `文件` 类型，并提示 `选择文件，并使用.txt或.json作为后缀名。`
- 第五步会把高亮切到中间输入框，模拟从虚拟文件系统拖动文件到对话框中并生成文件气泡，并提示 `从虚拟文件系统或操作系统直接拖入文件或目录到对话框。`
- 第六步会清除上一阶段的模拟气泡，继续在输入框中模拟输入 `@` 并唤起 `@` 菜单，提示 `或输入@来引入文件或强调需要使用的技能。`
- 前五步按钮均为 `知道了`，最后一步按钮为 `完成`
- 引导进行期间，其它区域会被暗化且不可点击；点击 `完成` 后会关闭遮罩并恢复正常交互
- 这条引导与首次使用引导、输入框引导、蜂群引导、插件引导、文档整理引导、拖拽上传引导、备忘录引导、沙盒引导、全屏引导、知识库引导等其它新手引导相互独立，可以兼容共存

补充说明：

- 引导中的编辑浮层和新建浮层均为演示专用面板，不会直接展开真实的编辑器或真实的新建弹窗
- 普通单击文件仍然保持现有预览行为
- 对可编辑文本文件执行双击时，会自动打开文件浮层并切换到 `编辑` 标签
