# 20260509-2 User Guide

## 目标

本次迭代补齐了左上角扇形菜单主入口的运行态提示。

- 当任一插件已启动时，左上角扇形菜单主入口也会同步显示绿色闪动态
- 不再只有展开后的插件圆按钮才显示绿色运行态

## 页面行为

- 页面完成插件列表加载后，会主动调用 `/api/plugins/status?name=插件key` 刷新一次当前运行态
- 如果至少有一个插件返回 `started=true`，左上角主入口按钮会立即切换为绿色闪动样式
- 当扇形菜单展开后，已启动的插件圆按钮仍会继续保持原有绿色闪动效果
- 如果后续所有插件都恢复为未启动，左上角主入口会自动恢复默认样式
- 主入口按钮的标题和无障碍标签会追加“已有插件启动”语义，便于快速识别当前状态

## 交互说明

1. 启动任意一个即时通讯插件。
2. 返回页面左上角，无需展开扇形菜单。
3. 此时主入口按钮会直接显示绿色闪动。
4. 再次展开扇形菜单时，已启动的插件圆按钮也会继续显示绿色闪动。

## 说明

- 本次修改只补充扇形菜单主入口的运行态提示，不改变原有展开动画、插件浮层和点击行为
- 插件状态来源仍统一使用 `/api/plugins/status?name=插件key`
- 更完整说明请查看上级手册 `../../USER_GUIDE.md`
