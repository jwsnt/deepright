# 20260613-3 用户手册

本次迭代补充了非本机访问 Site 时的只读限制，避免通过内网协作页面直接修改模型或插件配置。

## 访问限制

- 这组限制只看当前站点是否通过 `localhost` 或 `127.0.0.1` 打开，与服务当前处于 `单机` 还是 `协作` 模式无关
- 只要页面不是通过 `localhost` 或 `127.0.0.1` 访问，就会按远程访问规则处理

## 设置面板

- 已保存模型密钥在读取时统一显示为 `**********`
- 模型配置整体为只读：不允许新增模型，不允许删除模型，也不允许修改现有模型配置
- 客户化配置仍可展开查看，但只保留只读展示；不会出现 `重置`、`清空`、`保存` 等写操作入口

## 插件浮层

- 非本机访问时，插件浮层会隐藏全部插件参数
- `启动`、`重启`、`关闭` 等插件生命周期操作都会被禁用
- 插件浮层只保留日志查看能力，方便远程排查运行状态
