# 20260526-7 用户手册

本次迭代为右侧边栏 `CLI` 子面板补充了一条独立的新手引导流程。

- 当浏览器本地还没有“点击过 CLI 子面板”的记录时，第一次点击右侧 `CLI` 子面板中的任意元素，都会触发这条引导
- 引导开始后会自动展开右侧 Sidebar，并在命令展示区域临时模拟一条 `ls` 命令
- 第一步会高亮模拟命令本身，提示“系统执行的命令会在这里显示”
- 点击 `知道了` 后，会切换到模拟命令的终止按钮，提示可以用它终止预期外的系统命令
- 再次点击 `知道了` 后，会切换到模拟命令的复制按钮，提示可以复用已经执行过的系统命令
- 最后一步会清除模拟命令，并高亮 `CMD` 执行按钮，提示可以从这里执行自定义系统命令
- 引导过程中，除当前高亮区域外，其它区域都会被暗化且不可点击；只有通过 `知道了/完成` 才会推进流程
- 这条 CLI 引导与首次使用引导、首次点击输入框引导、蜂群引导、插件引导、`SOUL.md / USER.md` 引导、右侧备忘录引导和 Skill 提炼引导相互独立，可以兼容共存
