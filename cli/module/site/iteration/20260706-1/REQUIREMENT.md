### 需求介绍
+ 居中对话框中 assistant 响应里自动识别出的 `http/https` URL，在点击小气泡动作浮层中的 `预览` 或 `打开` 时，如果目标 host 为 `127.0.0.1` 或 `localhost`，需要在实际访问的 URL 上自动补齐当前会话上下文参数
+ 需要补齐的 query 参数如下：
    + `agentId`：当前 Agent ID
    + `chatId`：当前会话 ID
    + `themeLabel`：当前页面主题标签
+ 参数取值要求：
    + `agentId` 必须取当前激活会话实际绑定的 Agent，而不是固定读取某个历史缓存值
    + `chatId` 必须取当前激活会话 ID，确保同一页面切换会话后，新的 `预览` / `打开` 会自动带上新会话上下文
    + `themeLabel` 必须反映当前页面主题，并与页面实际展示一致；深色主题传 `深色模式`，浅色主题传 `浅色模式`
+ 本次补参只作用于 assistant URL 小气泡点击后的真实访问链路：
    + `预览`：右侧 Sidebar iframe 预览实际加载的目标 URL
    + `打开`：新窗口打开的目标 URL
    + 不要求修改 assistant 小气泡本身展示的摘要文本
    + 不要求修改 `复制` 按钮复制到剪贴板的原始 URL 文本
+ host 匹配规则要求：
    + 仅当目标 URL 的 host 为 `127.0.0.1` 或 `localhost` 时才追加以上参数
    + 其他普通远程域名 URL 保持现有行为，不得额外追加这三个参数
+ query 兼容要求：
    + 必须兼容目标 URL 原本已经带有 query 参数的情况
    + 如果原 URL 没有 query，则按标准 URL 形式追加参数
    + 如果原 URL 已有 query，则继续以标准 query 形式追加或覆盖对应键值，不得生成错误的分隔符
    + 若原 URL 已经包含 `agentId`、`chatId`、`themeLabel`，则以当前页面上下文值覆盖，保证最终访问参数与当前会话一致
+ 预览链路兼容要求：
    + 右侧 iframe 预览原有的自动打开、失败回退、加载超时、会话绑定、资源类 URL 过滤逻辑保持不变
    + 预览前的可访问性检查若会使用目标 URL，也必须基于补参后的本地 URL 执行，避免检查和真实加载目标不一致
+ 打开链路兼容要求：
    + 继续复用现有 `打开` 新窗口逻辑
    + 仅修改最终传给浏览器的新窗口 URL，不改变小气泡动作顺序和动作入口
+ 与既有 assistant URL 小气泡能力的兼容要求：
    + 小气泡识别规则、摘要展示规则、资源类 URL 过滤规则、动作浮层交互和新手引导逻辑不得被破坏
    + 非 `localhost/127.0.0.1` 的 URL 预览与打开行为必须与当前版本保持一致
