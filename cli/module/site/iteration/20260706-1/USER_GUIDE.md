# 20260706-1 用户手册

本次迭代补充了 assistant URL 小气泡在本地站点上的会话参数透传能力，方便本地页面预览或打开时自动拿到当前上下文。

## 生效范围

- 仅作用于 assistant 响应里自动识别出的 `http/https` URL 小气泡
- 仅在点击小气泡动作浮层中的 `预览` 或 `打开` 时生效
- 仅当目标 host 为 `localhost` 或 `127.0.0.1` 时才会自动补参数

## 自动补齐的参数

- `agentId`：当前激活会话实际绑定的 Agent ID
- `chatId`：当前激活会话 ID
- `themeLabel`：当前页面主题；深色主题传 `深色模式`，浅色主题传 `浅色模式`

## 具体行为

- 点击 `预览` 时，右侧 Sidebar iframe 实际加载的本地 URL 会自动补上这三个参数
- 点击 `打开` 时，新窗口访问的本地 URL 也会自动补上这三个参数
- 如果原始 URL 本身已经带有 query 参数，页面会继续按标准 URL query 形式追加或覆盖，不会破坏原有参数结构
- 如果原始 URL 已经包含 `agentId`、`chatId`、`themeLabel`，会自动用当前会话与当前主题对应的值覆盖

## 不受影响的部分

- URL 小气泡本身的摘要展示不变
- `复制` 仍然复制气泡绑定的原始完整 URL，不会把自动补上的本地上下文参数写回剪贴板
- 非 `localhost` / `127.0.0.1` 的普通远程 URL，`预览` 与 `打开` 行为保持不变
- 既有的资源类 URL 过滤、右侧 iframe 预览失败回退、加载超时、会话绑定和相关新手引导逻辑继续沿用现有规则
