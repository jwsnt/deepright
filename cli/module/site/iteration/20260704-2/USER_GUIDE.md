# 20260704-2 用户手册

本次迭代为左侧虚拟文件系统补充了技能目录禁用的展示与切换能力。

- 直属包含 `SKILL.md` 的目录，会在原目录图标位置显示技能目录开关
- 默认状态下，点击该开关会按当前会话禁用这个技能目录及其全部子孙技能
- 已禁用的目录会切换到禁用态图标；再次点击后会恢复该目录和其子孙技能
- 如果某个目录只是因为父级技能目录被禁用而失效，会显示继承禁用态；这时点击不会直接切换，而会提示 `当前目录因父级技能目录被禁用，需先恢复父级`
- 页面请求虚拟文件系统目录数据时会自动携带当前 `chatId`，并根据后端返回的状态字段刷新整行目录展示
- 切换成功后，页面会立即刷新当前目录，并在 Tips 位置提示 `技能目录已禁用` 或 `技能目录已恢复`
- 如果当前还没有有效会话，点击技能目录开关时会提示 `请先选择会话`
- 首次真实禁用任意技能目录后，如果浏览器本地还没有对应记录，还会额外触发一条独立的新手引导
