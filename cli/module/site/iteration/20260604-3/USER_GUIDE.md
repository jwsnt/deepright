# Site 迭代 20260604-3 使用手册

## 备忘录已完成提示

- 当右侧备忘录任务明细列表检测到新的已完成任务时，整个任务明细列表区域会同步闪烁，列表左上角也会显示一个 `8x8px`、会随浅色/深色主题切换的高反差蓝色小星。
- 如果右侧 Sidebar 这时处于收起状态，列表区域闪烁会改为闪动右侧栏展开图标，并自动改用与当前主题形成反差的提示色，提示先展开右侧查看。
- 点击、悬浮到任务明细列表，或从周期备忘录列表切回任务明细列表后，小星与区域闪烁都会立即消失。
- 如果新的已完成任务到达时，鼠标已经停留在任务明细列表区域内，页面不会再次补闪，避免打断当前查看。
- 这个提示只用于提醒“有新的已完成备忘录任务”，不会改动原有备忘录列表、查看会话或右侧栏展开收起逻辑。
