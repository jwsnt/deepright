# 20260613-1 USER_GUIDE

本次迭代为站点左侧边栏底部新增了 `单机 / 协作` 切换按钮，并直接对接 integration 的运行时 `standalone` 开关。

## 位置

- 按钮位于左下角 `关闭应用` 按钮左侧
- 只有通过 `localhost` 或 `127.0.0.1` 打开站点时，`单机 / 协作` 与 `关闭应用` 两个按钮才会显示

## 行为

- 当前服务处于协作模式时，按钮显示 `协作`
- 点击 `协作` 后，页面会调用 `POST /api/standalone=true`
- 切换成功后，当前 `--port` 端口上的全部 HTTP 服务都会变成仅允许本机访问

- 当前服务处于单机模式时，按钮显示 `单机`
- 点击 `单机` 后，页面会调用 `POST /api/standalone=false`
- 切换成功后，当前 `--port` 端口上的全部 HTTP 服务会重新允许其他 IP 访问

## 说明

- 页面初始化时会先读取 `GET /api/standalone`，用来同步当前运行态按钮文案
- 协作态按钮会使用金色样式
- 按钮只在通过 `localhost` 或 `127.0.0.1` 打开站点时显示；远程访问页面不会显示这个入口
- 切换过程中按钮本身会显示加载动画，不再额外弹出页面 Tips
