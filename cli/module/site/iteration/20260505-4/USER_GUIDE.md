# 20260505-4 使用手册

## 目标

本次迭代修复右上角备忘录时间线中已完成任务的“查看会话”重复恢复问题，并继续强调固定定位浮层的分域交互原则：

- 已完成任务首次点击 `查看会话` 时，会恢复对应备忘录会话
- 后续重复点击同一条已完成任务时，仍进入同一会话，但不会把已经恢复过的历史消息再次追加到界面
- 同一会话的恢复请求会按当前游标串行执行，避免重复点击或短时间重复触发 `/api/restore` 时并发追加相同消息

## 页面行为

- 右上角任务明细中，已完成任务点击 `查看会话` 后：
  - 若该备忘录会话尚未建立，会创建并切入对应会话
  - 若该备忘录会话已经存在，会直接回到原会话继续查看
- 再次点击同一条已完成任务时：
  - 页面会沿用该会话当前已经推进到的恢复游标
  - 新的恢复请求会等待前一次恢复完成后再继续执行
  - 已经渲染过的历史消息不会重复插入

## 分域规则

- 备忘录查看会话的确认框与相关浮层仍遵守左侧 Sidebar、中间会话区、右侧 Sidebar 的分域管理
- 未激活的固定定位遮罩层、确认框、弹窗、透明点击层保持彻底失活，不会跨区域拦截点击
- 本次修复不改变现有视觉布局与交互入口，只修正恢复链路的幂等行为
