# 迭代 20260428-9：备忘录明细忽略任务

## 功能说明

1. 鼠标悬停在备忘录明细列表项时，头部显示 8x8 透明度 50% 的小垃圾桶图标
2. 点击垃圾桶弹出二次确认浮层，展示任务明细信息（模型、思考模式、状态）
3. 确认后将任务状态设为"无需启动"（status=2），成功后立即刷新列表
4. 当鼠标或焦点不在任务明细列表中时，页面会每 30 秒自动刷新一次任务明细列表
5. 任务明细相关刷新入口增加了短防抖，避免短时间内重复请求

## 依赖接口

`POST /api/cron/detail/status?agentId=xxx&detailId=yyy&status=2`
