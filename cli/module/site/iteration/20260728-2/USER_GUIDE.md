# 虚拟文件系统最近文件提示与媒体输出跳转

虚拟文件系统会先显示目录、后显示文件：目录按名称字母顺序排列，文件按最后修改时间从新到旧排列；修改时间相同的文件按名称排列。

- 当前目录中最近 `30` 秒创建或修改的文件会高亮并闪动，目录不会高亮。用户移动鼠标进入或点击该文件整行会立即关闭它本次版本的提示；列表自动重绘到静止鼠标下方不会误当成悬停而关闭提示。
- 关闭提示会在刷新页面或切换目录后保持，但只会保存到该文件最后修改时间满 `30` 秒。浏览器只保留一个短期记录；所有记录到期即删除，重新修改同一文件会重新提示。
- 不使用持续轮询检查到期时间。列表刷新后只安排下一次到期更新，因此不会持续占用资源。
- 图片保存或编辑、视频提取图片帧、以及画布导出 PNG 后，会自动进入 `images/`；音频保存、音频裁剪或混音保存后会进入 `audios/`；视频编辑或录屏保存后会进入 `videos/`。Agent 标识只存在大小写差异时也会识别为同一工作区。每次进入后都会重新读取整个目标目录，因此同一次操作产生的多个最近文件都会一起提示。
- 画布导出 PDF 继续沿用原有的 `canvas/` 文档输出路径，不属于图片目录跳转。
