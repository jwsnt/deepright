# Site 迭代手册（20260724-3）

## 本次更新

页面备注的 `标注` 入口新增首次点击的新手引导，用于说明保存的标注会自动成为下一次提问的上下文。

## 触发方式

1. 在当前浏览器中，没有“点击过页面备注标注”的本地记录。
2. 在最后一条正常结束的 SSE 助手响应内完成文字框选。
3. 点击 `标注` 按钮。

鼠标悬停不会触发此引导。首次点击只用于显示说明，不会同时打开标注编辑浮层；点击 `完成` 后再次点击 `标注`，即可按原有流程添加页面备注。

## 引导流程

- 页面会高亮被点击的 `标注` 按钮，并暗化其余页面区域；除引导卡片和 `完成` 外，其它功能暂不可点击。
- 引导文案为“标注内容会自动添加至下次提问。”。
- 点击 `完成` 后遮罩关闭，页面全部功能立即恢复可用。

## 兼容说明

- 此引导使用独立的浏览器本地记录，不影响首次使用、输入框、蜂群、插件、备忘录及其它既有新手引导。
- 若点击时已有其它新手引导正在显示，页面不会写入本引导的完成记录；完成当前引导后再次点击 `标注` 即可正常触发。
