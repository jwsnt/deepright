### 需求介绍

- 当前 Agent 工作区根层的 `videos` 目录悬停时新增与现有视频工具图标同尺寸的“人物视频对口型”入口。点击时先锁定交互并依次检查 FFmpeg/FFprobe、再以当前页面的 Agent ID 检查 Wav2Lip；不得传递或推断会话 UUID、VFS 工作目录或其它 Agent 信息。
- 缺失 FFmpeg 时使用既有 FFmpeg 安装确认；缺失 Wav2Lip 时显示同类确认，并将服务端展开 `$workspace` 后的 `wav2lip.install` 请求发送至当前 Chat。浏览器不得自行安装。两项依赖均可用时打开居中域“人物视频对口型”浮层。
- 浮层沿用“视频提取主体”的任务列表、状态筛选、分页、日志、取消、重新开始、失败或已取消记录删除、完成任务复选框、批量复制和清空语义；关闭或 `Esc` 不取消任务，`Enter` 提交当前待加入任务。
- 顶部固定文案为“添加更多视频任务”。每条待加入项必须同时选择一个视频和一个对应音频，最多 5 条，可逐条删除。视频只允许既有受控视频格式；音频只允许 `wav`、`mp3`、`m4a`、`aac`、`flac`、`ogg`。音频选择后上传至当前 Agent `tmp/`，界面展示其路径；未配对的视频不得创建任务。
- 任务列表显示视频、音频、开始时间、状态、进度和输出视频路径。成功输出可复制绝对路径或预览；浮层打开预览后，关闭预览必须回到原浮层并保留待加入列表、筛选、分页、勾选和日志状态。
- 轮询发现可识别的任务失败原因时，浮层底部必须直接提示可执行的中文原因。例如模型缓存 `unexpected EOF` 时提示人脸检测模型缓存不完整或损坏、需删除指定缓存后重试；日志仍保留原始输出供排查。
