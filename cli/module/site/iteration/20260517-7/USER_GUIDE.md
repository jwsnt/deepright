# Site 迭代手册（20260517-7）

## 本次更新

- 左上角插件按钮打开后的 `PLUGIN META` 配置浮层面板透明度调整为与设置浮层一致
- 浅色模式与深色模式下都同步复用设置浮层的面板透明度、边框、阴影与模糊强度，保持原有位置、层级和交互不变

## 当前行为

1. 点击左上角插件按钮后，配置浮层仍会在中间会话区原位置弹出，不改变原有交互域和开关逻辑
2. `PLUGIN META` 配置面板已与设置浮层使用同一组面板透明度
3. 浅色模式和深色模式都会分别对齐各自设置浮层的边框、阴影与模糊强度，减少背景内容透出
4. 左上角扇形按钮本身未展开时继续保持原有默认外观，不额外变厚
5. 浮层的显示状态、pointer-events 和分域规则保持不变，不会影响左侧 Sidebar 以外的交互
