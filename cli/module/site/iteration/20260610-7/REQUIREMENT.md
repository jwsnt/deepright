### 需求介绍
+ 在虚拟文件系统提醒Skills文件错误时（红色闪动）的文件或目录（路径）后添加一个右对齐的修复小图标，使用和红色闪动同样的颜色
+ 点击该修复小图标弹出确认浮层（浮层在居中对话框水平垂直居中，其他背景模糊，是绑定回车，取消绑定ESC）
    + 标题："是否需要修复SKILL.md"
    + 内容：错误SKILL.md的文件绝对路径（非目录）
+ 点击是则自动为用户发送请求：参考[https://agentskills.io/specification]修复$(SKILL.md文件绝对路径)的错误。
    + 其中$(SKILL.md文件绝对路径)是SKILL.md文件系统绝对路径占位符，动态替换
