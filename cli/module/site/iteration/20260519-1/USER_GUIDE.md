# Site 迭代手册（20260519-1）

## 本次更新

- 页面首次打开时，左侧 Sidebar 和右侧 Sidebar 默认都会收起
- 页面内仍可手动展开或收起左右侧边栏，但每次重新打开页面时都会回到默认双侧收起
- 当左侧 Sidebar 收起且本地还没有任何模型配置时，点击输入框、模型选择入口或直接发送消息，会自动展开左侧 Sidebar，避免用户找不到 `设置` 入口

## 页面行为

1. 首次在浏览器打开站点时，左右两侧栏都不会默认展开，中间会话区会直接成为视觉焦点
2. 点击左上角菜单按钮后，可以单独展开左侧 Sidebar；再次点击会重新收起
3. 点击右侧边缘按钮后，可以单独展开右侧 Sidebar；再次点击会重新收起
4. 当前页面中的左右两侧展开状态彼此独立，不会互相覆盖
5. 重新打开页面后，会再次使用“默认双侧收起”的初始化规则，而不是恢复上一次布局
6. 如果当前无法选择模型或发送消息的原因是“本地一个模型都没配置”，页面会优先自动展开左侧 Sidebar，再继续展示原有模型提示

## 说明

- 本次迭代只调整 Sidebar 默认展开策略与无模型场景下的左侧栏自动展开逻辑，不改动既有会话、设置、浮层分域和右侧面板内容
