# 20260610-4 用户手册

本次迭代为左侧边栏里的“跨会话完成提醒”补充了一条独立的新手引导，用来说明如何发现别的会话已经返回完成内容，以及如何打开对应会话查看结果。

- 当浏览器本地还没有“跨会话完成提醒引导”的记录时，只要首次出现未读的已完成会话提醒，就会自动触发这条引导
- 如果左侧边栏当前处于收起状态，第一步会先高亮左上角的 `展开菜单` 按钮，并提示 `点击展开左侧边栏，查看未读的已完成会话。`
- 点击第一步的 `知道了` 后，会自动展开左侧边栏，高亮触发本次引导的会话，并在约 `2` 秒内把高亮过渡到该会话右侧新增的小 `x` 提醒图标
- 随后高亮会再回到整个会话行，并提示 `点击查看未读的已完成会话。`
- 点击第二步的 `知道了` 后，会自动切换到对应会话，并把高亮切到中间对话区域里这条会话最新的 SSE 响应内容
- 最后一步会提示 `点击会话内容。`，点击 `完成` 后关闭遮罩并恢复页面正常交互
- 如果左侧边栏一开始就是展开状态，则会跳过“展开菜单”这一步，直接进入会话提醒图标与会话内容的引导
- 引导期间，左侧栏、中间对话区和其它弹层之外的区域都会被暗化且不可点击
- 这条引导与首次使用引导、输入框引导、`@文件 / 技能` 引导、蜂群引导、插件引导、备忘录引导、沙盒引导、全屏引导、虚拟文件系统编辑引导等其它新手引导相互独立，可以兼容共存

补充说明：

- 会话右侧的小 `x` 提醒仅用于表示“该会话在后台已完成且尚未查看”，切换到该会话后会自动消失
- 当左侧边栏收起时，同样的提醒会转为左上角 `展开菜单` 按钮的闪动提示，避免未读完成会话被遮住
