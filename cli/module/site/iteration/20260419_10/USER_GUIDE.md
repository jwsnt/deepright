# Site 迭代 20260419_10 使用手册

## 变更说明

对话框输入 `@` 触发菜单浮层，支持在待提交内容的光标处插入文件和技能引用气泡。

## 使用方式

### 触发菜单
在输入框任意位置输入 `@`，弹出菜单：
- 文件（SVG 目录图标）：浏览并选择文件/目录
- 技能（SVG 闪电图标）：选择当前 Agent 的技能

### 中断监听
- 按 `ESC` 或 `空格`：关闭菜单，保留 `@` 字符

### 选择文件
1. 选择「文件」后弹出 300px 路径输入框（支持模糊前缀匹配）
2. 输入路径，自动列出目录内容
3. 点击文件夹图标进入子目录，点击文件选中
4. 气泡 `[FILE:文件名]` 插入到待提交内容的光标处，发送时替换为 `[FILE:绝对路径]`

### 选择技能
1. 选择「技能」后自动加载技能列表
2. 选择后气泡 `[SKILL:技能名称]` 插入到待提交内容的光标处

### 气泡行为
- 反差色内联显示在输入文本中，与文字混排
- 左上角 10×10px 垃圾桶图标（透明度 50%），点击删除
- 删除气泡后前后文字自然拼接

### 案例
- 输入 `ABC`，选择文件 `/DEV/X`，再输入 `DEF`
  - 展示：`ABC[FILE:X]DEF`
  - 提交：`ABC[FILE:/DEV/X]DEF`
  - 删除气泡：`ABCDEF`

### 键盘操作
- `↑` `↓`：导航菜单/列表
- `Enter`：确认选择
- `Escape`：关闭面板（保留 `@`）
- `空格`：关闭 `@` 菜单（保留 `@`）
