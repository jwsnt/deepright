# 设置内隐藏的运行时 Host 浮层

## 简介

本迭代在站点设置面板中增加了一个隐藏入口，用来修改 `integration` 当前运行中的 Host。

- 修改目标：`integration` 当前进程的运行时 Host
- 生效范围：仅当前运行周期
- 持久化：不会写入 `config.json`
- 重启后：恢复为启动时 Host

## 使用方法

1. 打开左下角的 `设置`
2. 在 10 秒内连续点击设置面板标题 `设置` 10 次
3. 弹出 `运行时 Host` 浮层
4. 输入新的 `http://` 或 `https://` 地址
5. 点击 `保存`

如果需要恢复为启动值，可以点击 `恢复启动值`。

## 浮层说明

- `当前 Host`：当前实际生效的上游地址
- `启动值`：本次 `integration` 启动时解析出的 Host
- `保存`：立即把当前运行时 Host 切到新地址
- `恢复启动值`：清除本次运行时覆盖

## 限制

- 该隐藏入口仅在本地访问站点时可用。
- 修改后不会影响设置面板中的其他未保存内容。
- 该浮层调用的是 `integration` 的 `/api/host` 接口。若服务未启动或接口不可达，会在浮层中显示错误信息。
