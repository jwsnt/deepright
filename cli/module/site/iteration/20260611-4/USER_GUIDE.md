# 20260611-4 用户手册

本次迭代为“首次点击初始化浏览器实例”补充了一条独立的新手引导，用来说明首次手动登录浏览器实例时的注意事项，并避免第一次点击就直接执行真实初始化。

- 当左侧快捷菜单旁的绿色 `初始化浏览器实例` 小按钮第一次被点击，且本地还没有“点击过初始化浏览器实例”的记录时，会先触发这条独立引导
- 第一步会弹出居中的新手引导卡片，提示 `Windows用户需要手动登录网站以获得必要权限。`
- 第二步会切换为一个带地址栏的 Chrome 动画示意，并在地址栏中展示 `http://example.com`，同时提示 `手动初始化会打开崭新的浏览器用于登录需要使用的账号。`
- 第三步会切换为闪动的警示框，标题改为 `请保持登录窗口`，并分两行强调 `在自动新建的空白浏览器中依次在地址栏输入网址并登录。` 和 `首次启动时请耐心等待。`
- 第四步会临时展开一个仅用于引导预览的 `正在进行浏览器插件登录` 浮层，先高亮整个浮层，再用约 `2` 秒过渡高亮到其中的 `完成` 按钮，并提示 `所有登录完成后回到该页面并点击完成。`
- 最后一步会继续高亮该预览浮层，并补充 `不同会话间的登录状态是隔离的，切换会话时请确认已经获得必要权限。`
- 点击最后一步的 `完成` 后，会关闭这条引导的遮罩与预览浮层，恢复页面正常交互；此时并不会真正执行 `instance init`
- 之后再次点击同一个绿色小按钮，才会走真实的浏览器实例初始化流程
- 这条引导与首次使用引导、首次点击输入框引导、浏览器插件重启引导、任意插件首次成功启动引导等其它新手引导相互独立，可以兼容共存
