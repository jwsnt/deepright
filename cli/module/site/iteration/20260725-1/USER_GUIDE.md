# Site 迭代手册（20260725-1）

## 音频和视频预览

当聊天消息中出现当前 Agent 工作目录内的媒体文件路径时，点击路径操作浮层中的 `预览`，即可在只读浮层打开播放器。

支持的视频扩展名为：`mp4`、`m4v`、`webm`、`ogv`、`mov`、`mkv`、`avi`、`mpg`、`mpeg`。

支持的音频扩展名为：`mp3`、`m4a`、`aac`、`wav`、`flac`、`ogg`、`opus`。

## 播放控制

媒体不会自动播放。浮层底部提供以下只读控制：

- 后退 15 秒与前进 15 秒图标：在媒体开头和结尾自动限制，不会越界。
- 播放与暂停图标：控制当前预览的播放状态。按钮不展示文字，悬停可查看功能说明。
- 进度条：可拖动定位到媒体中的任意可播放位置。
- 时间显示：展示当前播放时间与总时长。
- 音量：可在静音与最大音量之间连续调整。

预览浮层不显示编辑页签、保存按钮或图片标注工具。关闭浮层会停止播放，且不会改动原始媒体文件。

## 浏览器兼容性

文件扩展名受支持并不代表浏览器一定具备该文件所使用编解码器。若浏览器无法解码，浮层会显示加载或播放失败提示；此时可使用原有的 `下载文件` 操作在本机播放器中打开。
