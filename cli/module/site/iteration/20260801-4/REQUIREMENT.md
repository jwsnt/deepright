### 需求介绍

虚拟文件系统的“新增”类型增加“配音”。创建配音任务后，页面以现有“提取音频文字”任务浮层为基础提供 VoxCPM 文字转语音和参考音频克隆能力。

- 在“新增”类型中提供“配音”，名称仅支持 `.wav`（省略后缀时默认补为 `.wav`）。点击创建时必须同时检查当前 Agent 工作区 `audios/` 内用户填写的原名称和默认 `.wav` 名称；任一已存在则保留创建浮层并提示冲突，不得创建空文件或打开任务浮层。
- 当前 Agent 工作区根层的 `audios` 目录悬停时，显示与“提取音频文字”一致尺寸和显示时机的“文字转语音”小图标。点击后先调用 `GET /api/voxcpm/check` 并复用创建配音时的依赖检查锁与安装确认；缺失时仅提示安装，不得打开任务浮层或执行安装命令。检查通过后，以当前本地时间戳加 `.wav` 作为默认输出文件名，打开“文字转语音”任务浮层。
- 所有当前 Agent 工作区内的文本文件预览浮层，在底部操作区的“取消”按钮左侧提供与 `audios` 目录一致的“文字转语音”小图标；图标底边必须与“取消”按钮底边对齐，顶部保持原有预览布局。浅色暖色主题使用暖色强调，深色冷色主题使用冷色强调。点击时先复用 `GET /api/voxcpm/check`、检查锁与安装确认；检查通过后关闭文本预览并打开“文字转语音”任务浮层，初始待加入任务自动填入该文件的工作区相对路径及其绝对展示路径，仍由用户选择参考克隆音频。默认请求输出名取文本文件名去掉最后一个后缀后加 `.wav`，输出仍固定在 `audios/`；同名文件、已有任务输出或并发占用时由服务端追加时间戳及必要序号。
- 创建时调用 `GET /api/voxcpm/check`。检查期间复用既有依赖检查锁定层；配置错误或检查失败时中止创建并保留创建浮层。缺少 `voxcpm` 时显示与 FFmpeg 相同的安装确认框：取消或 `Esc` 仅关闭确认并保留创建浮层；确认或 `Enter` 关闭创建浮层，将服务端配置的 `install` 原文发送到当前 Chat。浏览器不得自行执行安装命令。
- 检查通过后打开居中域“文字转语音”任务浮层。其遮罩、尺寸、状态筛选、固定每页 5 条分页、日志轮询、取消、重新开始、失败或已取消任务删除、刷新和关闭/键盘交互均与“提取音频文字”任务一致；标题不得展示 Agent ID。
- 浮层顶部文案为“添加更多语音任务”。初始包含一条待加入语音任务；“添加”最多将待加入任务增加至 5 条，每条可单独删除。文字文件为唯一必填项；“参考音色”和“表达风格”均为可选项。参考音色为空时必须使用 VoxCPM `design` 自由生成声音，选择音频后使用 `clone` 克隆音色；表达风格输入内容作为当前任务单个 `--control` 参数，最多 240 个字符，空白会被规范化，不能作为命令行选项拼接。待加入任务在常规桌面宽度必须保持单行五列固定栅格：文字固定 200px、参考音色固定 200px、表达风格固定 153px、场景固定 100px、删除固定 56px；路径必须在本列内省略截断，任一文件名长度均不得改变其它控件的位置，仅小于 520px 时按响应式换行。两种文件选择复用现有文件选择与上传交互，允许从本机任意目录选择，上传后以绝对路径清晰展示。场景选择必须与“提取音频文字”使用相同的下拉交互和样式，默认“均衡克隆”；可选“均衡克隆”“质量优先”“快速预览”“清晰增强”“温暖叙述”和“轻快表达”。填写表达风格时优先使用填写内容；未填写时可使用场景内置表达风格。任务日志必须记录参考音色是否选择、实际 `design`/`clone` 模式及实际 `--control` 使用情况。浮层底部必须与“提取音频文字”一致，以“场景说明：”实时展示当前选择场景的特点；文字文件为空或不是可读取的文本时不得提交。
- 待加入任务提交时使用创建名称作为输出基名。只有一条任务时优先使用该名称；同名或并发冲突时由服务端在扩展名前追加时间戳。多条任务时每条均使用“创建名称 + 时间戳后缀”，并在同一批次内继续加序号避免冲突。输出固定为当前 Agent 工作区 `audios/` 内的 WAV，既有文件永不覆盖。
- 配音、提取音频文字和提取图片主体的任务列表均展示对应的源文件路径、开始时间、状态、进度条和输出文件路径；配音元信息固定两行：开始时间、场景、表达风格和自适应占用剩余空间的文字路径在第一行，参考音频和输出音频在第二行。表达风格未填写时显示“未填写”；表达风格或文字路径实际截断时，悬停必须展示完整值。状态至少为排队中、执行中、已完成、已取消和失败；排队中/执行中可取消，已取消可重新开始，失败可删除，所有已执行任务可查看日志。三类任务的已完成任务均可单独复制输出绝对路径并预览，且任务标题前显示多选框；选中至少一项时，状态筛选右侧使用与提取音频文字一致的过渡样式展开“复制”“清空”操作，复制以换行分隔写入所选输出的绝对路径，清空仅取消勾选而不影响任务或文件。三类任务的标题、源路径和输出路径过长时必须以省略号截断，且不得挤压、换行或隐藏状态和取消等操作控件；仅在实际截断时，悬停对应内容必须以任务浮层显示完整绝对路径，并提供原生完整路径提示兜底。
- 关闭浮层、页面刷新或应用重启不得取消或丢失已创建任务；再次打开时重新读取当前 Agent 的持久化任务、状态、日志和输出路径。浮层隐藏时必须完全失活，并与其它居中域前景浮层保持互斥。

### 编写代码
+ 所有前端依赖资源必须随站点页面一起可访问，并在发布链路中强校验资源存在性与正确MIME，禁止页面已引用但静态服务未实际发布的本地资源。
+ 修改前先确认服务实际读取的是哪一份运行文件；存在src/site与release/site 双份静态资源时，必须先确认运行目录，再修改并同步，不能只改源码文件。
+ 所有固定定位遮罩层、引导层、确认框、弹窗、日志面板、透明点击层必须统一管理层级、显示状态与 pointer-events，按左侧 Sidebar、居中会话区、右侧 Sidebar 分域隔离。
+ 所有浮层与遮罩默认遵守“交互域隔离 + 隐藏视图彻底失活”原则；隐藏态必须同时不可见、不参与层级竞争、不拦截点击、不接收焦点、不参与键盘导航。
+ 同一交互域任一时刻只能存在一个可交互的前景浮层；打开新浮层前必须先关闭当前浮层，禁止多个浮层重叠争抢点击和层级。
+ 浮层一定挂在它要压住的那一层内部；如果目标在弹窗、抽屉、设置面板等容器中，引导层应直接渲染到对应容器内部，不要依赖外层 z-index 强压。
+ 浮层定位、遮罩高亮与说明卡片位置必须收口到统一的公共函数或 portal 机制，统一坐标系，禁止在业务代码中各自手算 left/top。
+ 设计弹层结构时先确定挂载层级与坐标系，并避免把可能溢出的浮层放入overflow:hidden容器，防止裁切、错位和点击区域异常。
+ 布局逻辑与CSS限制必须一致；若CSS已动态计算 width、height、maxWidth，CSS 不得再写死更小的上限覆盖运行结果。
+ 选择器必须唯一且稳定，优先使用带作用域的 ID 或明确容器前缀，禁止直接依赖.settings-panel这类可能重复命中的通用类名。
+ 引导、确认、弹层等步骤切换不能只依赖理想时序；用户点击、浮层关闭、侧栏展开、动画结束、异步渲染等顺序变化时，流程仍必须可恢复。
+ 所有引导步骤应能根据当前 DOM 状态重新同步和兜底恢复，不能只依赖内存中的状态机，避免因为中途时序变化导致步骤丢失或跳错。
+ 排查浮层问题时，优先顺序固定为：先确认运行文件，再确认挂载层级，再检查层级与 pointer-events，再检查CSS尺寸限制，最后确认选择器唯一与状态恢复能力。
+ 优先复用成熟、轻量、可控的开源方案；在满足需求前提下保持代码简洁、依赖最少、包体积尽可能小。
+ 能用开源包的就用开源包
+ 代码简洁，包体积越小越好
+ 复用既有 Whisper 任务浮层的布局、轮询、分页、日志、文件上传和依赖检查锁；不新增前端依赖，不向浏览器暴露或拼接 VoxCPM 命令行参数。

### 需求介绍

在音频预览浮层增加“提取文字”小图标，并提供可持续查看、管理的 Whisper 音频转文字任务浮层。

- 图标仅在当前预览文件为音频时显示，位于现有音频裁剪图标附近，并与裁剪图标保持一致的宽高；点击时先调用服务端检查 Whisper 是否已安装。
- 虚拟文件系统在当前 Agent 工作目录根层的 `audios` 文件夹悬停时，也必须显示“提取音频文字”小图标。点击后复用同一 Whisper 依赖检查和任务浮层；从此入口打开时不得自动带入任何待加入队列的音频文件。
- Whisper 缺失时，显示与 FFmpeg 一致的安装确认交互：取消或 `Esc` 关闭提示并保留音频预览；确认或 `Enter` 关闭预览并把服务端配置的安装请求发送到当前 Chat。浏览器不得自行执行安装命令。
- Whisper 或 FFmpeg 首次检查、缓存过期检查期间，页面必须显示不可交互的等待锁定层，阻止重复点击、关闭浮层及键盘快捷键，直至检查成功、失败或切换到安装确认；检查已有可用缓存时应快速结束，不影响后续交互。
- Whisper 可用时，打开不展示 Agent ID 的“提取音频文字”任务浮层。浮层展示当前 Agent 的全部转写任务：源音频文件位置、开始时间、状态、进度条、文本文件位置；不额外显示“进度：百分比”文字，开始时间与“文字：文本文件位置”合并在进度条下的同一行，超长路径省略显示；任务状态至少包括排队中、执行中、已完成、已取消和失败，并支持状态筛选和每页 5 条分页。
- 任务浮层必须提供“添加更多音频任务”中的“添加”入口，使用现有视频音频剪辑添加音频所使用的文件选择与上传样式；用户可选择一个或多个音频文件，上传到当前 Agent 工作区后加入待创建列表；不展示上传目录的说明文字。
- 待加入队列以最多 5 条的列表展示。每条音频在删除按钮前必须提供场景下拉框，默认“中文会议”；下拉项使用精炼名称：“中文会议”“专业转写”“低延迟”“批量处理”“CPU 轻量”“中英技术”。每条任务必须单独提交所选场景，后续选择不得影响已入队任务；添加文件不会弹出确认框。切换场景时，浮层左下角必须即时显示当前场景的用途与准确率、延迟或资源取舍说明。底部提供“关闭”和“开始”：关闭或 `Esc` 仅关闭任务浮层，不影响已创建任务；开始或 `Enter` 直接将待加入文件及其场景提交队列并保持在任务浮层内。
- 日志按钮固定在每条任务的右下角。已执行或正在执行的任务均可查看执行日志；日志须显示所选场景和实际转写参数。排队中和正在执行的任务均可取消，已取消任务可重新开始；取消后界面应立即反映取消状态，且下一个排队任务可开始执行。
- 失败任务提供“删除”操作；删除后仅移除任务列表记录，不删除源音频或文字文件。
- 已完成任务在状态标签旁显示“复制”和“预览”：复制文字文件绝对路径，预览打开该文字文件的现有预览浮层。
- 日志面板默认收起；点击每条任务的日志按钮后，任务浮层内容区必须平滑下滑，使日志面板标题立即进入可视区域；日志展开期间，复用任务列表约 1.2 秒的轮询近实时刷新内容，无须再次点击日志按钮，关闭日志后停止刷新；展开时使用小型收起图标关闭。若文字文件在预览前已被删除，保留任务浮层并在左下角显示无法预览的错误提示。
- 从“提取音频文字”任务浮层打开完成任务的文字预览后，关闭该预览必须恢复原任务浮层，不得直接关闭整个浮层；恢复时保留该浮层当前的待加入列表、状态筛选、分页、勾选和已展开日志状态。
- 任务浮层关闭不取消任务；再次打开同一音频或刷新页面时，继续读取服务端持久化的任务、进度、日志和文本文件位置。
- 对完成任务的文本文件位置提供清晰展示；若可复制路径，复制结果仅作为辅助交互，不能代替路径本身。
- 每一条已完成任务的左上角均提供勾选框；勾选状态在任务浮层打开期间跨分页、筛选与列表刷新保持。至少勾选一项时，在状态筛选旁淡入“复制”和“清空”：复制将所有勾选任务的文字文件系统绝对路径以一行一条写入系统剪贴板，并在左下角提示结果；清空会移除全部勾选并淡出两个操作按钮。
- 转写完成后的文本统一保存到当前 Agent 工作目录的 `whisper/`；同名文本由服务端追加时间戳，页面展示服务端返回的最终路径。
- 所有新增确认框、任务浮层和日志视图必须纳入现有浮层域和全局键盘快捷键管理：隐藏时完全失活、同域不与其它前景浮层争夺交互、`Esc` 和 `Enter` 的行为可预测。

- 在当前 Agent 工作目录根层悬停 `images` 目录时，显示与 `audios` 目录“提取音频文字”完全相同尺寸、样式与显示时机的放大镜小图标。其标题和无障碍名称均为“提取图片主体”；点击后先检查 `rembg`，且不得预填待创建文件。
- 当前打开的文件为工作区图片时，在图片预览浮层工具栏显示同尺寸放大镜图标。点击后先检查 `rembg`；可用时打开任务浮层，并自动将当前图片加入待创建列表。非图片、无法确定当前 Agent 或工作区相对路径时，入口必须隐藏且不可用。
- 图片任务入口必须调用 `GET /api/rembg/check`。检查期间复用现有依赖检查锁定层，防止重复点击、关闭浮层及键盘快捷键；缺失依赖时显示与音频流程一致的安装确认框，标题为“需要安装 rembg”。取消或 `Esc` 只关闭确认；确认或 `Enter` 关闭当前预览并将服务端返回的安装请求发往当前 Chat。浏览器不得自行安装或执行命令。
- 可用时打开居中域的“提取图片主体”任务浮层，沿用音频任务浮层的尺寸、层级、遮罩、隐藏失活、关闭与键盘管理。标题不得展示 Agent ID；关闭或 `Esc` 不取消已创建任务，开始或 `Enter` 提交待创建任务。
- 浮层顶部文案固定为“添加更多图片任务”。“添加”应复用既有上传与任务待加入列表交互，允许多选，待加入列表上限为 5 条，并可逐条删除。选择或上传时必须先在浏览器侧筛选图片文件；服务端拒绝时仍须展示错误，不能把非图片加入待创建列表。
- 每条待加入图片在删除按钮前必须将模型下拉框与“边缘优化”开关置于同一行；默认模型为 `u2net`（通用）。下拉框仅展示中文用途名称，不展示内部模型标识。模型和开关均为任务级选项，前端提交时随对应路径发送，不得让后续选择修改已入队任务。选择模型或开关时，浮层左下状态区域必须即时展示用途；文字颜色和与右侧按钮的垂直对齐方式须与音频任务底部说明一致，并明确边缘优化对毛发、半透明、复杂边缘的改善与处理变慢提示。
- 任务列表应展示当前 Agent 的全部图片主体任务，支持 `queued`、`running`、`completed`、`cancelled`、`failed` 状态筛选与固定每页 5 条分页。每项展示源图片路径、开始时间、模型与 alpha matting 状态、状态、进度条与“图片：输出路径”；长路径省略显示，不额外显示冗余百分比文案。
- 排队中或执行中的任务提供取消；已取消任务提供重新开始；失败任务提供删除，且删除只移除任务记录。已完成任务提供输出图片绝对路径复制与图片预览，且标题前提供多选框；选中至少一项时，状态筛选右侧按“提取音频文字”浮层的样式展开“复制”“清空”，批量复制以换行写入所有所选输出的绝对路径，清空只取消勾选；从任务浮层打开预览后，关闭图片预览必须恢复原任务浮层，并保留待加入列表、筛选、分页、已展开日志与勾选状态。
- 每条任务提供默认收起的“日志”。打开日志时任务浮层内容平滑滚动到日志区域；任务列表与已展开日志约每 1.2 秒刷新，关闭日志后停止日志刷新。日志、状态和任务操作错误应在浮层内可见，不得影响其它前景浮层。
- 任务浮层、安装确认与图片预览之间必须保持既有的居中域互斥关系；隐藏态不得接收点击或焦点。关闭浮层、刷新页面或重启应用后，页面必须重新从服务端读取任务状态、日志和输出位置。
