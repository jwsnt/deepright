# Site 迭代手册（20260718-5）

## 本次更新

首次点击右侧备忘录创建区元数据行的 `STOP` 小图标时，会先进入独立的新手引导。引导高亮该图标并暂时遮罩其他区域，说明：关闭后该Agent的备忘录任务将不在执行。

## 使用说明

1. 打开右侧备忘录创建区。
2. 首次点击底部元数据行的 `STOP` 小图标时，阅读引导说明。
3. 点击 `完成` 关闭引导，页面所有功能恢复可操作。
4. 如需实际切换 STOP 状态，请在引导结束后再次点击该图标。

## 行为说明

- 首次点击仅用于显示引导，不会改变 STOP 状态，也不会向服务端发送状态更新请求。
- 引导完成记录保存在浏览器本地，仅影响本项 STOP 引导；不会覆盖或依赖其他新手引导记录。
- STOP 的实际状态仍由服务端按当前 Agent 保存，并继续在创建区和元数据栏两个入口间同步。
