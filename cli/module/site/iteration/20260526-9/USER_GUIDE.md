# 20260526-9 用户手册

本次迭代为浏览器插件浮层中的 `重启` 按钮补充了一条独立的新手引导流程。

- 当浏览器本地还没有“点击过浏览器插件重启按钮”的记录时，第一次在 `浏览器` 插件浮层里点击 `重启`，不会立刻执行插件重启，而是先显示引导遮罩
- 第一步会高亮 `重启` 按钮，并暗化插件浮层中的其他区域；文案提示“浏览器插件与Chrome共享Cookie，无需重复登录”
- 点击 `知道了` 后，引导会切换到插件参数里的 `headless` 区域，并继续锁定其他区域
- 第二步会高亮整个 `headless` 参数区域；文案提示“默认使用无感模式，填写TRUE或true开启有感模式”
- 点击最后一步 `完成` 后会关闭这条引导，恢复插件浮层正常交互；再次点击 `重启` 才会真正执行浏览器插件重启
- 这条引导仅作用于 `浏览器` 插件，不会影响其他插件的 `重启` 按钮行为
