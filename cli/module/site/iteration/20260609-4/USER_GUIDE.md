# 20260609-4 用户手册

本次迭代为中间输入区左上角的 `会话沙盒` 按钮补充了一条独立的新手引导流程，用于帮助用户理解不同沙盒模式的作用。

- 当浏览器本地还没有“点击过沙盒按钮”的记录时，第一次点击 `沙盒` 按钮不会立刻切换或展开真实沙盒操作，而是会先触发这条引导
- 第一步会高亮输入区左上角的 `沙盒` 按钮，并提示 `会话沙盒用于控制系统命令执行权限。`
- 第二步会自动展开 `会话沙盒` 浮层，并高亮 `目录权限` 按钮，提示 `目录权限控制可读写文件范围，防止误删。`
- 第三步会切换高亮 `离线执行` 按钮，并提示 `离线执行保证系统命令执行处于无网状态。`
- 第四步会切换高亮 `双重限制` 按钮，并提示 `双重限制同时控制文件和网络权限。`
- 前三步按钮均为 `知道了`，最后一步按钮为 `完成`
- 引导进行期间，其他区域会被暗化且不可点击；被高亮的沙盒入口只用于演示说明，不会立即触发真实沙盒模式切换
- 这条引导与首次使用引导、首次点击输入框引导、蜂群引导、插件引导、文档整理引导、备忘录引导、知识库引导等其它新手引导相互独立，可以兼容共存
