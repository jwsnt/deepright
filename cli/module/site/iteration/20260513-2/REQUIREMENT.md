### 需求介绍
+ 点击虚拟文件系统的Skill小图标弹出浮层，浮层包括：最近N轮对话、开始时间和结束时间
    + 浮层需要在居中对话框的容器水平垂直居中（展示参考点击左下角设置后展开浮层的风格）注意浅色背景和深色背景的浮层清晰度
    + 最近N轮对话和开始时间必须有一个
+ 选择日志范围并确认后收起浮层，锁定屏幕，调用log_skill生成日志文件并获取绝对路径和大小直到成功或失败
    + log_skill需求：../../../proxy/iteration/20260513-2/REQUIREMENT.md
+ 在获取日志路径和大小成功后（log_skill正确返回）后再次弹出浮层，提示用户输入提炼Skill的目标
    + log_skill失败则在虚拟文件系统提示Tips
        + log_skill获取日志大小为0等同于失败
    + 目标不能为空，除非取消
+ 确认需要提炼Skill内容的后，在当前会话输入框（当前Agent和Chat）自动为用户发送请求，并收起浮层，请求内容如下：
```
将文件中的请求、响应和工具调用整理成Skill，文件保存在:$替换为日志文件绝对路径。需要提炼的目标是：$替换为用户输入的提炼Skill目标
```
+ 由skill小图标触发的SSE请求，即使调用的CLI/PUB也再次触发skills小图标的闪动（skills小图标触发的请求不再触发skills小图标）
    + skill小图标触发的自动提炼请求可以正常执行CLI/PUB，但这类请求结束后不能再反向触发skill小图标自己闪动

### 编写代码
    + 所有固定定位遮罩层、确认框、弹窗必须统一管理层级、显示状态和pointer-events，按左侧Sidebar、居中会话区、右侧Sidebar分域隔离，禁止未激活浮层跨区域遮挡或拦截其他可操作控件点击
    + 涉及弹窗、日志面板、确认框、遮罩层、透明点击层、复制按钮、全局选区逻辑，默认都必须遵守“交互域隔离 + 隐藏视图彻底失活”原则
    + 左侧Skill图标在出现时可稳定点击，并在居中会话区按统一浮层规范弹出不可穿透、分域隔离的Skill提炼对话框
    + 设计上先统一弹层挂哪、用哪套坐标系，并避免把会溢出的弹层放进overflow:hidden 容器里
    + 代码上把定位收口成一个公共函数或portal 机制，不要在业务里各自手算 left/top
    + 能用开源包的就用开源包
    + 代码简洁，包体积越小越好
