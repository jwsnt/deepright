# Chat 级思考侧栏使用手册

当当前 Chat 的 SSE 响应正在进行时，右侧会隐藏知识库 WIKI 顶部标题和操作入口，只保留内容区的“正在思考”状态提示。如果思考片段已经产生，侧栏会展示与居中响应小气泡相同的内容，并在新片段到达时自动滚动到最新位置；尚未产生片段时显示闪动的 `...` 等待。

该状态严格属于当前 Chat。切换到另一个仍在响应的 Chat，会看到它自己的思考片段或等待态；即使恢复轮询尚未启动，页面也会先依据该 Chat 已保存的未结束请求保持正确展示。切换到已完成、异常或取消的 Chat，则直接看到该 Chat 对应 Agent 的知识库。后台其他 Chat 的流式响应不会改变当前侧栏。

正常完成、网络或服务端异常，以及点击停止取消后，侧栏都会恢复知识库；输入框上方的“努力工作中”也遵循同一规则。刷新页面时，如果当前 Chat 的请求仍未结束，页面会继续恢复响应和思考片段；恢复到终态后自动显示知识库。
