# 20260526-8 用户手册

本次迭代为右侧边栏 `知识库WIKI` 区域补充了一条独立的新手引导流程。

- 当浏览器本地还没有“点击过知识库WIKI区域”的记录时，第一次点击右侧 `知识库WIKI` 区域中的任意元素，都会触发这条引导
- 引导开始后会自动展开右侧 Sidebar，并先高亮整个知识库区域
- 第一步会提示“使用时积累的知识会被自动归档为WIKI”
- 点击 `知道了` 后，会切换到 `展开知识库全屏` 按钮，提示“如果知识库内容丰富，可以点击展开”
- 再次点击 `知道了` 后，会切换到 `整理知识库` 按钮，提示“也可以主动整理”
- 点击最后一步 `完成` 后会关闭引导，恢复知识库区域的正常交互
- 引导过程中，除当前高亮区域外，其它区域都会被暗化且不可点击；知识库面包屑、文档链接、展开和整理按钮也不会真正触发原有操作
- 这条知识库引导与首次使用引导、首次点击输入框引导、蜂群引导、插件引导、`SOUL.md / USER.md` 引导、右侧备忘录引导、CLI 引导和 Skill 提炼引导相互独立，可以兼容共存
