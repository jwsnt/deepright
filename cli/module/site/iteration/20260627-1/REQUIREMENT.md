### 需求介绍
+ 在居中对话框的每条SSE响应气泡左上角增加一个“收起思考内容”入口，用于单独收起和展开该条响应中的思考内容
    + 仅当该条SSE响应存在可识别的思考内容时才展示该入口；普通响应、用户请求气泡和右侧CLI子任务气泡不展示
    + 思考内容与正式回复需要继续在同一条assistant响应气泡内维护，不要因为收起思考而额外拆分气泡或新增独立消息
    + 默认进入收起态：首次渲染时优先展示正式回复内容，思考内容收起后不再占用正文高度
    + 点击左上角入口后，在当前气泡内切换为展开/收起思考内容，并保留现有淡入淡出或高度过渡体验，避免突兀闪烁
+ SSE流式返回期间需要兼容收起态和展开态：
    + 如果当前气泡处于收起态，后续新增的思考内容继续追加到思考区缓存，但不要因为流式更新反复撑开气泡
    + 如果当前气泡处于展开态，新增的思考内容和正式回复都继续按现有SSE节奏实时渲染
    + 正式回复区域的流式渲染、自动滚动、Markdown展示、复制和时间/状态标记不受收起思考内容影响
+ 收起思考内容的交互状态需要与当前Agent + Chat + 响应气泡绑定，并兼容现有恢复逻辑：
    + 切换会话后不要串到其他会话
    + 重新渲染当前会话、轮询恢复未结束响应或通过历史记录恢复消息时，需要按该气泡自身记录恢复展开/收起状态
    + 如果历史消息没有保存过该状态，则按默认收起处理
+ 左上角的收起入口需要与现有assistant气泡控件共存：
    + 不要遮挡现有复制、重试、思考片段或其他气泡交互热区
    + 悬浮、点击和失焦判断范围需要限定在当前SSE响应气泡内，不能影响相邻消息气泡
    + 深色/浅色模式都需要保持可见性和反差，不要破坏现有气泡视觉风格
