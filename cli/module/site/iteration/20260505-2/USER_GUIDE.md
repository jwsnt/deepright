# 20260505-2 使用手册

## 简介

本次迭代为 Site 补齐了“从本地文件系统直接拖入文件、图片或文件夹”的上传链路。拖入居中输入框或右上角备忘录输入框后，内容会先上传到当前 Agent 的 `tmp/` 目录，再以 `FILE` 气泡形式插入输入区。

## 功能说明

### 本地拖入上传

- 支持把本地文件、图片或文件夹直接拖入居中对话输入框
- 也支持把本地文件、图片或文件夹直接拖入右上角备忘录输入框
- 页面会先调用 `/api/upload`，把拖入内容上传到当前 Agent 的 `tmp/` 目录
- 上传完成后，会在对应输入框插入 `FILE` 气泡
- 气泡显示格式为 `[FILE:文件名]`
- 实际提交内容为 `[FILE:上传后的绝对路径]`

### 文件夹与目录结构

- 拖入文件夹时，会尽量保留原有目录结构
- 如果拖入的是空目录，也会在当前 Agent 的 `tmp/` 下补建对应目录
- 拖入文件夹后，插入的 `FILE` 气泡对应的是上传后文件夹本身的绝对路径

### 交互域锁定

- 上传期间会锁定当前触发区域，避免用户继续操作导致状态错乱
- 拖入居中输入框时，只锁定中间会话区
- 拖入右上角备忘录时，只锁定右侧 Sidebar
- 锁定遮罩遵守现有 overlay 分域规则，不会跨区域遮挡左侧 Sidebar 或其他未参与上传的区域

- 本地拖入上传依赖 `/api/upload` 接口可用，且当前会话需要绑定有效 Agent
