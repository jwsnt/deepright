# 20260526-6 使用说明

## 变更说明

- 右侧边栏 `CLI` 子面板在当前会话还没有任何系统指令记录时，会展示一个循环跑步的 Chrome 小恐龙动画
- 一旦当前会话收到首条 `cli/sub` 响应气泡，空态动画会立即隐藏，恢复原有 CLI 气泡列表
- 切换到其他没有 CLI 记录的会话时，空态动画会重新显示；切回已有 CLI 记录的会话时，仍然展示对应历史气泡

## 验证方式

1. 打开站点并进入任意一个还没有执行过系统指令的会话
2. 展开右侧边栏，观察 `正在执行的系统指令` 面板
3. 确认面板内展示循环跑步的小恐龙动画
4. 触发一条 CLI 子任务响应后，确认动画消失并显示实际响应气泡
