# 20260613-4 用户手册

本次迭代为三处上传入口补充了“大文件锁定上传”能力：

- 左侧虚拟文件系统中，点击 `上传文件` / `上传目录` 选择内容上传时，如果单个文件超过 `50MB`，或一个被上传目录汇总后超过 `50MB`，会弹出带大小提示的锁定层
- 左侧虚拟文件系统中，直接把系统文件或目录拖入上传时，超过 `50MB` 的文件或目录同样会显示锁定层
- 居中对话输入框拖入系统文件或目录上传时，如果文件或目录超过 `50MB`，锁定层会显示对应项目名称和大小
- 右侧备忘录输入框拖入系统文件或目录上传时，如果文件或目录超过 `50MB`，锁定层会显示对应项目名称和大小
- 无论上传入口来自左侧虚拟文件系统、居中输入框还是右侧备忘录，这个锁定层现在都统一显示在居中对话框区域的垂直居中位置
- 锁定层展示期间会使用居中对话区域的模糊背景，不再分成左侧或右侧单独浮层
- 锁定层中新增 `取消上传` 按钮，点击后会中断当前上传请求，不再继续传输剩余内容
- 取消后页面会恢复交互，并显示 `上传已取消` 提示
- 未超过 `50MB` 的上传流程保持原有行为，不会额外增加这次迭代的大文件提示文案
