# 20260609-5 用户手册

本次迭代为浏览器全屏按钮补充了一条独立的新手引导流程，用于帮助用户理解全屏模式下左右菜单会自动收起。

- 当当前浏览器第一次点击输入框左上角的 `全屏` 按钮，且页面已成功进入浏览器全屏时，才会自动触发这条引导
- 引导开始后会先保持全屏效果，并高亮左侧 `展开菜单` 按钮约 `2` 秒
- 左右两步高亮会根据当前浅色或深色模式切换更有对比度的描边和光晕，方便第一时间注意到目标按钮
- 随后引导会自动切到右侧 `展开右侧栏` 按钮，并提示 `全屏状态时会自动收起左右菜单。`
- 最后一步会显示一个 `完成` 按钮；点击后关闭这条引导遮罩并恢复页面正常交互
- 引导展示期间，左右侧和中间区域的其他位置都会被暗化且不可点击
- 这条引导与首次使用引导、输入框引导、蜂群引导、插件引导、备忘录引导、沙盒引导等其它新手引导相互独立，可以兼容共存
