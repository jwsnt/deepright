# 右侧 Sidebar 调整说明

## 本次变更

- 右侧 Sidebar 第一排高度调整为 `220px`，第二排高度调整为 `250px`
- 右侧 Sidebar 第二排 CLI 子任务列表容器底部新增固定 `5px` 占位留白，确保最后一个气泡不再紧贴面板底边

- 本次调整仅涉及右侧 Sidebar 局部样式，不改变原有交互流程
