# 20260614-4 用户手册

本次迭代为会话恢复增加了自动同步。

## 自动重载

- 每次切换到一个会话后，只要当前 `Agent + ChatID` 没有正在等待 SSE 响应，页面都会自动调用一次“重载当前会话”
- 首次打开页面进入默认会话时，也会按同样规则自动重载一次
- 当前会话处于结束态时，页面还会每 `30` 秒自动调用一次“重载当前会话”
- 自动重载复用现有恢复接口与 Tips 提示，成功后仍会提示 `已加载完成`

## 不触发场景

- 当前会话正在发送请求或等待 SSE 返回时，不会触发自动重载
- 当前会话没有绑定有效 Agent 时，不会触发自动重载
- 当前会话已经有一轮恢复请求在执行时，不会重复叠加新的自动重载
