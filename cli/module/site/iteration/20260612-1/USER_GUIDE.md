# 20260612-1 User Guide

## 目标

本次迭代为居中会话区增加“纯 JSON 气泡自动代码块展示”能力。

- 当单个请求气泡或响应气泡的内容只有 JSON，且可直接被识别为对象或数组时，会在最终展示时自动格式化并按 `json` 代码块渲染
- 普通 Markdown、夹杂说明文字的内容、报错内容和取消内容保持原有展示方式
- SSE 流式输出期间仍按原有实时渲染逻辑展示，避免半截 JSON 被误判；只在最终完成后切换为 JSON 代码块样式

## 交互说明

1. 在中间会话输入框发送一段仅包含 JSON 的内容，例如：

```json
{"name":"deepright","enabled":true}
```

2. 当请求气泡进入消息列表后，会自动格式化缩进并以 JSON 代码块样式展示。
3. 如果服务端 SSE 最终返回的整条响应内容也仅包含 JSON，例如：

```json
[{"id":1,"title":"demo"}]
```

4. 响应结束后，该响应气泡会从普通流式展示收敛为格式化后的 JSON 代码块样式。

## 说明

- 纯 JSON 识别仅针对单个气泡全文内容，不会截取正文中的局部 JSON 片段
- 当前仅识别可直接 `JSON.parse` 成功，且顶层为对象或数组的内容；渲染时会统一按两空格缩进重新格式化
- 该改动只影响 `site` 前端消息渲染层，不改动 SSE 协议、消息存储结构和复制内容
- 更完整说明请继续参考上级手册 `../../USER_GUIDE.md`
