# Site 迭代 20260520-2 使用手册

## 变更说明

本次迭代补充了 SSE/HTML 响应中表格的可读性约束，重点解决“位置”“路径”“行号范围”等列在窄容器中被挤压成竖排的问题。

## 表格渲染规则

- SSE 或 HTML 响应中的表格统一采用“按内容撑开 + 外层横向滚动”的渲染策略，不再强制压缩到消息气泡宽度内
- Markdown 表格和原始 HTML 表格使用同一套展示规则
- `位置`、`路径`、`行号`、`范围`、`Location`、`Path`、`Line`、`Range` 等定位类列默认不换行，优先保持横向阅读
- 普通文本仍可自然换行，但表格单元格不会继承会导致按字符强制断开的样式

## 使用效果

- 当表格总宽度超过消息气泡宽度时，页面会出现横向滚动，而不是压缩关键列
- 在 SSE 流式更新和最终完成态下，表格列宽策略保持一致，不会在结束后突然塌陷或错位
- 包含长路径、长文件名、长代码片段的表格仍可阅读，尤其是定位类列不会再显示成单字竖排
