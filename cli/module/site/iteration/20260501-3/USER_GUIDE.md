# 20260501-3 使用手册

## 简介

本迭代为右侧 CLI 子面板的 SSE 响应气泡补充了悬浮复制入口，可直接把当前气泡中的响应内容带入现有 `CMD` 浮层。

## 功能说明

### CLI 子气泡复制入口

- 鼠标悬停在右侧 CLI 子面板的任意一个响应气泡上时，会以整个独立气泡作为悬停判定区域，并在气泡左上角显示一个 `5x5` 的闪光复制小图标
- 每个气泡都有独立的小图标和独立的复制内容，互不影响
- 同一组独立气泡之间的垂直间隔为 `3px`
- 该图标仅在右侧 CLI 子面板中出现，不影响中间主对话区气泡

### 点击后的联动行为

- 点击小图标后，会先将当前气泡内的 SSE 响应内容复制到系统剪贴板
- 如果该响应外层由 Markdown 的三反引号代码块包裹，复制时会自动去掉外层包裹，只保留内部文本内容
- 随后自动展开现有的 `CMD` 浮层，并把刚复制的命令填入输入框
- 输入框会自动获得焦点，光标定位到命令末尾，便于继续编辑或直接执行

### 提示反馈

- 复制成功后，会复用左侧虚拟文件系统的 `Tips` 位置显示红字提示：`已复制到粘贴板`
- 后续执行流程仍沿用现有 `CMD` 浮层的二次确认与执行逻辑
