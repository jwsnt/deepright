# Site 迭代 20260512-1 使用手册

## 本次新增

- 左侧虚拟文件系统每 `30` 秒轮询一次 `/skills_warning`
- 错误 `SKILL.md` 所在整条路径高频高亮闪动
- 错误 `SKILL.md` 后显示高频高闪感叹号图标
- 点击感叹号后，在左侧 Sidebar 分域内弹出错误原因浮层

## 展示规则

- 如果某个 `SKILL.md` 解析失败，则：
  - 当前目录到该文件的路径链路都会高亮闪动
  - 文件名会高亮
  - 文件尾部出现红色感叹号按钮
- 点击感叹号后可查看：
  - 错误文件绝对路径
  - 解析失败原因

## 交互说明

- 浮层只在左侧 Sidebar 分域内显示
- 未显示时彻底失活，不会拦截中间会话区或右侧 Sidebar 的点击
- 点击浮层外部区域会自动关闭

## 数据来源

- 默认轮询 `GET /skills_warning`
- 后端下一轮扫描修复后，前端在下一次 30 秒轮询时自动移除高亮和感叹号

更完整说明请参考上级手册 `../../USER_GUIDE.md`。
