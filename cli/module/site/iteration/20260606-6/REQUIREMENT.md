### 需求介绍
+ 居中对话框中双击链接时原本会查看是否存在文件，如果有则展示点击预览的小气泡，这个气泡展示名改为预览，功能相同
    + 是否展示预览的条件为：该文件在文件系统存在，仅可预览纯文本、MARKDOWN、图片、HTML、PDF（以文件名判断）
        + 如果是相对路径，只判断是非为
            + skills目录下，如skills、skills/a
            + tmp目录下，如tmp、tmp/a
            + SOUL.md或USER.md
        + 使用当前Agent的工作目录作为路径前缀来判断，比如/tmp/A，使用$Agent工作目录/tmp/A
    + file:///路径的文件绝对路径也需要强调
+ 在这个气泡右侧增加一个平行小气泡，展示名叫下载文件，点击后使用浏览器下载该文件
    + 是否展示下载文件的条件为：该文件在文件系统存在
        + 如果是相对路径，只判断是非为
            + skills目录下，如skills、skills/a
            + tmp目录下，如tmp、tmp/a
            + SOUL.md或USER.md
        + 使用当前Agent的工作目录作为路径前缀来判断，比如/tmp/A，使用$Agent工作目录/tmp/A
    + file:///路径的文件绝对路径也需要强调
+ 下载小气泡右侧增加一个平行小气泡，展示名叫打开目录，点击后打开该文件所在的目录
    + 是否展示打开目标的条件为：该目录在文件系统存在
        + 如果是相对路径，只判断是非为
            + skills目录下，如skills、skills/a
            + tmp目录下，如tmp、tmp/a
            + SOUL.md或USER.md
        + 使用当前Agent的工作目录作为路径前缀来判断，比如/tmp/A，使用$Agent工作目录/tmp/A
    + file:///路径的文件绝对路径也需要强调
+ 居中对话框渲染SSD响应时，识别所有HTMl超链接（http或https），并使用蓝色字体加下划线着重强调，增加2个小气泡，一个展示名为预览，一个展示名为打开
    + 预览：虚拟文件系统预览
    + 打开：点击打开新窗口的浏览器加载
    + 技术实现补充：
        + 预览仅针对可交互网页URL，资源类文件URL不能进入预览链路
        + 资源类文件至少包括：`.js`、`.mjs`、`.cjs`、`.css`、`.less`、`.sass`、`.scss`、`.map`、`.wasm`
        + 判断资源类文件时，按URL的pathname最后一个文件名后缀判断，忽略query和hash
        + 如果识别出的超链接属于资源类文件，则仍然要保持蓝色下划线高亮，但只展示`打开`，不展示`预览`
        + 如果SSE流式响应或历史消息恢复过程中命中了资源类文件URL，也不能触发自动右侧URL预览
        + 如果当前会话已存储的右侧URL预览目标属于资源类文件，则刷新渲染时需要自动视为无效预览状态并回退
+ 居中对话框渲染SSD响应时，识别所有文件绝对路径或相对路径，并使用蓝色字体加下划线着重强调
    + file:///路径的文件绝对路径也需要强调
    + 如果是相对路径，判断是非为
        + skills目录下，如skills、skills/a
        + tmp目录下，如tmp、tmp/a
        + SOUL.md或USER.md
        + 使用当前Agent的工作目录作为路径前缀来判断，比如/tmp/A，使用$Agent工作目录/tmp/A
    +允许行内code参与路径高亮
+ 为虚拟文件系统中预览文件浮层右上角增加一个关闭按钮
+ 遵守双击自动框圈区域的原则：../20260419_19/REQUIREMENT.md
+ 用户发送的请求，展示到居中对话框时也需要识别以上文件路径和链接
+ 提取规则：
    + 提前文件路径或超链接是把中文标点和尾部杂质裁掉，比如www.deepright.cn，以及...和www.deepright.cn。null. 都只提取成真正链接
    + 不要把中文误显示成链接
