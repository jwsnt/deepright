# Site 迭代 20260606-6 使用手册

## 居中对话框路径快捷操作

- 居中对话框中的用户请求气泡与 assistant SSE 响应气泡渲染时，都会自动识别其中的 `http/https` 超链接和文件系统绝对路径（含 `file:///` 路径与目录绝对路径），并以蓝色下划线链接强调展示；相对路径仅对白名单目标 `skills`、`skills/...`、`tmp`、`tmp/...`、`SOUL.md`、`USER.md` 生效。
- 双击文件系统路径时，会先按前后标点、空白、空行边界自动框选当前这段明确路径；如果双击的是路径链接，则会优先框选整段链接文本，再按条件弹出 `预览`、`下载文件`、`打开目录`。
- 双击 `http/https` 超链接时，会先自动框选整段链接文本，再弹出 `预览`、`打开` 两个小气泡；`预览` 使用当前站点的预览浮层以内嵌页面方式查看，`打开` 会新开浏览器窗口访问对应网页。
- 文件 `预览` 仅在目标真实存在且文件名后缀属于纯文本、Markdown、图片、HTML、PDF 时出现；`下载文件` 仅在文件存在时出现；`打开目录` 会在可打开目录存在时出现，如果双击目标本身就是目录，则直接对应这个目录本身；相对路径只接受 `skills`、`skills/...`、`tmp`、`tmp/...`、`SOUL.md`、`USER.md`，并会先拼接当前 Agent 工作目录再判断这些条件。
