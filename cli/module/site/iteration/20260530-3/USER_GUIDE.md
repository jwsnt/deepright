# 20260530-3 用户手册

本次迭代为设置面板中“模型与密钥”的客户化配置 `模型URL` 输入框补充了一条独立的代理安全新手引导流程。

- 当浏览器本地还没有“点击过模型URL”的记录时，第一次点击任意模型客户化配置中的 `模型URL` 输入框，不会立刻进入编辑，而是先显示引导遮罩
- 引导开始后会在设置面板内部高亮当前模型的 `模型URL` 输入框；设置中的其他区域以及页面其余部分都会被暗化且不可点击
- 引导文案会提示：`注意数据安全，谨慎使用三方代理。`
- 点击 `完成` 后会关闭这条引导，恢复设置面板正常交互；再次点击 `模型URL` 输入框才会真正进入编辑
- 这条代理安全引导只作用于模型客户化配置中的 `模型URL` 输入框，不会影响同一模型下其他补充配置项的正常使用
- 这条代理安全引导与首次使用引导、首次点击输入框引导、蜂群引导、插件引导、`SOUL.md / USER.md` 引导、右侧备忘录引导、浏览器插件重启引导、远程插件重启引导、知识库WIKI 区域引导、知识库自动整理引导、CLI 引导和 Skill 提炼引导相互独立，可以兼容共存
