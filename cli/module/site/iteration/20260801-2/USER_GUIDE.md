# 20260801-2 用户手册

音频预览浮层右上角新增“提取音频文字”图标。

虚拟文件系统在工作目录根层的 `audios` 文件夹悬停时，也会显示“提取音频文字”图标。点击后会先检查 Whisper，检查通过则打开相同的任务浮层；此入口不会自动把任何音频带入待加入队列。

- 点击图标会先检查 Whisper。未安装时会询问是否发送安装请求：按 `Esc` 或点击取消会回到当前音频预览；按 `Enter` 或点击安装会关闭预览，并向当前 Chat 发送服务端配置的安装请求。
- 首次检查或检查缓存过期时，页面会锁定并显示等待提示，避免重复操作；检查完成后会继续打开任务浮层或显示安装确认。FFmpeg 的依赖检查也使用相同的等待锁定交互。
- Whisper 可用时会打开“提取音频文字”任务浮层。音频工具图标与裁剪图标保持相同尺寸，标题不会显示 Agent ID。当前预览的音频会自动加入待创建列表；也可以点击“添加更多音频任务”中的“添加”，以与视频音频剪辑相同的选择和上传方式一次加入多个音频文件。
- 待加入队列最多保留 5 个音频文件，并以列表展示；可逐条删除。添加文件不会弹出确认框；点击“开始”或按 `Enter` 会直接提交任务并保持在浮层中。点击“关闭”或按 `Esc` 仅关闭浮层，不影响已创建任务。任务固定使用 Whisper `base` 模型。
- 任务列表显示全部历史任务，可按状态筛选，并以每页 5 条分页显示源音频路径、开始时间、状态、进度条和文字路径。进度条下方将开始时间与“文字：输出路径”排在同一行，路径过长时自动省略，不重复显示“进度：百分比”。每条任务右下角可查看实时持久化日志；排队中或执行中的任务可点击“取消”，已取消任务可“重新开始”。完成任务会在状态旁显示“复制”（复制文字文件绝对路径）和“预览”（打开文本预览浮层）。转写文本统一保存到当前 Agent 工作目录的 `whisper/`，若同名 `.txt` 已存在，系统自动加时间戳创建新文件。取消当前任务后，下一个任务会自动开始。
- 失败任务可点击“删除”，仅移除该任务记录，不会删除源音频或文字文件。
- 已完成任务左上角可勾选。勾选会在分页、状态筛选和列表自动刷新时保持；状态筛选旁随即出现“复制”和“清空”。“复制”会将所有勾选任务的文字文件绝对路径按一行一条复制到系统剪贴板，并在浮层左下角提示数量；“清空”会取消全部勾选并淡出这两个按钮。
- 日志默认收起；点击每条任务的“日志”后，浮层会自动平滑下滑到日志窗口。日志展开期间会约每 1.2 秒自动刷新，无须再次点击；收起日志后停止刷新。展开后可通过标题栏的收起图标关闭。若预览前文字文件已经被删除，任务浮层会保持打开，并在左下角提示“文字文件已删除，无法预览”。
- 从任务浮层打开完成任务的文字预览后，关闭预览会回到原任务浮层；待加入列表、状态筛选、分页、勾选和已展开日志都会保留。
- 关闭任务浮层不会取消任务。重新打开、刷新页面或重启应用后，仍可查看已保存的队列、状态、进度、日志和文字文件位置。
