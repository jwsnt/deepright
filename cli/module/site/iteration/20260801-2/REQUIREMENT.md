### 需求介绍

在音频预览浮层增加“提取文字”小图标，并提供可持续查看、管理的 Whisper 音频转文字任务浮层。

- 图标仅在当前预览文件为音频时显示，位于现有音频裁剪图标附近，并与裁剪图标保持一致的宽高；点击时先调用服务端检查 Whisper 是否已安装。
- 虚拟文件系统在当前 Agent 工作目录根层的 `audios` 文件夹悬停时，也必须显示“提取音频文字”小图标。点击后复用同一 Whisper 依赖检查和任务浮层；从此入口打开时不得自动带入任何待加入队列的音频文件。
- Whisper 缺失时，显示与 FFmpeg 一致的安装确认交互：取消或 `Esc` 关闭提示并保留音频预览；确认或 `Enter` 关闭预览并把服务端配置的安装请求发送到当前 Chat。浏览器不得自行执行安装命令。
- Whisper 或 FFmpeg 首次检查、缓存过期检查期间，页面必须显示不可交互的等待锁定层，阻止重复点击、关闭浮层及键盘快捷键，直至检查成功、失败或切换到安装确认；检查已有可用缓存时应快速结束，不影响后续交互。
- Whisper 可用时，打开不展示 Agent ID 的“提取音频文字”任务浮层。浮层展示当前 Agent 的全部转写任务：源音频文件位置、开始时间、状态、进度条、文本文件位置；不额外显示“进度：百分比”文字，开始时间与“文字：文本文件位置”合并在进度条下的同一行，超长路径省略显示；任务状态至少包括排队中、执行中、已完成、已取消和失败，并支持状态筛选和每页 5 条分页。
- 任务浮层必须提供“添加更多音频任务”中的“添加”入口，使用现有视频音频剪辑添加音频所使用的文件选择与上传样式；用户可选择一个或多个音频文件，上传到当前 Agent 工作区后加入待创建列表；不展示上传目录的说明文字。
- 待加入队列以最多 5 条的列表展示，每条可单独删除；添加文件不会弹出确认框。底部提供“关闭”和“开始”：关闭或 `Esc` 仅关闭任务浮层，不影响已创建任务；开始或 `Enter` 直接将待加入文件提交队列并保持在任务浮层内。
- 日志按钮固定在每条任务的右下角。已执行或正在执行的任务均可查看执行日志；排队中和正在执行的任务均可取消，已取消任务可重新开始；取消后界面应立即反映取消状态，且下一个排队任务可开始执行。
- 失败任务提供“删除”操作；删除后仅移除任务列表记录，不删除源音频或文字文件。
- 已完成任务在状态标签旁显示“复制”和“预览”：复制文字文件绝对路径，预览打开该文字文件的现有预览浮层。
- 日志面板默认收起；点击每条任务的日志按钮后，任务浮层内容区必须平滑下滑，使日志面板标题立即进入可视区域；日志展开期间，复用任务列表约 1.2 秒的轮询近实时刷新内容，无须再次点击日志按钮，关闭日志后停止刷新；展开时使用小型收起图标关闭。若文字文件在预览前已被删除，保留任务浮层并在左下角显示无法预览的错误提示。
- 从“提取音频文字”任务浮层打开完成任务的文字预览后，关闭该预览必须恢复原任务浮层，不得直接关闭整个浮层；恢复时保留该浮层当前的待加入列表、状态筛选、分页、勾选和已展开日志状态。
- 任务浮层关闭不取消任务；再次打开同一音频或刷新页面时，继续读取服务端持久化的任务、进度、日志和文本文件位置。
- 对完成任务的文本文件位置提供清晰展示；若可复制路径，复制结果仅作为辅助交互，不能代替路径本身。
- 每一条已完成任务的左上角均提供勾选框；勾选状态在任务浮层打开期间跨分页、筛选与列表刷新保持。至少勾选一项时，在状态筛选旁淡入“复制”和“清空”：复制将所有勾选任务的文字文件系统绝对路径以一行一条写入系统剪贴板，并在左下角提示结果；清空会移除全部勾选并淡出两个操作按钮。
- 转写完成后的文本统一保存到当前 Agent 工作目录的 `whisper/`；同名文本由服务端追加时间戳，页面展示服务端返回的最终路径。
- 所有新增确认框、任务浮层和日志视图必须纳入现有浮层域和全局键盘快捷键管理：隐藏时完全失活、同域不与其它前景浮层争夺交互、`Esc` 和 `Enter` 的行为可预测。

### 编写代码
+ 所有前端依赖资源必须随站点页面一起可访问，并在发布链路中强校验资源存在性与正确 MIME，禁止页面已引用但静态服务未实际发布的本地资源。
+ 修改前先确认服务实际读取的是哪一份运行文件；存在 src/site 与 release/site 双份静态资源时，必须先确认运行目录，再修改并同步，不能只改源码文件。
+ 所有固定定位遮罩层、引导层、确认框、弹窗、日志面板、透明点击层必须统一管理层级、显示状态与 pointer-events，按左侧 Sidebar、居中会话区、右侧 Sidebar 分域隔离。
+ 所有浮层与遮罩默认遵守“交互域隔离 + 隐藏视图彻底失活”原则；隐藏态必须同时不可见、不参与层级竞争、不拦截点击、不接收焦点、不参与键盘导航。
+ 同一交互域任一时刻只能存在一个可交互的前景浮层；打开新浮层前必须先关闭当前浮层，禁止多个浮层重叠争抢点击和层级。
+ 优先复用现有音频文件选择、FFmpeg 安装确认、文件预览和 Toast 交互，保持代码简洁且不新增外部依赖。
