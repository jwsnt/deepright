# 20260525-6 User Guide

本次迭代为首次打开站点的浏览器增加了 Agent 与模型配置的新手引导。

- 当浏览器本地还没有任何 DeepRight 相关记录时，页面会自动进入新手引导
- 第一步会高亮 `请选择 Agent` 下拉框，并提示新手可以从 `DEF_AGENT` 开始
- 选择 Agent 后，左侧栏会自动展开，并继续高亮左下角 `设置` 按钮，提示点击设置配置需要使用的模型
- 打开设置后，引导会继续提示 `模型与密钥`、`快速响应`、`深度思考`、`多模态输入`、`多模态输出`
- 多模态输出之后，还会继续高亮 `新建Agent`、左侧虚拟文件系统、虚拟文件系统中的 `新增` 与 `上传`
- 在引导进行期间，非高亮区域会被暗化且不可点击
- 最后一步点击 `完成` 后，新手引导结束，页面恢复正常交互
