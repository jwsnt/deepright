# 20260611-5 用户手册

本次迭代为“居中对话框首次识别出文件或图片 URL”补充了一条独立的新手引导。

- 当浏览器本地还没有“文件 URL 操作引导”的记录时，只要居中对话框第一次识别出可操作的文件路径或图片路径，无论来源是用户输入还是 SSE 响应，都会自动触发这条引导
- 引导触发后，会在对应 URL 位置自动展开悬浮菜单，并展示 `预览`、`下载文件`、`打开目录` 这组操作入口
- 引导会同时高亮识别出的 URL 内容区域和悬浮菜单，并暗淡其他区域；引导进行期间，其它区域不可点击
- 引导文案为 `文本文件或图片可以通过预览进行编辑。`
- 引导只提供一个 `完成` 按钮；点击后会关闭这条引导遮罩，并恢复页面正常交互
- 这条引导与首次使用引导、首次点击输入框引导、蜂群引导、插件引导、备忘录引导、沙盒引导、全屏引导、插件成功启动引导等其它新手引导相互独立，可以兼容共存
- 如果首次识别出文件或图片 URL 时，页面正处于其它新手引导中，这条引导会等待当前引导结束后再自动展示，避免相互覆盖
