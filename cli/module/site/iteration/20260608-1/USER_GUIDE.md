# 20260608-1 User Guide

本次迭代为中间输入区补充了“会话沙盒”入口，并把沙盒状态改成按 `Agent + Chat` 独立回显。

## 新增能力

- 在居中对话框输入框上方、浏览器全屏按钮左侧新增了一个同尺寸的沙盒图标
- 点击沙盒图标后，会在中间会话区弹出水平垂直居中的确认浮层
- 浮层内提供 `开启` 与 `关闭` 两个选项：
  - `开启` 时按钮高亮
  - `关闭` 时保持灰色
- 切换不同会话或不同 Agent 时，页面会通过 `/api/sandbox_status?agentId=x&chatId=y` 自动读取当前会话的沙盒状态
- 切换沙盒状态时，页面会通过 `/api/sandbox=true?agentId=x&chatId=y` 或 `/api/sandbox=false?agentId=x&chatId=y` 立即写回当前会话状态

## 交互说明

- 沙盒状态只绑定当前 `Agent + ChatId`，不会复用到其他会话
- 如果当前会话还没有绑定 Agent，沙盒按钮会保留入口，但浮层会提示先绑定 Agent
- 在切换会话、切换 Agent、删除会话时，页面会同步刷新或清理对应的沙盒状态展示
- 浮层支持点击遮罩关闭，也支持 `Esc` 关闭

## 本次同步

- 与 `proxy`、`integration` 新增的 `/api/sandbox_status` 接口保持一致
- 前端不再假设沙盒是全局开关，而是完全以当前会话绑定状态为准
