# 20260504-4 使用手册

## 目标

本次迭代用于统一设置浮层与扇形菜单插件浮层的展示规则：

- 点击左下角 `设置` 后，浮层改为在中间会话区水平垂直居中展示
- 设置浮层使用与扇形菜单插件浮层一致的背景模糊效果
- 固定定位的遮罩层、确认框、弹窗继续按左侧 Sidebar、中间会话区、右侧 Sidebar 分域管理

## 页面行为

- 设置浮层不再跨区域覆盖整个左侧和中间内容，而是只在中间会话区打开
- 浮层打开后，左右 Sidebar 的可操作控件不会被设置浮层误遮挡
- 设置浮层的打开动画、面板圆角、边框和阴影与插件浮层保持同一套视觉风格
- 小屏宽度下，设置浮层会跟随中间区域宽度自适应收缩，避免超出可视范围

## 浮层规则

- 设置浮层现在属于中间会话区的 overlay 域
- 未激活时保持 `pointer-events:none`，不会拦截底层点击
- 打开设置浮层时，会主动关闭其他中间域浮层，避免多个中心弹层同时叠加
- 点击设置浮层外空白区域仍会直接关闭
