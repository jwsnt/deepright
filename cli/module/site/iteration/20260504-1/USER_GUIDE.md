# 20260504-1 使用手册

## 目标

本次迭代更新了左上角快捷入口的交互方式：

- 在 `新会话` 按钮右侧新增即时通讯图标
- 点击后展开扇形菜单
- 菜单项从 `/api/plugins/meta` 动态获取
- 展开时对被遮挡区域做模糊处理

## 页面行为

- 即时通讯入口紧贴 `新会话` 按钮右侧
- `新会话` 按钮会根据右侧入口自动让出空间
- 扇形菜单在浅色和深色模式下都会切换为对应视觉样式
- 菜单项数量不是写死的，而是根据 `/api/plugins/meta` 返回数组长度动态生成
- 每个菜单项的展示名称来自返回元素中的 `name`
- 如果没有插件数据，即时通讯入口保持禁用态，不展开菜单

## 数据来源

接口：

```text
GET /api/plugins/meta
```

返回示例：

```json
{
  "status": 0,
  "data": [
    {
      "name": "飞书",
      "param": ["appId", "appSecret"]
    }
  ]
}
```

说明：

- `site` 只消费 `name` 来展示扇形菜单文字
- 其余字段会保留给后续插件接入流程使用
- 接口由 `proxy` / `integration` 提供

## 模糊规则

扇形菜单展开后，以下区域会进入模糊态：

- `新会话` 按钮
- `最近` 标题
- 左侧会话列表

收起菜单后会恢复原始清晰状态。
