### 需求介绍
+ 左侧 Sidebar 的“最近”标题栏右侧、插件入口上方增加一个无文字的“恢复历史会话”小图标；图标须有可访问名称与悬浮提示。
+ 点击图标后，在中间会话区域水平、垂直居中显示恢复会话浮层，并复用现有浮层的遮罩、互斥打开、关闭按钮、点击遮罩关闭和焦点层级行为；暖色系使用暖橙/米白配色，冷色系使用蓝青/深蓝配色。
+ 浮层列表固定为两列：第一列显示会话 ID 及其恢复小图标，第二列显示该会话最后一次成功回答所对应的用户提问。会话 ID 与提问均须单行截断，并提供完整文本提示。
+ 列表由服务端分页提供，每页最多展示 10 条，提供上一页、下一页和当前页码；当前左侧“最近”会话列表中已展示的 `chatId` 必须作为排除条件传给服务端，因此分页结果不得包含这些会话。
+ 点击某条恢复小图标时：
    + 若该会话已经在左侧列表中，直接切换到该会话；否则在不超过既有 10 个本地会话上限的前提下创建该 `chatId` 的本地壳会话。
    + 新会话继承服务端返回的 Agent 绑定和最后提问标题，随后复用既有冷历史/`/api/restore` 恢复链路加载完整会话；不得复制、重放或新造一套消息恢复协议。
    + 恢复成功后关闭浮层；达到本地会话上限时保持既有上限提示，不创建会话。
+ 前端请求、翻页、恢复与关闭必须处理网络失败、非 JSON 返回、乱序响应和正在加载状态；每次打开浮层默认回到第一页。
