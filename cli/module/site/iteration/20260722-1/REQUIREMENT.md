### 需求介绍
+ 在居中“备忘录明细预览”和“备忘录元数据预览”浮层标题右侧操作区增加无文字的“运行”小图标；图标必须与现有编辑、删除、关闭小图标的尺寸、热区、间距、主题适配、hover/focus 样式和 aria 文案对齐。运行图标位于编辑图标之前。
+ 运行不是直接执行任务。确认后仅创建一条执行时间为服务端当前时间、状态为 `待执行`（`started = 0`）的新任务明细，由现有后续轮询按既有规则启动；页面不得等待任务实际启动或完成。
+ 备忘录明细预览：
    + 仅当明细状态为 `待执行`、`无需启动` 或 `已完成` 时展示并允许点击运行图标；状态为 `已启动` 时不得展示运行图标，也不得通过任何前端路径触发运行请求。
    + 点击后先展示二次确认浮层，标题固定为“运行备忘录”，说明明确该操作会创建一条新的待执行任务明细，并提供“复用原会话”和“不复用原会话”两个明确选项，以及取消、确认操作；默认选择“不复用原会话”。
    + 确认复用时，新明细继承源明细的 `chatId`；确认不复用时，新明细的 `chatId` 为空，由后续执行器按现有规则生成独立会话。取消不得发起请求或修改页面数据。
+ 备忘录元数据预览：
    + 对所有实际展示的元数据提供运行图标；点击后使用同一二次确认浮层和默认“不复用原会话”规则。复用时继承元数据保存的 `chatId`，不复用时新明细 `chatId` 为空。
    + 创建的新明细必须关联当前元数据，且不受该元数据的 Cron 或标准周期限制；它仅创建这一条当前时间的明细，不得修改元数据、周期配置或已有明细。
+ 确认提交后，页面必须展示全局不可交互的创建进度锁定层，并禁用当前浮层全部操作，直至创建接口返回成功或失败。锁定期间不得被点击遮罩、Esc、切换浮层或其他页面动作中断；锁定只等待“明细已创建”的接口响应，不等待轮询实际执行或完成。
+ 创建成功后关闭锁定层，提示固定为“已创建，等待执行”，刷新任务明细和元数据视图；创建失败后关闭锁定层，保留当前预览及确认前的状态，并展示服务端错误。不得因刷新造成正在展示的预览异常关闭或切换。
+ 兼容边界：
    + 新明细继承源任务的 `metaId`、Agent、模型、Thinking、校验、SWARM、内容和响应结构；不得复制 `id`、执行状态、执行结果或完成时间。
    + 创建出的明细仍必须通过现有执行器的 Agent 暂停和模型可用性等运行门禁；页面不得绕过或前置标记为“已启动”。
    + 保持现有备忘录预览的 `500ms` 悬停、编辑、删除、Esc、overlay 域和新手引导语义。编辑态、保存态、删除态、已有全局锁定态或确认浮层展示期间不得再触发运行入口；二次确认与创建锁定期间不得允许重复提交。

### 编写代码
+ 以现有site页面技术栈编写以上代码，要求：
    + 在../../index.html中按现有HTML/CSS/JavaScript组织方式实现
    + 不引入新的构建流程和额外运行时依赖
    + 在 `../../index.html` 复用 `rsMetaCenterPreview` 标题操作区、现有确认浮层、全局进度锁定层、备忘录明细缓存、`scheduleRefreshCronViews()`、VFS Tips 与 cron 请求链路；不得为运行功能再创建独立预览、独立遮罩或并行刷新机制。
    + 运行确认的选项、源类型、源 ID、当前选择和提交中状态仅保存在页面运行时；所有关闭、来源切换、Agent 切换、浮层销毁和请求完成路径都必须清理临时状态，禁止写入 chat payload、`saveChats()`、`localStorage` 或 URL。
    + 请求前以当前预览的 `id`、`metaId`、`agentId` 和状态重新构造参数；不得从展示文本、过期悬停缓存或客户端时间推导创建字段。最终可运行性、继承字段和创建结果均以服务端响应为准。
    + 请求期间必须防抖并处理非 JSON、网络错误、取消和乱序返回；仅与当前提交标识匹配的最新响应可以解除锁定、刷新列表或显示结果。
    + 为明细三种允许状态、已启动禁用、元数据入口、两种会话选择、取消、重复点击、成功刷新、失败恢复和锁定期间的交互阻断补充自动化测试。
    + 能用现有开源包和浏览器能力的就不要重复造轮子
+ 最小范围更新
