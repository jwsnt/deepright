# 20260504-6 使用手册

## 目标

本次迭代为扇形菜单插件浮层补充“启动前更新配置”的完整链路：

- 点击浮层主按钮后，先更新插件 `meta` 配置
- 配置更新成功后，立即启动对应插件
- 启动结果无论成功还是失败，都会在 `2` 秒后自动切换到日志查看

## 页面行为

- 插件浮层底部主按钮由 `重启` 调整为 `启动`
- 点击 `启动` 时，会读取当前浮层中的：
  - `复用当前会话`
  - 当前选择模型
  - Thinking 开关
  - 所有参数输入框内容
- 前端先请求 `/api/plugins/config`
- 配置成功后继续请求 `/api/plugins/start`

## 结果反馈

- 启动成功：
  - 左侧 Tips 提示 `插件名 启动成功`
  - 当前插件浮层进入 `2` 秒锁定态，参数区、日志按钮、关闭按钮、取消按钮、右上角关闭按钮、遮罩点击和 `Esc` 都会被禁用
  - 延迟 `2` 秒后自动切到日志流查看区
- 启动失败：
  - 左侧 Tips 提示 `插件名 启动失败`
  - 当前插件浮层同样会进入 `2` 秒锁定态，避免在自动跳转日志前继续误操作
  - 延迟 `2` 秒后自动切到日志流查看区
  - 日志区会补一条红色错误消息，直接展示失败原因

## 日志联动

- 自动跳转到日志区后，会继续通过 `/api/plugins/log?name=插件key` 读取 SSE 日志
- 延迟期间会显示锁定遮罩和进度条，沿用居中会话区内的分域遮罩规则，不会跨到左右 Sidebar 拦截操作
- `2` 秒结束后，参数区到日志区仍沿用现有浮层视图切换动画和渐变规则
- 点击 `返回` 后，仍可退回参数输入区

## 关闭规则

- 普通状态下，点击 `取消`、遮罩空白区域、或按 `Esc`，都会关闭浮层
- 锁定态的 `2` 秒延迟期间，上述关闭入口会被统一拦截，直到自动切到日志区后才恢复
- 关闭浮层时，会一并清理尚未触发的自动跳日志定时器
