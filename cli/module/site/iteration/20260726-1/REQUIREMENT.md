### 需求介绍
+ 音频预览浮层标题栏右侧、关闭按钮左侧新增裁剪图标；仅在预览音频时显示。点击图标后立即进入裁剪模式。
+ 裁剪模式以两个可拖动的起止时间手柄选择保留区间。两个时间点必须吸附到 `0.5` 秒，且不得超出媒体总时长；不得设置额外的最短时长业务限制。
+ 裁剪模式中应明确展示起始时间、结束时间和选中时长，并保留原有播放、暂停、进度和音量控制，便于试听选区。暖色主题的控件使用暖色系；冷色主题下裁剪图标、时间手柄、播放进度、音量及其悬停、焦点和选中状态均必须使用冷色系，并保持足够对比度。取消裁剪或关闭浮层不得修改原音频。
+ 点击“保存为新音频”后先显示文件名输入框，默认名称使用原文件名加 `_trim_时间戳.wav` 的规则；文件名仅可修改名称，不得包含路径。确认后才生成新文件。新文件必须是独立的 WAV 音频，固定保存到当前 Agent 工作目录的 `audios/` 目录；`audios` 缺失时由服务端创建。原文件的内容、名称和路径均不得被覆盖或改写。
+ 页面应在保存成功后刷新虚拟文件列表，复制服务端返回的绝对路径到系统剪贴板，并明确提示复制结果。浏览器无法解码源音频、媒体时长不可用或保存失败时，应保留原预览和裁剪选择并展示明确错误提示。

### 编写代码
+ 复用 `/api/media_preview` 读取当前 Agent 工作目录中的源音频，不在页面读取本机文件路径、不构造 `file://` 链接，也不得下载并覆盖原文件。
+ 使用浏览器 Web Audio API 解码与裁剪：起止样本位置由已吸附的 `0.5` 秒时间点计算，导出为 PCM WAV；通过受限 `/api/agent/audio` 以 Base64 二进制内容保存为 `audios/<带裁剪标识和时间戳的文件名>.wav`。
+ 保存请求必须使用当前预览所属 Agent 的 ID 和固定的 `audios/` 工作目录相对路径；不得新增浏览器持久化字段、第三方依赖或页面外的媒体处理进程。
+ 最小范围更新。
