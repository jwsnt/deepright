# Site 迭代手册（20260726-1）

## 音频裁剪

在音频预览浮层的右上角，关闭按钮左侧新增了裁剪图标。点击图标会立即进入裁剪模式，不会立即生成或修改任何文件。

- 使用“开始”和“结束”两个时间手柄选择需要保留的片段。手柄按 `0.5` 秒吸附，并同步显示开始、结束和选中时长。
- 裁剪模式仍可使用播放器的播放、暂停、进度和音量控制；播放到选区末尾会停止并回到选区起点，便于试听。暖色主题使用暖色控件，冷色主题下裁剪图标、时间手柄、播放进度和音量均会使用冷色控件。
- 点击“保存为新音频”后，先输入文件名，默认值使用带 `_trim` 和时间戳的命名规则。浏览器将选区导出为 WAV，并固定保存到当前 Agent 工作目录的 `audios/` 下。`audios` 不存在时会自动创建；成功时文件列表会刷新，页面会将新文件绝对路径复制到系统剪贴板并提示结果。
- 取消裁剪、关闭预览或保存失败均不会改动原音频。没有额外的最短时长限制；实际可选范围受音频总时长和 `0.5` 秒时间精度约束。

## 浏览器限制

裁剪需要浏览器能解码源音频的实际编码。若浏览器只可以展示文件但不能解码，或尚未获得媒体时长，页面会显示错误提示并保留预览与当前选择；此时不会生成半成品文件。
