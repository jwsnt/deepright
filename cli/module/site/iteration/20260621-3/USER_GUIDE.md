# 20260621-3 用户手册

本次迭代为待发送消息队列增加了“插入上报”能力。

## 行为说明

- 待发送列表里每条消息都在 `编辑` 按钮左侧新增了一个 `插入` 小图标
- 点击后会调用 `/api/message_insert/add`，并用当前时间戳作为 `tid`
- 已插入的待发送消息会持续高亮，按钮切换成进行中图标
- 页面不再轮询 `/api/message_insert/status`；单个会话同时最多保留 `5` 条插入中的消息
- 当收到 SSE 响应报文中 `metadata.__PROCESS__ = rag_insert` 且 `metadata.__TID__` 命中时，这条消息会立刻从待发送列表移除
- 同时，居中会话里会立即补出一条同内容的用户请求气泡，位置在本轮原始请求气泡之后、等待中的 SSE 响应气泡之前
- 这条补出的用户请求气泡会带一次插入入场动画，只在第一次插入到当前会话时播放，不会因为切换会话或后续重渲染反复闪动
- 已插入的待发送消息如果再次编辑，页面会复用同一个 `tid` 重新调用 `/api/message_insert/add` 覆盖后端内容
- 如果自动发送轮到这条消息但它还没被上游消费，页面会先 best-effort 调用 `/api/message_insert/del`，然后继续自动发送

## 接口示例

```json
POST /api/message_insert/add
{
  "agentId": "agent-a",
  "chatId": "chat-001",
  "tid": 1718966400000,
  "message": "这是一条待发送消息"
}
```
