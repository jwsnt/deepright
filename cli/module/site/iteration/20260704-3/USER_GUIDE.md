# 20260704-3 使用说明

## 变更简介

本次迭代补充了右侧边栏手动 `CMD` 的 URL 快捷打开能力：

- 当输入内容在去除首尾空白后仅为单个 `http/https` URL 时，确认执行后不会再按本机系统命令处理
- 页面会直接将这个 URL 作为新页面打开
- 只有整段输入仅为 URL 时才会触发；普通命令或混合文本仍保持原有执行方式

## 使用方式

1. 打开一个会话，并确保当前会话已经绑定 `Agent`
2. 在右侧边栏打开 `CMD` 面板
3. 输入一个完整的 `http://` 或 `https://` URL
4. 点击 `执行` 并确认后，页面会直接打开这个链接对应的新页面

## 规则说明

- 仅支持“输入内容本身就是一个 URL”的场景
- URL 前后的空白会被自动忽略
- 如果 URL 后面还带有其他命令内容、参数或额外文本，则不会触发快捷打开，仍按原有系统命令执行逻辑处理
