# 20260614-2 USER_GUIDE

本次迭代为设置面板中的 Agent 导入/导出入口补充了一条独立的新手引导。

## 触发方式

- 在设置面板里，首次点击 `导入 Agent` 或 `导出 Agent` 按钮时触发
- 触发后不会立刻执行真实导入或导出，而是先播放引导

## 引导流程

- 引导会先高亮 `导出 Agent` 按钮
- 约 `2` 秒后自动切换为高亮 `导入 Agent` 按钮
- 引导文案为 `导出或导入 Agent 配置，方便备份与协作。`
- 点击 `完成` 后关闭遮罩，恢复正常交互

## 兼容说明

- 如果当前没有已选中的 Agent，原本隐藏的 `导出 Agent` 按钮会在引导期间临时显示
- 引导结束后，如果导出按钮原本是隐藏的，会自动恢复隐藏
- 这条引导和首次使用、输入框、蜂群等其它新手引导相互独立
