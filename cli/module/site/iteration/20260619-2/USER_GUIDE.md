# 20260619-2 用户手册

本次迭代为居中输入框的“待处理消息”增加了一条独立的新手引导。

- 当当前会话还在响应中、并且浏览器本地还没有“加入过待处理消息列表”的记录时，第一次把消息加入待处理列表会触发这条引导
- 引导会自动展开输入框右上角的待处理列表，并依次高亮整个列表面板、第一条待处理消息、编辑按钮、删除按钮和拖动手柄
- 第一步会提示“待处理消息会在当前会话结束后自动发送”
- 后续步骤会分别提示可以在发送前编辑内容、从队列删除内容、以及通过拖动调整发送顺序
- 引导期间其它区域会被暗化且不可点击，最后一步点击 `完成` 后恢复正常交互
- 为了保证引导过程稳定，首次待处理消息引导开始前或等待开始期间，这条首个待处理消息不会被自动发送；引导结束后如果当前会话已经空闲，会立即恢复正常排队发送
- 这条引导与首次使用引导、首次点击输入框引导、蜂群引导、插件引导等其它新手引导相互独立；如果当时已有其它引导正在展示，它会等待前一个引导结束后再尝试开始
