# 备忘录保存

## 使用方式

1. 在备忘录输入内容, 选择模型、Thinking、时间和周期
2. 点击信封保存按钮
3. 如果输入框为空, 提示"请输入备忘录内容"; 如果未选模型且当前会话也无模型, 提示"请先选择模型"
4. 右下角弹出确认浮层(250px, 右对齐), 按顺序显示:
   - 模型(未选则使用当前会话模型)
   - 周期
   - 思考方式
   - 开始时间
5. 确认后点击「保存」提交, 点击「取消」或浮层外区域收起
6. 配置改动时自动收起, 再次点击保存以最新数据重新展开

## 反馈

- 成功: VFS 底部浮层提示"备忘录已保存", 输入框重置
- 失败: VFS 底部浮层提示失败原因(红色)
