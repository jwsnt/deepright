# 20260526-11 用户手册

本次迭代为左侧边栏 `最近` 标题右侧的小灯泡按钮补充了一条独立的新手引导流程。

- 当本地还没有“点击过最近区小灯泡按钮”的记录时，第一次点击左侧 `最近` 右侧的小灯泡按钮，不会立刻打开安装建议弹层，而是先显示引导遮罩
- 引导开始后会高亮小灯泡按钮，并暗化其他区域，其他控件不可点击
- 引导文案会提示：如果缺失重要的本地应用，会提示进行安装
- 点击 `完成` 后会关闭这条引导，恢复正常交互；再次点击小灯泡按钮才会真正打开安装建议弹层
- 这条引导仅作用于左侧 `最近` 区域的小灯泡按钮，不会影响现有的浏览器插件重启引导、远程插件重启引导和其他首次点击引导
- 这条小灯泡引导与首次使用引导、首次点击输入框引导、蜂群引导、插件引导、`SOUL.md / USER.md` 引导、右侧备忘录引导、知识库WIKI 引导、浏览器插件重启引导、远程插件重启引导、CLI 引导和 Skill 提炼引导相互独立，可以兼容共存
