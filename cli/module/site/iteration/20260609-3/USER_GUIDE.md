# 20260609-3 用户手册

本次迭代为右侧备忘录任务明细补充了一条独立的新手引导流程，用于帮助用户理解已完成任务的状态展示、预览和结果查看方式。

- 当右侧备忘录任务明细第一次出现 `已完成` 状态、且当前任务明细列表总数正好只有 `1` 条时，页面才会自动触发该引导；这里的总数会把其它状态的任务也一并算入，且当前浏览器本地还不能已有这条引导记录
- 第一步会高亮唯一一条已完成任务明细，并提示 `备忘录执行状态在此展示。`
- 第二步会模拟鼠标悬停这条已完成任务明细，并继续高亮这条任务行，提示 `悬停并查看备忘录任务明细。`
- 第三步会切到中间会话区高亮该条任务的预览浮层，并提示 `备忘录任务明展示在此。`
- 第四步会高亮这条任务的放大镜按钮，并提示 `查看备忘录任务结果。`
- 第五步与第六步会进入两段无文案过程动画，分别模拟点击放大镜按钮唤起右下角确认浮层、再点击 `查看` 恢复对应备忘录任务的会话内容
- 最后一步会切换到中间会话区高亮提示 `备忘录任务展示在此。`
- 如果这条已完成任务当前不在可见区域，引导会先自动滚动到这条任务，再继续后续步骤
- 这条引导与首次使用引导、输入框引导、备忘录主引导、首个备忘录任务引导、插件引导、Skill 引导等其它新手引导相互独立，可以兼容共存
