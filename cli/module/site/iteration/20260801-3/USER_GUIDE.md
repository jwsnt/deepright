# 20260801-3 用户手册

虚拟文件系统工作目录根层的 `images` 文件夹在悬停时会显示“提取图片主体”放大镜图标；图片预览浮层工具栏也提供同尺寸入口。两处入口使用与“提取音频文字”相同的任务浮层样式。

- 从图片预览打开时，当前图片会先加入待创建列表；从 `images` 文件夹打开时，待创建列表为空。
- 点击入口会先检查 `rembg`。检查中页面会暂时锁定，避免重复操作；未安装时会显示安装确认。按 `Esc` 或点击取消会关闭确认，按 `Enter` 或点击安装会将服务端配置的安装请求发送到当前 Chat。页面不会直接安装或运行 rembg。
- 检查通过后打开“提取图片主体”浮层。可从“添加更多图片任务”选择并上传更多图片；非图片文件不会加入待创建列表。待加入队列最多 5 个文件，可逐条删除。
- 每条待加入图片可单独选择模型，默认 `u2net`（通用）；下拉框仅显示“通用、人物、通用高质量、轻量快速、服饰、轻量通用、动漫”等中文用途名称。模型下拉框与“边缘优化”开关在同一行显示。可按需要开启边缘优化，它会改善毛发、半透明和复杂边缘，但处理时间更长。选择后浮层左下会显示与音频任务相同颜色、并与右侧按钮居中对齐的用途说明。
- 模型和 alpha matting 会随该任务保存。所选模型尚未下载时，任务开始后 rembg 会自动下载，实时下载进度或错误可在任务日志中查看。
- 点击“开始”或按 `Enter` 创建任务；点击“关闭”或按 `Esc` 仅关闭浮层。任务会继续在后台执行。
- 列表支持按排队中、执行中、已完成、已取消、失败筛选，每页显示 5 条。每条显示源图片、开始时间、状态、进度与输出图片位置。
- 排队中或执行中的任务可取消；已取消任务可重新开始；失败任务可删除任务记录。完成任务可复制输出图片的绝对路径或直接预览图片。
- 点击“日志”会展开并滚动到执行日志；日志展开期间约每 1.2 秒刷新。关闭图片预览后会回到原任务浮层，并保留待加入列表、筛选、分页和已展开日志。

成功图片保存于当前 Agent 工作目录的 `images/`，默认命名为 `<源文件名>_subject.png`；同名时系统会追加时间戳，已有图片不会被覆盖。
