# 20260608-3 User Guide

本次迭代为 macOS App 启动流程补充了居中的透明 Logo 动画，并保持原有浏览器异步打开逻辑不变。

## 新增能力

- 点击 `integration.app` 启动时，会先异步执行原有浏览器打开逻辑
- 同时会在屏幕中央显示基于 `site/icon.png` 的启动 Logo
- Logo 动画表现为从小到大放大，并在动画结束后消失
- 动画总时长约 `5` 秒
- Logo 图片默认复用应用资源目录中的 `site/icon.png`
- 启动浮层仅显示 Logo 图本体，不再显示任何文字

## CLI

为了满足“子模块复用 + CLI 收口”，同一套启动动画也可以单独执行：

```bash
./integration splash
```

可选参数：

- `--logo PATH`：覆盖默认 Logo 图片路径
- `--duration 5s`：覆盖动画时长
- `--async`：异步拉起动画后立即返回

## 交互说明

- 启动动画只在 macOS 下生效
- 浏览器打开与 Logo 动画并行执行，互不阻塞
- Logo 动画在屏幕中央水平、垂直居中显示
- Logo 动画结束后自动关闭，不需要手工操作

## 本次同步

- 实现保持 `integration` 主二进制收口，不新增独立启动程序
- 启动动画以可复用子模块形式实现，供 App 启动流程和 CLI 共用
