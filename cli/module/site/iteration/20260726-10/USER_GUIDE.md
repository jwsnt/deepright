# 视频编辑依赖检查使用手册

在视频预览浮层点击“编辑视频”时，页面会先检查服务端是否同时可用 `ffmpeg` 与 `ffprobe`。检查通过才会进入既有的视频切分界面。

如果缺少任一依赖，页面会在当前预览上显示安装确认。选择取消或按 `Esc` 后，预览保持打开且不会进入编辑；选择安装或按 `Enter` 后，预览关闭，主应用 `config/config.json.ffmpeg.install` 中配置的文本会自动作为用户消息发送到当前 Chat。页面不显示这些快捷键提示。

配置错误、检查请求失败或当前 Chat 不能发送时，会显示可理解的错误；页面不会自行检查本机路径、执行安装命令或转码视频。
