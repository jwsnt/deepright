# Site 迭代手册（20260725-3）

## 视频坐标提取

视频预览浮层标题栏新增坐标图标。点击后会在预览浮层中央要求填写坐标数量，默认是 `1`；可按 `Enter` 或点击“确认”开始，也可按 `Esc` 或点击“取消”放弃。

- 坐标按视频原始尺寸计算，采用 Canvas / FFmpeg 的左上角 `(0,0)`、Y 轴向下增长的坐标系；缩放显示不会影响结果。
- 开始后，预览浮层右下角会显示剩余提取次数；每点击一次视频画面，次数会减少一次。全部完成后才会复制到系统剪贴板，并显示“坐标位置已复制到系统剪贴板”。
- 单点导出示例为 `取值时画布尺寸: 宽度 1920 px, 高度 1080 px, 以左上角为原点的坐标位置: (960, 540), 使用时需要按实际画布尺寸缩放坐标`；多点导出示例为 `取值时画布尺寸: 宽度 1920 px, 高度 1080 px, 以左上角为原点的3个坐标位置: [(100, 200),(960, 540),(1500, 900)], 使用时需要按实际画布尺寸缩放坐标`。
- 多点提取时，已经点击的画面位置会保留带编号的圆形标记，方便继续定位；完成、取消、再次点击图标或关闭预览浮层都会清除标记。
- 图片预览也支持相同的多坐标提取流程。坐标以图片 Canvas 的左上角为 `(0,0)`，按原图像素尺寸导出；开始提取时会关闭切图工具，避免叠层干扰。

## 服务地址

本机打开设置时，标题旁新增服务地址图标，位于 `deviceId` 复制图标左侧。点击后会关闭设置并打开“服务地址”浮层。

- 浮层展示当前服务地址，并可在“修改服务地址”中输入新的绝对 `http` 或 `https` 地址；不支持查询串和片段。
- 保存后，新地址立即用于当前服务，并写入应用的 `config/config.json`，重启后仍然生效。
- 点击“恢复默认值”会立即将地址恢复为 `https://www.deepright.cn`，同样会保存到配置文件。
- 此入口仅在通过 `localhost`、`127.0.0.1` 或 `::1` 访问时显示；通过远程地址访问页面时不会显示，避免远程修改本机服务配置。
