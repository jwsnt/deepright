### 需求介绍
+ 视频预览浮层新增无文字的提取坐标图标，样式与现有视频取色图标一致，并提供“提取坐标”无障碍标签与悬停说明。
+ 点击图标后，在预览浮层内居中显示坐标数量输入框，默认值为 `1`；数量只能为正整数，`Esc` 或“取消”取消提取，`Enter` 或“确认”开始提取。
+ 确认后在浮层右下角展示剩余需要提取的次数，每次点击视频画面更新一次；关闭预览浮层前若未完成，不产生任何坐标结果。
+ 点击位置按视频原始像素尺寸换算，以 Canvas / FFmpeg 使用的左上角为 `(0,0)`、Y 轴向下增长的坐标系输出。单点复制格式为：`取值时画布尺寸: 宽度 xx px, 高度 xx px, 以左上角为原点的坐标位置: (x, y), 使用时需要按实际画布尺寸缩放坐标`；多点复制格式为：`取值时画布尺寸: 宽度 xx px, 高度 xx px, 以左上角为原点的n个坐标位置: [(x1, y1),...], 使用时需要按实际画布尺寸缩放坐标`。
+ 多点提取期间，在视频画面叠加已提取点位的编号标记；标记及居中输入浮层须在浅色主题使用暖色、深色主题使用冷色配色。完成或取消提取时清除全部标记。
+ 成功时显示“坐标位置已复制到系统剪贴板”，复制失败或尚未取得原始尺寸时使用现有异常 Tips；坐标提取不得改变播放进度或影响取色、播放控制。
+ 在设置浮层标题区域的现有 `deviceId` 复制图标左侧新增无文字 Host 小图标；Host 图标、`deviceId` 复制图标需沿用现有标题操作图标的尺寸、热区、主题、hover/focus 和无障碍文案。原 `deviceId` 图标右移，复制行为及新手引导定位保持不变。
+ Host 图标仅在通过 `localhost`、`127.0.0.1` 或 `::1` 访问页面时展示。本机限制应与服务端管理接口一致，远程访问入口不得显示或调用修改服务地址的能力。
+ 点击 Host 图标后，必须先关闭设置浮层，再以既有互斥居中 overlay 打开服务地址浮层；关闭、遮罩点击与 `Esc` 仍遵循现有 overlay 域和焦点语义。原连续点击“设置”标题唤起入口应移除。
+ 浮层标题由“运行时 Host”改为“服务地址”，移除“仅本次运行有效，重启后会恢复为原配置”说明及启动值展示。
+ 浮层字段文案固定为“当前服务地址”和“修改服务地址”；当前值取服务端当前生效值，输入框预填该值。地址继续只接受绝对 `http` 或 `https` URL，且不得包含查询串或片段。
+ “保存”必须使新地址立即生效，并由 Integration 与 Proxy 持久化写入各自解析出的 `config/config.json.host`；保存成功后关闭浮层。运行中更新与重启后的启动配置必须一致。
+ “恢复启动值”改为“恢复默认值”。点击后必须立即恢复并持久化为 `https://www.deepright.cn`，不依赖此前启动参数、旧配置或仅内存覆盖值；成功后当前服务地址和输入值同步刷新。
+ Integration 与 Proxy 的 `/api/host` 都只允许本机管理请求。`GET` 返回当前生效服务地址；`POST`/`PUT` 校验地址后原子地更新运行中地址及 `config/config.json.host`；`DELETE` 或 `reset=true` 将运行中地址和 `config/config.json.host` 一并恢复为默认地址。配置持久化失败时，接口必须返回可展示的失败信息，且不得报告保存成功或留下仅运行时生效的地址。
+ Integration CLI `host get`、`host set`、`host reset` 与该接口复用同一语义：`set` 持久化指定地址，`reset` 恢复默认地址；CLI 帮助和响应中的“运行时”“启动值”“仅本次”表述需同步移除。
