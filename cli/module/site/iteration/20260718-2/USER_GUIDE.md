# Site 迭代手册（20260718-2）

## 本次更新

- 设置页新增模型时，若已经存在其他保存成功的模型，密钥输入框右侧会显示复制小图标；小眼睛会自动左移，避免与复制入口重叠。
- 点击复制图标后，会展开一个轻量来源选择框，仅列出其他已保存的模型配置（不含 `deepright`），不会显示当前新增模型，也不会显示密钥内容。
- 选择来源后，API Key、模型 URL、基础模型、快速响应、深度思考、多模态输入和多模态输出会复制到当前新增模型的表单中。

## 使用说明

1. 打开设置，在“模型与密钥”区域点击“添加模型”。
2. 选择要新增的目标模型；若已有保存成功的其他模型，密钥输入框右侧会显示复制图标。
3. 点击复制图标并选择一个来源模型。
4. 页面会自动展开“客户化配置”，核对复制结果后按需要修改。
5. 点击现有“保存”按钮，才会真正保存新增模型配置。

## 兼容规则

- 目标模型支持、来源模型不支持的能力，会继续使用目标模型的默认值。
- 目标模型不支持的能力会始终保持不可编辑，即使来源模型存在对应配置也不会启用。
- `deepright` 不可作为复制来源或复制目标；新增 `deepright` 时不会出现复制入口。
- 复制不会修改来源模型，也不会自动保存当前新增模型。
