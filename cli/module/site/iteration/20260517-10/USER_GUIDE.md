# Site 迭代手册（20260517-10）

## 本次更新

- 插件浮层会根据 `/api/plugins/meta` 返回的 `scope` 动态决定是否展示 `复用当前会话`、`选择 Agent`、`模型选择`、`SWARM`、`Thinking`
- `scope` 为空数组时，上述五项会全部隐藏并失活
- `scope` 只返回部分能力时，浮层仅展示对应能力，其余配置不会再出现在界面上

## 页面行为

1. 当插件元数据里没有 `scope` 字段时，页面仍按兼容模式展示全部五项容器配置
2. 当 `scope` 为 `[]` 时，插件浮层顶部容器配置区会收起为“当前插件未开放容器配置项”
3. 当 `scope` 为 `["reuse"]`、`["agent"]` 这类有限集合时，页面只展示这些被声明支持的配置项
4. 被隐藏的配置项会同步失活，既不会响应点击，也不会在浮层里留下空白占位
5. 插件自定义 `meta` 参数区、启动/关闭/日志/取消按钮和日志视图切换行为保持不变
