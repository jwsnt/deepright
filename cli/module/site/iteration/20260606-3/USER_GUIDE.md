# Site 迭代 20260606-3 使用手册

## 浏览器插件快捷初始化入口

- 当 `browser` 插件已经处于启动状态时，左侧边栏顶部快捷插件按钮的右下方会出现一个很小的浏览器图标。
- 这个图标固定贴着快捷插件按钮右下角展示，只有 `browser` 插件处于已启动状态时才会显示；图标主体是 `3x3` 的实心荧光青绿色，并会按深浅色模式区分饱和度后做慢速闪烁。
- 点击该图标后，页面会以当前会话 ID 和当前 Agent ID 调用 `browser instance init` 来加载浏览器 CDP。
- 调用期间，整个界面都会进入锁定状态，包括左侧边栏、中间对话区和右侧边栏；界面会提示稍后会单独打开登录浏览器，这个过程可能需要等待若干分钟。
- 锁定界面的 `/api/plugins/exec` 不设置超时，前端会持续等待；等登录所有账号完成后再点击浮层里的 `完成` 按钮结束本次流程。
- `完成` 按钮不会立刻出现，而是在锁定界面显示满 30 秒后才会淡入显示。
- 点击 `完成` 按钮后，界面会立即解锁；同时页面会继续以同一组会话 ID 和 Agent ID 在后台调用 `browser instance shutdown` 来关闭浏览器 CDP。
- `browser instance shutdown` 返回成功或失败后，页面会继续给出对应结果提示，但不会再次锁定界面。
