# Site 迭代 20260502-2 使用手册

## 变更说明

在现有图片编辑器基础上，新增图形标注能力。

## 图片标注

- 保留原有橡皮擦工具
- 新增图形工具：圆、椭圆、矩形、三角形
- 支持切换描边颜色
- 支持调节线粗（边框粗细）
- 所有图形都通过鼠标拖拽起止点完成绘制
- 拖拽范围会直接决定图形大小，因此支持放大缩小标注范围

## 保存方式

- 保存方式与 `20260502-1` 保持一致
- 不覆盖原图，而是在原目录生成“原文件名 + 时间戳”的新图片
- 保存成功后，会自动复制新图片绝对路径到系统剪贴板
- 虚拟文件系统 Tips 会提示路径已保存至黏贴板
