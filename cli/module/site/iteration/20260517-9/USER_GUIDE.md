# Site 迭代手册（20260517-9）

## 本次更新

- 页面内纳入统一管理的弹窗、确认框、浮层在打开自己前，会先关闭当前已打开的同类浮层
- 左侧 Sidebar、中间会话区、右侧 Sidebar 的阻塞型浮层统一接入同一套开关链路，不再允许多个浮层同时残留可见
- 被关闭或失活的浮层会同步退出前台交互，不再继续拦截点击或与新浮层叠在一起

## 当前行为

1. 当设置、插件浮层、技能提炼浮层、文件编辑器、会话删除确认框、Agent 删除确认框、备忘录确认框、CLI 终止确认框等任一受管浮层准备打开时，页面会先关闭当前已打开的受管浮层，再展示新的浮层
2. 左侧、中间、右侧三大交互域仍保持分域层级和 pointer-events 隔离，但不会再出现多个阻塞型浮层同时停留在页面上的情况
3. 被关闭的浮层会同步失去前台层级与点击能力，避免旧浮层残留遮挡或拦截当前区域的操作
4. 提示类与状态类浮层仍保持非阻塞行为，例如 toast、hover 提示、上传中状态层，不会被这次改动误伤
