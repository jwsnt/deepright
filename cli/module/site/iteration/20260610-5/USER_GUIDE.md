# 20260610-5 用户手册

本次迭代为“首次成功创建非一次性的周期备忘录”补充了一条独立的新手引导，用来说明如何查看周期备忘录元数据、核对预览以及理解子任务与删除联动关系。

- 当浏览器本地还没有“首次周期备忘录创建引导”的记录时，第一次成功创建 `非仅一次` 的周期备忘录任务后，会自动触发这条引导
- 第一步会高亮右侧备忘录里的 `备忘录列表按钮`，提示 `点击查看备忘录元数据列表。`
- 点击第一步的 `知道了` 后，会自动切到周期备忘录元数据列表，并高亮这次刚创建成功的那条元数据，提示 `鼠标悬停查看备忘录原数据。`
- 点击第二步的 `知道了` 后，会自动展开中间会话区的元数据预览浮层，并高亮整个预览区域，提示 `核对周期性备忘录任务。`
- 点击第三步的 `知道了` 后，会把高亮切到右侧第一栏左半部分的 `任务明细列表`，提示 `周期性备忘录会定时创建子任务。`
- 点击第四步的 `知道了` 后，会回到这条周期备忘录元数据右侧的 `删除按钮`，提示 `删除周期性备忘录时也会删除子任务。`
- 最后一步点击 `完成` 后会关闭遮罩并恢复正常交互；引导期间其它区域都会被暗化且不可点击
- 这条引导与首次使用引导、右侧备忘录主引导、首个备忘录任务引导、已完成任务引导、插件引导、沙盒引导、全屏引导等其它新手引导相互独立，可以兼容共存
