# 迭代 20260717-4：备忘录保存后重置

创建备忘录时，表单不会在点击保存后立即清空，而是等待服务端确认任务已创建成功。

## 使用方式

1. 在右侧备忘录区域填写内容、执行时间、周期、模型及其他配置。
2. 点击保存，确认右下角弹窗中的任务配置。
3. 点击确认弹窗的 `保存` 后，页面显示“创建备忘录中”的全屏等待层；创建完成或失败返回前，整个页面不可操作。
4. 保存成功后，确认弹窗自动关闭，内容、开始时间、周期、模型、蜂群、Thinking、校验和“复用当前会话”等输入全部恢复为新建任务的默认状态；开始时间固定重置为保存成功时的当前时间，即使原先选择的是未来时间。
5. 在日常初始化和定时刷新中，若日历日期加上已选时间仍晚于当前时刻，则保持原值；若该时刻已到或已过，才更新为当前时间。该保护规则不影响保存成功后的强制重置。

## 保存失败时

- 内容或模型校验不通过时，不会打开确认弹窗或发起创建请求；已填写内容会保留。
- 服务端创建失败或网络异常时，确认弹窗不会关闭，时间、内容及其余配置保持不变，可修正后再次保存。
- 在确认弹窗点击 `取消` 只取消本次确认，不会清空当前草稿。
