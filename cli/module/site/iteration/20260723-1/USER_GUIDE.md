# 迭代 20260723-1：切换 Agent 时的备忘录遮罩

当前 Agent 实际切换后，右侧备忘录区域会立即显示“正在切换Agent”提示。该提示只覆盖备忘录明细与元数据区域，不会遮挡 CLI 子任务、中间会话区、左侧 Sidebar 或 Agent 切换入口。

## 遮罩范围与时长

- 遮罩覆盖左侧日历、任务明细、右侧备忘录编辑区、备忘录元数据列表以及该区域内的控制按钮；CLI 子任务保持可见和可操作。
- 被遮罩区域会模糊且不可操作，避免在旧 Agent 数据与新 Agent 数据交替时误操作。
- 每次切换固定显示 `0.5` 秒，随后自动恢复交互。

## 连续切换

- 如果在 `0.5` 秒内再次切换 Agent，页面会立即重新开始遮罩和计时。
- 页面只显示最后一次切换对应 Agent 的任务明细和元数据；较早请求即使在网络中晚到，也不会覆盖当前内容。
- 此过程不新增浏览器本地存储，也不会修改聊天、备忘录或 Agent 配置以外的既有保存操作。
