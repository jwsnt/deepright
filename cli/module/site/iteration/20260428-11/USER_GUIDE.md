# 迭代 20260428-11：输入区会话重载按钮

## 功能说明

1. 居中输入框右侧的文件夹图标上方新增一个重新加载图标
2. 点击重新加载图标后，会展开宽度为 `150px` 的确认浮层，标题居中显示“确定重载当前会话？”
3. 两个图标保持垂直对齐，尺寸和风格与现有输入区图标一致
4. 点击确认后，会按当前 Agent 和会话 ID 增量加载最后一条已知 SSE 时间之后的对话数据，并提示“已加载完成”
5. 点击取消或浮层外任意区域会自动收起浮层

## 实现说明

- 输入区右侧为纵向按钮组，上方为会话重载，下方为打开目录
- 会话重载通过 `/api/restore` 拉取当前 Agent 与会话 ID 在指定时间之后的增量记录
- 前端使用当前会话最后一次实际请求时间/恢复时间和最后一条恢复记录 ID 作为恢复游标
- 如果恢复接口返回同一轮回答的多条 `A` 增量记录，前端会按顺序合并到同一条 assistant 消息中，而不是拆成多条气泡
