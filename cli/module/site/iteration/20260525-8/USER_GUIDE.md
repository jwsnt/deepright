# 20260525-8 User Guide

本次迭代为“首次点击设置中 Agent 的蜂群小图标”增加了一条独立的新手引导流程。

- 当浏览器本地还没有“点击过蜂群开关”的记录时，第一次点击设置里 Agent 的蜂群小图标会触发蜂群引导
- 引导会依次高亮蜂群开关、蜂群 `Thinking`、蜂群模型选择、蜂群描述、蜂群确认、设置保存、设置内小蜜蜂图标和中间输入区小蜜蜂图标
- 蜂群描述步骤会提示补充 Agent 的作用、需要的输入信息和预计输出内容，帮助蜂群更准确地调用
- 设置内步骤统一挂在设置面板内部的引导层上，不会再被设置浮层自身遮住
- 当流程切换到设置内小蜜蜂图标时，会自动收起蜂群小面板，只保留 Agent 右侧的小蜜蜂图标高亮
- 当流程切换到中间输入区小蜜蜂图标时，会自动关闭设置浮层，并在中间会话区继续高亮输入区的小蜜蜂图标
- 引导期间其它区域会被暗化且不可点击；每一步通过 `知道了` 推进，最后一步点击 `完成` 后结束，并清理引导临时点亮的小蜜蜂图标状态
- 这条蜂群引导与首次使用引导、首次点击输入框引导互相独立，不会互相覆盖
