# Site 迭代 20260714-2 使用手册

## 本次更新

- 右侧边栏“正在执行的系统指令”标题栏中，`CMD` 按钮右侧新增了一个与知识库同风格的展开按钮。
- 点击该按钮后，系统指令区域会占满整个右侧边栏；再次点击会恢复为原来的上下布局。
- 该按钮只负责展开和还原，不带刷新语义。

## 使用方式

1. 打开任意会话，查看右侧边栏“正在执行的系统指令”区域。
2. 点击标题栏中 `CMD` 按钮右侧的展开按钮。
3. 系统指令区域会占满整个右侧边栏，知识库区域会暂时隐藏。
4. 再次点击同一个按钮，即可恢复为原来的上下布局。

## 页面行为

- 系统指令展开态只作用于右侧边栏，不会覆盖主页面，也不会进入浏览器原生全屏。
- 空态下同样支持展开；如果当前没有系统指令记录，空态内容会直接占满右侧边栏展示。
- 当系统指令面板已经处于展开态时，新的系统日志继续流入不会打断当前展开态。
- 展开和还原会尽量保持系统指令内容区当前滚动位置稳定，不会无故跳回顶部。

## 互斥与恢复

- 系统指令展开态与知识库 `WIKI` 展开态互斥：
  - 展开系统指令时，知识库若已展开会自动恢复常态。
  - 展开知识库时，系统指令若已展开也会自动恢复常态。
- 系统指令展开态只保存在当前页面运行时，不会写入 chat 持久化状态或浏览器本地存储。
- 切换会话后，系统指令展开态会自动恢复常态。
- 收起右侧边栏后，系统指令展开态会自动恢复常态。
- 页面刷新后，系统指令展开态默认不会保留。
