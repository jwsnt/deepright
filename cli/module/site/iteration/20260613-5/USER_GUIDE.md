# 20260613-5 用户手册

本次迭代为左侧边栏底部的“单机 / 协作”访问模式开关补充了一条独立的新手引导，用来说明协作模式的用途与边界。

- 当浏览器本地还没有任何“单机 / 协作”切换记录时，第一次点击这个开关不会立刻请求后端切换访问模式，而是先弹出这条引导
- 引导会高亮左侧边栏底部的 `协作` 按钮，并临时把按钮预览成协作模式
- 引导浮层会在中间区域展示一个浏览器地址栏示意，并以动画输入当前协作访问使用的 HTTP 地址
- 引导文案为 `协作模式允许通过浏览器进行内网团队合作，但请注意数据安全。`
- 引导期间其它区域会被暗化且不可点击；点击 `完成` 后，遮罩会关闭，按钮恢复为引导开始前的真实模式状态
- 这次引导不会真的修改当前端口的访问模式；在当前页面点完 `完成` 后，再次点击这个开关时才会执行真实切换，并留下首条切换记录
- 这条引导与首次使用引导、首次点击输入框引导、蜂群引导、插件引导、备忘录引导、沙盒引导、全屏引导等其它新手引导相互独立，可以兼容共存
