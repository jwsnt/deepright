# 20260608-4 User Guide

本次迭代为设置里的模型客户化配置补充了一条独立的新手引导，用来解释“五角星闪烁”的含义。

- 当设置面板打开后，如果本地还没有“见过闪烁客户化配置按钮”的记录，并且任意模型的 `客户化配置` 五角星正在闪烁，会自动启动这条引导
- 第一步会高亮闪烁的五角星按钮，并提示：`使用客户化配置时图标会闪烁提示。`
- 点击 `知道了` 后，会自动展开这条模型的客户化配置区域
- 第二步会高亮整块客户化配置区域，并提示：`仔细核对模型名称和服务商的URL。`
- 第二步使用 `完成` 按钮结束引导，结束后恢复正常交互
- 这条引导与首次使用引导、首次点击输入框引导、蜂群引导、插件引导、文档整理引导、知识库引导、首次点击客户化配置引导等其它引导相互独立
