# 应用安装提醒使用手册

管理员可在主应用资源目录的 `config/config.json` 中配置需要检查的应用：

```json
"install_app": {
  "interval": 60,
  "content": "请安装 $namelist",
  "linux": ["python3", "node", "curl", "wget", "git", "npm"],
  "wsl": ["python3", "node", "curl", "wget", "git", "npm"],
  "mac": ["python3", "git", "npm"]
}
```

- `interval` 的单位是分钟，决定首次检查之后的扫描间隔。
- `linux` 是普通 Linux 的检查列表，`wsl` 是 Windows 或 WSL 的检查列表，`mac` 是 macOS 的检查列表。
- 三个平台都只读取该配置对象，不支持通过 `--install_app` 追加应用。
- `content` 是发送给当前会话的请求模板。确认时，所有 `$namelist` 都会替换为待安装应用名称，以 `、` 分隔，例如 `请安装 node、npm`。

页面启动时会先在后台检查一次，之后按 `interval` 再次检查。发现缺失应用时，“最近”右侧的存储统计图标会暂时替换为闪烁的安装灯泡。点击灯泡可查看全部待安装应用并作出选择：

- 点击“取消”或按 `Esc` 关闭提示。
- 点击“确认”或按 `Enter`，页面会把替换后的请求写入当前会话并自动发送。
- 无论取消还是确认，灯泡都会在一个 `interval` 的冷却期内隐藏，原存储统计图标恢复显示；冷却结束后页面会再次检查。

确认不会直接在浏览器中安装任何软件。它只向当前会话发送配置好的安装请求，由当前 Agent 按会话权限处理。因此需先有可用的当前会话，并完成模型与密钥配置；会话忙碌、Agent 不可用或模型配置不完整时，页面会提示原因且不会发送。
