# 20260526-10 用户手册

本次迭代为远程插件浮层中的 `重启` 按钮补充了一条独立的新手引导流程，并保持它与浏览器插件重启引导及其他首次引导互不冲突。

- 当本地还没有“点击过远程插件重启按钮”的记录时，第一次在 `远程` 插件浮层里点击 `重启`，不会立刻执行插件重启，而是先显示引导遮罩
- 引导开始后会高亮 `重启` 按钮，并暗化插件浮层中的其他区域，其他控件不可点击
- 引导文案会提示：远程插件提供 SSH 操控远程主机的能力
- 点击 `完成` 后会关闭这条引导，恢复插件浮层正常交互；再次点击 `重启` 才会真正执行远程插件重启
- 这条引导仅作用于 `远程` 插件，不会影响 `浏览器` 插件已有的首次重启引导；两者分别使用各自的本地点击记录，互不覆盖
- 这条远程插件引导与首次使用引导、首次点击输入框引导、蜂群引导、插件引导、`SOUL.md / USER.md` 引导、右侧备忘录引导、知识库WIKI 引导、浏览器插件重启引导、CLI 引导和 Skill 提炼引导相互独立，可以兼容共存
