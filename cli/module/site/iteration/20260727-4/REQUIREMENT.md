### 需求介绍
+ 左侧虚拟文件系统的“新增”类型增加“混音”。混音名称为空时禁止创建；无后缀时自动补全 `.wav`，已有 `.wav` 后缀时保持原样（大小写不敏感），其它后缀、路径分隔符和非法文件名必须在创建浮层中提示错误。点击创建前，以最终文件名检查当前 Agent 工作区 `audios/` 下是否已有同名 `.wav`；存在时不得打开混音浮层或覆盖文件。创建混音不得预先写入空文件。
+ 点击创建后必须先检查 FFmpeg/FFprobe 可用性；检查、缺失提示、安装请求确认及取消行为与录屏创建完全一致，检查通过后才打开居中的混音浮层。浮层包含文件投放区、可水平缩放和滚动的多轨时间轴、播放头、播放/暂停控制、音轨参数面板以及保存/关闭操作；关闭不保存草稿，且不得留下临时文件或半成品。
+ 混音浮层提供“添加音频文件”按钮，并接受投放区或时间轴任意位置的系统文件拖入、VFS 文件拖入与文件选择。系统来源不受 Agent 或当前 VFS 路径限制；前端在添加时自动上传一份副本至当前混音 Agent 的 `tmp/` 后加入工程。每个可由服务端 FFmpeg/FFprobe 解析的音频流都可作为源，不能解析或不含音频流的文件须保留在当前界面并显示服务端错误。允许将同一源文件重复加入，允许任意片段重叠；拖入后的每个片段都可在时间轴上独立拖动、选择和删除。
+ 每个片段必须支持非破坏性裁剪（源起点、源终点）、时间轴开始位置、播放速率 `0.25×–4×`、循环、总时长、音量、左声道音量、右声道音量、淡入和淡出。裁剪起点变化时，时间轴位置必须同步相同差值，以保持保留下来的源音频不在时间轴上移动：例如未移动的 `0–7s` 源裁剪为 `3–4s` 后，片段时间轴位置为 `3s`；裁剪终点不改变时间轴位置。左右声道音量独立生效，某侧为 `0` 等同该侧禁音。循环默认关闭；开启后仅填充该片段在时间轴上的已设定总时长，拖长片段即增加循环次数，不能产生无限时间线。
+ 首期效果器包含均衡器、压缩器、混响和延迟。效果器按片段保存并按界面顺序串联；参数必须显式展示、可恢复默认且在保存时完整提交，不能以浏览器的实时预览结果替代最终导出。效果器标题旁必须提供常用效果预设：人声清晰、减少刺耳、会议讲解、自然空间感、回声效果；选择预设会先删除当前片段已有全部效果器，再加入预设定义的效果器与参数，后续手动编辑效果器会取消该预设选择。选择或切换效果器时，底部状态区必须展示该效果器的作用、有效参数范围和建议起始参数。音量、声道、裁剪、速率、循环、淡入淡出与效果器共同作用于该片段后再参与混音。
+ 底部提供“试听”按钮。点击后前端将当前完整工程提交 Integration 生成临时 WAV 并播放，必须体现裁剪、位置、音量、声道、速率、循环、淡入淡出和效果器；试听中按钮切换为“停止试听”，编辑、拖入和保存不得与试听并发。试听绝不创建或覆盖 `audios/` 文件、不刷新 VFS、不保存草稿，完成、停止、失败或关闭浮层时清理临时资源。
+ 点击保存后，前端将完整混音工程（源工作区相对路径及上述片段参数）提交 Integration；浏览器不得自行承担最终编码或假定仅浏览器可解码的格式。保存中必须锁定重复提交并显示进度/错误；成功时刷新 VFS 的 `audios/`，最终文件固定为 `audios/<名称>.wav`，并尽力复制服务端返回的绝对路径。保存失败不得生成最终 WAV 或覆盖既有文件。
+ 导出固定为双声道 WAV。浮层在采样率前提供“常用导出”预设：音乐发布（`44.1 kHz / 16-bit`）、视频配音（`48 kHz / 16-bit`）、后期编辑（`48 kHz / 24-bit`）、高质量音乐（`44.1 kHz / 24-bit`）；选择后自动设置采样率和位深，手动修改任一项会取消预设。采样率提供 `44.1 kHz`、`48 kHz`，位深提供 `16-bit`、`24-bit`，默认 `44.1 kHz / 16-bit`；导出声道、采样率和位深由保存请求明确传递。时间轴总时长取所有片段处理后的最晚结束位置；空时间轴不得保存。

### 技术约束
+ 混音浮层复用现有 VFS 拖放、文件列表刷新、提示与媒体预览入口。对任何系统文件来源，前端通过既有上传链路写入当前混音 Agent 的 `tmp/` 并仅提交上传结果的工作区相对路径；不得把浏览器本机绝对路径或 `file://` URL 提交给混音接口。
+ 前端使用明确、可序列化的工程对象提交片段，数值必须为有限非负数；裁剪终点大于起点、播放速率在规定范围、循环片段总时长为正、淡入淡出之和不超过处理后片段时长。服务端返回的解析/渲染错误应逐项映射回片段，前端不得自行拼接 FFmpeg 命令。
+ 最终导出使用同源受限接口；请求只含 Agent ID、输出文件名、导出采样率/位深和工程对象，不接收任意命令、绝对路径、输出目录、浏览器二进制或任意滤镜表达式。前端预听可以使用浏览器可播放的源，但预听失败不得阻止服务端支持的格式参与最终保存。
