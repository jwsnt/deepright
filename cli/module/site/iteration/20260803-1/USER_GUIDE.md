# 媒体任务重新开始与日志求助

“文字转语音”“提取音频文字”“提取图片主体”“人物视频对口型”和“视频提取主体”任务在失败或已取消时都可以点击“重新开始”。重新开始会沿用这条任务原本的参数重新进入队列，并显示一份全新的执行日志；此前的日志不会保留。

打开任一任务的“日志”后，标题栏收起按钮左侧有“让 AI 解析日志”图标。点击图标会询问“是否让AI解析日志？”。按 `Esc` 或点击“取消”放弃；按 `Enter` 或点击“确认”后只显示“正在保存日志”，底部按钮会隐藏并锁定界面。求助消息进入发送链路后会立即关闭确认框和任务浮层，不等待 AI 开始执行或输出；发送前失败时才解除锁定并显示原因。求助消息始终发送到确认时的当前会话；若该会话正忙，会自动加入其待发送列表并在可发送后继续发送。日志保存为当前 Agent 工作目录中 `tmp/<功能名>_YYYYMMDD_HHMMSS.log`，消息中的日志会显示为文件路径气泡，可供 AI 读取。

执行日志会显示任务目的、实际使用的 Python/CPython 解释器与执行入口、原始输入和最终输出的绝对路径、实际模型与具体参数。遇到模型或运行时资源下载时，可查看下载源、准备写入的绝对路径、进度和校验结果；任务失败时，最后一条记录会给出具体原因和详细错误输出。
