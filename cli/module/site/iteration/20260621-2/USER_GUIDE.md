# 20260621-2 用户手册

本次迭代为居中对话区里的 `__TASK_START__` 任务气泡补充了一条首次可见的新手引导。

## 触发规则

- 如果浏览器本地还没有“任务气泡引导已看过”的记录，且当前会话第一次在 assistant 气泡右上角展示出 `__TASK_START__` 小圆球，页面会自动启动这条引导
- 这条引导和首次使用、首次点击输入框、蜂群、插件、`__RETRY__`、多模态输出参数等其它新手引导彼此独立
- 如果任务气泡首次出现时页面里正有其他新手引导在播放，这条引导会先进入等待队列，等当前引导结束后再补播

## 引导效果

- 引导会高亮当前 assistant 气泡右上角的任务小圆球，并暗化居中对话区里的其他部分
- 引导文案为：`启动多Agent时会在此提示。`
- 点击 `完成` 后会关闭这条引导，并顺带收起仍处于打开状态的 `多模态输出参数` 面板，恢复页面正常交互

## 同步结果

- 总手册 `../../USER_GUIDE.md` 已同步补充任务气泡首次引导的触发、排队和收尾行为
- 本次实现仅作用于站点前端，不改变 `__TASK_START__` / `__TASK_CLOSE__` 任务气泡原有的显示、更新和清理规则
