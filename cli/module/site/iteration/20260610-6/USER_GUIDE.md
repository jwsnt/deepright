# 20260610-6 用户手册

本次迭代调整了插件浮层里“插件参数”的展示方式，不再只展示参数 Key，而是直接把插件声明里的参数说明同步展示到输入框提示中。

- Site 会按照 `/api/plugins/meta` 返回的 `param` 顺序渲染插件参数；每个元素都使用 `[{"key":"placeholder"}]` 这种对象结构
- 每一行都会固定展示参数 Key，并把同一项里的 value 作为输入框的 `placeholder`
- `placeholder` 只用于提示用户当前字段应该填写什么，不会被当作真实默认值写回配置
- 如果这个插件参数已经有已保存的实际值，输入框会直接展示该值，不再继续显示 `placeholder`
- 当 `placeholder` 文案太长、在输入框内显示不全时，只要当前输入框还是空的，鼠标悬停或聚焦该输入框，就会在插件浮层内额外显示完整提示
- 浏览器插件里的 `headless`、`chrome` 这类参数会直接按这套新规则展示；其中 `headless` 的提示文案只表示“默认行为说明”，不代表页面会自动填入这个值
