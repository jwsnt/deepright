# 20260501-2 使用手册

## 简介

本迭代为 Site 右侧 `CMD` 小图标补充了命令输入浮层、二次确认交互和成功提示同步能力。

## 功能说明

### CMD 浮层

- 点击右侧分割带标题“正在执行的系统指令”后的 `CMD` 小图标，会在页面中央弹出一个 `500x110` 的命令浮层
- 浮层中的命令输入框字体为 `10px`
- 输入框高度不低于 `35px`，当前实现为 `42px`，并增加上下内边距，以提升视觉占比

### 危险提示

- 输入态会显示 `10px` 红色小字危险提示，内容为执行规则：仅允许本机请求执行，且包含 `rm` 的命令会被拦截
- 危险提示文案与输入框之间保持 `5px` 间距，并采用水平右对齐
- 切换到二次确认态，以及从二次确认态返回输入态时，会保持用户近似无切换感
- 二次确认态中的提示文案与输入态危险提示文案使用相同样式、位置和规则文案，并会在切换时高亮且闪烁危险提示

### 执行反馈

- 输入命令后需要二次确认，确认后才会调用 `/api/cmd`
- 执行成功后，会复用左侧虚拟文件系统的 Tips 位置显示红字成功提示
- 执行失败时，仍会使用居中的错误提示方式反馈失败信息
- 每次重新打开 CMD 浮层都会清空输入框和确认内容，不保留之前的执行记录
