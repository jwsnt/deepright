# 迭代 20260530-6：`/install_app` 自动刷新频率调整

本次迭代调整了左侧 `最近` 标题右侧安装提示小灯泡对应的 `/install_app` 轮询频率。

- 页面初始化完成后，仍会先立即读取一次 `http://127.0.0.1:8080/install_app`
- 页面处于可见状态时，后续自动刷新频率调整为每 `60` 秒一次
- 浏览器标签页从后台切回前台时，仍会立即补做一次刷新，避免提示状态滞后
- 点击安装提示小灯泡时，仍会立即重新请求 `/install_app`，再按最新返回结果弹出确认浮层

用户可见效果：

- 待安装应用提示不会再以高频率重复轮询
- 首屏、手动点击和页面重新可见时的提示实时性保持不变
