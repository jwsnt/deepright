# Site 迭代 20260711-2 使用手册

## 本次更新

- 首次打开 Site 时，页面不再长时间停留在空白页，而是会先显示一个轻量级的 `正在加载中` 提醒。
- 当主页面的基础骨架已经可见后，这个提醒会立即让位给正常页面，不再等待所有异步初始化全部完成。
- 如果首屏初始化明显变慢，提示文案会升级为“仍在加载，请稍候”等轻量提醒；如果初始化失败，也不会一直停留在无意义的 loading 遮罩下。

## 使用方式

1. 像平时一样直接打开 `/site/` 页面。
2. 如果主界面还没完成首屏接管，页面中央会先出现 `正在加载中` 提醒。
3. 当主页面基础内容可见后，提醒会自动消失，页面继续按原有方式补齐模型、插件、知识库和会话数据。

## 页面行为

- 这次提醒只用于首屏快速反馈，不会在普通会话切换、知识库刷新、右侧预览加载或其它局部刷新时重复弹出。
- 提醒本身是轻量级 HTML / CSS 实现，不依赖额外图片、字体或重型动画，也不会新增额外网络请求。
- 低功耗或节能场景下，这个提醒仍可正常展示；必要时会自动退化为更简单的纯文案提示。
- 新增提醒不会把现有 `init()` 里的异步初始化强行绑定成一个总锁；正常页面出现后，后续异步数据仍会继续按原有链路补齐。

## 兼容性说明

- 这次改动解决的是 `index.html` 已经开始执行后的前端首屏白屏感知，不包含静态资源在服务端返回之前的等待阶段。
- 预加载提醒与右侧 iframe 预览 loading、知识库 loading、上传锁定、插件锁定等现有局部 loading 状态相互独立，不会混用同一套语义。
- 主手册 `../../USER_GUIDE.md` 已同步补充这次“首屏轻量级预加载提醒”的总说明。
