# Proxy 迭代 20260419_5 使用手册

## 变更说明

新增 `GET /api/files?path=xxx` 接口，支持模糊查找（前缀匹配）指定路径下的文件和目录。

## 接口说明

| 方法 | 路径 | 参数 | 说明 |
|------|------|------|------|
| GET | `/api/files` | `path`（必填） | 模糊查找指定路径下的文件和目录 |

## 模糊查找逻辑

- `path` 是已存在的目录：列出该目录下所有文件和目录
- `path` 不是目录：取最后一段作为前缀，在父目录中前缀匹配

### 示例

| 请求 path | 行为 |
|-----------|------|
| `/a/b/c/`（目录） | 列出 `/a/b/c/` 下所有内容 |
| `/a/b/SO` | 在 `/a/b/` 下匹配以 `SO` 开头的文件/目录 |
| `~/Doc` | 在 `~/` 下匹配以 `Doc` 开头的内容 |

## path 支持

- 绝对路径：`/a/b/c`
- `~` 路径：`~/Documents`
- 含空格路径：通过 URL 编码传递

## 响应示例

```json
[
  {"name": "SOUL.md", "type": "file"},
  {"name": "skills", "type": "dir"}
]
```

## 错误码

- 400：缺少 path 参数或路径展开失败
- 404：父目录不存在
- 405：非 GET 请求
