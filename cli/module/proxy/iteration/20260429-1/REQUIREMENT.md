### 需求介绍
+ 每分钟执行一次定时任务，获取需要开始执行时间已经超过当前时间点（精确到秒）但尚未执行的（备忘录）任务明细
    + 任务明细需求：../../../cron/REQUIREMENT.md
    + 备忘录需求：../../../proxy/iteration/20260427-5/REQUIREMENT.md
+ 需要召回的任务明细要求：
    + 开始执行时间已经超过当前时间点
    + 开始执行时间不超过当前时间1小时，超过则不用执行
+ 将每个需要执行的任务明细转为等同于页面的用户请求转发/v1/chat/completions：
    + 请求内容：任务内容
    + 其他请求AgentId、请求模型和思考模式与任务明细对应
    + 会话ID：不同于页面生成的会话，这里的会话ID等于任务元数据ID@任务明细ID的字符串组合（用@连接）
    + 需要在Metadata中附带与普通用户请求一致的属性（包括Agent/Skills）：../../../proxy/REQUIREMENT.md
    + 请求Header的Authorization使用各自任务明细指定模型的Token
+ 对应每个（备忘录）任务明细的请求和SSE响应需要写入会话存储，类型为定时任务：../20260427-8/REQUIREMENT.md
+ 开始后立即更新状态为已启动，SSD响应完成后更新为已完成，任何中途失败回滚到待启动直到已完成
