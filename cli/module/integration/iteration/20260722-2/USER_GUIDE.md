# 迭代 20260722-2：模型配置测试接口

设置页会通过本机的 `POST /api/model/test` 测试单个模型服务商的当前配置。该接口只接受当前行的服务商、密钥与客户化模型字段；这些值只在本次内存请求中使用，不会写入 `token_store`、Agent 配置、聊天记录或会话恢复数据。

## 运行时测试配置

应用资源目录的 `config/config.json` 必须包含：

```json
{
  "test": {
    "content": "Hello World",
    "timeout": 60
  }
}
```

- `content` 是发送给服务商的测试内容，不能为空。
- `timeout` 是正整数秒，覆盖连接、首包和整个 SSE 流。
- 两项任一缺失或无效时，接口返回“配置错误”，不会使用前端或内置默认值。

## 判定与隔离

- 每次测试生成独立 UUID，并以 `metadata.test = true` 标记发送最小上游 `/v1/chat/completions` 请求；该字段会原样传至 `--host` 指定的最终处理服务器，不会展开 Agent、技能、记忆、知识、路由、插件、任务或工具上下文。
- 普通聊天、Cron、CLI 等非测试请求不会携带 `metadata.test`；普通 `/v1/chat/completions` 即使收到客户端伪造的该字段，也会在转发前移除。
- 测试固定使用 `__model`。密钥或 `__model` 为空时接口拒绝请求，不会回退到快速、思考或多模态模型。
- `__url` 可以为空以使用服务商默认地址；非空时必须是无用户名和密码、带主机名的完整 `http://` 或 `https://` URL。反斜杠、空白、中文标点（如 `、`）和无效百分号编码属于非法字符，会在转发前被拒绝。
- 只有 HTTP 200、至少一个有效业务 SSE 数据包且最终收到 `[DONE]` 才返回成功。
- HTTP 非 200、首包或总超时、空流、流中断、流内错误和缺少 `[DONE]` 都返回配置错误。服务商错误 JSON 存在 `content`（包括 `choices[].delta.content`）时，只展示该字段；内容会脱敏并截断，避免回显密钥或整段服务商响应。401、403、404、429、503 和其他 5xx 会只显示统一的中文原因与处理建议（404 为“请检查模型 URL 和基础模型”），不再附服务商内容；即使状态码只写在 `content` 中（如 `(code=401)`）也会识别。
- 客户端取消会中止上游请求，不写入任何测试状态。
- 接口仅返回脱敏、截断后的最终测试结果，不返回模型正文；设置页会在对应模型行内显示成功、失败或取消结果，不使用虚拟文件系统提示。
