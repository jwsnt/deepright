# 迭代 20260717-1：自动任务模型配置透传

备忘录、邮件、飞书和其他由 Integration 自动执行的任务，现在会使用与居中对话输入框相同的模型客户化配置。

## 生效范围

- 适用于通过 `task_detail` 执行器发起的所有自动任务，包括普通备忘录/定时任务、邮件和飞书。
- 任务仍使用创建时选择的 `model`；不需要修改任务创建接口或重新创建既有的未执行任务。
- 居中对话的原有转发行为不变。

## 透传字段

任务实际发送到上游 `/v1/chat/completions` 前，会按该次任务的 `model` 从 `token_store` 读取当前配置，并将已配置的非空字段写入 `metadata`：

- `__url`
- `__model`
- `__model_fast`
- `__model_thinking`
- `__model_multi_input`
- `__model_multi_output`

未配置、为空或当前 provider 不支持的字段不会发送空值。现有的 `__provider`、`__token` 和 `Authorization` 认证行为保持不变。

## 配置更新

配置在任务执行时读取，而不是在创建任务时保存快照。因此，在任务执行前通过模型配置界面或 `/api/token` 更新 URL 或模型名称后，下一次执行会自动使用更新后的值。

例如，先创建一条使用 `openai` 的明日备忘录，随后把 `openai` 的 `__model_thinking` 更新为新模型；该备忘录执行时会使用新模型，无需删除或重新创建任务。

## 兼容性

- 仅配置 token 的模型仍可正常执行，metadata 不会额外出现空的 `__*` 字段。
- 读取模型配置失败时，任务沿用既有失败处理，不会发送缺少模型客户化配置的降级请求。
- `task_meta` 和 `task_detail` 不保存 token 或模型客户化配置，避免任务数据滞后于当前模型设置。
