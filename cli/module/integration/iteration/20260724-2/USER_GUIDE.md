# `@` 菜单缓存

Integration 使用主应用 `config/config.json` 中的必填配置管理 `@` 菜单数据：

```json
{
  "at": {
    "refresh": 60,
    "cache": 120
  }
}
```

- `refresh` 和 `cache` 均以秒为单位，且必须是大于 `0` 的整数；配置缺失或非法时服务会拒绝启动。
- 服务启动后立即预热，并按 `refresh` 周期刷新 `/api/skills` 与 `/api/swarm_agent` 使用的快照。
- 每次成功刷新都会重新开始计算 `cache` 有效期；刷新失败保留旧快照但不延长有效期。
- 快照过期后的用户请求会同步刷新；刷新失败返回接口错误，不会返回过期数据。
- 首次读取某个 `chatId` 时会生成禁用技能筛选快照；通过 `/api/skill_state` 禁用或恢复技能目录成功后，会立即更新该会话筛选结果并重新开始计算 `cache` 有效期。
- 保存任意 Agent 的蜂群开关后，会立即更新基础缓存与所有会话筛选缓存中的 Agent 可见性，并重新开始计算 `cache` 有效期。
- 普通聊天、CLI 和定时任务不使用该缓存。
