# 迭代 20260717-2：会话列表最终一致性刷新

会话列表现在会在同一浏览器配置文件、同一站点的多个窗口间保持最终一致。

## 刷新规则

- 当前窗口创建、删除会话或更新会话列表摘要后，会立即保存并刷新本窗口列表。
- 其他同源窗口通常会通过浏览器的本地存储变更事件立即收到更新。
- 页面可见时，会话列表每 30 秒检查一次本地存储；内容未变化时不会重复渲染。
- 页面从后台切回前台时，会立即检查并应用最新会话列表，不等待下一次轮询。

## 范围

该能力仅覆盖同一浏览器配置文件、同一 origin 下的多个窗口或标签页。不同浏览器配置文件、无痕窗口、不同设备或不同站点不共享浏览器本地存储，未包含在此次同步范围内。

会话的既有本地持久化、空间压缩和流式聊天行为保持不变。
