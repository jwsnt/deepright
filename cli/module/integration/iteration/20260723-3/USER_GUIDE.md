# 备忘录元数据任务明细新手引导

## 使用方式

首次打开“备忘录元数据预览”浮层时，页面会自动展示一次任务明细入口引导。

1. 右侧 Sidebar 自动收起，居中的元数据预览浮层保持打开。
2. 在“内容”标题右侧，任务列表图标会被高亮。
3. 引导提示为“点击列表，查看具体任务明细。”
4. 点击可用的“完成”按钮后，引导遮罩关闭，预览浮层和页面其余功能恢复正常操作。

该引导只记录在当前浏览器本地，与首次使用引导和首次点击居中对话输入框的引导独立；不会写入备忘录、聊天记录、Agent 配置或服务端数据。

## 说明

引导显示期间，元数据预览中除引导卡片外的按钮、鼠标和键盘交互会暂时锁定，避免误操作。完成后可再次点击任务列表图标，进入当前元数据限定范围内的任务明细列表。
