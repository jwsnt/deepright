# 20260723-2 用户手册

## 更快打开工作区

- 右侧工作区加载当前 Agent 时，会直接解析该 Agent 的工作区路径并读取文件列表，不再等待全部 Agent 的技能目录扫描。
- 如果浏览器保存的 Agent 名称已失效或仅大小写不同，页面才会自动查询 Agent 列表并重试；已访问过的 Agent 在本次页面会话内会复用已确认的工作区路径。
- 快速连续切换 Agent 时，过期请求不会覆盖当前工作区。

## 技能与备忘录任务

- 该优化只影响工作区显示，不会缓存或复用技能快照。
- 普通会话、备忘录定时任务和 Connect 任务在发送给上游前，都会按当前磁盘状态刷新 Agent 技能。
- 因此，用户不打开页面也不影响离线备忘录任务携带技能；修改技能后，下一次实际执行会使用最新技能。

相关通用说明请继续参考上级手册 `../../USER_GUIDE.md`。
