# 视频切分服务使用手册

## 接口

使用同源 `POST /api/video_trim`：

```json
{
  "agentId": "AgentId",
  "path": "media/source.mov",
  "start": 1.5,
  "end": 4.0
}
```

`start` 与 `end` 以秒为单位，必须为 `0.5` 秒粒度，且 `end` 大于 `start`。接口只接受当前 Agent 工作目录内允许预览的视频相对路径。

## 输出与安全

请求可额外传入仅含文件名的 `outputName` 指定输出名；未传入时使用带 `_trim` 和高精度时间戳的默认名。服务始终在当前 Agent 工作目录的 `videos/` 下生成新 MP4，目录不存在时自动创建，响应字段 `savedAs` 返回新文件绝对路径，供页面复制到系统剪贴板。源视频永不修改。输出为 H.264 视频、AAC 音频和 MP4 封装；能读取时会参考源视频目标码率。

绝对路径、路径逃逸、目录、音频、跨 Agent 文件与符号链接逃逸均会被拒绝。转码先写入工作区内临时文件，成功后才原子改名；转码失败、超时或依赖缺失不会留下最终文件。

## 运行依赖

运行环境需要同时提供 `ffmpeg` 与 `ffprobe`。Windows 安装包通过 WSL 自动安装 `ffmpeg` 软件包，二者会随该软件包提供。
