### 需求介绍
+ 新增同源 `POST /api/video_trim` 受限接口，供 Site 对当前 Agent 工作目录内的视频生成切分副本；请求携带 `agentId`、工作区相对 `path`、`start` 与 `end`（秒），并可选携带仅含文件名的 `outputName`。
+ 接口仅接受已允许预览的视频文件，拒绝非 POST、缺失字段、非有限数值、结束时间不大于开始时间、非 `0.5` 秒粒度、绝对路径、`~`、`..`、目录、跨 Agent 路径和符号链接逃逸。
+ 输出固定为 MP4，保存为当前 Agent 工作目录 `videos/` 下由 `outputName` 指定的新文件；未指定时使用带 `_trim` 和高精度时间戳的默认名称，目录不存在时创建。拒绝路径字符、非 `.mp4` 后缀与同名文件；始终新建，绝不覆盖、删除、改名或修改源视频。成功响应必须通过 `savedAs` 返回绝对路径，供页面复制到系统剪贴板。
+ 服务端调用受控的 FFmpeg 参数进行重编码，以获得 0.5 秒精度：视频编码为 H.264，音频编码为 AAC；通过 FFprobe 读取源视频流目标码率并在可获得时用于输出，无法读取时采用 FFmpeg 的安全默认策略。由于统一 MP4 且需精确切分，不承诺逐字节保留原封装、编码或码率。
+ FFmpeg 与 FFprobe 的可执行文件只从受控环境查找，源路径、输出路径与命令参数均由服务端生成，设置执行超时，写入工作区内临时 MP4 后原子改名；命令缺失、探测失败、转码失败和清理失败均返回 JSON 错误且不得留下最终文件。
+ Windows 安装包的 WSL 工具安装名单新增 `ffmpeg`，以同时提供 `ffmpeg` 与 `ffprobe`；构建产生的 Windows 安装流程必须保留此安装步骤。
