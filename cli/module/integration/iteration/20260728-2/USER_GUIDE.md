# 虚拟文件系统最后修改时间

`GET /api/files` 返回的每个文件和目录条目均包含 `modifiedAt`，其值为服务端文件系统最后修改时间的 Unix 毫秒时间戳。

- 原有的 `name`、`type`、技能目录状态字段及按名称前缀查询行为不变。
- 接口会先返回按名称排列的目录，再返回按最后修改时间从新到旧排列的文件；同一修改时间的文件按名称排列。Site 仍会按同一规则显示，避免不同读取路径出现顺序差异。
- Site 使用该时间显示文件顺序和最近产生或修改的文件提示；Integration 不保存浏览器的提示或忽略状态。
- 若目录或文件不可读取，接口仍沿用既有错误响应。
