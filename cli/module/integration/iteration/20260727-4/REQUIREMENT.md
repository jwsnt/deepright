### 需求介绍
+ 新增同源受限 `POST /api/audio_mix` 接口，用于将当前 Agent 工作区中可由受控 FFmpeg/FFprobe 解析的多个音频源按工程定义合成为 WAV。请求仅包含 `agentId`、安全的 `.wav` `outputName`、导出采样率/位深与受限工程对象；不接收浏览器二进制、绝对路径、任意输出目录、Shell/FFmpeg 命令或任意滤镜表达式。
+ 工程对象由有限条片段组成。每条片段只能引用当前 Agent 工作区内的普通文件，使用规范化相对路径；必须拒绝绝对路径、`~`、`..`、目录、符号链接逃逸、跨 Agent 路径、空路径及不能被 FFprobe 识别为含音频流的源。所有源在执行前由服务端解析，接口不能成为任意文件读取器或通用命令执行器。
+ 每条片段仅允许源裁剪起止时间、时间轴开始位置、`0.25–4` 播放速率、布尔循环及其有限总时长、音量、左右声道音量、静音、淡入/淡出和以下结构化效果器：均衡器、压缩器、混响、延迟。服务端须校验所有数值为有限值、各时长非负、裁剪终点大于起点、循环片段总时长为正、淡入淡出不超过处理后的片段时长，并对效果器类型、参数范围及排序做白名单校验；不得把前端字符串直接拼入 FFmpeg filter。
+ 服务端使用自身生成的受控 FFmpeg filter graph：先对各源裁剪、循环/限长、速率、音量/独立左右声道、静音、淡入淡出和白名单效果器处理，再按时间轴开始位置延迟并合并。允许多个片段和同一源重叠；循环只能在声明的片段总时长内展开。最终统一输出双声道 WAV，采样率仅允许 `44100` 或 `48000`，位深仅允许 `16` 或 `24`；分别对应受控 PCM 编码，不能由请求指定 codec、channel layout 或滤镜。
+ `outputName` 必须是非空、单个安全 `.wav` 文件名；输出固定为当前 Agent 工作区 `audios/`。目录不存在时创建，保存前和最终原子提交时都不得覆盖同名文件；发生并发冲突时返回明确冲突错误而非改名、覆盖或丢弃既有文件。服务端先在同一 `audios/` 目录生成不可见临时 WAV，成功后原子改名；失败、超时、依赖缺失、校验/探测错误或取消时必须清理临时文件，不能留下最终 WAV。
+ 接口复用现有受控 FFmpeg/FFprobe 定位和工作区安全解析原则。未安装任一依赖、执行超时、解析失败或渲染失败必须返回可展示错误；不得执行安装命令、不得修改源文件、不得放宽既有二进制写入接口或暴露通用转码能力。

### 技术约束
+ 请求体、片段数量、效果器数量、路径长度、单片段时长、总时间轴时长与 FFmpeg 执行时间均须有服务端上限；超限前返回明确错误。源文件在探测与渲染期间须维持当前 Agent 工作区边界，不得从文件名、元数据或错误文本泄露工作区外内容。
+ 接口的成功响应至少返回实际 `agentId`、`path`、`savedAs` 和可展示 `content`；响应不得返回 FFmpeg 完整命令或未受限源路径。保存成功后再刷新现有 VFS，服务端不保存混音草稿或工程文件。
