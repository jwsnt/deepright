### 需求介绍

- 以下持久化队列统一支持失败和已取消任务重新开始：VoxCPM 文字转语音、Whisper 提取音频文字、rembg 提取图片主体、Wav2Lip 人物视频对口型、RVM 视频提取主体。相应重启接口仅接受当前 Agent 的任务 ID，保留原任务的全部受控输入和参数，重新分配原有规范要求的安全输出路径，并将状态设为 `queued`、进度设为 `0`、取消标记清零。
- 任一次重新开始（无论原状态为 `failed` 或 `cancelled`）必须在同一事务中清空该任务持久化 `logs`，重启本身不得写入“已重新加入…队列”或其它占位日志；仅在任务真正开始执行后写入本次日志。旧日志不得在日志读取接口、任务列表或日志求助文件中出现。完成或正在执行的任务不允许通过重启接口重启。
- 新增受控的任务日志求助接口。请求只接受当前 Agent 的 `agentId`、受限任务类型及正整数任务 ID；任务类型固定映射为“文字转语音”“提取音频文字”“提取图片主体”“人物视频对口型”“视频提取主体”，不得由客户端提供功能显示名、文件名、路径、日志或提示词模板。接口必须验证任务归属当前 Agent，并读取该任务当前的持久化日志。
- 求助接口必须在该任务所属 Agent 工作目录的 `tmp/` 下创建 UTF-8 文本日志文件，文件名固定为 `<功能名>_YYYYMMDD_HHMMSS.log`。如同一秒冲突，追加必要的安全序号；不得覆盖既有文件，不得写到工作目录外，不得接受客户端路径。文件内容为当前完整任务日志；空日志仍需生成有效的空 UTF-8 文件。
- 每次求助接口调用必须即时读取并校验活动 `config/config.json.seekHelp`：值必须为非空字符串，且同时包含 `$function` 和 `$log` 占位符。服务端仅将 `$function` 替换为受控功能名称，并将 `$log` 替换为 `[FILE:<刚保存日志文件的绝对路径>]`，返回生成后的消息文本；不得执行、转发或持久化该消息，也不得暴露其它 Agent 的路径或日志。
- 接口错误必须使用既有 JSON `status`/`content` 约定。创建目录、读取任务日志、写入日志文件、配置缺失/无效、未知任务类型、跨 Agent 访问、不可重启的状态或路径校验失败均必须返回可展示错误，且不得创建工作目录外的文件。
- VoxCPM、Whisper、rembg、Wav2Lip 与 RVM 的每次执行日志均须记录任务目的、任务实际启动的 Python/CPython 解释器与执行入口/脚本路径、服务端解析后的原始输入绝对路径、最终输出绝对路径、实际模型/权重和具体命令参数名及值；不得只记录场景名称。输出路径因冲突重分配时，日志必须再记录最终路径。文字转语音可不重复记录文字正文，但必须记录文字文件路径并保留 `--text` 参数名。命令包装器无法解析 shebang 时也必须明确记录该情况和直接执行的入口。
- 任务在执行期下载模型或运行时资源时，日志必须记录下载源、资源名称、进度、准备写入的文件或目录绝对路径以及校验或失败结果；仅使用系统默认位置且任务无需指定落盘位置时不必记录下载目标。进度不可获得时须明确说明下载源未提供总大小。子进程、网络、校验、输入校验、模型加载和输出写入失败均须在最终失败日志中包含具体原因及受限长度的详细诊断输出，完整子进程输出仍按既有日志上限逐行保存。
- VoxCPM 文字转语音、Whisper 提取音频文字、rembg 提取图片主体、Wav2Lip 人物视频对口型与 RVM 视频提取主体必须共用同一等待队列。服务启动时读取 `config/config.json.modelTask.concurrence`，其值必须是正整数，作为五类任务合计的同时执行上限；默认值为 `1`。等待名额的任务必须保持 `queued`，仅在获得公共执行名额后转为 `running`。取消、失败、重试和服务重启恢复不得泄漏执行名额；配置非法时必须安全回退为 `1` 并记录服务端诊断日志。
- 五类媒体任务均必须提供 Integration CLI，固定入口为 `integration api <whisper|rembg|voxcpm|wav2lip|rvm> <check|list|create|cancel|restart|delete|log>`；`integration service` 保持等价别名。CLI 仅调用已有受控 HTTP 接口，不直接访问任务数据库、工作区文件或模型运行时。每个功能的 `--help` 必须说明任务目的、公共等待队列、状态及重试/删除边界、创建参数、可重复参数的配对或应用规则，并至少包含依赖检查、查询、创建、取消、重新开始和日志读取示例。

### 编写代码
+ 复用既有 SQLite、Agent 工作目录解析、路径边界校验、时间戳、配置读取和 JSON 响应能力；不得增加新的数据库表或外部 Go 依赖。
+ 任务日志写入与重新开始状态更新必须保持原子性，避免任务读取接口观察到新状态与旧日志混合的中间状态。
+ 公共模型任务队列不得新增任务数据库表或改变既有任务接口、持久化字段、路径边界和取消语义；并发限制必须覆盖全部五类任务，而非分别限制每个任务类型。
+ CLI 创建命令只能接受现有接口允许的工作区相对路径和白名单参数；Wav2Lip 的视频与音频必须按 CLI 参数出现顺序一一配对，RVM 场景可提供一次或为每个视频各提供一次。CLI 解析阶段必须拒绝缺失 Agent、空路径、不匹配配对、超过接口上限和未知额外位置参数。
+ 求助接口只读任务记录，除目标 `tmp` 日志文件外不得修改媒体任务状态、原输出、源文件或已有日志。
+ 保持实现最小化；所有路径均以受控服务端解析结果为准，禁止信任浏览器传入的绝对路径或日志文本。
