# Integration 迭代手册（20260726-1）

## 图片与视频多坐标提取

文件预览浮层中的坐标图标同时支持视频和图片。点击图标后，先在浮层中央填写要提取的坐标数量，默认值为 `1`。

- 按 `Enter` 或点击“确认”开始提取；按 `Esc` 或点击“取消”放弃。
- 坐标按取值时媒体的原始像素尺寸计算，采用 Canvas / FFmpeg 的左上角 `(0,0)` 原点，Y 轴向下增长。预览缩放不改变导出的坐标。
- 提取中会在右下角显示剩余次数。多点时，画面会显示已选位置的编号标记；浅色主题标记使用拖动条滑块相同的 `#FF4500` 暖色，深色主题使用冷色。
- 单点完成时复制：`取值时画布尺寸: 宽度 2880 px, 高度 1800 px, 以左上角为原点的坐标位置: (616, 601), 使用时需要按实际画布尺寸缩放坐标`。
- 多点完成时复制：`取值时画布尺寸: 宽度 2880 px, 高度 1800 px, 以左上角为原点的3个坐标位置: [(616, 601),(900, 700),(1200, 900)], 使用时需要按实际画布尺寸缩放坐标`。
- 完成、取消、按 `Esc`、再次点击坐标图标或关闭预览都会清除临时坐标和全部标记。图片开始提取时会自动关闭切图工具，避免两个叠层互相干扰。

该功能仅使用浏览器中的现有媒体或 Canvas，不调用新的 Integration 接口，也不会上传媒体内容或改写文件。
