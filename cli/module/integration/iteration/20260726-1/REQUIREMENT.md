### 需求介绍
+ Site 的视频与图片预览浮层必须共用同一套多坐标提取交互。视频以原视频帧尺寸、图片以原图片 Canvas 尺寸作为取值时画布尺寸；两者均采用 Canvas / FFmpeg 的左上角 `(0,0)` 原点和 Y 轴向下增长的像素坐标系。
+ 坐标图标仅在存在可用视频媒体元素或已加载图片 Canvas 时展示。点击图标后，必须在文件预览面板内部居中显示坐标数量输入浮层，默认值为 `1`，且只接受正整数。
+ 数量浮层中，`Enter` 与“确认”开始提取，`Esc` 与“取消”放弃提取；浮层打开期间不得让预览浮层的通用 `Esc` 行为关闭整个预览。
+ 确认后，预览面板右下角必须显示剩余需要提取的次数。每次在目标媒体画面内有效点击仅记录一个原始像素坐标并更新次数；提取未完成时不得写入系统剪贴板。
+ 单点完成后一次性复制：`取值时画布尺寸: 宽度 x px, 高度 x px, 以左上角为原点的坐标位置: (x, y), 使用时需要按实际画布尺寸缩放坐标`。多点完成后一次性复制：`取值时画布尺寸: 宽度 x px, 高度 x px, 以左上角为原点的n个坐标位置: [(x1, y1),...], 使用时需要按实际画布尺寸缩放坐标`；其中 `n` 必须替换为实际提取数量。
+ 多点提取期间，已选位置必须在视频或图片画面自身的显示层上保留编号标记，并随媒体缩放保持与原始像素坐标对位。浅色主题使用与拖动条滑块一致的暖色 `#FF4500`，深色主题使用冷色；完成、取消、再次点击坐标图标、按 `Esc` 或关闭预览浮层时必须清除全部标记和提取状态。
+ 图片 Canvas 的坐标提取必须捕获点击并阻止同一次点击进入图片绘制逻辑；提取开始时关闭切图工具，切图工具重新开启时取消坐标提取，防止两类叠层和指针交互冲突。视频取点不得改变播放位置或播放控制状态。
+ 所有坐标计算、标记、数量输入、提示和剪贴板写入均在浏览器本地完成；不得新增接口、上传媒体帧或读写媒体文件。

### 编写代码
+ 在 `../../../site/index.html` 的文件预览、图片 Canvas 与媒体预览逻辑中实现共用的坐标状态机、像素换算、标记层和键盘处理；不新增第三方依赖或 Integration HTTP 接口。
+ 图片标记层须根据 Canvas 当前显示矩形和滚动偏移定位，并在 Canvas 尺寸变化时重新同步；视频标记层须位于视频显示层内并使用相对位置定位。
+ 保持已有取色、图片编辑、切图、视频播放、Range 媒体预览和无障碍焦点行为；坐标提取只能在已加载的目标媒体上启用。
