### 需求介绍
+ `__model_multi_input` 和 `__model_multi_output` 允许保存 `@服务商名称`，其值必须原样随请求携带。
+ 无论当前服务商是否原生支持多模态输入或输出，只要页面选择了服务商引用，普通对话、CLI/GET、飞书、邮件和备忘录任务都必须携带对应字段。
+ 删除服务商时，服务端必须检查所有已配置服务商的多模态输入和输出字段；所有引用被删除服务商的 `@服务商名称` 必须在同一事务中清空。

### 编写代码
+ 使用现有 Proxy token store 和 metadata 注入路径完成最小范围更新。
+ 直接聊天和定时任务都从同一服务商配置读取多模态字段；CLI/GET、飞书和邮件通过既有 `proxy token --provider` 数据路径获得相同值。
+ 删除接口和批量保存中的删除都必须清理引用，且保留普通模型名称和未受影响的服务商配置。
+ 覆盖 `@服务商名称` 透传、定时任务注入、删除清理和批量保存删除清理。
