# Integration 迭代手册（20260726-3）

## 居中浮层期间隐藏 URL 预览

右侧 URL `iframe` 预览已打开时，页面显示任何居中、阻断交互的模态浮层，预览都会临时隐藏；虚拟文件系统的“新建文件或目录”和“上传文件或目录”均属于这一规则。

- 预览只会隐藏，不会被关闭或卸载。浮层全部关闭后，它会恢复为此前的右侧预览或页内展开状态，已加载页面、当前 URL、滚动位置和当前会话绑定均会保留。
- 右侧 Sidebar 的展开状态和用户偏好不受影响；连续切换多个居中模态时，预览会持续隐藏，不会闪现。
- Toast、非阻断交互的加载提示、左右侧栏锚定浮层、右侧栏内确认框以及浏览器原生文件选择器不会触发这项行为。
- 若预览已页内展开，展开背景和关闭/还原控件也会同时隐藏；按 `Esc` 时以当前居中模态的既有键盘行为为准，不会还原或关闭预览。
