# 迭代 20260723-1：飞书 MCP 地址参数

飞书插件配置新增了可选的 `mcp_url` 字段，用于保存飞书 MCP 服务地址。该字段默认留空，不影响现有 `appId` 和 `appSecret` 的配置或插件启动。

## 参数查询

执行以下命令可查看插件元数据字段说明：

```bash
./feishu param
```

返回值会在现有字段后包含：

```json
{
  "mcp_url": "飞书MCP地址"
}
```

`command` 的原有命令列表不变；`mcp_url` 是 `param` 返回的可选元数据字段，不是新的 CLI 子命令。

## 页面配置

在飞书插件浮层的“插件参数”区域填写 `mcp_url` 后，保存或启动插件时会与其他参数一并写入配置。再次打开浮层会回填已保存的地址。

`mcp_url` 输入框右侧的闪烁 URL 图标会在新页面打开飞书 MCP 文档：<https://open.feishu.cn/page/mcp/7616252843057548502>。
