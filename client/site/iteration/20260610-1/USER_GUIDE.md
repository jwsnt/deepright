# 20260610-1 使用说明

## 变更简介

本次迭代调整了右侧边栏手动 `CMD` 的结果展示方式：

- 点击执行后，命令会立即写入右侧 `CLI` 子任务面板
- 命令执行成功或失败后，结果会继续更新到同一条 `CLI` 记录中
- 原本展示在虚拟文件系统 `Tips` 中的执行结果已移除，不再兼容旧展示方式

## 使用方式

1. 打开一个会话，并确保当前会话已经绑定 `Agent`
2. 在右侧边栏打开 `CMD` 面板
3. 输入自定义系统命令并确认执行
4. 关闭面板后，可在右侧 `CLI` 子任务面板查看：
   - 执行的命令
   - 当前状态（执行中 / 成功 / 失败）
   - 执行返回内容

## 展示说明

- 手动 `CMD` 会和已有的 `CLI` 子任务内容一起按时间顺序展示
- 成功和失败都会保留记录，切换会话后再次返回仍可看到
- `CLI` 气泡左上角复制按钮仍可继续把命令复制回 `CMD` 输入框
