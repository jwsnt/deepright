### 第一性原则

+ 仅可以新增/更新/删除site（../..）同目录及其子目录下的文件和文件夹。

### 技术规范

+ 严格遵守整体设计文档：../../../DESIGN.md
+ 本模块设计文档：../../DESIGN.md
+ 不新增第三方依赖，不破坏既有虚拟文件系统、文件预览或媒体编辑功能。

### 需求介绍

+ 虚拟文件系统的每个当前目录必须先展示全部目录，再展示全部文件。
+ 目录按名称的本地化字母顺序升序排列；文件按 `modifiedAt` 降序排列，最后修改时间相同或缺失时按名称的本地化字母顺序升序排列。
+ 当前目录中的普通文件在其 `modifiedAt` 距浏览器当前时间不少于 `0` 且小于 `30` 秒时，高亮并闪动；目录不参与此提示。
+ Agent 工作目录根部的 `config.json`、`Knowledge.md`、`mcp.json`、`SOUL.md` 与 `USER.md` 不参与此提示；仅豁免根部的精确文件名，子目录同名文件仍按常规处理。
+ 文件行被用户鼠标悬停或点击后，必须立即取消该文件当前版本的高亮和闪动。忽略状态以“虚拟文件绝对路径 + modifiedAt”为版本标识；同一路径后续产生新的最后修改时间时必须重新参与提示。列表自动重绘而行恰好出现于静止鼠标下方，不得被视作用户悬停或自动关闭提示。
+ 已忽略状态需要跨页面刷新和目录切换有效，但不得长期占用本地存储：仅使用一个集中 `localStorage` 键保存尚未到期的记录，每项的到期时刻固定为 `modifiedAt + 30 秒`，到期立即删除；无有效记录时删除整个键。
+ 到期检查禁止使用固定间隔轮询。页面只允许为最近一个高亮或已忽略记录设置一次性定时器；文件列表刷新、页面重绘、写入忽略状态和定时器到期时均清除过期记录并重新计算下一个到期时刻。
+ 以下保存或导出请求成功后，虚拟文件系统必须立即跳转到对应目录、重新读取列表，并按上述规则检查该目录内所有最近 `30` 秒修改的文件；不得依赖或指定某个单独文件路径，因此一次请求产生多个文件时都能同时提示：
  + 图片浮层保存或编辑：`images`。
  + 音频浮层保存或编辑：`audios`。
  + 视频浮层保存或编辑：`videos`。
  + 录屏浮层保存或编辑：`videos`。
  + 画布导出 PNG 图片：`images`。
  + 混音浮层保存或编辑：`audios`。
+ 仅在服务端确认保存或导出成功后跳转。画布导出 PDF 继续按其既有文档输出行为处理，不作为“创建图片”的目录跳转。

### 编写代码

+ 最小范围更新，不新增第三方依赖。
+ 使用 `/api/files` 的 `modifiedAt` 字段完成排序和最近文件状态；列表请求继续使用无缓存读取，确保保存后可立即看到新状态。
+ 所有上述保存成功入口复用同一目录跳转和刷新逻辑，避免针对特定输出文件的选择、滚动或追踪；同一 Agent 的标识仅大小写差异时仍必须识别为同一工作区并完成跳转。
