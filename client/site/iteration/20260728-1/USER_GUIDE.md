# 视频编辑裁剪范围

在视频预览浮层点击“编辑视频”并通过 FFmpeg/FFprobe 环境检查后，时间切分面板会提供“选择裁剪范围”开关。默认关闭，关闭时导出行为与原有视频切分一致。

- 开启后，在视频画面中选择矩形、椭圆或钢笔三种形状。矩形和椭圆可拖动蓝色选区及四角手柄调整；选择“钢笔”后单击画面依次落点，双击或再次点击第一个点即可闭合。可用“清除路径”重新绘制。
- 补边色默认黑色，也可切换白色。选区会等比放大并居中放入源视频画布；因比例不同而未占用的区域，以及椭圆或钢笔闭合区域之外，都会填充所选颜色。
- 裁剪范围只作用于当前“开始”和“结束”之间的时间片段；保持默认的完整时间范围时，即对整段视频生效。手动调整时间仍按 `0.5` 秒定位；默认结束位置会保留媒体真实时长，因此例如 `12.4` 秒的视频可完整导出。
- 未闭合、没有面积或无效的钢笔选区不能保存。关闭开关、取消编辑或保存失败不会生成文件，也不会修改源视频。
- 保存仍会生成新的 MP4 到当前 Agent 工作目录的 `videos/`，刷新文件列表并尽力复制最终绝对路径；需要受控环境中的 `ffmpeg` 和 `ffprobe`。
