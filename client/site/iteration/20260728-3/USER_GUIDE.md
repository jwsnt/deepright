# 视频音频剪辑使用手册

在视频预览浮层右上角，提取帧按钮左侧的音符图标现在是“剪辑音频”。点击后先检查 FFmpeg 和 FFprobe；如果缺失，会显示安装确认，检查成功才进入剪辑界面。

剪辑界面保留视频画面和播放控制，下方提供音轨时间轴。原视频第一音轨会作为“原视频音轨”加入，可拖动、调整参数或删除；无原音轨的视频也能进入，添加新的音频后即可导出。

点击“添加音频”选择本机音频。文件会先安全暂存到当前 Agent 工作区，再加入时间轴。每段音轨可设置裁剪起止、时间轴位置、播放速率、循环时长、整体与左右声道音量、淡入淡出，以及均衡器、压缩器、混响、延迟等效果器；参数范围与“混音”一致。

点击“试听”会临时生成当前完整时间轴的混音，并从当前视频时间同步播放。试听期间视频原声自动静音；再次点击可停止。试听、关闭或失败不会创建 `videos/` 下的最终文件。

点击“保存为新视频”后，系统保持原视频画面并合并当前音轨。默认文件为 `videos/<原文件名>_edit.mp4`。若发现同名文件会显示提示，最终文件自动追加时间戳，不会覆盖源视频或已有导出。保存成功后自动切换到 `videos/`，新文件会高亮闪动；保存失败会保留剪辑界面和当前目录，方便调整后重试。

“原视频音轨”片段最左侧的下载图标可单独提取该视频的第一音轨。点击后需确认；确认后会导出 MP3 到 `audios/`。同名文件会自动追加时间戳。成功时虚拟文件系统自动切换到 `audios/`，新文件沿用最近文件的 30 秒高亮闪动规则；没有可提取音轨或提取失败时会显示原因，且不会切换目录。提取完成后仍可继续当前音频剪辑。

最近文件提示不会作用于工作目录根部的 `config.json`、`Knowledge.md`、`mcp.json`、`SOUL.md` 和 `USER.md`；子目录中的同名文件不受此限制。
