### 需求介绍

视频预览顶部原“提取音频”入口改为“剪辑音频”，位置保持在提取帧按钮左侧。

- 点击入口先检查 `ffmpeg` 与 `ffprobe`；缺失时复用视频剪辑的安装确认，不进入剪辑界面。
- 检查通过后在文件编辑浮层内进入音频剪辑模式。保留视频画面和播放控制，并显示与现有混音一致的多轨时间轴、音轨检查器和新增音频入口。
- 视频原有第一音轨作为“原视频音轨”加入时间轴；它可调整裁剪范围、时间轴位置、速率、循环、整体/左右声道音量、淡入淡出和现有四类效果器，也可删除。没有原音轨的视频仍可进入，用户可新增音频后导出。
- 原视频音轨片段最左侧提供独立的提取小图标。点击后必须先确认；确认后将源视频第一音轨导出为 MP3 到当前 Agent 的 `audios/`。成功后保持当前剪辑界面、切换虚拟文件系统到 `audios/`，并复用最近文件 30 秒高亮闪动；无音轨或提取失败时提示原因且不切换目录。文件同名时由服务端自动追加时间戳，不覆盖已有文件。
- 用户可拖入或选择工作区/本地音频，将额外音轨加入时间轴；额外音轨使用与混音相同的参数和交互。
- 提供“试听”按钮，按当前完整工程生成临时混音并与视频画面同步播放；试听不写入 `videos/`，停止、关闭或失败时清理临时资源。
- 保存导出保持源视频画面，使用当前时间轴音轨生成新 AAC 音频，输出 MP4 到当前 Agent 的 `videos/`。默认名称为 `<原文件名>_edit.mp4`；存在同名文件时提示用户，服务端自动在扩展名前追加时间戳且不覆盖已有文件。
- 成功后关闭音频剪辑状态、跳转 `videos/` 并触发现有最近文件高亮；失败时留在当前界面与目录，源视频和已有文件保持不变。
