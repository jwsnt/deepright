# 居中对话框图片浏览器缓存

## 功能说明

居中对话框中已经成功展示过的远程图片，现会自动写入浏览器缓存。

当图片首次显示成功后，即使后端图片链接后续下线、返回 `404`，或远程资源暂时不可访问，页面刷新后仍会优先尝试从浏览器本地持久缓存恢复这张已展示过的图片。

## 实现方式

- 站点新增浏览器端图片缓存能力
- 对话消息中的远程图片首次成功加载后，自动写入浏览器本地缓存
- 后续同一图片地址再次渲染时，优先使用浏览器本地缓存结果
- 页面刷新后，如果浏览器本地缓存仍在，已展示图片依旧可以正常显示

## 适用范围

- 仅针对居中对话框内 assistant 消息中已经成功展示过的远程图片
- 本地 `data:` 图片、未成功加载过的图片，不在本次缓存兜底范围内

## 注意事项

- 浏览器需要支持本地持久缓存能力，当前实现使用 `Service Worker`、`Cache Storage` 与 `IndexedDB`
- 如果浏览器手动清理站点缓存，已缓存图片会一并失效
- 若图片地址从未成功加载过，则无法在源地址失效后继续显示
