# 20260526-1 用户手册

本次迭代为左侧插件按钮补充了一条独立的新手引导流程。

- 当浏览器本地还没有“点击过插件按钮”的记录，并且当前至少存在一个可用插件时，第一次点击左侧插件按钮会触发插件引导
- 引导会自动展开左侧 Sidebar，并展开扇形插件菜单
- 流程会依次高亮扇形插件菜单、第一个插件图标、插件浮层、插件启动按钮和插件日志按钮
- 每一步都通过 `知道了` 或 `完成` 推进；进行中时，其它区域会被暗化且不可点击
- 这条插件引导与首次使用引导、首次点击输入框引导、首次点击蜂群图标引导相互独立，不会互相覆盖
- 插件引导会根据当前 DOM 状态自动恢复目标区域：菜单被收起时会重新展开，插件浮层被关闭时会重新打开第一个插件的配置浮层
