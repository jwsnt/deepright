## 配音

在虚拟文件系统点击“新增”，选择“配音”并填写 WAV 名称。省略 `.wav` 会自动补齐；创建前会检查 `audios/` 中填写的名称及默认 WAV 名称，已有同名文件时不会创建空文件。

创建会先检查 `voxcpm`。未安装时会显示与 FFmpeg 一致的安装确认；取消保留创建窗口，确认会关闭创建窗口并把配置的安装请求发送到当前任务。配置错误或检查失败时会保留创建窗口并显示错误；浏览器不会自行安装。

也可以把鼠标悬停在当前 Agent 根目录的 `audios` 文件夹上，点击新增的“文字转语音”小图标快速创建配音。该入口同样先检查 `voxcpm` 并在缺失时提示安装；检查通过后会直接打开任务浮层，默认输出文件名为当前时间戳加 `.wav`。

预览当前 Agent 工作区中的文本文件时，底部“取消”按钮左侧也会显示“文字转语音”小图标，图标底边与“取消”按钮底边对齐，顶部保持原有预览布局。点击并通过环境检查后，文本文件会自动填入待加入任务；参考音色和表达风格都可不填。不选参考音色时会使用 VoxCPM `design` 自由生成声音。默认输出名为“文本文件名去后缀 + `.wav`”，生成文件仍保存在 `audios/`；发生同名冲突时会自动追加时间戳。

检查通过后会打开“文字转语音”。每条语音任务只必须选择文字文件；“参考音色”和“表达风格”均可不填，文件均可从任意本机目录选择；上传后会显示工作区中的绝对路径。不选择参考音色会使用 VoxCPM `design` 自由生成声音，选择后才使用 `clone` 克隆该音色。文字与参考音色路径在固定源文件列中截断，表达风格、场景和删除控件保持固定宽度和对齐，不会因路径或文件名变长错位。文字与参考音色后方的“表达风格”输入框可选填，例如“温和、平稳、自然的叙述语气”；填写后会作为该条任务的 `--control` 指令记录在执行日志，并覆盖场景原有的表达风格。日志也会明确显示参考音色是否选择、使用的 `design` 或 `clone` 模式，以及是否传入 `--control`。场景下拉框与“提取音频文字”浮层使用相同交互和样式，默认“均衡克隆”；底部“场景说明”会随最近选择实时显示该场景特点。场景提供“均衡克隆”“质量优先”“快速预览”“清晰增强”“温暖叙述”和“轻快表达”，服务端据此使用受控的 CFG、推理步数、文字规范化、参考音频增强及风格控制参数。最多可同时加入 5 条任务。单条任务优先使用创建时填写的名称；多条任务或发生冲突时，输出 WAV 会在名称后追加时间戳并保存至 `audios/`。

任务信息分两行显示：第一行是开始时间、场景、表达风格与自适应占用剩余空间的文字路径，第二行是参考音频与生成音频。表达风格未填写时显示“未填写”；表达风格和文字路径被截断时，悬停即可查看完整值。任务浮层支持状态筛选、每页 5 条分页、自动刷新日志、取消、重新开始、删除失败或已取消任务；完成 WAV 可直接复制路径或预览，也可勾选多条完成任务后，在状态筛选右侧展开的“复制”一次复制所有绝对路径，“清空”只会取消勾选。“提取图片主体”浮层中的完成图片也提供相同的多选、批量复制输出绝对路径与清空勾选操作。配音、提取音频文字和提取图片主体任务中，过长的任务名称、源路径和输出路径都会以 `...` 截断；悬停被截断内容即可查看完整绝对路径，状态与取消等操作控件始终完整显示。关闭浮层、刷新页面或重启应用不会取消已经创建的任务。
