# Site 迭代手册（20260517-1）

## 本次更新

- 右侧 Sidebar 新增与左侧一致的收起/展开能力
- 页面首次打开时，右侧 Sidebar 默认处于收起状态
- 右侧收起后会把原本占用的宽度释放给中间会话区，提升聊天区域可视宽度
- 右侧收起态保留一个细窄的微弱闪光入口，用于提示可以重新展开
- 右侧展开/收起状态会保存在浏览器本地，下次进入页面时延续上一次状态

## 使用方式

1. 页面首次加载时，右侧 Sidebar 默认收起，仅显示右侧边缘的细窄发光按钮
2. 点击右侧边缘的发光按钮，可展开右侧 Sidebar
3. 在右侧 Sidebar 的“正在执行的系统指令”标题行与“知识库WIKI”标题行，都增加了收起按钮
4. 点击收起按钮后，右侧 Sidebar 会缩回为窄条，中间会话区随之变宽

## 交互说明

- 右侧收起入口仅占右侧一条窄栏，不会覆盖中间会话区交互
- 右侧收起后，右侧区域内部面板完全隐藏，不会残留可点击的幽灵层
- 右侧展开后，原有备忘录、CLI 子任务、知识库 WIKI 等内容布局保持不变
- 所有固定定位浮层仍然继续遵守 left / center / right 三域隔离，不会因为右侧收起而跨域拦截点击
