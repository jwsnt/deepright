# 跨 Agent 媒体预览

居中对话框和备忘录中带有图片、音频或视频的文件气泡会保留文件所属 Agent。点击“预览”时，如果该 Agent 与页面当前选择的 Agent 不同，系统会提示“需要复制输入框文件到当前 Agent 吗？”。点击“确认复制”或按 `Enter` 会复制该输入框内全部属于其他 Agent 的图片、音频、视频文件；点击“取消”或按 `Esc` 保持原文件和气泡不变。

从系统拖入居中对话框或备忘录的文件会上传到页面当前选择的 Agent 工作区，并记录该 Agent 作为文件所属方；随后切换到其他 Agent 预览时会触发复制确认。

复制期间页面会锁定，直到本批次的全部文件成功复制或完成失败处理。整批成功后，系统会在页面当前选择 Agent 的工作区中保留原有相对目录，并打开最初点击“预览”的副本，例如源文件 `tmp/clip.mp4` 会复制为目标 Agent 的 `tmp/clip.mp4`；仅当同名时才会在扩展名前增加时间戳。原 Agent 的文件、已发送消息和已有任务不会被改动。

成功复制后，居中对话框和备忘录中所有引用同一源 Agent 与源文件的气泡都会改为副本路径。随后在媒体预览中使用 SAM2、RVM 或 Wav2Lip 时，会检查并使用当前选择 Agent 的工作区依赖。普通消息编辑浮层不触发此复制确认。
