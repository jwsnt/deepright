### 需求介绍

- 居中对话框 `msgInput` 与备忘录输入框 `rsNoteInput` 中的图片、音频、视频文件气泡，在用户点击“预览”时，必须识别文件所属 Agent 与页面当前选择的 Agent 是否一致。普通消息编辑浮层不纳入本需求。
- 当文件属于其他 Agent 时，不得直接打开媒体预览；必须展示复制确认浮层，提示“需要复制输入框文件到当前 Agent 吗？”。确认按钮或 `Enter` 必须批量复制该输入框内全部跨 Agent 媒体文件；取消按钮或 `Esc` 不改变任何文件、气泡或草稿。
- 复制期间必须以不可关闭的全局锁定层阻止重复操作、页面点击和快捷键，直到本批次所有文件均已成功复制或已完成失败处理后才解除锁定；应显示进行中的文件数量。仅当整批复制成功后，才打开用户最初点击“预览”的文件。失败时保留未复制文件和原气泡，并显示可理解的批量失败原因。
- 复制目标必须是页面当前选择 Agent 的工作区，保留源文件在源工作区内的相对目录；目标同名文件存在时才在扩展名前追加时间戳后缀，未冲突时保留原文件名。复制成功后以目标文件、目标 Agent 打开媒体预览。
- 从系统拖入居中对话框或备忘录输入框的文件，必须直接上传到页面当前选择 Agent 的 `tmp` 目录，并以接口返回的 Agent 写入文件气泡归属；不得回退使用尚未同步的会话绑定 Agent 或设置页旧值。
- 复制不是移动：源文件必须保留，已发送消息、历史链接、既有任务和原 Agent 工作区均不得被改变。成功后必须同步刷新居中对话框和备忘录输入框内所有指向同一“源 Agent + 源路径”的文件气泡，使其改为目标 Agent 与目标绝对路径，并持久化对应输入草稿。
- 文件本已属于页面当前选择的 Agent、不是图片/音频/视频、无法解析所属 Agent 或用户取消确认时，不展示复制执行流程，保持既有预览行为。
