# 20260504-5 使用手册

## 目标

本次迭代用于统一 CLI 子面板 `CMD` 执行浮层与扇形菜单插件浮层的展示规则：

- 点击右侧 CLI 子面板中的 `CMD` 图标后，浮层改为在中间会话区水平垂直居中展示
- `CMD` 浮层使用与扇形菜单插件浮层一致的背景模糊效果
- 固定定位的遮罩层、确认框、弹窗继续按左侧 Sidebar、中间会话区、右侧 Sidebar 分域管理

## 页面行为

- `CMD` 浮层只覆盖中间会话区，不会跨区域遮挡左右 Sidebar
- 浮层保留原有 `500x110` 的命令输入与二次确认交互
- 小屏宽度下，`CMD` 浮层会跟随中间区域宽度自适应收缩，避免超出可视范围
- 打开 `CMD` 浮层时，会主动收起其他中间域浮层，避免多个中心弹层同时叠加

## 浮层规则

- `CMD` 浮层属于中间会话区的 overlay 域
- 未激活时保持 `pointer-events:none`，不会拦截底层点击
- 点击浮层外空白区域仍会直接关闭
- 浮层打开和关闭时，仍复用现有统一的 overlay 激活状态管理
