### 需求介绍
+ 视频预览浮层右上角、关闭按钮左侧新增冷色系“编辑”图标；仅在当前 Agent 工作目录的视频预览可用。
+ 点击图标立即进入视频切分模式，暂停当前视频并显示开始、结束两个可拖动手柄；两个时间点和选区时长均以 `0.5` 秒为最小定位单位。暖色主题下切分浮层及其滑块、播放器控制、操作按钮和保存命名确认使用暖色空间；冷色主题下上述界面统一使用冷色空间，不得残留暖色强调色。
+ 切分模式中的播放、进度拖动和前进/后退均限制在当前选区内，到达结束时间即暂停并回到选区起点，便于试听选段。
+ 用户点击“保存为新视频”前不产生任何文件；取消、关闭浮层、读取时长失败或保存失败均不改变原视频。
+ 点击“保存为新视频”后先显示文件名输入框，默认名称使用原文件名加 `_trim_时间戳.mp4` 的规则；文件名仅可修改名称，不得包含路径。确认后调用 Integration 的受限视频切分接口，成功后在当前 Agent 工作目录的 `videos/` 目录生成新 MP4 文件；目录不存在时由服务端创建。页面刷新虚拟文件列表，复制服务端返回的绝对路径到系统剪贴板，并明确提示复制结果；原视频不得被覆盖、删除或改名。
+ 视频的取色、坐标提取等既有视频预览工具与切分模式互斥，进入切分模式时退出这些工具，避免在同一视频画面上出现冲突操作。
+ 页面不读取本机绝对路径、不构造 `file://` 链接、不在浏览器上传整段视频或自行转码；服务端错误应保留当前预览和选区并展示可理解的原因。
