### 需求介绍
+ 在页面右下角增加与 Chat 绑定的便签入口。入口默认收起为紧贴右下角的小气泡，并以低频闪动提示可用；点击在保持入口可见的前提下展开便签，再次点击收起。
+ 便签浮层固定宽 `300px`、高 `350px`。内容区支持文字输入、自动换行和内部滚动；文字、换行及气泡计入与居中对话输入框一致的总字符上限。
+ 便签支持拖入和粘贴文件、图片、视频，并将其保留为与居中对话输入框一致的文件/图片/视频气泡；普通 URL 也以气泡形式保留。
+ 在便签输入 `@` 时，可选择当前 Chat 和 Agent 上下文可访问的文件、技能和 Agent；选择结果以对应气泡展示。候选范围必须与当前 Chat 的居中对话输入框相同。
+ 便签底部提供“对话框”“备忘录”“清空”三个操作：
  + “对话框”将便签内容及全部气泡追加到居中对话输入框，然后清空当前便签并收起浮层。
  + “备忘录”将便签内容及全部气泡追加到右侧备忘录输入框，然后清空当前便签并收起浮层。
  + “清空”必须先二次确认；确认后仅清空当前 Chat 的便签。
+ 每个 Chat 维护独立的便签内容。内容须在刷新页面、应用重启后恢复；切换 Chat 时自动收起便签，但不得丢失任一 Chat 的内容或其气泡元数据。
+ 便签在常规页面和展开后的 URL iframe 覆盖窗口中均可展示、编辑；屏保、关机确认/关机倒计时、以及右侧栏 URL iframe 的未展开预览状态中必须隐藏。切换 Chat 后，便签必须处于收起状态。

### 编写代码
+ 将便签数据作为 Chat 本地持久化载荷的一部分，并与 Chat 删除、存储压缩和跨页面存储同步兼容；不可因便签内容丢失或破坏会话历史。
+ 复用现有输入框的气泡 HTML 与附件属主标记，转发到对话框或备忘录时须保留气泡显示和文件属主信息。
+ 便签显示状态仅为瞬态 UI 状态，不写入持久化数据；右侧栏 URL 预览、其展开状态、屏保和关机浮层变化时须立即同步显示状态。
+ 除必须隐藏的屏保、关机和右侧栏未展开 URL iframe 外，便签必须位于所有页面浮层之上，且保持可点击、可编辑。
