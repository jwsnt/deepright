### 需求介绍
+ 为最后一条正常结束的 SSE 助手响应增加“页面备注”能力，帮助用户引用响应中的局部内容并在下一次提问时附带自己的说明。
+ 标注范围与入口
    + 仅当前 chat 中最后一条正常结束、非异常、非手动终止的 SSE 助手响应可标注；流式响应中、异常响应和历史响应均不可标注。
    + 用户在该响应气泡内框选非空文字后，展示“标注”按钮。链接、文件、技能及其它带特殊交互的气泡也可框选其可见文本。
    + 标注按钮必须使用用户完成框选时的文本与范围快照；后续浮层展示、保存的引用内容必须与框选文字逐字一致，不得因按钮点击、焦点切换或异步操作条更新丢失首尾字符。
    + 特殊气泡原有的打开、下载、预览等按钮与行为必须保持不变；标注入口作为其前置的新增操作，不得覆盖或截获原按钮事件。
    + 标注入口的视觉风格与 URL 自动识别预览入口一致。
+ 标注编辑浮层
    + 点击“标注”打开浮层，浮层的视觉与 SSE 响应结束后的右下角编辑样式一致。
    + 浮层中的“引用内容”保持单行展示；内容超过可用宽度时以 `...` 省略，完整引用通过悬浮提示可见。
    + 浮层复用居中 SSE 输入框的完整编辑能力和展示方式：富文本输入、图片、视频、文件、拖放/上传及 `@` 文件、技能等唤起能力。
    + 保存时记录“引用内容”和“我的备注”；空引用或空备注不得保存。气泡正文显示引用内容前 5 个字符，超出部分显示 `...`；用户可编辑或删除已保存标注。
+ 标注展示与持久化
    + 已标注的引用文字以统一的纯色下滑波浪线标识，不按标注顺序交替颜色；标注气泡同样按当前冷暖主题分别统一为对应冷色或暖色，不得在同一主题内交替颜色；删除标注后应立即移除该标注对应的波浪线。
    + 标注按 chat 维度保存到浏览器本地存储，刷新页面后必须恢复；不写入服务端或数据库。
    + 同一响应允许保存多条标注，展示和发送排序均以引用在原响应文本中的起始位置为准；相同位置按创建顺序排序。
    + 标注气泡列表最左侧提供“完全清除标注”小图标。点击后弹出确认浮层，文案为“是否清除所有标注？”，提供“取消”和“删除”两个操作；`Esc` 等同取消，`Enter` 等同删除。确认删除后，仅删除当前 SSE 响应的全部标注、其波浪线及标注气泡展示，不影响其它 chat 或其它响应。
+ 发送拼接与生命周期
    + 下次从当前 chat 发送 SSE 时，将所有暂存标注按排序结果汇总为 Markdown 表格，并置于本次用户输入之前：
      ```markdown
      ### 标注内容

      | 引用内容 | 我的备注 |
      | --- | --- |
      | xxx | yyy |

      用户本次输入
      ```
    + 标注中的附件、媒体和 `@` 引用按现有输入框的实际提交格式拼接，不降级为纯展示文本。
    + 发送后若新 SSE 正常完成，自动删除该 chat 已发送的全部标注并清除波浪线；该新响应成为唯一可标注的响应。
    + 新 SSE 异常、被中止或失败时，原标注与波浪线必须保留，以供再次发送。
+ 本地存储统计
    + 在“本地存储统计”汇总卡片末尾增加“页面备注”一栏，展示该缓存占用空间及标注数量。
    + 此栏提供“立即清空”操作；点击后立即删除所有 chat 的页面备注、暂存内容及页面波浪线展示，并刷新统计。
    + 页面备注必须纳入本地存储自动治理：当超过预算触发自动清理，或浏览器配额不足触发保存降级时，立即清除所有 chat 的页面备注、待发送内容和波浪线展示，再继续缓存清理或会话压缩。
