# 20260510-1 User Guide

## 目标

本次迭代在右侧边栏最下方补齐了 `知识库WIKI` 标题栏，并接入了 `wiki_md` 静态 Markdown 展示区。

- 标题内容为 `知识库WIKI`
- 标题右侧新增刷新图标
- 标题栏样式、尺寸和视觉语言与右侧 `正在执行的系统指令` 分割带保持一致
- 标题栏右侧会展示 Mock 的 `最近刷新 HH:mm:ss` 时间
- 下方内容区默认读取 `site/wiki_md/index.md`

## 交互说明

1. 打开页面后，查看右侧边栏最下方区域。
2. 最上方会显示 `知识库WIKI` 标题栏。
3. 下方内容区会渲染 `wiki_md` 中的静态 Markdown 文档。
4. 点击 Markdown 中的相对链接后，会在当前 `知识库WIKI` 面板内继续打开对应文档。
5. 点击标题右侧刷新图标后，图标会短暂旋转，并重新加载当前文档，同时更新最近刷新时间。

## 说明

- 本次修改使用 `site/wiki_md` 作为静态 Markdown 测试目录
- 当前迭代不新增额外后端接口，也不改变现有 CLI 子面板、备忘录面板和弹层分域规则
- 更完整说明请继续参考上级手册 `../../USER_GUIDE.md`
