# 20260505-6 使用手册

## 目标

本次迭代为左上角扇形菜单补充“已启动插件高亮提示”能力：

- 每次展开扇形菜单时，页面会主动刷新插件运行状态
- 已经启动的插件按钮会显示绿色闪动效果
- 状态判断统一复用 `/api/plugins/status?name=插件key`
- 插件浮层中的启动、关闭操作完成后，扇形菜单状态会同步刷新

## 页面行为

- 扇形菜单按钮仍然来自 `/api/plugins/meta`
- 页面首次加载到插件列表后，会继续沿用已有的扇形布局和展开动画
- 每次点击左上角即时通讯入口展开扇形菜单时，页面会并行请求各插件的 `/api/plugins/status`
- 如果某个插件状态返回 `started=true`，对应扇形按钮会立即切换为绿色闪动样式
- 绿色闪动只表示该插件当前已启动，不会改变原有点击行为
- 如果状态接口返回未启动或请求失败，该插件按钮会保持原有默认样式
- 扇形菜单展开后，如果随后在插件浮层中成功执行 `重启`，对应插件按钮会同步切换为绿色闪动
- 如果在插件浮层中成功执行 `关闭`，对应插件按钮会同步恢复默认样式
- 扇形菜单按钮的标题和无障碍标签会追加“已启动”语义，便于区分当前运行态

## 状态来源

- 插件运行态统一通过 `/api/plugins/status?name=插件key` 获取
- 这里的 `name` 实际上传递插件 `key`；如果没有独立 `key`，则回退为插件名称
- 页面不会额外引入新的状态接口，也不会改变现有插件启动、关闭接口

## 浮层与交互规则

- 本次迭代不改变既有扇形菜单、插件浮层和设置浮层的分域 overlay 规则
- 左侧 Sidebar、居中会话区、右侧 Sidebar 仍按既有方式隔离 pointer-events 和层级
- 未激活的浮层仍保持彻底失活，不会跨区域拦截点击
- 绿色闪动只作用于扇形菜单按钮视觉层，不新增遮罩或额外透明点击层
