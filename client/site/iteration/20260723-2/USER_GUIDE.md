# 20260723-2 用户手册

## 元数据查询

- “备忘录查询”的“元数据”结果表不再显示状态列。元数据可能对应多条任务明细，状态仍可作为筛选条件使用，但不会在元数据行中汇总展示。
- “任务明细”结果表继续显示每一条任务自己的状态。

## 从元数据查看任务列表

1. 在右侧备忘录元数据列表悬停一条元数据，打开“备忘录元数据预览”。
2. 点击“内容”标题右侧的列表图标。
3. 页面会直接打开该元数据的任务明细列表，并自动查询其全部历史与待执行任务。
4. 可继续按执行时间、Agent、模型、状态和任务内容筛选；筛选范围始终是这条元数据，不能切换到其他元数据或元数据查询页。
5. 点击每行预览仍可查看具体任务。返回列表后，会继续保持同一条元数据的限定范围。

关闭查询、点击遮罩或按 `Esc` 后，再从普通备忘录查询打开时，会恢复原有的查询维度、条件、结果和滚动位置。

## 说明

- 这个列表只用于查询和预览，不会创建、修改或删除备忘录、任务明细或会话。
- 相关通用说明请继续参考上级手册 `../../USER_GUIDE.md`。
