# 20260609-1 用户手册

本次迭代为左侧虚拟文件系统中的文件目录展示区域补充了一条独立的新手引导流程。

- 当浏览器本地还没有“点击过 / 悬停过虚拟文件系统文件目录展示区域”的记录时，第一次把鼠标移入该区域，或第一次点击该区域，都会触发这条拖拽上传引导
- 引导第一步会高亮整个虚拟文件系统文件目录展示区域，并提示：`将系统文件或目录拖入虚拟文件系统即可自动上传`
- 点击 `知道了` 后，会进入第二步；页面会继续锁定左侧、居中和右侧三个交互域，并播放一段模拟鼠标把系统文件拖入虚拟文件系统的动画，同时提示：`拖入文件，开始上传。`
- 动画播放完成后，浮层才会出现 `完成` 按钮；点击后关闭这条引导并恢复正常交互
- 引导期间文件列表本身不会响应查看、进入目录、下载、删除等真实操作，避免和引导演示互相干扰
- 这条拖拽上传引导与首次使用引导、首次点击输入框引导、蜂群引导、插件引导、`SOUL.md / USER.md` 引导、右侧备忘录引导、Skill 提炼引导、知识库引导等其它引导相互独立，并且可以兼容共存
