# 设置中的服务地址浮层

## 简介

站点设置面板提供服务地址入口，用来修改 `integration` 当前使用的上游服务地址。

- 修改目标：`integration` 当前生效的服务地址
- 生效范围：立即生效
- 持久化：写入应用资源目录的 `config/config.json`
- 重启后：继续使用已保存的服务地址

## 使用方法

1. 打开左下角的 `设置`
2. 点击标题中、`deviceId` 复制图标左侧的服务地址图标
3. 弹出 `服务地址` 浮层，设置面板会自动关闭
4. 输入新的 `http://` 或 `https://` 地址
5. 点击 `保存`

如果需要恢复默认地址，可以点击 `恢复默认值`；它会保存 `https://www.deepright.cn`。

## 浮层说明

- `当前服务地址`：当前实际生效的上游地址
- `修改服务地址`：输入新的完整地址
- `保存`：立即切换并写入 `config/config.json.host`
- `恢复默认值`：立即恢复并写入默认服务地址

## 限制

- 该隐藏入口仅在本地访问站点时可用。
- 修改后不会影响设置面板中的其他未保存内容；入口仅在 `localhost`、`127.0.0.1` 或 `::1` 访问时展示。
- 该浮层调用的是 `integration` 的 `/api/host` 接口。若服务未启动或接口不可达，会在浮层中显示错误信息。
