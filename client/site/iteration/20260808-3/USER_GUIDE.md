# Site：删除会话时终止请求

确认删除会话后，页面会立刻停止该会话尚未结束的预发送、SSE 读取、恢复轮询和待发送队列自动出队；该会话会立即从列表和本地记录中移除。

- 浏览器内的待发送消息会立即清空。页面还会查询并物理删除服务端 `message_insert` 中该会话未完成的插入消息，避免之后再次自动发送。
- 删除与 SSE 完成、历史恢复或队列正要出队同时发生时，删除优先。晚到的数据不会恢复该会话、重新创建待发送队列或发起下一条请求。
- 已发往服务端的请求会立即取消；如果未确认成功，页面每隔 `15` 秒再尝试一次，最多共 `3` 次。
- 三次均未成功时，页面停止重试，并提示“会话已删除，但取消请求失败，后端可能仍在处理”。待发送消息清理失败时也会给出明确提示。

对应需求见 [REQUIREMENT.md](REQUIREMENT.md)。
