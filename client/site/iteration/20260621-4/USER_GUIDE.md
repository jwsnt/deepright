# 20260621-4 使用手册

## 简介

本次迭代补充了待发送消息队列的新手引导流程，在原有 `编辑 -> 删除 -> 拖动` 说明之间新增了 `插入` 按钮的独立讲解步骤。

## 页面行为

- 当浏览器本地还没有待发送消息队列引导记录，并且用户第一次把消息加入待发送列表时，页面会自动启动这条独立引导
- 引导前半段保持原样，仍会先高亮整个待发送列表，再高亮第一条待发送消息
- 随后会依次高亮第一条消息上的 `编辑` 按钮、`删除` 按钮、`插入` 按钮和左侧拖拽手柄
- `插入` 这一步的引导文案为 `立即插入消息，引导新流程。`
- 点击 `知道了` 后，引导会继续切到拖拽手柄；最后点击 `完成` 后关闭遮罩并恢复页面全部区域可点击

## 兼容规则

- 这次只是扩展原有待发送消息队列引导顺序，不会改变待发送列表的自动发送、编辑、删除、插入和拖拽排序功能
- 引导期间除当前高亮目标和引导卡片外，其它区域都会被暗化且不可点击
- 这条引导与首次使用引导、首次点击输入框引导、蜂群引导、插件引导、备忘录引导、`__RETRY__` 引导等现有新手引导相互独立，可以兼容共存
- 如果首次加入待发送列表时正有其它引导仍在进行中，这条引导会等待当前引导结束后再补播
