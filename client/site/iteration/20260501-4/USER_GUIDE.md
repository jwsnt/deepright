# 20260501-4 使用手册

## 简介

本迭代为 Site 的会话消息和右侧 CLI 子面板增加了按会话维度的展示数量上限。

## 功能说明

### 主会话消息上限

- 每个会话（Agent + Chat）的居中会话框最多保留并展示最近 `2000` 条消息
- 该上限按请求与响应合并计算，即用户消息和 assistant 消息都会计入总数

### 右侧 CLI 子面板上限

- 每个会话（Agent + Chat）的右侧 CLI 子面板最多展示最近 `100` 条独立响应气泡
- 当新的 CLI 子响应继续进入时，最早的旧气泡会自动移出展示范围
- 切换会话或刷新页面后恢复展示时，仍只保留最近 `100` 条 CLI 子响应
