# 20260517-5 使用说明

## 迭代目标

本次迭代调整左侧虚拟文件系统 `Tips` 的展示位置：当左侧 Sidebar 收起时，提示改为显示在居中对话框左下角。

## 变更说明

- 左侧 Sidebar 展开时，`Tips` 仍显示在虚拟文件系统底部，样式、颜色、展示时长保持不变。
- 左侧 Sidebar 收起时，原本的 `Tips` 会自动切换到居中对话框左下角显示。
- 新位置位于居中对话框之外，并与居中对话框区域保持垂直左对齐。
- 左侧 Sidebar 再次展开后，`Tips` 会自动恢复到虚拟文件系统原位置。
- 提示逻辑仍复用同一套消息入口，因此所有原有成功/失败提示都会跟随位置切换，无需分别维护两套文案。

## 验收建议

1. 在左侧 Sidebar 展开状态下，触发任意一个 `Tips`，确认提示仍出现在虚拟文件系统底部。
2. 收起左侧 Sidebar。
3. 再次触发任意一个 `Tips`，确认提示显示在居中对话框左下角，且颜色与展示时长不变。
4. 重新展开左侧 Sidebar，确认后续 `Tips` 恢复到左侧虚拟文件系统底部。
