# 20260511-6 User Guide

## 目标

本次迭代为右下角 `知识库WIKI` 内容区补充了悬停感知的自动刷新能力。

## 行为

1. 当鼠标不在 `知识库WIKI` 内容区内时，页面会每 `30` 秒自动刷新当前正在查看的知识库文档。
2. 当鼠标进入知识库内容区后，自动刷新会暂停，避免打断当前阅读。
3. 自动刷新会同步更新标题栏中的 `最近刷新` 时间。
4. 自动刷新过程不会插入“正在加载”占位，也不会主动把滚动条拉回顶部；只有内容实际变化时才会重新渲染。

## 说明

- 本次迭代只调整知识库右下角内容区的自动刷新逻辑，不修改手动展开/收起按钮行为
- 更完整说明请继续参考上级手册 `../../USER_GUIDE.md`
