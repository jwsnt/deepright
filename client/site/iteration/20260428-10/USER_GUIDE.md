# 迭代 20260428-10：SSE 响应时间与状态展示

## 功能说明

1. 居中输入框发送消息后，assistant 气泡在收到并渲染 SSE `content` 时，右下角展示接收时间和状态
2. 展示格式为 `yyyy-MM-dd hh:mm:ss 状态`
3. 时间和状态使用浅色字体，字号为 `10px`，并保持右对齐
4. SSE 返回多条增量内容时，每次渲染都会刷新显示时间和状态
5. SSE 未结束时状态为 `等待`，SSE 结束后状态为 `完成`

## 实现说明

- 时间戳独立存储在 assistant 消息对象的 `receivedAt` 字段中，不参与 Markdown 内容拼接
- 状态独立存储在 assistant 消息对象的 `streamStatus` 字段中
- 每次收到可渲染的 SSE 文本片段时，都会更新 `receivedAt` 并将状态标记为 `等待`
- SSE 正常结束、停止等待后，会将最后一条 assistant 消息状态更新为 `完成`
- 切换会话、重新渲染消息列表、惰性加载历史消息时，都会复用已保存的时间和状态展示
