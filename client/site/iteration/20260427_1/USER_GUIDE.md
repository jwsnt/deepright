# 右侧边栏使用手册

## 布局

- 右侧边栏宽度为左侧 Sidebar 的 2 倍(520px)
- 上半部分为田字四方格:
  - 左上格: 日历(2/3) + 时间轮任务列表(1/3)
  - 右上格: 备忘输入(7/8) + 时间选择与操作按钮(1/8)
  - 其余两格: 预留扩展
- 下半部分: 预留扩展

## 日历

- 点击 ◀ ▶ 翻阅月份
- 今天以主题色高亮, 点击日期以淡红色标记

## 备忘输入

- 占位符显示当前 Agent 名称(20px 字体), 最大高度 150px, 超出滚动
- 支持从 VFS 或系统拖入文件/目录(拖入时有光圈提示), 以气泡形式插入
- 支持输入 @ 触发文件和技能选择菜单(独立于主对话框的菜单, 紧贴 @ 字符展开)
- 底部左侧: 30px 小地球图标选择模型(字体统一 10px), 右侧: Thinking 开关
- 下方右对齐: 时间选择器(小时下拉 + 分钟输入) + 垃圾桶取消 + 信封保存
- 焦点不在时间控件时每 10 秒自动同步系统时间
- 取消按钮重置所有状态
