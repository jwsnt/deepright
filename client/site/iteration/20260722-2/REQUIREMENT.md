### 需求介绍
+ 仅在“设置”浮层的“模型与密钥”每一行按需展示紧凑的无文字 Test 小图标，位于密钥输入框右侧、客户化配置与删除图标之前；图标需要与现有圆形图标的尺寸、主题、hover/focus 和无障碍文本保持一致，tooltip 固定为“测试配置”。设置浮层外、模型选择器和聊天界面均不得展示该入口。
+ Test 默认隐藏，仅当该行当前有效配置相对最近一次成功保存的配置发生变化、且当前密钥非空且未掩码时淡入显示；密钥为空时不得展示 Test 图标。Seedream 不提供 Test 图标。deepright 修改密钥后必须显示并可使用 Test，测试请求以内部固定 `__model = deepright` 标识该内置模型。保存成功且服务端返回的配置与当前行一致后淡出隐藏，保存失败时继续显示。比较范围严格限于密钥、`__url`、`__model`、`__model_fast`、`__model_thinking`、`__model_multi_input`、`__model_multi_output`，展开/收起客户化配置、显示密钥和切换 Agent 不得触发。新增未保存行存在有效草稿配置时可显示；配置改回已保存值时立即隐藏。
+ “添加模型”按钮仅在存在尚未配置的服务商时显示；当前已选择或已保存的服务商均视为已配置。最后一个可选服务商被选择后立即隐藏；删除该行或重新出现可选服务商后恢复显示。不得显示一个无法选择任何服务商的空白模型行。
+ 点击 Test 使用当前行尚未保存的服务商、密钥和客户化配置，不要求先保存。密钥为空或掩码时图标隐藏；图标已显示但服务商缺失或有效 `__model` 为空时，图标必须置灰并通过 tooltip 说明不可测试原因；deepright 是唯一内置例外，使用固定 `__model = deepright`，不得回退到 `__model_fast`、`__model_thinking` 等其他模型。
+ 模型 URL 可留空以使用服务商默认地址；填写时必须是无用户名和密码、带主机名的完整 `http://` 或 `https://` URL。URL 只接受标准 ASCII URL 字符；反斜杠、空白、中文标点（如 `、`）和无效百分号编码均为非法。输入框失焦时页面必须立即在其下方展示格式提示；非法输入须阻止保存，并使 Test 图标置灰且说明“模型 URL 格式不正确，请填写 http:// 或 https:// 开头的完整 URL”。
+ 点击可用 Test 后，请求 `POST /api/model/test`，将当前行的有效配置发送到服务端；服务端转发 `/v1/chat/completions` 时必须携带 `metadata.test = true` 并透传至 `--host` 指定的最终处理服务器。请求内容和超时只由服务端读取 `config.json.test.content`、`config.json.test.timeout`，页面不得读取、缓存、显示或覆盖这两个配置值；普通页面会话不得携带该字段。
+ 测试进行期间，该行 Test 图标切换为紧凑 loading/取消状态，禁止再次测试、编辑服务商、密钥、客户化配置、复制、导入与删除该行；密码区域必须完全替换为不透明、闪动、不可编辑的“正在测试配置，请耐心等待。”提示，原密钥文本以及小眼睛、复制和 CURL 等全部框内控件不得可见，直至成功、失败或取消后恢复原输入框。取消按钮可立即终止当前请求。设置的其他行和保存/取消流程保持既有语义。
+ 成功仅在服务端确认 HTTP 200、有效 SSE 数据与 `[DONE]` 完整到达时，在“模型 URL”标题右侧提示“配置成功”，不得额外占用一行。失败时仍在模型主行下方提示“配置错误：{服务端脱敏后的具体原因}”；服务商错误 JSON 有 `content` 时只展示该字段（包括 `choices[].delta.content`），不得展示完整原始响应。服务端识别 HTTP、错误 JSON，或服务商 `content` 中显式标记的 `code/status` 的 401、403、404、429、503、其他 5xx 时，页面仅展示相应的统一中文原因与处理建议，不附服务商原始内容或分隔符；404 文案为“服务商资源不存在（404），请检查模型 URL 和基础模型”。用户主动取消时仅提示“测试已取消”，不作为配置错误，也不得提供自动或立即重试入口。结果不得使用虚拟文件系统 Toast 或设置浮层外提示，避免被设置浮层遮挡；后续配置编辑或图标隐藏时清除旧结果。
+ 测试不能创建、更新或展示任何聊天会话；页面不得调用 `saveChats()`、修改 localStorage、URL、当前会话、模型选择、Agent、备忘录、记忆、技能或普通 SSE 状态。随机测试会话 ID 仅在请求服务端时使用且不可见。

### 编写代码
+ 以现有site页面技术栈编写以上代码，要求：
    + 在../../index.html中按现有HTML/CSS/JavaScript组织方式实现
    + 不引入新的构建流程和额外运行时依赖
    + 在 `../../index.html` 复用模型配置行、客户化配置解析、现有 toast 与 AbortController 能力；不得为测试创建或复用普通聊天、会话、全局工作中状态、历史恢复或持久化状态。
    + 请求前从当前 DOM 行重建服务商、Token 和有效客户化配置，保证未保存编辑值参与测试；每行运行时仅允许一个 AbortController/请求序号，完成、失败、取消、删除、重新渲染和关闭设置时均清理该临时状态。
    + SSE 消费需处理非 JSON、网络异常、HTTP 非 2xx、SSE error/错误 JSON、空流、缺少 `[DONE]`、首包/总超时、取消与乱序返回；只有当前请求序号可更新该行 loading 状态或显示结果。
    + 保持测试图标最小空间占用，以 CSS 宽度、透明度和缩放动画淡入淡出，并为隐藏态、禁用原因、loading 与取消提供可访问名称；测试时避免把 Token、请求正文或原始错误详情写入 DOM、控制台或提示。
    + 覆盖自动化测试：仅设置内可见、未保存配置透传、三种置灰原因、`__model` 强制、重复点击阻断、成功、各失败类别、取消、关闭设置/删除行清理、以及无 chat/localStorage 副作用。
    + 能用现有开源包和浏览器能力的就不要重复造轮子
+ 最小范围更新
