# 迭代 20260530-7：节能模式开关

本次迭代在左侧边栏底部的主题切换同一行新增了 `节能` 开关，默认关闭。

- 打开 `节能` 后，欢迎页开屏动画会直接跳过，不再播放星空开场
- 欢迎页中的持续漂浮动画会停止，页面背景改为静态展示
- 页面内原本依赖毛玻璃的主要区域会改为普通半透明背景，降低持续渲染消耗
- 页面定时任务会切换到节能节奏：
  - `pageTaskSchedulerStep` 改为每 `15` 秒执行一次
  - `heartbeat` 保持每 `30` 秒
  - `vfs` 保持每 `30` 秒
  - `wiki` 与 `quickPlugins` 保持每 `60` 秒

使用方式：

1. 打开左侧边栏底部
2. 在 `深色/浅色模式` 右侧点击 `节能` 开关
3. 开关状态会保存在当前浏览器本地，下次打开页面仍会沿用

用户可见效果：

- 开启节能后，空会话欢迎页会直接显示问候语，不再等待开屏动画结束
- 开启节能后，界面依旧保持半透明风格，但不会再使用毛玻璃模糊
- 关闭节能后，页面恢复原来的视觉效果与常规轮询节奏
