# 20260503-2 User Guide

## 目标

本次迭代重做了首页空白态的开场动画，动画中心统一围绕 `../../icon.png` 的图像中心展开。

## 动画效果

- 动画总时长控制为约 `8s`
- 爆发中心仅使用 icon 中心附近、半径约 `600px` 的圆域
- icon 会从小快速放大
- 中心会伴随强闪、放射光束、粒子爆发和多层能量环
- 动画实际绘制时仅保留 icon 中间 logo 主体的透明有效区域，不再带出两侧无关区域与半透明底纹
- 动画结束时整体渐隐并消失，再显示欢迎文案

## 资源路径

- 开场动画与页面 favicon 都改为使用同目录相对路径 `./icon.png`
- 不再依赖外部绝对路径资源
