# Site 迭代 20260627-1 使用手册

## 本次更新

- 居中对话框中的 SSE assistant 响应气泡，在存在思考内容时，会在左上角增加一个“收起思考内容”入口。
- 思考内容与正式回复仍然属于同一条 assistant 响应气泡，不会因为收起或展开而拆成多条消息。
- 新增思考内容时，默认优先以收起态展示，先把正式回复保留在主要可读区域。

## 页面行为

- 只有包含可识别思考内容的 SSE assistant 响应气泡，才会显示左上角入口。
- 默认状态下，思考内容会被收起，不再占用当前响应正文高度。
- 点击左上角入口后，可以在当前气泡内切换展开或收起思考内容。
- 如果响应仍在流式返回：
  - 收起态下，新追加的思考内容会继续写入当前响应，但不会自动把思考区重新撑开。
  - 展开态下，思考内容和正式回复都会继续实时更新。
- 正式回复区域的 Markdown 展示、自动滚动、复制、时间和状态标记保持原有行为，不受思考区展开或收起影响。

## 状态说明

- 展开或收起状态按当前 Agent、当前会话和当前响应气泡分别记录，不会串到其他会话。
- 切换会话、重载当前会话、轮询恢复未完成响应或恢复历史消息时，会尽量恢复该气泡之前的展开/收起状态。
- 如果历史数据里还没有保存过这项状态，则按默认收起处理。

## 说明

- 这次变更只补充居中 SSE assistant 气泡的思考内容收起交互，不改变现有消息分组和页面技术栈。
- 当前目录交付文件为：`REQUIREMENT.md`、`USER_GUIDE.md`
