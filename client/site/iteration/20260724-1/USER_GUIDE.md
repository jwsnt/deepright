# Site 迭代手册（20260724-1）

## 本次更新

虚拟文件系统中的 `mcp.json` 增加了首次打开时的独立新手引导，用于说明该文件可选地配置 MCP 服务。

## 触发方式

1. 在当前浏览器中，虚拟文件系统尚未记录过打开 `mcp.json`。
2. 点击打开虚拟文件系统中的 `mcp.json` 文件。

鼠标悬停不会触发该引导。

## 引导流程

- 页面会高亮 `mcp.json` 文件，并显示“用于配置MCP服务（可选）。”。
- 遮罩出现期间，除引导卡片和 `完成` 按钮外，其它页面区域不可点击。
- 点击 `完成` 后遮罩关闭，页面立即恢复正常交互。
- 首次触发引导的点击只用于展示说明，不会同时打开文件；之后再打开 `mcp.json` 时，文件会按原有流程正常打开。

## 兼容说明

- 此引导的浏览器记录与首次打开站点、首次点击输入框、插件、SOUL.md / USER.md 等引导相互独立，互不影响。
- `mcp.json` 不会再进入“首次编辑普通文件”的引导范围，避免同一次操作触发多个引导。
