# Site 迭代手册（20260531-1）

## 本次更新

- 页面启动时会自动识别当前浏览器所在设备是否为 x86 架构。
- 当检测为 x86 架构时，节能模式默认开启，首次进入不再需要手动切换。
- 当检测为 x86 架构时，页面默认保持浅色模式，同时停止按时间自动在浅色和深色之间切换。
- 手动点击主题按钮或节能按钮后，仍然保留原有的手动切换能力。

## 当前行为

1. 在 x86 设备首次打开页面时，右上角的 `节能` 开关会默认处于开启状态。
2. 在 x86 设备上，页面启动后默认展示浅色主题；夜间也不会再因为自动主题逻辑切换到深色。
3. 如果用户手动关闭节能，后续刷新页面会继续按本地保存的手动结果展示，不会反复被默认值覆盖。
4. 如果用户手动切换为深色模式，页面会保留这次手动选择；只是 x86 分支不再执行“按时间自动切换主题”。
5. 非 x86 架构继续保持原有主题与节能行为，不受这次迭代影响。
