# 20260526-5 用户手册

本次迭代为左侧虚拟文件系统中的 `skills` 目录和 `创建SKILL` 入口补充了一条独立的新手引导流程。

- 当浏览器本地还没有“点击过 skills 目录或创建SKILL按钮”的记录时，第一次点击虚拟文件系统中的 `skills` 目录或 `创建SKILL` 按钮，都会触发这条技能提炼引导
- 引导会优先高亮 `skills` 目录，提示这里用于存放 Agent 技能目录
- 点击 `知道了` 后，会继续高亮 `创建SKILL` 按钮，提示成功经验也可以被整理成可复用技能
- 随后引导会高亮 `创建技能` 浮层本身，提示需要先选择本次提炼 Skill 的上下文范围
- 在范围配置阶段，引导会继续高亮 `提炼最近N轮对话` 及其输入框整体，提示每次提问和回答算作一轮对话
- 接下来会高亮 `开始时间 / 结束时间` 选择区域整体，提示也可以按期望的时间范围来提炼 Skill
- 接下来会高亮提炼目标浮层中的 `提炼目标` 输入区域，提示精准的提炼目标是技能质量的关键
- 最后一步会继续高亮 `提炼目标` 输入区域，并模拟清空默认文案后重新输入 `把文件中最近几轮对话和工具调用提炼成可复用 生成最近1周，HTML格式财务报表 的SKILL。`，同时展示鼠标点击和键盘输入动画，强调需要的约束、目标和格式
- 引导过程中，除当前高亮区域外，其它区域会被暗化且不可点击；前六步通过 `知道了` 推进，最后一步点击 `完成` 后恢复正常交互
- 这条技能提炼引导与首次使用引导、首次点击输入框引导、蜂群引导、插件引导、`SOUL.md / USER.md` 引导、右侧备忘录引导相互独立，可以兼容共存
