# 20260517-4 使用说明

## 迭代目标

本次迭代为居中对话框的思考模式区域新增 `HTML` 开关，用于控制 `/v1/chat/completions` 请求是否显式声明需要 HTML 输出。

## 变更说明

- 居中输入框上方、原有 `Thinking/Auto` 开关左侧新增一个 `HTML` 开关。
- `HTML` 开关按会话独立保存；切换到不同会话时，会回到该会话上次保存的状态。
- 开启后，当前会话后续所有转发到 `/v1/chat/completions` 的请求都会自动补充：

```json
{
  "metadata": {
    "html": true
  }
}
```

- 关闭后，不会再额外附带 `metadata.html`。
- 该开关只影响居中会话区的 `/v1/chat/completions` 请求，不影响右侧备忘录、插件或其他接口。

## 验收建议

1. 打开页面，任选一个会话。
2. 打开 `HTML` 开关并发送一条消息。
3. 在浏览器开发者工具的 Network 中检查对应 `/v1/chat/completions` 请求体，确认存在 `metadata.html = true`。
4. 关闭 `HTML` 开关后再次发送消息，确认请求体中不再携带该字段。
5. 新建或切换到其他会话，确认每个会话的 `HTML` 开关状态彼此独立。
