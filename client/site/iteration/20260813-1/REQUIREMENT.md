### 需求介绍

- 新增“视频提取物体”入口，与既有“视频提取人物”入口同处于当前 Agent 工作区根层 `videos` 目录、视频文件操作区及视频预览工具栏；入口先检查 FFmpeg/FFprobe 和当前 Agent 的 SAM2 运行环境，缺失时展示服务端返回的安装提示并发送到当前 Chat，不在浏览器自行安装。
- 任务浮层沿用视频提取人物的列表、状态筛选、分页、日志、取消、重新开始、删除、预览、复制与批量选择交互。每条待创建任务选择一个模型：默认“速度优先（tiny）”=`sam2_hiera_tiny.pt`，还可选“兼顾精度（small）”=`sam2_hiera_small.pt`、“综合均衡（base）”=`sam2_hiera_base_plus.pt`、“高精度分割（large）”=`sam2_hiera_large.pt`。已保存任务在列表中显示所选模型。
- 每个任务可在视频首帧指定目标，可组合使用点击点、框选区域和掩码图：点击点记录像素坐标及前景/背景属性；框选区域记录左上和右下坐标；掩码图可由本机选择后上传至当前 Agent `tmp/`，或填写当前 Agent 工作区内的绝对路径。三种标注均未提供时，任务自动提取首帧最显著主体。
- 掩码图必须与首帧像素尺寸一致。RGB 图提供“绿幕抠图”“白底抠图”“黑底抠图”三种背景色模式：对应背景色视为背景，其余视为目标。带 Alpha 的 PNG 提供“透明擦除抠图”：透明区域视为目标，其余区域视为背景；半透明边缘按透明度平滑转换。首帧标注用于后续帧自动跟踪，界面不要求用户提供与视频等长的掩码。
- 浮层应清楚显示当前任务的模型与提示摘要；标注为可选，未标注时显示“自动提取最显著主体”并允许开始。保留既有页面的键盘、焦点和遮罩隔离行为，不影响视频提取人物任务。
