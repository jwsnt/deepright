# 视频提取物体

在视频预览工具栏、`videos` 目录或视频文件操作区点击“视频提取物体”。系统先检查 FFmpeg/FFprobe 和当前 Agent 的 SAM2；缺失时确认安装会将安装说明发送到当前 Chat。

在任务浮层选择 SAM2 模型：默认“速度优先（tiny）”，也可选 small、base 或 large。首帧上可点击目标点（可选择目标或排除）、拖动框选目标，并可附加掩码图；三者都不填也可以开始，SAM2 会自动选择首帧最显著主体。掩码图可以选择本机文件上传，或填写当前 Agent 工作区中的绝对路径；尺寸必须与视频首帧一致。

RGB 掩码图选择绿幕、白底或黑底模式时，对应背景色会排除，其余区域作为目标。透明擦除模式使用带 Alpha 的 PNG：透明区域为目标，其余区域为背景。完成后点击“开始”，SAM2 会用用户首帧提示或自动选择的主体跟踪后续帧。

任务列表保存并显示模型与提示摘要，支持日志、取消、重新开始、删除失败/取消任务、复制和预览。主输出是 `videos/<源文件名>_object.mov` 的透明视频，另有同名 MP4 黑底预览副本；已有文件不会被覆盖。
