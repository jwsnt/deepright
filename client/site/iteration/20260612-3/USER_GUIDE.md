# 20260612-3 用户手册

本次迭代为居中对话框与右侧备忘录录入区的 `SWARM` 开关补充了可用性提示，避免在当前 Agent 既没有可调度的蜂群成员、也没有配置任何外部设备连接时误以为蜂群已经可以正常协作。

- 当居中对话框或备忘录录入区把 `SWARM` 从关闭切到开启时，页面会同时检查：
  - `GET /api/swarm_agent?agentId=当前AgentId` 是否返回了可用蜂群 Agent
  - 当前 Agent 的 `router_remote` 是否已经配置了任意外部设备连接
- 如果这两项都为空，会在 Tips 位置提示 `当前无可用蜂群Agent`
- 当同一开关从开启切回关闭时，会改为提示当前区域已经关闭蜂群：
  - 居中对话框提示 `当前对话已关闭蜂群`
  - 备忘录录入区提示 `当前备忘录已关闭蜂群`
- `@ Agent` 菜单与这次提示复用同一份 `/api/swarm_agent` 查询逻辑，因此开启提示和后续 `@ Agent` 可见性保持一致
