# 20260526-2 用户手册

本次迭代为虚拟文件系统中的 `SOUL.md / USER.md` 文件入口补充了一条独立的新手引导流程。

- 当浏览器本地还没有“点击过 SOUL.md / USER.md”的记录时，第一次点击 `SOUL.md` 或 `USER.md` 的任意入口都会触发文档整理引导
- 任意入口包括文件行本身、小灯泡、下载、删除等该文件的可点击位置
- 引导会优先依次高亮 `SOUL.md 文件行`、`SOUL.md 小灯泡`、`USER.md 文件行`、`USER.md 小灯泡`
- 如果当前不存在 `SOUL.md`，流程会直接从 `USER.md` 开始
- 如果当前不存在 `USER.md`，则会在 `SOUL.md` 相关步骤结束后直接完成
- 引导期间左侧 Sidebar 会保持展开，并自动回到虚拟文件系统根目录，确保 SOUL / USER 文件行与灯泡按钮始终可恢复定位
- 这条引导与首次使用引导、首次点击输入框引导、蜂群引导、插件引导相互独立，不会互相覆盖
