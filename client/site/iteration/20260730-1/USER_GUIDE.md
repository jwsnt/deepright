# 构建迷你应用使用手册

在主应用资源目录的 `config/config.json` 中配置 `miniapp`：

```json
"miniapp": {
  "build": "请使用 @__internal_cli 为 $name 的 $function 构建迷你应用",
  "function": "全部功能"
}
```

右侧栏“正在执行的系统指令”标题后有一个“构建迷你应用”图标。点击后会打开居中浮层；主输入框没有“Git地址”标签，提示为 `https://github.com/owner/repo 或 CLI名称`，可以输入 CLI 名称或 Git 地址。

浮层下方的“功能列表（可选）”初始不显示任何功能项。点击 `+` 后增加第一项，点击每项后的 `−` 删除该项，最后一项也可以删除。空白功能会忽略，多个有效功能按输入顺序以全角顿号 `、` 连接；如果没有任何有效功能，则使用 `miniapp.function`，例如“全部功能”。

确认时页面会重新读取运行中的 `config/config.json.miniapp`，把模板内所有 `$name` 替换为主输入内容，把所有 `$function` 替换为功能列表或默认功能。模板必须同时包含这两个变量，默认功能必须为非空文本；配置不正确时，浮层会保留并显示原因。

生成的完整文案会先写入当前会话输入框，再沿用普通会话的 Agent、模型、令牌、输入长度和 SSE 校验自动发送。页面不会直接执行 CLI、拉取 Git 仓库或构建应用。取消、点击遮罩或按 `Esc` 会关闭浮层并保留未提交内容；发送成功后才清空本次草稿。
