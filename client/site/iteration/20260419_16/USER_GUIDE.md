# Site 迭代 20260419_16 使用手册

## 变更说明

虚拟文件系统的文件预览按文件类型区分展示方式。

## 预览方式

| 文件类型 | 后缀 | 预览方式 | 可编辑 |
|---------|------|---------|--------|
| 文本 | .md, .txt, .json, .go, .py 等 | Markdown 渲染 | 是 |
| HTML | .html, .htm | iframe 渲染（支持脚本交互） | 是 |
| 图片 | .png, .jpg, .gif, .svg 等 | 通过 /api/raw base64 渲染 | 否 |
| PDF | .pdf | pdf.js 渲染（逐页 canvas） | 否 |
| 不支持 | .zip, .exe, .mp4 等 | 仅提示"不支持预览此文件格式" | 否 |

## 浮层自适应

- 图片、PDF、不支持格式：浮层自适应大小
- 文本、HTML：固定 700×700px
- 预览区和编辑区有大色差区分（编辑区深色代码风格）
