# 20260513-2 使用说明

## 迭代内容

- 左侧虚拟文件系统标题栏中的 `Skill` 小图标新增可点击提炼能力
- 点击后可先导出当前 `Agent + Chat` 对应范围内的日志，再补充提炼目标
- 确认目标后，页面会自动把提炼请求发送到当前会话

## 使用流程

1. 当前会话最新一轮 SSE 完成后，页面会先调用 `/log_skill_status`；如果 `proxy` 在日志数据库最近一轮中检测到 `工具响应（cli/pub）`，左侧 `Skill` 小图标会亮起
2. 点击亮起的 `Skill` 小图标，会在中间会话区居中弹出日志范围浮层
3. 在浮层中填写以下条件：
   - `最近 N 轮对话`
   - `开始时间`
   - `结束时间`
4. 其中 `最近 N 轮对话` 和 `开始时间` 至少要填写一个，`结束时间` 可选
5. 点击确认后，范围浮层会收起，页面进入锁定状态，并调用 `/log_skill` 导出日志
6. 如果导出失败，会在左侧虚拟文件系统 Tips 区域提示失败信息；其中日志大小返回 `0` 也按失败处理
7. 如果导出成功，会再次以相同风格居中弹出浮层，展示日志绝对路径和大小，并要求输入“提炼 Skill 的目标”
8. 提炼目标不能为空；点击取消则直接关闭，不会自动发送
9. 点击发送后，页面会立即收起浮层，并自动向当前会话发送以下请求：

```text
将文件中的请求、响应和工具调用整理成Skill，文件保存在:$日志文件绝对路径。需要提炼的目标是：$用户输入的提炼Skill目标
```

## 交互说明

- 整个提炼流程与当前 `Agent + Chat` 强绑定；如果中途切换会话，需要重新发起
- 导出日志期间会锁定页面，避免误操作
- 两个浮层都参考左下角“设置”面板的视觉风格，在浅色与深色模式下都保持清晰可读
- 按 `Esc`、点击浮层外部区域、切换会话或新建会话时，未提交的提炼浮层会关闭
- 只有在当前会话对应的 `Skill` 图标点亮时，才表示这一轮具备可提炼的日志基础
- 这条自动发送的 SSE 请求会直接附带 `metadata.extract = "true"`
- 同时页面会附带 `metadata.requestSource = "skill_extract"` 标记本轮来源
- 普通请求与由 `Skill` 小图标触发的提炼请求，在发送时都会先把当前 `Skill` 图标收起
- 如果本轮请求来源是 `Skill` 小图标，则这一轮结束后不会再次调用 `/log_skill_status` 来重新点亮 `Skill` 图标，避免提炼请求自我回流触发
