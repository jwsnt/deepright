# Site 迭代手册（20260515-3）

## 本次更新

- 左侧 `最近` 标题右侧的小灯泡从纯展示态改为可点击安装提示入口
- 点击小灯泡后，页面会重新读取 `/install_app`，并取返回数组的第一个元素作为待安装应用
- 中间会话区会弹出与 `Skill` 提炼浮层同风格的确认浮层，提示是否需要安装该应用
- 点击确认后，页面会自动在当前 Agent 和当前 Chat 中发送 `帮我安装$第一个元素内容`

## 当前行为

1. 只有当 `/install_app` 返回非空数组时，小灯泡才会显示
2. 每次点击小灯泡，页面都会重新读取一次 `/install_app`，而不是只使用轮询缓存
3. 浮层展示内容始终取最新返回数组的第一个元素
4. 点击确认前，页面会校验当前会话是否空闲、Agent 是否有效、模型和密钥是否已配置
5. 校验通过后，浮层会收起，并自动发送 `帮我安装$第一个元素内容`
6. 如果点击取消、按 `Esc`、切换会话、打开其他居中浮层，当前安装提示浮层会立即关闭

## 说明

- 该安装提示浮层与 `Skill` 提炼浮层复用同一套中间会话区弹层风格和交互域隔离规则
- 浮层隐藏后会彻底失活，不会跨区域遮挡或拦截左右 Sidebar 的操作
