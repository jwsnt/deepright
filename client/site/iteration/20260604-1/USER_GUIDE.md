# 迭代 20260604-1：居中对话框全屏图标

本次迭代把居中对话框左上角补齐为真正的浏览器全屏入口，并补上进入全屏时的双侧收口行为。

- 全屏入口改为小型图标，位于中间输入框上方左侧，和下方的小地球模型按钮保持垂直对齐
- 图标与右侧 `SWARM / HTML / Auto` 保持同一水平线，视觉上延续输入区现有玻璃质感控件
- 非全屏状态点击该图标时，页面会进入浏览器全屏，并同步收起左侧 Sidebar 与右侧 Sidebar
- 全屏状态再次点击该图标时，会退出浏览器全屏；退出时不会强行展开或重置左右侧边栏
- 如果用户通过浏览器原生方式退出全屏，例如按 `Esc`，页面里的图标状态也会自动同步

使用方式：

1. 打开站点首页
2. 在中间输入框上方左侧找到全屏小图标
3. 点击一次进入全屏并收起左右侧边栏
4. 再点击一次退出全屏

用户可见效果：

- 进入全屏后，当前聊天页面会扩展为浏览器全屏显示，中间会话区更聚焦
- 左右侧边栏只会在进入全屏时自动收起；退出全屏时保持退出瞬间的状态不变
- 不支持全屏的浏览器会弹出提示，但不会影响聊天、模型选择或其他现有功能
