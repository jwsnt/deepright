# Site 迭代手册（20260517-8）

## 本次更新

- 左上角即时通讯插件入口在页面可见时每 `30` 秒自动刷新一次
- 刷新时会重新请求 `/api/plugins/meta`
- 刷新后会同步更新插件列表和左上角按钮状态

## 页面行为

1. 页面初始化后，仍会先加载一次插件列表并同步一次插件运行状态
2. 当页面处于可见状态时，每 `30` 秒会再次请求 `/api/plugins/meta`
3. 如果插件新增、删除、改名或参数定义变化，左上角扇形菜单会在下一轮自动刷新后同步更新
4. 自动刷新后会继续查询各插件运行状态，并刷新主入口高亮态与扇形按钮高亮态
5. 自动刷新过程中会尽量保留当前内存中的运行状态显示，避免短时间闪烁回退

## 适用场景

- 后端新增或替换插件后，不需要手动刷新整页才能在左上角看到新按钮
- 插件配置变更后，重新打开插件浮层时可以拿到更接近实时的参数默认值
- 页面长时间停留时，插件入口状态可以持续跟随后端变化

## 依赖说明

- 自动刷新依赖 `proxy` / `integration` 提供的 `GET /api/plugins/meta`
- 后端该接口本轮也已同步改为每次请求实时读取
