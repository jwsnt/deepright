# 20260527-4 使用手册

## 目标

本次迭代补充左侧边栏 `logoSvg` 的状态表达：

- 无任务状态下，`logoSvg` 改为报表小图标，并保持慢速闪动
- 开始执行任务后，`logoSvg` 切回原有默认图标
- `Token 用量` 浮层继续复用同一个 `#logoSvg` 入口，因此两种图标都可以正常触发同一浮层

## 页面行为

- 页面初始会优先按“无任务”状态展示报表图标
- 心跳接口返回任务执行中时，图标会切回默认样式并保持既有任务态闪动
- 心跳接口返回空闲后，图标会自动恢复为报表样式
- `Token 用量` 浮层的打开方式、查询逻辑、锁定规则和关闭规则保持不变

## 兼容性

- 图标切换没有改动 `logoSvg` 的 DOM 节点、ID、点击事件和键盘事件
- 现有新手引导、浮层互斥、点击外部关闭逻辑继续复用原来的 `#logoSvg` 选择器
- 深色和浅色主题都使用同一套描边/填充逻辑，避免报表图标在不同背景下发灰或看不清
