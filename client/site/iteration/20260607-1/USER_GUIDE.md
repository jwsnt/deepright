# 20260607-1 User Guide

本次迭代调整了设置中的新手引导拆分方式。

- 首次使用引导在进入设置后，只会高亮 `模型与密钥`
- 点击 `知道了` 后，会直接切换到 `新建Agent`，不再继续讲解客户化配置里的 `快速响应`、`深度思考`、`多模态输入`、`多模态输出`
- 首次点击任意模型的 `客户化配置` 小图标时，如果本地还没有“点击过客户化配置”的记录，会启动一条独立的新手引导
- 这条独立引导会按 `模型URL -> 快速响应 -> 深度思考 -> 多模态输入 -> 多模态输出` 的顺序推进
- 前四步使用 `知道了` 按钮，最后一步使用 `完成` 按钮
- 客户化配置引导与首次使用引导、首次点击输入框引导、蜂群引导、插件引导、文档整理引导、备忘录引导、知识库引导、浏览器插件引导等其它引导相互独立，可以兼容共存
