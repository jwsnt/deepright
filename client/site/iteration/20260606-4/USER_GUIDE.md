# Site 迭代 20260606-4 使用手册

## 过程报文与结果报文切换

- 居中对话框在接收 SSE 响应时，会根据每条报文里的 `biz` 和 `workflow` 把当前流式内容分成两类。
- 当 `biz=main` 且 `workflow=base@close` 时，这条报文会被识别为结果报文。
- 当 `biz=base` 且 `workflow=close` 时，这条报文也会被识别为结果报文。
- `data: [DONE]` 作为结束标记，归到结果侧处理。
- 不在以上范围内的报文都按过程报文处理；当前线上常见过程报文会出现在 `workflow=main`、`sub`、`__sub` 等阶段。
- 同一种类型连续到达时，居中 assistant 气泡会继续按现有方式累加显示。
- 如果流式过程中从过程报文切到结果报文，或从结果报文切回过程报文，当前气泡里已经累加的旧类型内容会先伴随一次爆炸清空动画消失，再从新类型的这条报文重新开始累加。
- 这次清空只影响当前正在流式展示的那一段内容，不会额外新增新的 assistant 气泡。
- 如果左下角 `节能` 已开启，类型切换时仍会按相同规则清空并从新类型重新累计，但不会播放爆炸动画。
- 重新加载会话或恢复历史未完成响应时，页面也会按同一套分类规则重建最后可见的 assistant 内容，避免把过程报文和结果报文错误拼接在一起。
