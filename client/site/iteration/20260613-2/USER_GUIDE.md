# 20260613-2 用户手册

本次迭代收紧了设置面板中“模型与密钥”的模型选择规则，避免同一个模型被重复配置。

## 模型下拉规则

- 在设置中新增模型时，模型下拉框会自动排除当前其它条目里已经配置过的模型
- 在设置中修改某一条模型时，该条目会保留自己的当前模型；其它已配置模型仍会从下拉候选中移除
- 这个排除规则只看“是否已经配置了该模型”，不校验密钥是否正确
- 因此，即使某个已配置模型的密钥填写错误，该模型也不会再次出现在其它条目的候选列表中
- 当某条模型被改成其它模型，或该条模型被删除后，被释放出来的模型会重新回到其它条目的可选列表

## 影响范围

- 本次迭代只调整设置浮层里的模型下拉候选计算规则
- 不改变模型密钥的保存方式
- 不改变“同一模型只能配置一次”的保存校验规则
