# Site 迭代 20260719-1 使用手册

## 本次更新

- 会话恢复继续以 `chatId` 为范围；跨 Agent 的同一会话仍会恢复到同一时间线。
- 冷历史只恢复中心聊天正文，不再读取或恢复右侧 `CLI` 子任务历史。
- 冷历史首屏和向上加载改为数据库分页：先取最近一批记录，必要时向前补齐到该轮提问，再按正序显示。
- 切回正在 SSE 输出或正在恢复轮询的会话时，页面不再额外排队一次自动恢复，也不会因此显示恢复遮罩。

## 冷历史会话

- 首次打开没有中心消息的已完成会话时，页面恢复最近约 120 条原始聊天记录；该数量是记录目标，而不是 120 轮问答。
- 若这批记录从某轮回答的中间开始，系统会自动带上该轮对应的用户提问，因此实际返回数量可能略多于 120 条。
- 每页都从完整提问开始，向上滚动加载更早内容时不会重复或截断某一轮回答。
- 冷历史不会请求、返回或展示历史 `CLI` 命令及输出；右侧 CLI 仅保留当前页实时任务的运行时展示。

## 正在执行的会话

- SSE 正在实时输出时，页面直接使用现有流式状态，不会再发起冗余的恢复请求。
- 页面刷新后需要恢复未完成任务时，恢复轮询仍会正常工作；切换会话不会在轮询之外追加第二个自动恢复请求。
- 已完成且不处于上述两种状态的会话，仍按原有方式增量恢复或加载冷历史。

## 兼容性说明

- `/api/restore` 的响应结构和历史分页游标保持兼容。
- 已有的备忘录查看、异常恢复、任务徽标和中心会话正文恢复不受影响。
- 主手册 [../../USER_GUIDE.md](/Users/shenjiawei/Documents/code/deepright/cli/module/site/USER_GUIDE.md) 会同步记录本次恢复行为。
