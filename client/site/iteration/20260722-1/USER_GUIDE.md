# 迭代 20260722-1：从备忘录预览创建待执行任务

## 运行备忘录

在备忘录任务明细或备忘录元数据预览标题右侧，点击运行图标即可创建一条新的任务明细。

1. 点击运行图标。
2. 在“运行备忘录”确认框中选择是否复用原会话；默认“不复用原会话”。
3. 点击“确认运行”。页面会短暂锁定，直到新任务明细创建成功或失败。

成功后会提示“已创建，等待执行”。该操作不会立即调用模型，新明细的状态是“待执行”，由后续现有轮询启动。

## 会话与状态规则

- 选择“复用原会话”时，新明细继续使用来源任务或元数据的会话。
- 选择“不复用原会话”时，新明细会在实际执行时创建独立会话。
- 任务明细处于“待执行”“无需启动”或“已完成”时可以运行；“已启动”任务不会显示运行图标，避免同一会话或同一任务并发重跑。
- 元数据入口只创建一条当前时间的任务明细，不修改该备忘录的周期、Cron 配置或已有任务明细。
- 新明细仍受 Agent 暂停、模型可用性等现有执行门禁约束。
- 右侧任务明细按执行时间从早到晚排列；同一秒创建的任务按任务 ID 排列。
