# 20260801-1 用户手册

本次迭代将所有会话中的技能目录改为默认关闭、按需启用。

- 左侧虚拟文件系统中，直属包含 `SKILL.md` 的目录会先显示关闭图标；新建会话、既有会话和切换 Agent 后首次出现的技能目录均如此。
- 点击关闭图标会在当前 `Agent + Chat` 会话启用该目录。成功后当前目录立即刷新，并提示“技能目录已启用”；该技能也会立即进入当前会话的 `@ 技能` 菜单。
- 再次点击已启用目录会关闭它，并提示“技能目录已关闭”。关闭父级目录会继续使子孙技能继承关闭；子级需要先启用父级才可操作。
- 用户已启用的选择会跨页面刷新和应用重启保留；之后新增或首次发现的技能目录仍默认关闭。
- 首次启用技能时会显示会话级提示，说明技能默认关闭、需要时可点击开启。
