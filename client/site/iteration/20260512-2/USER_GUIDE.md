# Sidebar 安装提示灯

本次迭代在左侧 Sidebar 中 `新会话` 下方、`最近` 标题右侧紧贴位置新增了一个小灯泡状态提示。

## 行为说明

- 页面固定读取 `http://127.0.0.1:8080/install_app` 接口。
- 如果页面被错误地从其他本地端口打开，会自动跳转回 `http://127.0.0.1:8080/site/#app`。
- 当接口返回空数组 `[]` 时，不展示小灯泡。
- 当接口返回非空数组时，小灯泡会在 `最近` 右侧显示并持续闪烁。
- 接口中的每个元素表示当前仍需安装的应用，例如 `git`。
- 页面会定时重新读取该接口，并在标签页重新可见时立即刷新一次，确保安装状态变化能尽快同步到界面。

## 使用说明

1. 启动提供 `/install_app` 接口的服务。
2. 打开 Site 页面。
3. 观察左侧 `最近` 标题右侧：
   - 若没有待安装项，不显示灯泡。
   - 若存在待安装项，例如 `["git"]`，则显示闪烁灯泡。

## 备注

- 小灯泡仅作为状态提示，不会拦截左侧 Sidebar 的会话操作。
- 悬停灯泡时，会显示当前待安装的应用名称。
