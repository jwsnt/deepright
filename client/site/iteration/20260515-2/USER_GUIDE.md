# Site 迭代手册（20260515-2）

## 本次更新

- 左侧虚拟文件系统上的 `Skill` 小图标改为常驻显示
- 默认状态改为灰色，不再像之前那样彻底消失
- 原有点亮策略保持不变：当前会话最近一轮命中 `cli/get` 或 `cli/pub` 时，图标仍会切换为金色闪动
- 无论图标当前是灰色还是金色，只要当前不在等待 SSE 响应，都允许点击进入提炼流程
- 范围浮层文案调整为“选择需要提炼的日志范围，对话轮数和开始时间至少填写一个”
- `提炼最近N轮对话` 默认值改为 `1`，并新增范围浮层 `重置` 按钮，用于恢复默认轮数并清空时间
- 提炼目标输入框默认预填 `把文件中最近几轮对话和工具调用提炼成可复用的SKILL`，并允许继续修改
- 提炼目标浮层新增 `重置` 按钮，只清空提炼目标输入框
- 每次 SSE 响应结束后，范围与目标草稿都会自动重置回默认值

## 当前行为

1. 左侧虚拟文件系统标题栏中，`返回上级` 按钮右侧会始终显示一个 `Skill` 小图标
2. 默认情况下，这个图标会以灰色常驻展示，表示当前会话暂时没有可提炼的 Skill 日志
3. 当当前 `Agent + 会话` 最近一轮 SSE 完成后命中 `cli/get` 或 `cli/pub`，图标会切换为金色闪动
4. 普通请求发送时，如果原本已经点亮，图标会先退出高亮并回到灰色态
5. 如果当前轮请求来源是 `skill_extract`，这一轮结束后图标也会保持灰色，不会因为本轮再次命中 `cli/get` 或 `cli/pub` 就重新点亮
6. 无论图标当前是灰色常驻态还是金色点亮态，只要当前会话不在发送请求、等待 SSE 响应，都可以点击进入提炼浮层
7. 只有在当前会话正在响应期间，图标才会临时不可点击
8. 范围浮层会显示 `提炼最近N轮对话`、`开始时间`、`结束时间` 三项，其中 `提炼最近N轮对话` 默认值为 `1`
9. 范围浮层底部提供 `重置` 按钮；点击后会恢复默认轮数 `1`，并清空开始时间和结束时间
10. 日志导出成功后，提炼目标浮层会显示 `日志导出成功，请补充提炼目标`，并自动预填 `把文件中最近几轮对话和工具调用提炼成可复用的SKILL`
11. 用户可以直接在默认文案上修改；点击 `重置` 后，仅清空提炼目标输入框，其他导出结果与浮层状态保持不变
12. 每次 SSE 响应结束后，这两处浮层草稿都会自动重置为默认值，避免沿用上一轮输入

## 说明

- 本次只修改图标的“消失策略”，把彻底隐藏改为常驻灰色
- 与 `Agent + 会话` 绑定的检查策略、日志判定策略和提炼流程本身都不变
- 这次更新同时兼容上一轮对 `skill_extract` 的限制：由 `Skill` 小图标自己发起的请求结束后，不会再把自己点亮
