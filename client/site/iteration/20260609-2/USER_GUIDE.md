# 20260609-2 用户手册

本次迭代为右侧备忘录输入框补充了一条独立的新手引导流程，用于帮助用户完成首个备忘录任务。

- 当备忘录新手引导已经完成、且当前至少已配置一个模型时，第一次把鼠标悬停到右侧备忘录输入框，或第一次点击该输入框，都会触发这条引导
- 第一步会高亮右侧备忘录输入框，并询问 `是否需要试试备忘录？`
- 如果点击 `否`，这条引导会立即结束，且不会再次自动触发
- 如果点击 `是`，引导会继续在右侧备忘录区域内模拟一次完整创建流程
- 演示流程会依次模拟：在输入框输入 `推荐下我明天的着装风格`、选择首个已配置模型、把时间设置为当前时间后 `1` 分钟，并点击提交按钮
- 演示过程中会显示模拟鼠标和键盘输入效果，其它区域会被暗化且不可点击
- 这段流程会直接帮助用户创建这条备忘录任务；如果提交失败，点击最后一步 `完成` 后，会恢复原来的备忘录草稿状态
- 这条引导与首次使用引导、输入框引导、备忘录主引导、插件引导、Skill 引导等其它新手引导相互独立，可以兼容共存
