### 需求介绍
+ 在每个模型客户化配置的“多模态输入”和“多模态输出”输入框左侧增加小箭头下拉入口；仅点击该入口时展开服务商选择菜单，不常驻展示服务商列表。
+ 多模态输入下拉框仅展示当前已配置、且配置了多模态输入模型的服务商；多模态输出同理。`deepright` 仅在其已配置时显示，并作为可选服务商参与相同规则。
+ 下拉框没有可选服务商时不展示服务商名称。当前服务商本身是否支持该多模态能力不影响下拉框可用性。
+ 除 `deepright` 外，点击多模态输入或输出的箭头时，在模型客户化配置区底部显示“正在指定代理多模态模型”提示；暖色界面使用暖色光带，冷色界面使用冷色光带。选择服务商、移出菜单、点击其它位置或按 `Esc` 后提示和菜单同时消失。
+ 选择服务商后，对应模型输入框写入 `@服务商名称`。支持该多模态能力的当前服务商仍允许手动输入模型名；不支持时模型输入框只读，仍可通过下拉框选择服务商。
+ 当前服务商不支持某项多模态能力时，该字段不使用模型服务商的默认值，也不从复制配置等操作自动填入代理；只有用户点击箭头并选择服务商后才保存 `@服务商名称`。
+ 客户化配置收起时，模型配置测试成功必须在密钥输入区显示“✓ 配置成功”提示，2 秒后自动消失；客户化配置展开时保持原有的配置区成功提示流程。
+ 删除服务商后，页面必须同步移除所有引用该服务商的 `@服务商名称` 配置。

### 编写代码
+ 在 `../../index.html` 按既有 HTML、CSS 和 JavaScript 组织方式实现。
+ 下拉候选项、保存草稿、重置、清空、复制配置、远程只读和删除后的页面状态必须使用同一份多模态字段值。
+ 仅将 `@服务商名称` 持久化为既有 `__model_multi_input` 或 `__model_multi_output` 的值；不新增浏览器本地持久化字段。
+ 覆盖配置服务商、手动模型、无候选项、当前服务商不支持但可引用、删除引用服务商和保存后的界面刷新。
