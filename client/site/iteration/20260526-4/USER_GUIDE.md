# 20260526-4 用户手册

本次迭代为右侧边栏第一栏中的备忘录列表补充了悬停预览能力。

- 当鼠标悬停在左上角的备忘录元数据列表任意一条元数据上时，页面会在居中对话框的水平垂直居中位置展示预览浮层
- 这个预览浮层会展示该条备忘录元数据对应的内容与配置，方便在不切换视图的情况下快速查看详情
- 预览浮层显示期间，只会模糊居中对话框区域内除浮层外的背景，不会影响左侧 Sidebar 和右侧 Sidebar 的可见性与定位
- 当鼠标移出对应元数据条目后，预览浮层会自动消失，并带有淡出动画效果
- 当鼠标悬停在左上角的备忘录任务明细列表任意一条任务明细上时，页面同样会在居中对话框正中展示预览浮层
- 任务明细预览会展示该条任务明细的内容与配置，便于快速确认任务状态和上下文
- 任务明细预览显示期间，同样只模糊居中对话框背景；鼠标移出后浮层会自动消失，并带有动画过渡
- 这两类 hover 预览都属于备忘录查看增强，不会修改真实备忘录元数据、任务明细或当前会话内容
