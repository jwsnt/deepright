# 20260527-1 使用手册

## 目标

本次迭代为站点左上角 `logoSvg` 增加 `Token 用量` 居中浮层：

- 点击左侧边栏左上角 logo 后，在中间会话区打开 Token 查询浮层
- 浮层默认自动查询最近 `7` 天到当前时刻的数据
- 查询结果同时支持 `按 Agent 汇总百分比`、`按 Agent + 模型聚合百分比` 和 `原始日志明细`
- 查询期间锁定界面，避免浮层在请求未完成时被误操作

## 查询参数

- `开始时间`：可选，默认回填为当前时间往前 `7` 天
- `结束时间`：可选，默认回填为当前时刻
- `最大记录条数`：可选，默认 `500`
- `最大记录条数`：最大也只能填到 `500`
- 页面请求接口时使用 `/api/consume?starTime=...&closeTime=...&limit=...`
- 本次界面不单独提供 `agentId` 输入框，默认查询全部 Agent，再由前端按响应中的 `agentId` 聚合

## 页面行为

- 浮层打开后会立刻发起首次查询，不需要手动点击 `查询`
- 每次查询开始时，输入框、按钮和关闭动作都会被锁定，直到响应返回
- 查询成功后：
  - 上半部分按 `agentId` 汇总，并在一行里展示 `thinking / total`、`input / total`、`cache / total` 的百分比值，同时显示 `TOTAL / 1000` 后以 `k` 结尾的数值
  - 中间部分按 `agentId + model` 维度聚合成滚动列表，每行展示一条与第一部分同格式的汇总结果，并使用同样的 `k` 单位
  - 第三部分原始日志默认折叠；点击 `展开` 后会切换为固定上限高度的表格展示，一行一条展示时间、Agent、模型、用途和原始 Token 数值，同时前两部分折叠；数据较多时会在该区域内显示滚动条
- 如果查询范围内没有数据，三个结果区都会给出空状态提示
- 浮层底部会标记当前查询使用的最大记录条数，以及原始记录总数、Agent 汇总数和 `Agent + 模型` 聚合数

## 浮层规则

- 新浮层接入现有 center domain overlay 体系，继续复用统一的层级、显隐和 pointer-events 规则
- 浮层只覆盖中间会话区，并保留既有背景毛玻璃效果
- 点击浮层卡片外的任意非浮层区域会关闭浮层
- 如果当前中心域已有其他独占浮层，打开 Token 用量浮层前会先关闭旧浮层
- 查询锁定期间，浮层外点击不会穿透触发其他交互
