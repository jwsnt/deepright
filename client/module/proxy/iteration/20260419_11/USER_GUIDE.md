# Proxy 迭代 20260419_11 使用手册

## 变更说明

新增心跳状态追踪和 `GET /api/heartbeat` 接口，支持三种状态。

## 接口说明

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/heartbeat` | 返回最后一次心跳的时间戳和状态 |

## 响应格式

```json
{"lastTimestamp": 1713600000000, "status": 0}
```

## 状态码

| status | 含义 |
|--------|------|
| 0 | 心跳成功，无任务 |
| 1 | 心跳失败（网络异常） |
| 2 | 心跳成功，有任务 |

## 状态判定

- 心跳请求成功且无任务：status=0
- 心跳请求网络异常：status=1
- 心跳请求成功且有待处理任务：status=2（即使任务执行失败也不影响）
