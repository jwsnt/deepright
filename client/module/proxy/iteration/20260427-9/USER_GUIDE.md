# 转发连接管理与主动取消

## 功能说明

1. 按 AgentId+Chat 维度管理活跃转发连接，同一维度同时只有一个活跃连接
2. 新建请求时自动取消同维度的旧连接
3. 非主动断开（如刷新页面）不关闭上游转发连接，会话存储继续直到 SSE 完成
4. 主动取消时在 `chat_log` 中写入 X 标记并停止后续写入

## 取消接口

`POST /api/cancel?agentId=xxx&chat=yyy`

### 响应

```json
{"status": 0, "cancelled": true}
```

## 会话存储标记

| role | 说明 |
|------|------|
| Q | 用户提问（原始请求 JSON） |
| A | 助手回答增量块（原始 SSE 报文分段） |
| X | 主动取消断开 |
