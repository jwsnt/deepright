# Chat 便签

右下角的便签气泡默认收起并缓慢闪动。点击可展开固定为 `300 × 350px` 的便签；再次点击入口可收起。便签按 Chat 分开保存，切换会话会自动收起，但已写内容会在返回该 Chat 或刷新、重启应用后恢复。

便签可直接输入文字，支持自动换行和内部滚动，且与对话输入框共用 `5000` 字符上限。可拖入或粘贴文件、图片、视频；输入 `@` 后可按当前 Chat 的权限选择文件、技能和 Agent。附件、URL、技能和 Agent 均以气泡展示。

底部按钮的行为如下：

+ **对话框**：把便签内容和气泡追加到居中对话输入框，并清空、收起该便签。
+ **备忘录**：把便签内容和气泡追加到右侧备忘录输入框，并清空、收起该便签。
+ **清空**：先显示确认，确认后清空当前 Chat 的便签。

右侧栏 URL 预览处于普通栏内预览状态时，便签会隐藏；将该预览展开为覆盖窗口后，便签会重新显示且可编辑。屏保、关闭应用确认和关机倒计时期间，便签不会显示；其它浮层出现时，便签始终位于最上层且可继续操作。
