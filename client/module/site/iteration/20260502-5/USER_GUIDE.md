# 居中对话框气泡复制按钮

## 功能说明

在居中对话框中，所有用户请求气泡和 SSE 响应气泡的右下角外侧新增一个 `10x10px` 复制图标。

点击复制图标后，会将当前气泡中的文本内容复制到系统剪贴板，并在左侧虚拟文件系统的 Tips 位置提示复制成功。

## 适用范围

- 用户请求气泡
- assistant 流式响应气泡
- assistant 错误气泡

## 交互说明

- 复制按钮位于气泡外侧右下角，与气泡垂直右对齐
- 历史消息与正在流式更新中的消息都支持复制
- 如果当前气泡没有可复制文本，会提示复制失败原因

## 注意事项

- 复制能力依赖浏览器剪贴板接口
- 在不支持自动复制的浏览器环境中，会提示复制失败
