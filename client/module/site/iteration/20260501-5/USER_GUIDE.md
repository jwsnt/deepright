# 20260501-5 使用手册

## 简介

本迭代为右侧 CLI 子面板的每条 SSE 响应气泡补充了终止入口，可直接通过右侧同款确认浮层终止对应命令。

## 功能说明

### 终止图标

- 在每条 CLI 子任务响应气泡左上角的复制图标后，新增一个同色系的终止小图标
- 终止图标仅作用于当前独立气泡，不会影响相邻气泡或整组响应

### 浮动确认

- 点击终止小图标后，会在右侧 Sidebar 内弹出与备忘录保存浮层一致样式的确认框，提示是否终止当前命令
- 确认框会展示当前气泡对应命令的预览内容，便于核对；该命令取值逻辑与复制图标完全一致，若外层存在 Markdown 三反引号代码块包裹，会先去掉包裹再取值
- 点击“确认”后才会调用 `/api/kill`，点击“取消”或点击其他区域会关闭确认框

### 结果提示

- 点击确认后，无论终止成功还是失败，右侧确认浮层都会立即收起
- 终止成功后，会复用左侧虚拟文件系统的 `Tips` 位置显示红字提示：`已终止`
- 如果当前未选择会话、未选择 Agent，或终止失败，也会通过同一提示区域反馈错误信息
- 若当前页面不是从本地集成服务同源打开，前端会自动回退尝试本机常用执行服务地址，以避免 `/api/kill` 因 origin 不一致而落到错误服务
