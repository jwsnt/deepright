# Site 迭代手册（20260517-11）

## 本次更新

- 左右 Sidebar 收起或展开时，居中会话区会按当前实际可用宽度重新计算消息气泡与欢迎卡片宽度。
- 对话中的普通文本、Markdown 与 HTML 内嵌内容都会跟随中间域一起放宽，不再长期受固定 `780px` 上限限制。
- 右侧栏或左侧栏释放出的空间会优先让给中间对话区，保持会话阅读与预览区域尽量接近可用最大宽度。

## 页面行为

1. 默认三栏展开时，会继续保持现有的居中观感，不会突然把消息拉成过宽的整屏样式。
2. 收起左侧 Sidebar 后，居中会话区会立刻重新计算宽度，消息气泡、Markdown 表格、代码块和 HTML iframe 可展示区域同步变宽。
3. 收起右侧 Sidebar 后，同样会把释放出的宽度让给中间会话区，方便阅读长文本和嵌入页面。
4. 左右两侧都收起时，欢迎语卡片和消息内容会进一步扩展，但仍保留安全边距，避免内容贴边。
5. 窗口尺寸变化、Sidebar 过渡动画和恢复展开时，宽度计算会自动同步，不需要刷新页面。
