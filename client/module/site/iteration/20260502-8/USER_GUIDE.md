# 20260502-8 使用手册

## 简介

本迭代为 Site 输入框补充了“系统剪贴板图片粘贴转 `FILE` 气泡”能力，并修正了右上角备忘录中超长文件路径气泡会撑破输入框的问题。

## 功能说明

### 图片粘贴转 FILE 气泡

- 在居中对话框输入框或右上角备忘录输入框中执行系统粘贴操作时，如果剪贴板内容为图片，页面会自动调用 `/api/edit`
- 图片会保存到当前 Agent 的 `tmp/` 目录下，文件名为随机生成
- 生成后的气泡样式与 `@文件` 完全一致
- 输入框中的显示格式为：`[FILE:图片文件名]`
- 实际提交内容为：`[FILE:图片绝对路径]`

### 右上角备忘录气泡宽度

- 右上角备忘录中的气泡最大宽度不会超过输入框可用宽度
- 当文件名或路径过长时，气泡内容会自动省略显示，不再把输入框横向撑破
- 气泡左上角的删除按钮会继续保持可见和可点击

### 浮层管理

- 固定定位的遮罩层、确认框、弹窗统一按左侧 Sidebar、中间会话区、右侧 Sidebar 分域管理
- 未激活浮层默认不会拦截点击，避免跨区域遮挡其他可操作控件

## 依赖说明

- 图片粘贴依赖 `/api/edit` 支持二进制文件写入
- 当前会话必须已经绑定有效 Agent，才能将图片保存到对应 Agent 的 `tmp/` 目录
