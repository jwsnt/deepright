# 20260525-7 User Guide

本次迭代为“首次点击左侧新会话或居中输入框”的场景增加了一条独立的新手引导流程。

- 当浏览器本地还没有“点击过输入框”的记录时，第一次点击左侧 `新会话` 或第一次点击中间输入框都会触发输入引导
- 引导会依次高亮输入框左侧模型选择按钮、发送按钮、输入区 `@` 提示、会话渲染区域、右侧 `CLI` 子面板区域、`SWARM`、`HTML`、`Thinking/Auto`、右侧刷新会话按钮、左侧 `新会话`、左侧会话列表和首个会话删除按钮
- `CLI` 步骤会自动展开右侧栏，并高亮右侧边栏第二栏整个 `CLI` 子面板区域，提示执行的系统命令会在这里显示
- `@` 提示步骤会临时模拟输入 `@`，并弹起文件/技能菜单，提示可以通过 `@` 来引入文件或强调需要使用的技能；切到下一步后会自动恢复输入框内容
- 当流程切换到左侧 `新会话` 与会话列表相关步骤时，如果左侧 Sidebar 当前是收起状态，页面会自动展开左侧栏
- 每一步都会暗化其它区域，并通过 `知道了` 按钮切换到下一步
- 最后一步点击 `完成` 后结束，页面恢复正常交互
- 这条输入引导与首次打开站点时的 Agent / 模型配置引导互相独立，不会覆盖已有的首次使用引导流程
