# 上传功能使用手册

## 功能说明

在虚拟文件系统(VFS)中新增了文件上传功能, 支持上传文件和目录到 Agent 的 `tmp` 目录。

## 使用方式

### 按钮上传

1. 在 VFS 头部栏, 点击新建和打开右侧的上传图标(带发光效果)
2. 在弹出的浮层中选择:
   - **文件**: 选择一个或多个文件上传
   - **文件夹**: 选择整个目录上传(保留目录结构)
3. 选择完成后自动开始上传

### 拖拽上传

直接将文件或目录拖入 VFS 文件列表区域即可上传。

## 上传进度

上传过程中, VFS 头部栏的"返回上级"按钮右侧会显示旋转进度图标。点击该图标可立即取消上传。

上传完成后, VFS 底部会展示提示浮层, 5 秒后自动收起:
- 成功: 显示上传文件所在的目录路径(相对 Agent 工作目录), 多个目录用空格分隔, 超出自动省略
- 失败: 显示失败原因(红色文字)
- 取消: 显示"上传已取消"

## 限制

- 单次上传最大 200MB
- 需要先在设置中配置 AgentID
- 上传的文件存放在 Agent 工作目录下的 `tmp` 目录

## 接口

上传通过 `POST /api/upload?agentId=xxx` 接口完成, 由 Proxy 服务提供。
