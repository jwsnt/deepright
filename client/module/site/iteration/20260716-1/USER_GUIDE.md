# Site 迭代 20260716-1 使用手册

## 本次更新

- 页面会在浏览器本地保存心跳失败告警阈值及缓存时间；不会保存完整的 `config.json`。
- 缓存有效期为 300 秒。有效期内，页面直接使用缓存值，不会重复读取 `/api/data`。
- 缓存过期后，页面会重新读取 `config.json` 中的 `http.heartbeat`；配置修改最多在 300 秒内生效。

## 心跳失败时的行为

- integration 的 `/api/heartbeat` 不可连接时，页面判定本地应用已关闭；达到失败阈值后，告警标识会显示“本地应用已关闭”，并持续到 integration 恢复通信。
- integration 可连接但返回 `status === 1`、HTTP 非成功状态或无效响应时，页面判定为转发服务心跳异常，继续使用 `REMOTE SERVICE ALERT` 的 10 秒短时告警。
- integration 恢复通信但转发服务仍异常时，页面会先结束“本地应用已关闭”告警，再按转发服务异常的短时规则提示。
- 没有有效缓存、读取配置失败、配置无效，或浏览器本地缓存不可用、损坏、时间异常时，页面统一按连续 3 次失败触发告警。
- 本地缓存只保存当前浏览器站点下的心跳失败阈值，不保存其他运行配置。
