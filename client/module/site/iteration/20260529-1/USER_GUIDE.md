# 20260529-1 使用说明

本次迭代修复了设置面板里 `deepright` 模型的客户化配置行为：

- 如果把任意已配置模型切换成 `deepright`，客户化配置五角星会立即隐藏。
- 对已经存在的模型条目来说，这类切换在保存时会被当成“修改原记录”，不会额外残留一条旧模型配置。
- 保存设置时，会自动清空该条记录原先遗留的 `__url`、`__model`、`__model_fast`、`__model_thinking`、`__model_multi_input`、`__model_multi_output`。
- 重新打开设置时，已保存为 `deepright` 的模型条目不会再回填这些客户化字段。

验证方式：

1. 在设置里先新增一个支持客户化配置的模型，例如 `openai`。
2. 填入任意密钥，并展开五角星补充配置，输入任意自定义值。
3. 将该模型直接切换为 `deepright`。
4. 确认五角星图标立即消失后点击保存。
5. 再次打开设置，确认该条记录仍为 `deepright`，且不显示客户化配置图标，也不会保留之前的补充配置值。
