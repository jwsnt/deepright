# 20260504-5 使用手册

## 目标

本次迭代为扇形菜单插件浮层补充日志查看能力：

- 点击插件浮层底部的 `日志` 按钮后，中间参数输入区域会切换为插件日志流展示区
- 日志流通过 `/api/plugins/log?name=插件key` 以 SSE 方式持续读取
- 日志展示风格与右侧 `CMD` 子面板保持一致，但不显示复制和终止按钮

## 页面行为

- 打开插件浮层后，底部仍保留 `重启`、`关闭`、`日志`、`取消`
- 点击 `日志` 后，按钮文案会切换为 `返回`
- 浮层标题区会同步切换为日志态说明，提示当前正在查看该插件日志
- 日志区域会持续自动滚动到底部，适合直接观察最新输出
- 再次点击 `返回` 后，会立即关闭当前日志 SSE 连接，并恢复原来的参数输入区域

## 关闭规则

- 点击 `返回`
- 点击 `取消`
- 点击浮层空白遮罩区域
- 按下 `Esc`

以上操作都会立即终止当前日志 SSE 读取，避免隐藏状态下继续占用连接。

## 日志显示

- SSE 中每个 `event` 块按完整事件边界解析，不按固定字节片段直接渲染
- 普通日志按右侧 `CMD` 子面板的蓝绿色消息气泡样式展示
- `event: error` 会按红色错误气泡展示
- 若浏览器不支持流式读取或接口返回异常，会直接在日志区显示错误提示
