# 20260505-7 User Guide

## 目标

本次迭代补齐了居中输入框在“未选择模型”场景下的交互提醒。

- 如果当前没有选择模型，点击居中输入框时，会在中间会话区弹出居中提示浮层
- 如果当前没有选择模型，直接按 Enter 发送时，也会弹出同样的提示浮层
- 提示文案为 `请先选择模型`，副文案为 `点击输入框左侧小地球选择模型`

## 交互样式

- 提示浮层复用了“会话数量已达上限”相同的 `center notice` 样式
- 背景带有同样的模糊处理
- 浮层只作用于中间会话区，不会遮挡左右 Sidebar 的可操作控件
- 未显示时保持彻底失活，不会额外拦截点击

## 使用说明

1. 打开页面但暂不选择模型
2. 点击居中输入框，或直接输入内容后按 Enter
3. 页面会提示先点击输入框左侧小地球选择模型
4. 选择模型后，提示会自动关闭，后续发送恢复正常

## 说明

- 本次修改仅影响居中对话输入框的“未选模型”提醒逻辑
- 右上角备忘录输入与现有其他浮层交互不受影响
- 更完整说明请查看上级手册 `../../USER_GUIDE.md`
