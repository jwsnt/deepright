### 需求介绍
+ 页面打开时，左右侧边栏默认保持展开，不得自动收起。
+ 当模型或 Agent 任一未配置时，持续高亮左侧边栏底部的“设置”按钮，引导用户完成配置。
+ 在该例外状态下，高亮左侧边栏底部的“设置”按钮，并持续闪光以提示用户完成配置。
+ 闪光色系必须随当前主题变化，复用页面既有的主题色变量；浅色与深色主题均应保持协调、清晰可见。
+ 仅当至少已配置并成功保存一个可用模型，且至少已配置并成功保存一个可用 Agent 时，停止闪光；关闭设置或填写但未保存、配置无效时不得停止。

### 编写代码
+ 以现有site页面技术栈编写以上代码，要求：
    + 在../../index.html中按现有HTML/CSS/JavaScript组织方式实现
    + 不引入新的构建流程和额外运行时依赖
    + 代码简洁，尽量复用现有知识库展开态、右侧边栏标题 action 区、右侧栏布局同步和 chat 切换链路
    + 系统指令展开态必须与知识库展开态显式分流，避免共用同一个状态位导致语义串线
    + “系统指令是否展开”只能保存在页面运行时状态，不得写入 chat 持久化字段、`saveChats()`、`localStorage` 或 URL
    + chat 切换、右侧边栏收起、知识库进入展开态等场景下，都必须显式回收系统指令展开态，避免残留脏状态
    + 日志流式追加期间，展开态切换不得中断现有 CLI 子面板渲染、恢复和滚动沉底逻辑
    + 新按钮的 DOM 落位、显隐和 aria 文案必须稳定，禁止在不同状态下漂移到标题栏之外
    + 能用现有开源包和浏览器能力的就不要重复造轮子
+ 最小范围更新
