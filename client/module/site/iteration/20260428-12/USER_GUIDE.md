# 迭代 20260428-12：SSE 发送前等待动画

## 功能说明

1. 发送消息后，不会立即向后端发起 SSE 请求，而是先等待 `3s`
2. 等待期间，整个页面垂直水平居中位置展示 `100x100px` 的转圈等待图标
3. 转圈等待图标带有淡入淡出动画效果
4. 3 秒结束后，才真正发起 SSE 请求；请求成功发出后，转圈等待图标消失
5. 转圈等待效果与当前会话绑定，切换会话时会按会话实时显示，但不会重新开始计时

## 实现说明

- 发送前等待与原有 SSE 工作中状态分离，避免混淆“预发送等待”和“流式响应中”
- 等待阶段使用独立计时器和固定结束时间控制，结束后才进入真正的 `fetch('/v1/chat/completions')`
- 切换会话时会根据当前会话是否仍处于等待窗口内，实时切换等待图标显示状态
- 如果用户在等待阶段点击终止，会立即清除等待计时器并收起等待图标
