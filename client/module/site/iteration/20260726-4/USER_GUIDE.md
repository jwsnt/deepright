# Site 迭代手册（20260726-4）

## 新增高保真音频

在左侧虚拟文件系统点击“新增”，选择“音频”，输入文件名并点击“创建”，即可进入录音浮层。此时不会创建空文件。

- 名称没有后缀时自动补 `.wav`；已填写 `.wav`（大小写不敏感）保持不变。其它后缀不能创建录音。
- 浮层标题为“录制”。开始、结束、重置三个控件始终同一行；暖色主题下浮层与全部控件使用暖色空间，冷色主题下则统一使用冷色空间。点击开始后才请求麦克风权限，录制时长从 `00:00` 实时增长。
- 未结束录制时仅显示状态与时长框；点击结束后该框会移除，页面内播放器直接顶到该位置。点击“重置”会丢弃当前未保存录音、隐藏播放器，并重新回到开始状态。
- 录制中按 `Esc` 会弹出放弃确认；按 `Enter` 则先结束再保存。停止后按 `Enter` 可直接保存，未录制时不能保存。
- 音频以无损 PCM WAV 输出。浏览器会尽量采用设备采样率和可用声道，并关闭回声消除、降噪、自动增益。浏览器不支持录音、麦克风被拒绝、编码失败或保存失败时，浮层会显示原因并保留可重试内容。
- 保存成功后，工作区的 `audios/` 目录会出现指定文件名的 WAV；目录不存在时会自动创建，绝对保存路径会复制到系统剪贴板并显示提示。保存前取消、重置和关闭都不会写入工作区。
