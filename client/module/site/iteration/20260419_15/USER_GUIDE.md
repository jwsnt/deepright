# Site 迭代 20260419_15 使用手册

## 变更说明

所有会话状态以会话维度独立管理：streaming 状态、输入框草稿（含 `@` 气泡）、闪光/工作指示器/暂停键。

## 行为说明

### Streaming 状态
- 每个会话有独立的 streaming 状态和 AbortController
- 切换会话时自动恢复该会话的 UI 状态（闪光、工作指示器、暂停键）
- 暂停键只中断当前会话的请求，不影响其他会话

### 输入框草稿
- 切换会话时自动保存当前输入框内容（包括文本和 `@` 文件/技能气泡）
- 切换回时自动恢复之前的输入内容
- 发送消息后清除该会话的草稿
- 删除会话时清除对应草稿

### 切换会话
- 如果目标会话正在等待响应：恢复闪光、"努力工作中"和暂停键
- 如果目标会话已完成：正常显示，等待用户输入
