# Site 迭代 20260711-1 使用手册

## 本次更新

- 当右侧 Sidebar 的 URL `iframe` 预览已经打开后，预览左边界靠上的位置会新增一个展开小图标。
- 点击该小图标后，当前网站浏览会以站内页内覆盖的方式展开成一个超大浮层，覆盖当前 HTML 可视区域，并在四周各保留 `15px` 缩进。
- 展开态下页面只保留右上角一个高亮的还原按钮；点击后只会还原到当前右侧 `iframe` 预览尺寸，不会关闭网站浏览。

## 使用方式

1. 先通过 assistant URL 小气泡的 `预览` 打开右侧网站浏览。
2. 在右侧 `iframe` 预览区左上角点击展开小图标。
3. 网站内容会以四周各 `15px` 缩进的大浮层方式覆盖当前页面展开显示，浮层外背景会同步毛玻璃模糊。
4. 点击右上角还原按钮，或在父页面仍有焦点时按 `Esc`，即可恢复到右侧预览尺寸。

## 页面行为

- 展开态只使用当前页面运行时状态，不会写入 chat 持久化数据。
- 展开态下，原本用于“关闭网站浏览”的入口会暂时让位，不再作为可点击关闭按钮出现。
- 展开态期间不会新触发任何新手引导。
- 展开态会拦截浮层外页面的普通点击，只保留浮层内容区和右上角还原按钮作为当前主交互区域。
- 如果展开期间切换会话、当前预览被关闭、加载失败或加载超时，页面会自动退出展开态，并恢复到正确的右侧栏展示结果。

## 兼容性说明

- 本次能力是站内页内展开，不会调用浏览器原生全屏，也不会复用输入框左上角的浏览器全屏按钮语义。
- `Esc` 还原依赖父页面收到键盘事件；如果焦点已经进入跨域 `iframe` 内部，父页面不一定能捕获到 `Esc`，此时仍可使用右上角还原按钮退出展开。
- 右侧 `iframe` 预览原有的会话绑定、失败回退、加载超时与原布局切回逻辑保持不变。
