# 迭代 20260717-5：备忘录元数据预览与编辑

## 查看元数据

1. 打开右侧 Sidebar 的备忘录元数据列表。
2. 将鼠标悬停到任一元数据条目，中间区域会显示该备忘录的配置预览。
3. 鼠标离开条目或预览后，预览会保留 `0.5 秒` 再关闭；在这段时间内回到同一条目，或将鼠标移到预览上，预览会继续显示。
4. 直接移到另一条元数据时，预览会立即切换为新内容。

列表只展示周期性备忘录元数据；“仅一次”任务不在此列表中显示。

## 编辑元数据

1. 在预览标题右侧点击编辑图标。
2. 可修改起始时间、周期、模型、Thinking、SWARM、校验和内容；Agent 保持只读。
3. 周期选择沿用创建备忘录的重复周期入口，可选择仅一次、工作日、自然日、每小时、每15分钟或每30分钟。
4. 起始时间只能选择当前时间之后的时刻，最早从下一整分钟开始。
5. 点击保存图标提交修改。

编辑时鼠标离开元数据条目或预览范围，浮层仍会保持打开；悬停其他元数据也不会覆盖当前草稿。页面背景会锁定不可点击，仅当前浮层可编辑。元数据浮层尚未关闭时，鼠标经过任务明细不会显示或切换到任务明细浮层。

## 保存、取消与任务重建

- 点击保存后，页面会显示全局等待层，直到更新和待执行任务重建全部完成。
- 保存会更新当前元数据，只删除该元数据下“待执行”的任务明细，再用最新配置重建待执行任务。
- 已启动、无需启动和已完成任务明细会被保留，不会被删除或重建；如果新任务时间与保留任务重合，系统不会重复创建。
- 保存成功后，浮层保持打开并显示最新只读配置；保存失败时，已输入的编辑内容会保留，可修正后重试。
- 点击取消图标或按 `Esc` 会放弃本次草稿、恢复编辑前的配置并退出编辑态；预览不会关闭。
- 自定义 Cron 元数据若不切换到标准周期，会继续保留原有 Cron 表达式。
