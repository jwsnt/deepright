# 多模态代理模型选择引导使用手册

## 首次选择代理

在设置中展开任一非 `deepright` 模型的客户化配置后，点击“多模态输入”或“多模态输出”输入框左侧的小箭头，会在当前浏览器首次触发一条独立的新手引导。

- 引导会关闭刚刚点击的代理下拉菜单，在“正在指定代理多模态模型”提示处高亮，并显示“可以通过配置代理模型，支持多模态能力。”。
- 点击 `完成` 后，引导关闭，设置中的所有功能恢复可用；如需选择服务商，请再次点击小箭头打开菜单。
- 该首次记录在引导展示时立即保存，并在所有模型客户化配置之间共用；多模态输入和多模态输出不会分别重复播放。
- `deepright` 模型不参与此引导。

## 与其他引导的关系

- 本引导与首次使用引导独立；首次使用引导完成后，首次点击代理小箭头仍可触发它。
- 如果其它新手引导正在显示，本次点击不会抢占该引导；之后再次点击小箭头即可按正常规则触发。
- 设置中的“新手引导”总开关保存为关闭状态时，本引导不会触发。
