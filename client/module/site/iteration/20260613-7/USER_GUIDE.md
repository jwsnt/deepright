# 20260613-7 用户手册

本次迭代为 `@ __internal_browser` 增加了一条独立的新手引导，用来帮助用户快速学会如何向浏览器技能提问。

- 当居中输入框或备忘录输入框第一次通过 `@` 选择 `__internal_browser`，并且当前所选模型已经配置了可用密钥时，这条引导才会触发
- 如果这次首次触发时页面里正有其他新手引导在进行，这条引导会先进入等待队列，等当前引导结束后再补播，不会打断已有流程
- 引导会在居中输入区弹出提示 `需要了解__internal_browser如何使用吗？`，其中 `Enter` 等同于点击 `是`，`Esc` 等同于点击 `否`
- 点击 `是` 后，居中输入框会自动用技能气泡样式插入 `[SKILL:__internal_browser]`，继续补全 `给我几个用自然语言描述[SKILL:__internal_browser]的案例`；自动输入完成后遮罩会立即关闭，页面恢复可操作，同时继续自动发送这条示例消息
- 点击 `否` 或按 `Esc` 后，会直接关闭遮罩，不会自动发送任何内容，也不会重复弹出这条引导
- 这条引导与首次使用引导、首次点击输入框引导、浏览器插件悬停引导、`__internal_cron` 技能引导、蜂群引导、插件引导、备忘录引导、沙盒引导、全屏引导等其它新手引导相互独立，可以兼容共存
