# 20260610-3 用户手册

本次迭代为中间输入区首次输入 `@` 时补充了一条独立的新手引导，用来说明如何在 `@文件 / 技能` 菜单里通过键盘完成选择。

- 当浏览器本地还没有“首次 `@` 菜单引导”的记录时，第一次在中间对话输入框输入 `@`，不会立刻进入真实的 `@` 选择流程，而是先展示这条引导
- 第一步会高亮 `@文件 / 技能` 菜单，并用动画在 `文件` 与 `技能` 之间切换，提示 `使用键盘上下选择文件还是技能。`
- 点击第一步的 `知道了` 后，会切到 `文件` 视图，模拟输入根目录，并展示 `3` 个目录和 `2` 个文件，提示 `通过键盘上下选择目录中的文件。`
- 点击第二步的 `知道了` 后，会把焦点切到第一个模拟目录，并用 `右方向键` 的动画进入目录，再展示 `3` 个模拟文件，提示 `通过键盘右进入选择目录。`
- 最后一步点击 `完成` 后会关闭遮罩并恢复页面正常交互
- 引导期间，其它区域会被暗化且不可点击；引导中的 `@` 菜单和目录内容都是演示专用，不会真的读取文件系统，也不会真的插入文件或技能
- 这条引导与首次使用引导、输入框引导、蜂群引导、插件引导、文档整理引导、备忘录引导、沙盒引导、全屏引导、虚拟文件系统编辑引导等其它新手引导相互独立，可以兼容共存
