# Site 迭代 20260419_12 使用手册

## 变更说明

左侧边栏新增虚拟文件系统（VFS），展示当前 Agent 工作目录的文件和目录，支持浏览、查看和编辑文件。

## 虚拟文件系统

- 位于 sidebar 下方、设置按钮上方，高度 300px
- 选择 Agent 后自动显示，未选择时隐藏
- 每 10 秒自动刷新当前目录，仅在内容变化时更新 DOM
- 目录排在前面，文件排在后面，按名称排序
- 点击目录进入子目录，点击左上角 ⬆ 返回上级

## 文件编辑器

- 点击文件打开 500×500px 居中浮层（透明度 20%）
- 顶部显示文件相对路径和「预览/编辑」标签页
- 预览模式：Markdown 渲染展示
- 编辑模式：纯文本编辑器
- 底部按钮：
  - 保存：调用 `/api/edit` 写入文件，成功后关闭并刷新 VFS
  - 取消：关闭浮层（ESC 键也可关闭）
