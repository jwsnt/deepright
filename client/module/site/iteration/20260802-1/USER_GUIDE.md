# 迷你应用调试使用手册

进入当前 Agent 工作区的 `app/` 目录后，点击虚拟文件系统标题栏的“迷你应用”图标。列表只显示 HTML 和配对的 Markdown 两列；每行 Markdown 右侧有一个小瓢虫图标用于调试对应 HTML。Markdown 文件名太长时会自动以省略号显示，瓢虫图标始终完整留在浮层内。

点击某个 HTML 行的 Debug 图标会打开“调试迷你应用”浮层。浮层以单行显示本次目标 HTML 的绝对路径，超出宽度时自动截断；悬停路径可查看完整值。浮层提供固定高度的“修复原因”输入区；输入过长时在该区域内滚动。浅色界面使用暖色，深色界面使用冷色，便于与普通构建浮层区分。

可直接输入问题描述，也可把左侧虚拟文件系统中的文件拖进输入区。把系统文件或图片拖入，或从剪贴板粘贴图片、文件时，文件会先上传到当前 Agent 的 `tmp/` 目录，再作为附件一起发送。按 `Shift+Enter` 可换行；按 `Esc` 或点击取消可关闭浮层而不提交。点击遮罩或浮层外部会保持浮层打开。

修复原因不能为空。原因为空时“确认”不可点击，按 `Enter` 也不会发送。填写后点击“确认”或按 `Enter`，页面会把目标 HTML 的绝对路径和原因带入当前会话，作为一条修复请求自动发送；发送成功后浮层会关闭并清空草稿。会话已切换、Agent 或模型不可用、会话正在处理或配置无效时，浮层会保留并显示原因。
