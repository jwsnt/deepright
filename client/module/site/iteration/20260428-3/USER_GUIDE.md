# 迭代 20260428-3：备忘录元数据列表视图

## 功能说明

在右上备忘录区域的信封保存图标后新增切换图标（田字格），点击后备忘录模块切换为周期性备忘录元数据列表。

## 列表展示

每行显示：周期类型、时间（MM-DD HH:mm）、模型、思考模式、删除按钮（×）。各列固定宽度，超出以省略号截断。

## 交互

- 鼠标悬浮列表项时向左下展开浮层显示备忘录完整内容，移开自动收起
- 点击行末 × 按钮删除该备忘录（同时删除元数据和明细）
- 切换视图和悬浮内容均有淡入淡出效果
- 下半部分右侧有切换图标，点击返回备忘录输入视图

## 依赖接口

- `POST /api/cron/detail/metadata?agentId=xxx` — 查询元数据
- `POST /api/cron/delete?id=xxx` — 删除元数据及明细
