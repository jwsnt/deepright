# Site 迭代手册（20260516-2）

## 本次更新

- 左侧虚拟文件系统中的 `USER.md` 文件右侧新增金色小灯泡入口
- 小灯泡默认显示为灰色，仅当 `USER.md` 最后更新时间距离当前时间超过 `8` 小时时才会点亮并闪动
- 小灯泡固定在文件行操作区最右侧，删除和下载图标显示时不再引起行内位置跳动
- 如果当前 `Agent + Chat` 正在发送请求、等待 SSE 响应或恢复未完成请求，小灯泡会临时禁用，且不会展开确认浮层
- 点击小灯泡后，会在中间会话区弹出与 `Skill` 提炼浮层同风格的确认浮层
- 浮层提示文案为 `检测到USER.md，是否重新整理？`
- 浮层会直接预览即将发送的整理提示：`按@USER.md的要求重新整理 [FILE:/.../USER.md]`
- 其中 `[FILE:/.../USER.md]` 会以绝对路径小气泡的形式展示，便于用户确认目标文件

## 当前行为

1. 只有虚拟文件系统当前目录列表中出现文件名为 `USER.md` 的文件时，该行右侧才会显示小灯泡
2. 页面会调用收口后的 `/file/lastUpdate` 判断 `USER.md` 最后更新时间；未超过 `8` 小时时保持灰色，超过后切换为金色闪动
3. 当当前 `Agent + Chat` 正在发送请求、等待 SSE 响应或恢复未完成请求时，小灯泡会临时不可点击，也不会展开提示浮层
4. 小灯泡点击后不会在左侧 Sidebar 内展开，而是复用中间会话区的居中浮层体系
5. 浮层确认前会校验当前会话是否空闲、Agent 是否有效、模型和密钥是否已配置
6. 校验通过后，页面会自动发送 `按@USER.md的要求重新整理 [FILE:/.../USER.md]`
7. 浮层中的 `[FILE:/.../USER.md]` 使用虚拟文件系统里的绝对路径，不会退化成相对路径
8. 点击取消、点击浮层外空白区域、按 `Esc`、切换会话或打开其他居中浮层时，当前提示浮层会立即关闭

## 说明

- `USER.md` 整理浮层与 `SOUL.md`、`Skill` 提炼浮层、安装提示浮层一样，遵守中间会话区分域 overlay 的层级与 pointer-events 隔离规则
- 浮层隐藏后会彻底失活，不会跨区域遮挡左侧或右侧 Sidebar 的可操作控件
