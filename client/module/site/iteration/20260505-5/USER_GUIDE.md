# 20260505-5 使用手册

## 目标

本次迭代补充右上角备忘录明细“查看会话”的过期提示逻辑，并保持现有分域交互与界面结构不变：

- 点击备忘录明细中的 `查看会话` 时，仍会按现有流程发起 `/api/restore` 恢复
- 如果恢复接口没有返回任何新数据，且当前保存的最后恢复时间已经晚于该条备忘录消息时间，则提示该消息已过期
- 提示继续复用左侧虚拟文件系统的 Tips 位置，不新增新的弹层或遮罩

## 页面行为

- 右上角备忘录明细中，已完成任务点击 `查看会话` 后：
  - 若恢复到了新消息，则仍按原逻辑进入并展示对应会话
  - 若 `/api/restore` 没有返回任何新数据，且该备忘录时间早于当前会话已记录的最后恢复时间，则在左侧虚拟文件系统 Tips 位置提示 `消息已恢复，删除会话可重建`
- 该提示只影响当前这次查看恢复，不会改变已有会话列表、弹层层级或其它 Sidebar 的交互

## 分域规则

- 本次修复不新增新的固定定位浮层、确认框或遮罩层
- 左侧 Sidebar、中间会话区、右侧 Sidebar 仍继续遵守“交互域隔离 + 隐藏视图彻底失活”原则
- 过期提示复用既有 VFS Tips 位置，因此不会跨区域遮挡或拦截右侧备忘录与中间会话区的点击

- 备忘录重复恢复与串行恢复逻辑可参考 `../20260505-4/USER_GUIDE.md`
