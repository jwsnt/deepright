# 迭代 20260717-3：备忘录任务明细预览与编辑

## 查看任务明细

1. 在右侧 Sidebar 的备忘录任务明细列表中，将鼠标悬停到任一任务。
2. 中间区域会打开“备忘录配置预览”，显示该任务的周期、时间、模型、SWARM、Thinking、校验、Agent、状态和内容。
3. 鼠标离开任务或预览后，预览会保留 `0.5 秒` 再关闭。在这段时间内回到同一任务，或把鼠标移到预览上，预览会继续显示。
4. 直接移到另一条任务时，预览会立即切换为新任务内容。

## 编辑待执行任务

只有状态为“待执行”的任务可以编辑。

1. 悬停目标任务，在预览标题右侧点击编辑图标。
2. 可编辑执行时间、模型、Thinking、SWARM、校验和内容；周期、状态和 Agent 保持只读。
3. 执行时间只能选择当前时间之后的时刻，时间控件最早从下一整分钟开始。过去时间不能保存。
4. 点击保存图标提交修改。页面会继续保留预览，并显示服务端返回的最新任务内容。

保存仅作用于当前任务明细，不会修改周期规则，也不会连带修改其他历史或未来任务。

## 取消、Esc 与保存失败

- 点击取消图标，或在编辑态按 `Esc`，都会放弃本次草稿、恢复原始内容并退出编辑态；预览不会关闭。
- 编辑时离开任务和预览范围，预览仍会保持打开，避免未保存内容丢失；页面背景同时锁定不可点击，仅当前浮层可编辑；保存或取消后，才恢复普通的 `0.5 秒` 悬停关闭规则。
- 如果任务在打开编辑后已经启动，保存会失败。页面会保留编辑态和已输入内容，方便重新查看或取消。
- 内容为空、内容过长、模型不可用或执行时间早于当前时间时，也不会提交保存；修正后可再次点击保存。
