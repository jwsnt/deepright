# SSE 快捷回复使用手册

在主应用资源目录的 `config/config.json` 中配置 `shortcut` 字符串数组：

```json
"shortcut": ["好的", "同意", "执行"]
```

当当前会话有最后一条正常完成的 SSE assistant 响应时，该消息 footer 的复制图标和思考灯泡之间会显示快捷回复图标。只有去除首尾空白后仍非空的字符串会显示；重复项按首次出现保留。配置缺失或没有有效项时，图标不会出现。

点击图标后，快捷回复会以无外层框、9px 缩小字号、22px 边框高度的紧凑横向按钮平铺在该响应底部的时间、完成 Agent 与完成状态信息行上。展开时，原信息行会淡出并隐藏；收起或选择一项后，信息行会淡入恢复。不会显示扇形、遮罩或背景模糊，其他响应内容保持清晰可见。暖色模式使用暖橙色系，冷色模式使用蓝青色系。再次点击图标、点击菜单外任意位置、按 `Esc`、调整窗口或任意滚动页面（包括拖动滚动条与新响应内容带来的滚动）都会立即收起菜单。每次展开都会重新读取运行配置，修改 `shortcut` 后无需重启页面即可在下一次打开时使用新列表。

当前会话已经发起请求时，快捷回复图标会保持显示但处于禁用状态；SSE 响应结束后自动恢复可点击。若请求开始前菜单已打开，它会立即收起。

点击列表中的任一项会将文本写入当前会话输入框并立即发送。发送继续使用普通会话的模型、Agent、思考／HTML／蜂群设置及输入校验；会话忙碌、模型或 Agent 不可用等情况仍按原有页面提示处理。
