# 20260611-2 用户手册

本次迭代为“浏览器插件首次成功启动后的首次悬停”补充了一条独立的新手引导，用来提示用户主动通过 `__internal_browser` 技能调用浏览器插件，并可一键自动演示一次真实发送。

- 当本地还没有“任意插件首次成功启动”的历史记录，并且第一次成功启动的是浏览器插件时，系统会记录一条“等待首次悬停浏览器插件”的引导资格
- 之后当用户第一次把鼠标悬停到左侧扇形菜单里已经启动成功且变为绿色的浏览器插件按钮上时，会触发这条新引导
- 引导会切换到居中对话输入区域，动画模拟输入 `@` 并高亮 `__internal_browser` 技能，同时暗化其它区域且禁止点击
- 引导文案为 `可以主动使用__internal_browser技能唤起浏览器插件。`
- 点击 `完成` 后，会切换到一个居中的确认浮层，询问 `是否需要测试插件？`
- 确认浮层支持键盘快捷键：按 `Enter` 等同点击 `是`，按 `Esc` 等同点击 `否`
- 无论点击 `是` 还是 `否`，都会先立即关闭这条新手引导的遮罩，并收起键盘模拟层，恢复页面全部区域可点击
- 点击 `是` 后，会在无遮罩、无键盘模拟层的状态下，直接使用真实的居中输入框与真实的 `@` 技能列表动画演示选择 `@ __internal_browser`，再输入 `在维基百科搜索下Deepseek`，最后自动发送
- 点击 `否` 后，仅关闭本次引导，不会自动发送测试消息
- 这条引导与首次成功启动任意插件后的绿色图标引导、首次输入框引导、首次使用引导等其它新手引导相互独立；如果悬停发生时其它引导仍在进行中，会等当前引导结束后再继续展示
