# Site 迭代手册（20260603-1）

## 本次更新

- 左侧边栏底部的 `节能` 开关继续作为页面唯一的节能入口。
- 页面内所有“节能 / 降级渲染”相关标记，统一只跟随 `节能` 开关开启或关闭，不再直接跟随操作系统判断。
- `Mac x86` 设备只影响启动默认值：首次进入时默认开启 `节能`，并默认使用浅色主题，同时关闭按时间自动切换深浅色主题。

## 当前行为

1. 无论当前是哪个操作系统，只要手动打开 `节能`，页面就会进入低消耗渲染状态，例如关闭开屏动画、关闭欢迎区持续动画，并把毛玻璃效果简化为普通半透明背景。
2. 无论当前是不是 `x86`，只要手动关闭 `节能`，这些节能 / 降级渲染效果都会一起关闭，恢复常规渲染表现。
3. `Mac x86` 设备在本地没有保存过手动节能结果时，首次打开页面会默认开启 `节能`；如果用户后来手动改过开关，刷新后优先沿用本地保存结果。
4. `Mac x86` 设备默认以浅色主题启动，且不会再按时间自动切换主题；但用户手动切换为深色后，页面仍会保留这次手动选择。
