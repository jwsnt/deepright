# 迭代 20260428-5：备忘录明细时间轮真实数据

## 功能说明

右上角日历下方的时间轮列表从 `/api/cron/detail/list` 获取真实备忘录明细数据。日历优先完整展示（不滚动），间隔 5px 后展示列表。

## 列表展示

- 每行：时间（MM-DD HH:mm，不换行）、备忘录内容（超出省略号截断）
- 时间轮样式（左侧竖线 + 圆点）
- 空列表显示灰色 `--当前无待执行任务--`

## 刷新机制

- 每 30 秒自动刷新
- 切换日历日期、保存/删除备忘录、更改 Agent 后立即刷新
- 使用本地日期（非 UTC）

## 交互

- 30 分钟内待执行任务高亮闪烁
- 鼠标悬浮展示元数据浮层（模型、思考模式、状态、完整内容），移开收起

## 数据来源

`POST /api/cron/detail/list?agentId=xxx&date=yyyy-MM-dd`
