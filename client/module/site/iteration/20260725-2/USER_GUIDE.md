# Site 迭代手册（20260725-2）

## 图片与视频取色

视频预览浮层标题栏提供吸管图标。点击后会先显示“开始取色”，再点击当前视频帧中的任意可视像素即可取得该点颜色。

图片预览不显示额外的吸管图标；请使用工具栏“颜色”控件内置的系统吸管。该控件右侧还支持直接输入或粘贴 `#RRGGBB`，例如 `#FF4D4F`。选取或提交颜色后，画笔、形状和文字会立即使用新颜色。

- 颜色以大写 `#RRGGBB` 格式自动复制到系统剪贴板。
- 取色或提交合法 Hex 成功时，预览浮层左下角提示“取色结果已复制到系统剪贴板”。正常 Tips 与当前主题下启用态的“节能”开关使用相同配色。
- 画面还未准备好、浏览器无法读取像素或系统拒绝剪贴板写入时，同一位置会显示暖色异常 Tips；预览和播放不会被关闭或改变。
- 视频读取点击瞬间的当前帧；缩放显示时，仍会对应到正确的源画面像素。
- 视频吸管为单次取色操作；点击后再次点击吸管或按 `Esc` 可直接退出，不会关闭预览浮层。

页面所有运行期提示统一使用“剪贴板”这一文案。
