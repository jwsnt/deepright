# 20260505-1 使用手册

## 简介

本次迭代补充了右上角备忘录明细悬停浮层中的 `类型` 字段展示，并继续收紧了固定定位浮层的分域管理规则，避免未激活浮层跨区域拦截点击。

## 备忘录明细浮层

- 右上角备忘录列表项悬停时，浮动层会展示：
  - `Agent`
  - `类型`
  - 备忘录内容
- `类型` 取值来自 cron 明细返回的 `type`
- 当后端未返回 `type` 时，前端会回退显示为 `cron`

## 浮层分域规则

- 右侧 Sidebar 内的时间线详情浮层和备忘录详情浮层，已纳入统一 overlay 状态管理
- 这两个右侧浮层默认保持 `pointer-events:none`
- 仅在悬停激活期间显示，不会再以未激活状态误拦截右侧或中间区域点击
- 浮层定位会限制在右侧 Sidebar 可视范围内，避免窗口尺寸变化后漂移到中间会话区

## 固定定位弹层修正

- 左侧 Sidebar 使用的固定确认框和数量上限提示，会继续限定在左侧域中心位置
- 中间文件编辑浮层的固定定位范围已收紧到中间会话区，不再覆盖左侧 Sidebar
- 文件编辑面板宽度会随中间可用空间自适应收缩，减少小窗口下的跨区遮挡
