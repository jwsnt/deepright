# 20260524-1 使用说明

## 迭代目标

本次迭代修正了站点侧虚拟文件系统的“新建文件或目录”流程：用户仍然只输入单个名称，但当当前浏览目录不在 workspace 根目录时，前端会自动拼接当前相对目录后再调用 `/api/agent/create`。

## 交互说明

- 创建弹窗输入框仍只接受单个文件名或目录名
- 前端会拒绝 `/`、`\`、空白字符、`.`、`..` 等非法名称
- 当前位于 workspace 根目录时，输入 `data` 会创建到 `<workspace>/data`
- 当前位于 `docs` 目录时，输入 `data` 会创建到 `<workspace>/docs/data`
- 当前位于 `docs` 目录时，输入 `note.md` 会创建到 `<workspace>/docs/note.md`
- 创建成功后会关闭弹窗、清空错误提示并刷新当前目录内容
- 创建失败时，会在弹窗原错误位置展示后端返回内容

## 验收建议

1. 在 workspace 根目录打开创建弹窗，创建目录 `data`，确认结果位于根目录下。
2. 进入 `docs` 目录后创建目录 `data`，确认结果位于 `docs/data`。
3. 在 `docs` 目录创建文件 `note.md`，确认结果位于 `docs/note.md`。
4. 尝试输入 `.`、`..`、`a/b`、`a\\b` 或带空格名称，确认前端直接拦截。
