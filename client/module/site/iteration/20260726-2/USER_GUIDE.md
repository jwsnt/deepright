# Site 迭代手册（20260726-2）

## 无限画布

在左侧虚拟文件系统点击“新建”，填写名称并选择“画布”，再点击“创建”即可进入无限画布编辑器。名称必填并沿用原有合法性规则；只允许无后缀或以 `.canvas` 结尾，未带后缀时会自动追加 `.canvas`，其它后缀会提示错误。

- 首次点击“保存”前，画布只保存在当前浏览器编辑状态，工作区中不会出现空文件。保存成功后编辑器不会关闭，可以继续编辑并再次保存。
- 顶部工具栏可添加便签、文本和图片，支持拖动节点、空白处框选、多选、连线、撤销和重做。颜色入口只在悬停或选中便签/文本时显示；点击后打开颜色浮层，可选择颜色或点击“恢复默认背景”。浅色主题默认采用暖橙/米杏背景与深色文字，深色主题默认采用深蓝背景与浅色文字；选择任意颜色后，文字会自动变为高反差颜色。文本默认没有背景，恢复默认会改回透明。连线前可选正向 `→`、反向 `←` 或双向 `↔` 箭头；点击“连线”后会锁定当前方向，完成 A → B 创建时立即生效。选中已有连线后，也可直接通过该方向选择更新箭头。顶部不再提供备注输入：无备注时“添加备注”和红色 `×` 仅在悬停或选中连线时显示；有备注时备注摘要会常驻在连线中部，单击即可打开画布内的编辑浮层，保存或清除备注，不会弹出系统对话框。进入连线模式后，点击元素 A 的任意位置，再点击元素 B 的任意位置即可立即连上，文字或图片内容区也可直接点击。单击线条会选中连线，也可按 `Delete/Backspace` 删除。按 `Esc` 仅关闭备注浮层。缩小一号的放大镜 `−` / `+` 图标固定在画布右下侧、缩略图上方；也可滚轮缩放，按住空格或使用中键拖动画布，右下角小地图显示全局位置。
- 图片支持本地选择、拖放和粘贴。图片会和节点、连线、标题、视口位置一起存入 `.canvas`，因此重新打开该文件后可以继续编辑。
- 标题可修改，但不会更改文件名。首次保存如发现同名 `.canvas` 文件，会在覆盖前提示确认。
- 画布会跟随页面主题：浅色模式采用暖橙、琥珀和米杏色系；深色模式采用冷色系。底部操作提示在暖色主题使用米杏背景与深色文字，在冷色主题使用深蓝背景与浅色文字；错误提示也保持高对比。PNG/PDF 导出也会保留当前主题的画布配色。
- 关闭、右上角 `×`、点击遮罩或 `Esc` 都是离开入口。未保存的新画布始终会要求确认放弃；已保存的画布只有存在后续未保存修改时才会要求确认。
- “导出”先选择整个画布或当前视口，再选择 PNG 或 PDF。导出菜单和内容会跟随当前主题使用可读的冷暖配色；生成的文件会保存到当前 Agent 工作目录的 `canvas/`，目录不存在时自动创建，且每次导出保留独立文件。成功后会将该文件的绝对路径复制到系统剪贴板并提示；若浏览器不允许复制，文件仍已保存，提示会说明复制失败。不支持 SVG。
