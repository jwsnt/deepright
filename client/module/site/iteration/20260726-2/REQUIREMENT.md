### 需求介绍
+ 左侧虚拟文件系统的“新建文件或目录”浮层新增“画布”类型。名称必须填写，并沿用现有名称合法性校验；画布名称只允许无文件后缀，或以 `.canvas` 结尾。无后缀时保存自动补充 `.canvas`，其它后缀必须在创建前提示错误，已带 `.canvas` 时不得重复追加。
+ 选择“画布”并点击“创建”后，页面立即打开独立的无限画布编辑浮层，而不是先创建空文件。新画布在首次点击“保存”前只能存在于浏览器临时状态；取消、关闭、点击遮罩或刷新页面均不得在 Agent 工作区留下文件。
+ 画布编辑浮层须包含无限画布的核心交互：鼠标/触控板缩放、自由平移、卡片或便签、独立文本、节点拖拽、框选、多选、连线、撤销、重做与小地图。缩放控件使用放大镜加号／减号图标而非纯文本符号，尺寸须小于常规工具按钮一档，并固定在画布右下侧、缩略图上方对齐。进入连线模式后，点击元素 A 的任意位置（便签/文本的内容区或空白区、图片区域）选择起点，再点击元素 B 的任意位置必须立即创建连线，不得要求命中元素边缘、选择框或额外可点击区域。顶部仅保留正向 `→`、反向 `←`、双向 `↔` 的箭头方向选择；开始创建连线时须锁定并应用当前方向，选中既有连线后修改该选择也须立即更新其方向，且方向须同时反映在编辑器与 PNG/PDF 导出中。顶部不得提供连线备注输入。无备注连线的中部“添加备注”与删除操作仅在连线被悬停或选中后出现；已有备注时，备注摘要须常驻在连线中部，单击即可在画布内浮层编辑或清除备注；不得使用浏览器原生 `prompt`，`Esc` 只关闭备注编辑浮层。单击线条须选中连线并显示明确的删除操作，且支持 `Delete/Backspace` 删除选中连线。默认在画布中央提供可删除的引导卡片，文案为“欢迎来到无限画布，\n可拖动画布、滚轮缩放，\n并从上方工具栏添加内容。”；背景使用可辨识位置的点阵网格。
+ 卡片、文本及图片都是可选择和拖动的画布节点；图片必须同时支持本地上传、拖放到画布和粘贴图片。便签和文本的颜色入口仅在悬停或选中元素时显示；点击后打开颜色浮层，浮层内同时提供颜色选择和“恢复默认背景”操作。默认便签在浅色主题使用暖橙/米杏色（深色文字），深色主题使用深蓝冷色（浅色文字），自定义颜色后必须按背景亮度自动选择高反差字体颜色。文本默认保持无背景，选择颜色后才显示圆角背景，并同样自动使用高反差字体；恢复默认后回到透明。图片数据作为画布内容保存，重新打开同一 `.canvas` 文件后必须可以继续编辑。
+ 顶部标题允许修改画布标题；标题是画布 JSON 的内容/元数据，默认取文件名去除 `.canvas` 后的部分，保存标题不得修改实际文件名。
+ 点击“保存”后使用既定文件名创建或更新 `.canvas` 文件，保存成功后编辑浮层继续保持打开。首次保存或外部同名文件已存在时，必须提示是否覆盖；用户确认后才可写入。保存后的再次编辑也必须再次点击“保存”才更新文件列表中的内容。
+ 画布编辑器应提供明显的“关闭”与右上角关闭按钮。对新建但未保存的画布，无论是否编辑过，点击关闭、取消、遮罩或 `Esc` 都必须先弹出“放弃未保存内容”确认；已保存画布只有在存在尚未保存修改时才需要该确认。
+ 打开已有 `.canvas` 文件时，必须解析其保存的画布状态并进入同一编辑浮层；遇到不合法或旧版本内容时，以可编辑的空白画布和提示回退，不得使文件预览浮层崩溃。
+ 编辑器提供两步导出菜单：先选择“整个画布”或“当前视口”，再选择 PNG 或 PDF；菜单自身在浅色主题使用暖色背景与深色文字，在深色主题使用冷色背景与浅色文字。PNG/PDF 由浏览器生成后必须写入当前 Agent 工作目录的 `canvas/` 子目录，目录不存在时创建；同名导出不得覆盖历史文件。保存成功后必须将服务端返回的绝对路径复制到系统剪贴板并提示，复制失败不得影响文件已保存的结果。导出不支持 SVG。
+ 画布保存格式为版本化 JSON，至少包含 `version`、`title`、视口、节点（类型、坐标、内容/图片及可选背景色）和连线（端点、箭头类型 `forward` / `reverse` / `both`、备注）；前端不得将本机路径、`file://` 链接或未经编码的图片文件路径写入 `.canvas`。旧文件缺失箭头类型时按 `forward` 兼容。

### 编写代码
+ 在 `index.html` 的 VFS 新建类型、文件打开分流和既有居中 overlay 管理中最小范围实现画布编辑器；不引入第三方前端依赖。
+ 复用现有受限工作区接口保存和读取 `.canvas` 文件与导出二进制文件，图片只以 Data URL / JSON 内容在浏览器和工作区之间传输；PNG/PDF 在浏览器生成后以 Base64 经受限接口写入 `canvas/`，不新增服务端图形渲染或本机任意路径读写能力。
+ 画布节点、连线、框选、缩放和平移必须在浅色和深色主题下可辨识；浅色（暖色）主题的画布背景、点阵、引导卡片、阴影、缩略图、导出内容与底部状态提示必须使用暖橙、琥珀、米杏色系，并保持深色高对比文字；深色主题继续使用冷色系，状态提示须使用深蓝背景与高对比浅色文字。错误提示在两种主题下同样必须清晰可辨。画布关闭确认、覆盖确认和键盘焦点须融入既有 overlay 互斥、`Esc` 与可访问性语义。
+ 最小范围更新。
