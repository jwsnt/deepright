# 视频预览切分使用手册

## 使用方式

1. 在当前 Agent 的虚拟文件系统中打开视频预览。
2. 点击右上角关闭按钮左侧的冷色“编辑视频”图标。
3. 拖动“开始”和“结束”手柄，以 `0.5` 秒为单位选择片段；播放、进度拖动和前进/后退可试听选区。切分浮层会随主题统一配色：暖色主题使用暖色控件，冷色主题使用冷色控件。
4. 点击“保存为新视频”，输入文件名（默认值沿用 `_trim_时间戳.mp4` 命名规则）后确认。成功后会刷新文件列表，将新视频的绝对路径复制到系统剪贴板，并提示复制成功。

## 保存规则

- 保存前、取消、关闭浮层或失败时均不会产生文件。
- 成功后会在当前 Agent 工作目录的 `videos/` 下生成一个带 `_trim` 和时间戳的新 MP4；目录不存在时自动创建。
- 原视频不会被覆盖、修改、删除或改名。
- 取色和坐标提取不会与视频切分同时启用；进入切分模式会退出这些工具。

## 异常处理

视频时长尚未读取、服务端未安装 FFmpeg/FFprobe、源编码无法转码或服务端返回错误时，页面会保留当前预览和选区，并显示失败原因。
