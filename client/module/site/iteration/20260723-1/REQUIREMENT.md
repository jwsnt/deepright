### 需求介绍
+ 当前 Agent 发生切换并完成保存后，右侧备忘录区域必须立即显示切换蒙层。蒙层覆盖备忘录第一栏的完整区域：左侧日历、任务明细、右侧备忘录编辑区、备忘录元数据列表及其底部全部全局控制按钮；不覆盖中间会话区、左侧 Sidebar 或 Agent 切换入口。
+ 蒙层显示文案固定为“正在切换Agent”，拦截被覆盖区域的鼠标、键盘与触摸交互，并对其下方内容使用模糊效果。每次切换的蒙层最少且固定显示 `2` 秒，随后自动恢复被覆盖区域的交互。
+ 连续切换时，页面必须立即取消上一次 `2` 秒计时并重新开始蒙层效果；任务明细和元数据的旧请求应尽力通过 `AbortController` 取消。每次刷新分配仅在页面运行期有效的递增请求序号，只有当前最新序号且 Agent 仍匹配的响应可以更新备忘录区域；无法取消或较晚返回的旧响应必须忽略。
+ 此交互不得写入 localStorage、聊天、备忘录、Agent 配置或其他服务端持久化数据；刷新页面后请求序号、计时器和取消控制器自然失效。

### 编写代码
+ 以现有site页面技术栈编写以上代码，要求：
    + 在../../index.html中按现有HTML/CSS/JavaScript组织方式实现
    + 不引入新的构建流程和额外运行时依赖
    + 在 `../../index.html` 复用模型配置行、客户化配置解析、现有 toast 与 AbortController 能力；不得为测试创建或复用普通聊天、会话、全局工作中状态、历史恢复或持久化状态。
    + 请求前从当前 DOM 行重建服务商、Token 和有效客户化配置，保证未保存编辑值参与测试；每行运行时仅允许一个 AbortController/请求序号，完成、失败、取消、删除、重新渲染和关闭设置时均清理该临时状态。
    + SSE 消费需处理非 JSON、网络异常、HTTP 非 2xx、SSE error/错误 JSON、空流、缺少 `[DONE]`、首包/总超时、取消与乱序返回；只有当前请求序号可更新该行 loading 状态或显示结果。
    + 保持测试图标最小空间占用，并为禁用原因、loading 与取消提供可访问名称；测试时避免把 Token、请求正文或原始错误详情写入 DOM、控制台或提示。
    + 覆盖自动化测试：仅设置内可见、未保存配置透传、三种置灰原因、`__model` 强制、重复点击阻断、成功、各失败类别、取消、关闭设置/删除行清理、以及无 chat/localStorage 副作用。
    + 能用现有开源包和浏览器能力的就不要重复造轮子
+ 最小范围更新
