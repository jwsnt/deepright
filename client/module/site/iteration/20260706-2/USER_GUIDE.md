# 20260706-2 用户手册

本次迭代为会话清理相关操作补充了一个独立的新手引导，帮助首次接触该区域的用户理解“清空会话”和“重新加载会话”的用途。

## 触发方式

- 首次点击会话区顶部的`清空当前会话`按钮时触发
- 该引导只记录“是否点过清空会话按钮”，与首次使用、首次点击输入框、蜂群引导、插件引导等其他新手引导互不复用记录

## 引导步骤

1. 首次点击`清空当前会话`按钮后，页面会先进入引导态，而不是立刻弹出清空确认框
2. 第一段引导会高亮`清空当前会话`按钮，并提示：`清空会话可以让界面保持整洁。`
3. 点击`知道了`后，引导会切换到右下角的`重新加载会话`按钮，并提示：`可以通过重新加载会话恢复内容。`
4. 点击`完成`后，引导结束，页面恢复正常交互

## 兼容性说明

- 首次使用引导仍按原逻辑判断“是否存在浏览器记录”，不会因为本次点击清空会话而被覆盖
- 首次点击输入框、首次点击设置蜂群图标、首次点击插件按钮等其他独立引导仍各自保留自己的触发记录
- 引导进行中，清空会话与重新加载会话的实际按钮操作会被锁定，避免在阅读提示时误触发真实功能
- 引导完成后，`清空当前会话`确认框和`重新加载会话`确认框继续沿用原有交互
