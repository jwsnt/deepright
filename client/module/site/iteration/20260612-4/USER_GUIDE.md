# 20260612-4 用户手册

本次迭代补充了居中对话框里“按文件名反查工作目录”的兜底能力。

## 触发方式

- 在居中对话框中双击或框选一段连续内容
- 如果这段内容没有先被识别成绝对路径、白名单相对路径、图片路径或 `http/https` 链接，页面会把它当作文件名继续尝试查找

## 查找顺序

1. 当前 Agent 工作目录，排除 `tmp` 与 `images` 子树
2. 当前 Agent 工作目录下的 `tmp`
3. 当前 Agent 工作目录下的 `images`

## 结果展示

- 找到 1 个匹配文件时，继续沿用原来的小气泡操作：`预览`、`下载文件`、`打开目录`
- 找到多个同名文件时，小气泡会按绝对路径逐条列出，并为每条路径提供对应的 `预览`、`下载文件`、`打开目录`
- 如果没有找到任何匹配项，则保持原始选中效果，不额外弹出操作

## CLI

站点模块新增了一个可复用的 Go 子模块与独立 CLI：

```bash
go run ./cmd/filenamelookup -root /absolute/workspace -name report.md
```

命令会输出按 `workspace -> tmp -> images` 顺序排列的 JSON 结果，便于其它模块复用同一套查找规则。
