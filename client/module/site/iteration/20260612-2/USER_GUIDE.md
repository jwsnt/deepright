# 邮件插件扫描间隔提醒

本次迭代在 `Site` 的邮件插件浮层中补充了 `email_pop3_interval` 的提醒逻辑。

## 触发规则

- 仅对 `email` 插件生效
- 当 `email_pop3_interval` 留空时，不做提醒，继续按默认值 `300` 秒处理
- 当 `email_pop3_interval` 明确填写且小于 `300` 时，点击 `启动插件` 或 `重启插件` 会先弹出提醒浮层

提醒文案为：

```text
过于频繁的扫描间隔会导致邮件服务商拒绝服务
```

## 交互说明

1. 打开左侧快捷插件菜单中的 `邮件` 插件浮层
2. 填写 `email_pop3_interval`
3. 如果填写值小于 `300`，点击启动时会先出现提醒浮层
4. 浮层只提供一个 `知道了` 按钮
5. 浮层中固定展示 `推荐使用：300`
6. 点击 `知道了` 后，当前这次启动/重启操作会继续执行

## 建议

- 推荐直接填写 `300` 或更大的秒数
- 如果希望沿用默认扫描周期，可以将 `email_pop3_interval` 保持为空
