# 20260611-8 用户手册

本次迭代为“设置中首次成功开启并保存蜂群配置”补充了一条独立的新手引导，用来帮助用户理解居中对话框里的蜂群开关和 `@ Agent` 调用方式。

- 只有当设置里的蜂群配置第一次被成功保存为开启状态时，这条引导才会进入触发队列；后续再次保存蜂群配置不会重复触发
- 如果首次成功保存蜂群配置时，页面里正有其他新手引导在进行，这条引导会等待当前引导结束后再补播，不会打断已有流程
- 引导第一步会高亮居中输入区右上角的 `SWARM` 开关，并用约 `2` 秒的动画模拟一次从关闭到开启的切换；文案为 `在当前对话中开启蜂群后可以自动或指定调用蜂群成员。`
- 点击 `知道了` 后，引导会切到居中输入框，模拟输入 `@`、唤起 Agent 菜单，并自动选择这次首次成功开启并保存蜂群配置的 Agent；文案为 `蜂群成员间只能相互调用。`
- 点击第二步的 `完成` 后，遮罩会关闭，模拟插入的 `@ Agent` 气泡会被移除，输入框会恢复成引导开始前的原始内容
- 这条引导与首次使用引导、首次点击输入框引导、首次切换模型引导、插件引导、备忘录引导、沙盒引导、全屏引导等其它新手引导相互独立，可以兼容共存
- 任意新手引导进行期间，居中输入框按 `Enter` 都不会触发发送；只有引导结束后才会恢复正常的回车发送行为
