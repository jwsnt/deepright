# 居中对话框请求气泡重试

## 功能说明

在居中对话框中，仅用户请求气泡新增一个 `15x15px` 的重试图标。

该图标位于请求气泡右下角外侧，并与复制图标保持水平右对齐。

## 交互说明

- 点击重试图标后，会读取当前请求气泡的文本内容
- 页面会自动重新发起一次 HTTP 请求
- 居中对话框会新增一条新的请求气泡，并按正常流程继续等待 SSE 响应
- 请求成功发出后，会在左侧虚拟文件系统的 Tips 位置提示 `重试成功`
- 仅当当前会话不存在活跃 SSE 连接或恢复轮询时，才允许通过重试图标重试；否则提示 `消息正在发送中`

## 适用范围

- 仅用户请求气泡显示重试图标
- assistant 响应气泡与错误气泡不显示重试图标

## 注意事项

- 如果当前会话正在响应中，点击重试会优先走现有停止/取消逻辑
- 如果当前请求气泡没有可用文本内容，则不会执行重试
