# Site 迭代手册（20260517-6）

## 本次更新

- 设置中的 `打开 Agent 目录` 与输入框区域的 `打开 Agent 目录` 统一改为中间会话区专属的居中确认浮层
- 目录确认浮层打开时会带背景模糊效果，点击 `取消` 或浮层外空白区域会立即关闭
- 设置中的 `打开 Agent 目录` 现在会先关闭设置浮层，再展示目录确认浮层，避免设置层残留遮挡
- 左侧虚拟文件系统中的 `打开目录` 仍保持直接打开当前目录，不经过设置浮层

## 当前行为

1. 点击设置中的 `打开 Agent 目录` 后，设置浮层会先收起，再在中间会话区弹出水平垂直居中的目录确认浮层
2. 点击输入框区域的 `打开 Agent 目录` 后，会复用同一套目录确认浮层，但不会额外打开或关闭设置浮层
3. 目录确认浮层展示期间带背景模糊效果，且只作用于中间会话区，不会遮挡左右 Sidebar 的可操作控件
4. 点击目录确认浮层中的 `取消`，或点击浮层外任意空白区域，都会立即关闭该确认浮层
5. 点击目录确认浮层中的 `打开` 后，会继续调用现有目录打开接口，设置入口不会再出现原设置浮层残留遮挡
6. 点击左侧虚拟文件系统中的 `打开目录` 时，会直接打开当前目录，不会弹出设置浮层
