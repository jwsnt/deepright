# 混音使用手册

在左侧虚拟文件系统点击“新增”，选择“混音”并填写名称。没有后缀时页面自动补 `.wav`；已有 `.wav` 后缀保持不变，填写其它后缀会提示错误。创建前会先以与录屏完全相同的方式检查 FFmpeg/FFprobe；缺失时会显示相同的安装提示和操作。检查通过后会检查当前 Agent 的 `audios/` 是否已有同名 WAV；同名时不会打开混音浮层，也不会创建空文件。

打开浮层后，可从任意位置把本地文件拖入投放区或时间轴，也可点击“添加音频文件”选择一个或多个文件；左侧虚拟文件系统中的文件同样可直接拖入。来源不受当前 VFS 路径限制：本地文件会自动上传副本到当前混音工程使用的临时目录后加入时间轴。文件是否可用由服务端 FFmpeg/FFprobe 判断：浏览器不能预听的格式只要服务端能解析，仍可参与最终导出；不能解析或不含音频流的文件会在保存时显示对应片段的错误。

时间轴中的每段音轨都可拖动改变开始位置、重复加入、重叠、选择或删除。右侧参数面板可设置：

- 源裁剪起点与终点；终点为 `0` 时使用完整源音频。调整裁剪起点会让时间轴位置同步变化，保持原始音频的时间对应关系：例如 `0–7s` 裁剪为 `3–4s` 后，时间轴位置为 `3s`；调整裁剪终点不移动片段。
- 播放速率 `0.25×–4×`、循环及循环总时长；循环只填充该片段总时长，不会产生无限时间线。
- 整体音量与左右声道独立音量；某一声道设置为 `0` 时，该侧没有声音。
- 淡入、淡出，以及可按顺序叠加的均衡器、压缩器、混响和延迟效果器。效果器标题旁的“常用效果”提供人声清晰、减少刺耳、会议讲解、自然空间感和回声效果；选择后会替换当前片段已有的全部效果器，之后手动编辑会取消预设选择。选择或切换效果器时，底部状态区会说明其作用、参数范围和建议起始值。

底部“常用导出”位于采样率前，可一键选择音乐发布（`44.1 kHz / 16-bit`）、视频配音（`48 kHz / 16-bit`）、后期编辑（`48 kHz / 24-bit`）或高质量音乐（`44.1 kHz / 24-bit`）；手动改动采样率或位深会取消预设。也可单独选择 `44.1/48 kHz` 与 `16/24-bit`，默认是 `44.1 kHz / 16-bit`。点击“试听”会按当前完整工程由服务端生成临时 WAV 并播放，按钮会变为“停止试听”；试听不会写入 `audios/` 或创建草稿。点击“保存 WAV”后才会将双声道 WAV 保存至当前 Agent 的 `audios/<名称>.wav`，成功后刷新 VFS 并尽力复制最终绝对路径到系统剪贴板。

关闭混音浮层会直接放弃未保存的工程，不保存草稿或临时文件。保存需要运行环境同时提供 `ffmpeg` 和 `ffprobe`；缺失依赖、参数无效、源文件无法解析、执行超时或同名冲突都会保留浮层并显示原因，既有 WAV 与源文件不会被覆盖或修改。
