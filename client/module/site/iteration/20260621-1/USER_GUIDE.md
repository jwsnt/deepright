# 20260621-1 用户手册

本次迭代为设置里的“多模态输出参数”补充了一条独立的新手引导，用来帮助用户理解多模态输出参数面板和它的 Agent 作用域。

- 当设置面板打开后，如果本地还没有“多模态输出参数引导已触发”的记录，首次悬停或点击任意可用的 `编辑多模态输出参数` 按钮时，会启动这条引导
- 第一步会高亮当前触发的多模态配置按钮，并提示：`编辑多模态输出参数。`
- 点击第一步的 `知道了` 后，会自动展开 `多模态输出参数` 浮层
- 第二步会高亮浮层中的参数区域，并提示：`参考不同模型服务商配置。`
- 点击第二步的 `知道了` 后，会切换到 `仅作用于当前 Agent` 说明区域
- 第三步会提示：`不同Agent可以配置独立的多模态输出参数。`
- 点击第三步的 `完成` 后，会同时关闭这条引导遮罩和多模态输出参数浮层，页面恢复正常交互
- 这条引导与首次使用引导、首次点击输入框引导、蜂群引导、插件引导、文档整理引导、知识库引导、客户化配置引导、客户化配置闪烁引导等其它引导相互独立
