# 输入路径与 URL 气泡使用手册

## 自动转换

居中请求、右侧备忘录、Chat 便签、消息编辑、页面标注和迷你应用修复原因输入框会自动识别文件路径与 URL，并将完整目标显示为可删除的摘要气泡。

- 支持 HTTP(S)、`www.`、`file:///`、绝对路径、`~/` 路径和已有白名单相对路径。
- 文件不存在时仍会生成气泡，方便继续引用或复制路径。
- 粘贴完整内容会立即转换。连续键入或输入法提交时不会转换；离开输入框后才会识别，因此不会打断路径或 URL 的连续输入。

## 气泡操作

点击气泡可打开操作菜单。文件会根据实际状态提供复制、预览、下载文件或打开目录；URL 提供复制、预览和打开。

气泡上显示的是短摘要，但发送、复制和打开操作始终使用完整原始路径或 URL。点击气泡右侧删除按钮可移除该引用。
