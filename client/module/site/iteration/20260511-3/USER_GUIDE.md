# 20260511-3 User Guide

## 目标

本次迭代将知识库标题右侧的小图标从“刷新知识库”调整为“展开/收起知识库全屏”。

## 交互

1. 默认状态下，右侧边栏仍展示第一栏、第二栏和最下方知识库栏。
2. 点击知识库标题右侧小图标后：
   - 右侧第一栏和第二栏会带动画收起
   - 最下方知识库栏会撑满整个右侧边栏
3. 再次点击同一图标后：
   - 上方两栏会带动画恢复
   - 知识库栏回到原本布局

## 说明

- 展开态与收起态通过同一个按钮切换
- 按钮会同步切换提示文案，便于识别当前动作
- 更完整说明请继续参考上级手册 `../../USER_GUIDE.md`
