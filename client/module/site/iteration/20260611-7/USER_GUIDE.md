# 20260611-7 用户手册

本次迭代为“居中对话输入框首次切换到不同模型”补充了一条独立的新手引导，用来提示用户当前会话上下文在切换模型后仍会继续生效。

- 只有当当前居中会话已经出现过一条正常结束的 assistant SSE 响应时，这条引导才有资格触发
- 在此之前，即使用户先切换过输入框左侧的小地球模型，也不会留下“已看过该引导”的记录
- 当浏览器本地还没有“切换模型引导”的记录时，第一次把当前会话从一个已选模型切到另一个不同模型后，页面会立即触发这条独立引导
- 引导会高亮居中输入框左侧的小地球模型按钮，并提示 `当前上下文切换到不同模型后依然生效。`
- 这条引导只有一个 `完成` 按钮；点击后关闭遮罩并恢复页面正常交互
- 引导展示期间，除该引导卡片外的其它区域都会被暗化且不可点击
- 这条引导与首次使用引导、首次点击输入框引导、蜂群引导、插件引导、会话完成提醒引导、插件启动成功引导等其它新手引导相互独立，可以兼容共存
