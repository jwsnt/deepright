# 人物视频对口型

在当前 Agent 工作区根层悬停 `videos` 目录时，可点击“人物视频对口型”小图标；每个视频文件右侧以及视频预览工具栏也提供相同入口。文件或预览入口会自动带入当前视频。所有入口先检查 FFmpeg/FFprobe，再仅以当前页面的 Agent ID 检查该 Agent 的 Wav2Lip；不使用会话 UUID，也不会将 VFS 工作目录传给检查接口。

任一依赖缺失时，点击“安装”会把服务端配置的安装请求发送到当前 Chat；其中 `$workspace` 已替换为当前 Agent 的实际工作目录。页面不会自行安装。依赖可用后会打开“人物视频对口型”浮层。

浮层最多暂存 5 条任务。每一条都必须选择一个视频和一个对应音频；从本机选择的文件会上传到当前 Agent 的 `tmp/`，视频只接受受控视频格式，音频只接受 WAV、MP3、M4A、AAC、FLAC 或 OGG。未选择音频时不能开始。关闭或 `Esc` 只关闭浮层；`Enter` 会创建当前已配对的任务。

任务列表显示视频、音频、开始时间、状态、进度和输出路径，支持状态筛选、每页 5 条、日志、取消、重新开始以及删除失败或已取消记录。已完成的 MP4 可预览或复制绝对路径；勾选多个完成任务后，“复制”会按行复制所有输出路径，“清空”只取消勾选。输出为 `videos/<视频名>_lip_sync.mp4`；同名时自动追加时间戳且不会覆盖。关闭由列表打开的视频预览后会返回同一浮层，并保留待加入项、筛选、分页、勾选和日志状态。

对于可识别的失败，浮层会直接显示中文原因。例如 PyTorch 模型缓存出现 `unexpected EOF` 时，会提示人脸检测模型缓存不完整或损坏，以及删除 `~/.cache/torch/hub/checkpoints/s3fd-619a316812.pth` 后重新执行；完整原始错误仍可在“日志”查看。
