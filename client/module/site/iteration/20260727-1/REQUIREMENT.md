### 需求介绍
+ 用户从居中聊天输入框、右侧备忘录输入框或页面备注输入框拖入、粘贴本地文件、图片、音频、视频或文件夹时，上传结果必须以规范化的绝对路径写入 `FILE` 气泡；不得把相对于当前页面、Integration 进程或 Agent 根目录的路径保存到草稿或消息。
+ 每个由上传产生的 `FILE` 气泡必须记录其上传时的 `agentId`，并在切换会话、切换 Agent、恢复草稿和排队发送时保持该归属。提交给 Agent 的文本格式仍为既有的 `[FILE:绝对路径]`，不得向模型文本添加前端归属标记。
+ 用户消息写入本地会话记录时，必须保存其上传附件绝对路径与归属 `agentId` 的映射；消息渲染出的文件气泡应恢复该归属。历史消息缺少此映射时，页面必须可通过附件绝对路径和已知 Agent 工作区确定归属；旧的白名单相对路径仍按当前会话 Agent 工作区解析，保持兼容。
+ 点击草稿或消息中的文件气泡执行预览、下载或打开目录时，必须使用附件归属 Agent 的工作区，而不是当前选中的 Agent。图片、PDF、音频和视频预览均适用；文件夹仅提供既有的下载或打开目录操作。
+ 媒体预览请求仍只能向 Integration 传递“归属 Agent 工作区内的相对路径”。前端须把已确认属于该工作区的绝对路径换算后再请求预览；不得构造 `file://` 链接，也不得让媒体接口接收任意绝对路径。
+ Agent A 和 Agent B 存在同名文件时，预览 A 上传并归属 A 的附件不得读取 B 的同名文件。Agent 已删除或附件不再存在时，保留原有的明确失败提示。
