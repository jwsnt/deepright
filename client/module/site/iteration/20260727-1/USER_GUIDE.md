# 跨 Agent 附件预览使用手册

在居中聊天、右侧备忘录或页面备注输入框粘贴、拖入本地文件后，文件仍保存到当时所选 Agent 的 `tmp/` 目录。输入框只显示文件名，但提交给 Agent 的内容保持为 `[FILE:附件绝对路径]`。

每个上传附件会记住所属 Agent。之后即使切换到另一个 Agent、切回聊天草稿或查看历史消息，点击附件气泡的预览、下载和打开目录仍会定位到原 Agent 的文件。图片、PDF、音频和视频均遵循这一规则；文件夹不提供媒体预览，但可继续下载或打开目录。

旧消息中的白名单相对路径（如 `tmp/example.mp4`）仍按当前会话 Agent 工作区处理。缺少归属记录的旧绝对路径会根据 Agent 工作区尝试恢复归属；已删除 Agent 或已不存在的文件会显示原有失败提示。

浏览器不会直接打开本机 `file://` 路径。音频和视频会先由页面按附件所属 Agent 换算为工作区相对路径，再由受限媒体预览接口读取，因此不同 Agent 的同名文件不会串读。
