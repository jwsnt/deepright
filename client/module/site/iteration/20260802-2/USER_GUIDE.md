# 迷你应用列表引导使用手册

首次进入当前 Agent 工作区的 `app/` 目录时，页面会检查迷你应用列表是否已有至少一组按现有规则配对的 HTML 和 Markdown 文件。条件满足且浏览器此前从未展示过该引导时，虚拟文件系统顶部的“迷你应用”图标会被高亮，并显示文案“点击查看所有迷你应用。”。

引导显示期间，左侧虚拟文件系统的其它功能和被高亮的图标都不可操作；仅“完成”按钮可用。点击“完成”会关闭遮罩，恢复全部功能，此后可点击图标打开迷你应用列表。

展示记录以当前浏览器全局保存。进入 `app/` 时没有有效配对不会显示或写入记录；如果用户仍停留在该目录、后续刷新才出现配对，也不会立即显示，下一次重新进入 `app/` 时才会再次检查。

本迭代沿用既有迷你应用浮层配对逻辑，不改变 HTML、Markdown 文件的展示、预览或拖放行为。
