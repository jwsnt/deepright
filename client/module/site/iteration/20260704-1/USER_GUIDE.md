# 20260704-1 用户手册

本次迭代为左侧虚拟文件系统里的“首次禁用技能目录”补充了一条独立的新手引导。

## 触发规则

- 如果浏览器本地还没有“禁用过技能目录”的记录，用户第一次真实禁用任意技能目录时，就会自动触发这条引导
- 这里的“真实禁用”指目录已经成功切换到禁用态，而不是仅仅点到了继承禁用态目录或无效入口
- 这条引导和首次使用、首次点击输入框、插件、备忘录、沙盒、全屏、知识库等其他新手引导相互独立，可以兼容共存
- 如果首次禁用技能目录时页面正处于其他新手引导中，这条引导会等待当前引导结束后再补充展示

## 引导效果

- 引导会高亮刚被禁用的整行技能目录，并暗化其他区域，期间其他位置都不可点击
- 引导文案为 `禁用技能为会话级别，再次点击可开启。`
- 引导只提供一个 `完成` 按钮；点击后会关闭遮罩并恢复页面正常交互

## 同步结果

- 总手册 `../../USER_GUIDE.md` 已同步补充这条技能目录禁用引导的触发方式、遮罩效果和收尾行为
- 本次手册更新只描述站点前端交互，不改变技能目录禁用本身按 `Agent + Chat` 会话生效的规则
