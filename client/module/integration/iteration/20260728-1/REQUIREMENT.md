### 需求介绍
+ 扩展受限 `POST /api/video_trim`，使 Site 可选地提交视频画面裁剪参数。未提供裁剪参数时必须保持原有按时间切分、另存 MP4 的行为。
+ 裁剪请求只能使用结构化且白名单化的选区：矩形、椭圆/圆形、或由有限个归一化坐标点构成的闭合钢笔多边形；所有坐标必须为有限值且在源画面比例范围内，矩形/椭圆必须有正面积，多边形必须至少三点、面积非零。仅允许 `black` 和 `white` 补边色，缺省为 `black`。未知字段、非法形状、非法颜色、超出范围、退化或过长的路径必须拒绝。
+ 服务端必须自行将已校验的结构化选区转换成固定 FFmpeg filter graph：先保留所选区域，按源画布尺寸等比缩放并居中，再使用选择的黑/白色填充比例差和椭圆/多边形外部区域。不得接收、拼接或执行客户端提供的 FFmpeg 命令、滤镜、文件路径或表达式。
+ 时间切分与画面裁剪在同一次受控转码中完成；裁剪只应用于请求的时间区间，若时间范围是完整视频则作用于整段。接口必须接受媒体真实的有限结束时长，即使其不在前端 `0.5` 秒定位刻度上。输出保持 H.264/AAC MP4，并在必要时仅向右侧或底部补齐至偶数像素，源文件始终不被改写。
+ 继续限定源文件、输出目录、临时文件、同名保护、工作区隔离和失败清理；为保持高分辨率源画布，视频切分/裁剪转码的受控超时为 `15` 分钟。所有成功输出仅落在当前 Agent 工作目录 `videos/`。
