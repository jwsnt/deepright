### 需求介绍

+ `GET /api/files` 返回的每一项文件和目录元数据必须包含 `modifiedAt`，值为该条目的最后修改时间 Unix 毫秒时间戳。
+ `modifiedAt` 必须来自服务端文件系统的最后修改时间；列表请求、按文件名前缀查询和既有技能目录状态字段均保持原有语义。
+ `GET /api/files` 的返回顺序必须与虚拟文件系统一致：目录按名称升序，随后文件按 `modifiedAt` 降序、同一时间按名称升序；浏览器仍可按同一规则防御性排序。
+ 文件不存在、无法读取目录或其他既有错误的 HTTP 状态与响应行为不得因增加该字段而改变。
+ 浏览器据此完成虚拟文件系统的显示排序、最近文件提示和媒体输出目录跳转；服务端不维护浏览器的高亮或已忽略状态。
