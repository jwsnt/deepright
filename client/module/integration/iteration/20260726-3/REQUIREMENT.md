### 需求介绍
+ 当页面存在右侧 URL `iframe` 预览时，任何居中且阻断页面交互的模态浮层显示期间，必须临时隐藏该 URL 预览。左侧虚拟文件系统的“新建文件或目录”和“上传文件或目录”浮层属于此范围。
+ 此规则仅适用于中心域或全局域的非被动（非 `data-overlay-passive`）浮层；Toast、非阻断交互的加载提示、左右侧栏锚定浮层、右侧栏内确认框、原生文件选择器及其它非居中、非阻断交互的元素均不得触发隐藏。
+ 临时隐藏仅改变 URL 预览的可见性和可交互性：不得关闭预览、清空 iframe 的 `src`、清除当前会话绑定的预览 URL，或改写右侧边栏的展开/收起状态与其浏览器持久化偏好。
+ 居中阻断式浮层全部关闭后，已存在的 URL `iframe` 必须恢复原来的右侧或页内展开显示状态，保持已加载页面、滚动位置及会话绑定不变；多个符合条件的浮层连续切换时，预览必须持续隐藏，不得在切换间隙闪现。
+ URL 预览处于页内展开态时，居中阻断式浮层同样必须覆盖此规则：展开预览的背景、关闭/还原控件和 iframe 均不可见、不可交互；浮层关闭后恢复原展开态。此期间按 `Esc` 必须优先遵循当前模态浮层的既有语义，不得还原或关闭 URL 预览。

### 编写代码
+ 在 `../../../site/index.html` 的既有 overlay 注册与状态刷新机制中统一计算“中心/全局且阻断交互”的活动浮层，并据此切换 URL 预览的临时挂起展示状态；不得在 VFS 新建、上传等单个入口重复实现。
+ URL 预览继续保持挂载，不新增接口、浏览器持久化字段、第三方依赖或服务端改动；挂起样式须同时覆盖右侧预览、页内展开背景及其悬浮控制按钮，并阻止焦点和指针进入预览。
+ 最小范围更新，不新增外部依赖。
