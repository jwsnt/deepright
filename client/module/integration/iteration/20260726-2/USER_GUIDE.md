# Integration 迭代手册（20260726-2）

## 新建文件后直接进入编辑

在 Site 左侧虚拟文件系统的“新建文件或目录”弹窗中，选择纯文本文件（例如 `txt`、`json`、`md`、`html`）并创建成功后，页面会使用本次输入名称和当前 VFS 目录组成的 workspace 内路径，自动打开新文件的预览浮层。

- 文本和 HTML 文件在内容加载完成后直接显示“编辑”页签与编辑器，不需要先查看预览或手动切换。
- 当前目录会照常刷新；自动打开不依赖刷新后的文件列表，因此不会误打开同名的其它文件。
- 选择“目录”、创建失败、网络请求异常或未选择 Agent 时不会打开预览浮层，原有错误提示和目录创建流程保持不变。
- 图片、音视频、PDF、压缩包、Office 文档和其它非纯文本文件即使创建成功，也不会自动打开预览浮层或进入编辑态；本次不新增格式转换、编辑器或服务端接口。
