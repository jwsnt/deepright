# 20260503-13 使用手册

## 目标

本次迭代补齐了右上角备忘录明细列表悬停浮层中的任务类型展示：

- 悬停查看备忘录明细时，浮动层新增 `类型` 一列
- 类型数据直接复用 `/api/cron/detail/metadata` 返回的 `type` 字段
- 保持现有备忘录列表、删除、查询与 Cron 数据结构不变

## 使用方式

1. 启动 `proxy` 服务并打开站点页面
2. 在右侧备忘录区域切换到备忘录列表视图
3. 将鼠标悬停在某条备忘录上
4. 浮动层会展示：
   - `Agent`
   - `类型`
   - `内容`

## 类型说明

- 默认备忘录任务类型为 `cron`
- 如果任务由其他模块写入，例如 Connect 相关能力，则会显示对应模块类型值

## 接口关系

本次展示层复用已有接口：

```text
POST /api/cron/detail/metadata?agentId=xxx
```

接口返回中的每条元数据都支持读取 `type` 字段；前端悬浮层会直接展示该值。
