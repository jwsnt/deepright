# Proxy 迭代手册（20260517-1）

## 本次更新

- `GET /api/plugins/meta` 改为每次请求实时读取
- 不再复用插件发现缓存
- 返回结果会同步读取当前最新插件列表与最新已保存 `meta`

## 接口行为

请求：

```text
GET /api/plugins/meta
```

说明：

- 只支持 `GET`
- 底层仍然合并 `connect list-plugins` 与 `connect meta-list`
- 但本接口本身不再复用 `connect-cache` 的插件发现缓存
- 每次请求都会重新扫描当前可执行插件
- 每次请求都会重新读取当前数据库中的插件配置 `meta`
- 如果插件未配置，则 `meta` 仍返回空对象 `{}`

## 适用场景

- 新增、删除、替换插件二进制后，希望下一次接口调用立即看到最新插件列表
- 更新插件配置后，希望前端或其他调用方下一次请求立即看到最新已填参数
- 避免左上角插件入口继续拿到旧插件名称、旧参数定义或旧默认值

## 同步结果

- `proxy` 主手册已同步补充该接口“每次实时读取”的规则
- `integration` 对外同路径接口已同步改成相同行为
- `site` 已配合改为页面可见时每 `30` 秒重新读取一次该接口
