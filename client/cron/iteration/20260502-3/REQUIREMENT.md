### 需求介绍
+ 为cron模块构建CLI（命令行）工具来创建任务元数据的功能，并编写详细的--help
+ 通过CLI创建任务元数据需要提供以下数据：
    + 使用周期：int，0=仅一次、1=、工作日、2=自然日、3=每小时、4=每15分钟、5=每30分钟
    + 原始时间（首次开始时间）：string，yyyy-MM-dd hh:mm格式表示的时间
    + 绑定的AgentId：string
    + 会话ID（CHAT_ID）：string
    + 选择的模型：string
    + 是否深度思考：boolean
    + Cron表达式：string
    + 任务的内容：string
+ 通过CLI（命令行）创建的任务元数据执行逻辑等同cron模块其他创建方式，模型Token由调用时动态传递：
    + 创建方式：../../REQUIREMENT.md
+ 创建时需要检查数据，指定Agent必须存在，指定模型是否在Proxy已注册（填写Token），及其他参数必须符合格式和要求
+ 案例：
```
./integration cron create --content "每15分钟检查一次上游接口健康" --model "OpenAI" --thinking true --rawTime "2026-05-03 10:00" --cycle 4 --chatId "chat-001"
```
