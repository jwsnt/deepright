### 需求介绍

- `config/config.json` 的 `sam2` 配置必须包含正整数小时 `check` 和非空 `install` 安装提示。安装提示要求将 SAM2 代码与配置安装到当前 Agent `$workspace/sam2`，并预置最基础的 `sam2_hiera_tiny.pt`；官方源不可用时使用明确的备用源。服务端按当前 Agent 展开唯一允许的 `$workspace` 占位符。
- 新增受控视频物体提取接口与持久化队列。任务仅接受当前 Agent 工作区内的视频、首帧提示和四种受控模型 ID；模型 ID 分别对应 `sam2_hiera_tiny.pt`、`sam2_hiera_small.pt`、`sam2_hiera_base_plus.pt`、`sam2_hiera_large.pt`，默认 tiny。任务状态、列表、取消、重新开始、删除及日志语义与视频提取人物一致，任务列表和日志均返回/记录选定模型。
- 服务端必须校验视频流、Agent 和路径边界，校验点坐标、框坐标和掩码文件边界；掩码图必须与首帧尺寸一致。RGB 掩码按受控背景色（绿、白、黑）反转为前景，RGBA 透明擦除模式以透明区域为前景。点、框和掩码均可不提供；完全未标注时自动识别首帧最显著主体作为视频跟踪目标。
- 执行时以首帧提示初始化 SAM2 视频预测器，并将对象掩码传播至后续帧；生成带透明通道的 MOV 及黑底 H.264 MP4 预览。执行日志记录模型名称、权重路径、提示类型、输入和输出路径、设备回退及模型下载过程。
- 模型缺失时，运行时按所选模型下载到 `$workspace/sam2/checkpoints/`；必须先使用官方源，失败后重新从备用源下载，不混用断点数据。下载、校验和失败原因进入任务日志。模型、运行时或编码失败不得覆盖已有输出，取消和失败必须清理本任务临时文件。
