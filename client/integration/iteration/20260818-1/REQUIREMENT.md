### 需求介绍

- 提供受控的 Agent 间媒体文件复制接口，供居中对话框和备忘录中的媒体预览确认流程调用。请求必须包含源 Agent、目标 Agent 与源文件在源工作区内的相对路径；不得接受或信任客户端提供的源、目标绝对路径。
- 服务端必须分别校验源、目标 Agent 标识和工作区存在性，解析并校验源文件真实路径位于源 Agent 工作区内；仅允许常规图片、音频、视频文件，拒绝目录、工作区外路径、符号链接逃逸、空路径与不支持类型。
- 复制目标位于目标 Agent 工作区中与源文件相同的相对目录。目标目录不存在时创建；目标文件不存在时保留原文件名，存在时仅在扩展名前增加可排序的时间戳后缀并重试，绝不覆盖既有文件。
- 操作语义必须是复制而非移动：源文件及其历史路径不得删除或改名。复制必须通过受控文件 API 完成，不得调用 shell 或拼接 `cp` 命令；复制失败必须清理本次未完成的目标临时文件，不得留下半成品或覆盖已有文件。
- 成功响应必须仅返回已验证的目标 Agent、目标工作区相对路径和目标绝对路径，供前端重绑文件气泡及重新打开预览。错误响应必须说明可安全展示的失败原因，且不得泄露工作区外路径。
- 接口必须覆盖：相同源/目标 Agent、无效 Agent、源文件不存在、源路径越界、媒体类型不支持、目标目录自动创建、无冲突复制、同名冲突时间戳改名、复制失败清理与源文件仍存在等验收行为。
