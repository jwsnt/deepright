# 跨 Agent 媒体文件复制接口

`POST /api/media/copy` 将一个图片、音频或视频文件复制到另一 Agent 的工作区。JSON 请求包含 `sourceAgentId`、`targetAgentId` 与源工作区相对路径 `path`；源和目标 Agent 必须不同。服务端不接受客户端提供的绝对文件路径。

服务端验证两个 Agent、源文件和工作区边界，拒绝目录、路径越界、工作区外符号链接和不支持的文件类型。目标保留源文件的工作区相对目录，自动创建缺失目录；目标不存在时保留原名，冲突时在扩展名前追加时间戳，绝不覆盖原文件。

接口只复制，不移动或删除源文件。响应返回目标 `agentId`、工作区相对 `path` 和目标绝对 `savedAs`；复制失败会删除本次未完成的目标文件。
