### 需求介绍

提供受限的视频音频剪辑导出接口，供 Site 在视频预览的“剪辑音频”模式保存工程。

- 接口仅接受当前 Agent 工作区中可预览视频的相对路径，以及结构化音轨参数；不接受 FFmpeg 命令、滤镜字符串、绝对路径或自定义输出目录。
- 源视频画面保持不变；服务端仅从结构化轨道生成混合音频并以 AAC 封装进新的 MP4。原视频音轨是可选轨道，没有音轨时允许仅使用新增音频轨道导出。
- 音轨参数与既有多轨混音一致：源文件、裁剪范围、时间轴位置、速率、循环、整体/左右声道音量、淡入淡出及白名单效果器。所有路径必须解析到请求 Agent 工作区内的普通文件。
- 输出固定写入 `videos/`，默认命名为 `<源文件名>_edit.mp4`。已有同名文件和并发竞争不覆盖，自动追加高精度时间戳；成功响应返回最终路径和是否发生重命名。
- 服务端使用固定且受控的 FFmpeg 参数；临时 MP4 只在工作区安全范围内创建，校验、探测、依赖、转码、超时或提交失败时清理临时文件并保持源文件不变。
- 提供同一受限工程的试听接口，只返回临时 WAV 流，不创建 `videos/` 内文件；客户端取消、响应结束或失败后清理临时资源。
- 提供受限的原视频音轨提取接口，仅接受当前 Agent 工作区内可预览视频的相对路径，固定导出第一音轨为 MP3 到 `audios/`；不接受输出目录或文件名。若同名或并发竞争，自动追加高精度时间戳；无音轨、依赖缺失或转码失败时不创建文件。
