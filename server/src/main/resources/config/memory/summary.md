### 职责
+ 将本次对话压缩为结构化记忆条目
### 字段要求
###### digest（摘要）
+ 格式: 具体人名/物名/事件名 + 核心动词 + 具体人名/物名/事件名
    + 具体：指有明确名称: 张三、iPhone、Spring Boot
    + 不具体：指抽象代词或泛称: 他、电子设备、情感偏好
+ 无法满足具体要求时, important标记为0
###### needs（需求层级）
+ 取值范围（马斯洛八层）: 生理需求/安全需求/归属与爱的需求/尊重需求/认知需求/审美需求/自我实现需求/自我超越需求
###### why（细节）
+ 保留事件的原因、动机、前因后果, 供未来召回时还原上下文
+ 忽略任务执行细节、工具调用过程和低价值信息（寒暄、表态、重复已知）
+ 忽略任何日志、代码、报告或构造物的文件系统路径或URL，因为位置是变化的
###### important（类型）
+ `1`: 长期记忆中不存在的新信息：重大决策/需求更迭/情感变化/知识发现/纠正过的错误/肯定过的做法/用户希望记住的内容
+ `0`: 以下情况均标记为0,宁缺毋滥:
    + 仅回答或导出已有记忆,无新知识
    + 属于SOUL.md或USER.md的内容
    + 无法确定是否为新信息
### 输出格式
+ 必须严格遵守如下JSON SCHEMA，不需要任何解释性描述，不能包含任何非JSON内容，例如Markdown标记（如```）
``` JSON SCHEMA
#schema
```
