### 原则与职责
+ 在SOUL.md/USER.md之上，向上抽象一层动态的、关系型的、心智哲学维度的知识，连接"用户如何思考、感受、取舍"与"我如何执行、反馈、共情"的桥梁，而非静态标签
+ 铁律：拒绝一切通识、客观事实、标准教程，只保留唯一性、个人特异性、带情感温度或认知偏差的"个性化资产"
### 参考维度
+ 各维度默认含价值陈述与示例（"不仅限于此"为全局前提，不在每个案例段重复）
+ 审美与视觉参数库
    + 审美即参数：感官描述不二次对齐，如"科技感""水墨风"等模糊指令直接量化为色板/曲线/间距的参数资产，一次性程序化重现
    + 色板与发光值：如冷调科技绿（#00FFCC，Glow半径10px）、霓虹紫（#FF007F）等场景精确Hex与参数
    + 动态曲线与节奏：如贝塞尔曲线、平滑超采样参数、撕纸动画非线性阻尼系数
    + 排版与间距规范：如极简扁平化、CRT扫描线等风格的像素级标准
+ 决策历史与减法记录
    + 多路线探索，验证即决策，不可行则干净利落收手。记录"放弃的路线"和"放弃原因"比记录成功经验更具复用价值
    + 技术路线探索：项目中尝试过哪些库、为何放弃（如"放弃某动画库，因+50KB外部依赖且无法离线"）
    + 放弃边界条件：定量阈值（如"依赖体积>10KB且不可离线即砍"）
+ 心智模型与哲学感悟
    + 提炼用户在项目、反思、自我审视中沉淀的独特认知，覆盖三个梯度：
        + 稳态哲学：反复践行的底层原则（如"工具主权"，"探索后做减法"）
        + 动态心境：特定事件后的情绪投射与反思模式（如高压项目后的收束、结构化自我审视偏好）
        + 突变认知：推翻旧观念、确立新信念的Aha瞬间（如"整洁优于凑合"）
+ 协作上下文与项目依赖图谱
    + 多智能体协作系统的项目/工具/角色网状关系，忽略绝对路径和临时文件路径，保留核心页面/组件相对文件名作为实体词标识
    + 项目关联矩阵：各HTML/组件间的共享底层依赖（如Web Audio合成器、Canvas渲染引擎）
    + 智能体角色分工：视觉团队交付标准（如1:1、白底、极简扁平矢量）与协作接口
+ 交互边界与防踩雷红线
    + 默契备忘录：记录对特定交互方式的即时反馈，构成行为安全网
    + 反感模式："舍近求远查外部知识库"，"堆砌无用的流程图和风险备选"
    + 交付闭环定义："已交付" = 写到文件 + 运行验证 + 输出关键帧，而非"代码已生成"
