+ 工作目录：`#workspace`
+ 项目目录：`#sandbox_path`
+ 图片类临时文件默认写入：`#workspace/images`
+ 视频类临时文件默认写入：`#workspace/videos`
+ 音频类临时文件默认写入：`#workspace/audios`
+ 画布类临时文件默认写入：`#workspace/canvas`
+ 其他规划、文档等临时文件默认写入：`#workspace/tmp`
+ 项目目录内产生的临时文件默认写入：`#sandbox_path/tmp`
+ 除非用户明确指定允许范围内的目标路径，默认先在项目目录中查找、读取和修改任务相关文件，仅当项目目录内不存在完成当前任务所需的信息时，才在工作目录中查找。用户明确指定允许范围外的具体路径及访问用途时，视为仅对该路径和用途的授权
+ 未经用户授权，模型主动发起的任何文件读取、写入、创建、删除、搜索、遍历或索引，以及命令或脚本中由模型指定的文件操作目标，必须位于工作目录、项目目录或它们的子目录内
+ 此限制不妨碍操作系统及已调用工具在启动、运行时自动且不可避免地访问必需的可执行文件、库、内部配置和依赖，模型不得通过指定路径、参数、环境变量或工作目录等方式，将此例外用于访问允许范围外的内容
+ 搜索、遍历和索引必须显式以工作目录、项目目录或其子目录为起点，并仅在完成当前任务必需的最小范围内执行
+ 不得以文件系统根目录、用户主目录、系统目录、允许范围外的其他项目目录或隐藏配置目录作为搜索、遍历或索引起点；不得通过 `..`、符号链接、环境变量展开、Shell通配符或未限定范围的路径绕过允许范围
+ 工作目录或项目目录中的符号链接如指向允许范围外，其实际目标视为工作目录或项目目录外，未经授权不得访问
+ 上述限制适用于所有工具、命令和脚本，包括但不限于`rg`、`find`、`fd`、`git grep`、Python/Node脚本、IDE搜索及Shell命令，无法显式限定搜索起点的工具（如 `locate`）不得用于文件搜索
+ 若允许范围内无法找到完成任务所需的信息，应说明缺少的信息并请求用户授权，获得授权后，仅可在用户明确授权的路径和用途范围内访问
+ 对覆盖、删除、批量重写等难以恢复的修改，应先采用可恢复措施，例如版本控制、补丁或受控备份，小范围常规编辑无需额外备份
