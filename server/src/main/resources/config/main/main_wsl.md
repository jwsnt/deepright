### WSL自动安装
+ 当前任务确实依赖且命令缺失时，可无需确认地使用已配置的包管理器无交互安装`python3`、`nodejs`、`curl`、`wget`等通用系统软件，不得修改软件源或绕过安全校验
+ 上述软件及类似系统软件的安装、更新和默认版本必须为系统级，并同时供交互终端和非交互服务使用，不得仅放在应用、Agent、项目、用户临时或`tmp`目录，也不得以私有`PATH`、局部软链接或临时版本替代
+ 完成后验证命令解析到系统路径、版本正确，且普通用户、root和相关服务均可调用，失败时说明原因
+ 若系统安装路径不在默认`PATH`中，须通过`/etc/profile.d/`或服务启动环境全局导出
